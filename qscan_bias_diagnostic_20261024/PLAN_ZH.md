# 无真值偏差诊断：能否提前识别 QScan 的退化（冻结方案）

登记：2026-10-24。开发探针、输入核验和一次冒烟测试之后，任何确认数据被诊断之前。上一轮：`qscan_bias_variance_20261024`。

## 问题

只用观测道集和公开配置（不读真值），能否在运行前判断 QScan 是否会比 FullCalRefit（所用 Q）更差？

上一轮的约束：
- 必须同时区分 F1/Moderate 的退化（期望 ΔMSE +37.6%）与 F2/Moderate 的改善（−8.0%）；
- QScan 的偏差来自数据拟合准则本身，所以只看数据拟合的量预计会失败。

## 候选（全部只用观测与公开配置）

- **B0（主候选）：所用 Q 正确世界的参数自助。**
  - 以 FullCalRefit 输出为该世界的真值，数据 = G(所用 Q)·输出 + 估计噪声。
  - 噪声为 AR(1)：窗口从 0.02 s 到第一个公开宏观界面时间前 1.5 个主周期，在其中估计系数 φ̂ 与逐道 MAD σ̂。
  - K=6 次抽样，每次按原方法重估 σ，分别运行 c=1 与 c=ĉ（ĉ 为观测上 QScan 的选择）。
  - 预测：ΔMSE*>0 判为 QScan 更差。分解中的 Δ偏差²* 与 Δ方差* 一并记录。
- **V（只看方差）**：B0 世界的 Δ方差*；预计总为负，即总判 QScan 更好。
- **G（第三轮门限）**：[J(1.031)−J(ĉ)]/J(1.031) > 0.01 判 QScan 更好，否则判为“不更好”。
- **CV（留出预测）**：每五个 20 ms 块留出一个（20% 样本），在其余样本上按 FullCalRefit 规则拟合，预测留出数据；ΔCV>0 判 QScan 更差。
- **RS（残差结构）**：残差能量高于噪声底的部分，ΔRS>0 判 QScan 更差；另报告残差滞后一阶相关超出噪声模型的部分（RC），只作描述。

开发阶段曾试过“QScan 的 Q 正确”的镜像世界 B1。它在四个开发场景都强烈为负，没有符号信息，为节省计算不再运行。

## 数据（清单见 `predictions/manifest.csv`，68 个道集）

- **开发（F1/F2，已见）**：
  - Q0：F1/F2 × Moderate/Strong，各取上一轮第 1–3 个重复实现，共 12 个；
  - 高信噪比：20/26 dB 探针各取第 1–2 个实现，共 8 个；
  - Q 误差：归档观测上 Q 误差 ±30%，共 8 个。
- **确认（我未用过）**：
  - 两套不同的地质，均为 Kennett 细层正演：qscan_criterion 的 F3/F4（QC）与 round3 的 F3/F4（R3）；
  - Q0：每个场景取归档观测 1 个 + 新噪声 2 个，共 24 个；
  - Q 误差：归档观测上 ±30%，共 16 个。
- **已知信息声明**：我看过 qscan_criterion 报告中 QC-F3/F4 在 Q0 的汇总比值，没有看过 R3-F3/F4 的逐场景结果。
- 全部输入是 Git 对象的逐字节本地副本（`cache/SNAPSHOT.json`）。QC 的纯净道集由 Kennett 正演重算，已与归档观测逐位核对。

## 真值与评分（封存预测之后才计算）

- Q0 道集的真值标签取该场景的**期望** ΔMSE 符号：
  - 开发场景来自上一轮 100/40 个实现；
  - 确认场景来自 12 个新实现（含已诊断的第 1–2 个）。
  - |期望 ΔMSE| / 期望 MSE_base ≥ 5% 的场景称为“明确”场景。
- Q 误差道集只有单个归档实现，用实际 ΔMSE 的符号。

## 预先判定

- **E1（开发，必要条件）**：B0 在 F1/Moderate 的 3 个道集都判“更差”，在 F2/Moderate 的 3 个道集都判“更好”。
- **E2（确认，Q0）**：在明确的确认场景的道集上，B0 的符号正确率 ≥ 0.75，且同时高于 G 与 V。若没有明确场景，记为“不可检验”。
- **E3（Q 误差，描述）**：B0 假设所用 Q 正确，预计在 Q 误差 −30% 时会把有益的 QScan 判为更差。报告 B0 的误报率，及 G 的表现。
- **E4（描述）**：Q0 时 CV、RS、G、V 的符号正确率。预期 CV 与 RS 在 F1 和 F2 上都倾向 QScan，无法区分。
- **幅度（描述）**：各 Q0 场景中 B0 的 ΔMSE*（按 ‖x̂‖² 归一）与期望 ΔMSE（按 ‖x⋆‖² 归一）的 Spearman 相关。

## 结论规则

- E1 与 E2 都通过：B0 可作为“所用 Q 可信时，QScan 的改变是否值得”的无真值检查；下一步再与 Q 可靠性的独立证据结合。
- E1 通过、E2 不通过：B0 只停留在开发数据上有效，分析失败原因。
- E1 不通过：放弃 B0。

## 不做

不改 FullCalRefit、QScan；看到确认数据后不再调 K、噪声窗口、留出方式或阈值；预测不读真值；F1/F2 只作开发；不把本轮称为最终未见测试。
