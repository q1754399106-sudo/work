# 统一保幅补偿方法

用户入口为 `core_p1/compensate_seismic.m`。它对全部模型执行同一套 PrunedFullCalRefit 规则，不接收模型名称、场景标签或真实反射信息。Offset/Section仅表示已知采集方式，用于偏移距道集的相干干扰处理。

方法复用射线积分衰减与独立校准模块，把主要数值路线改为非平稳反射系数反演和再合成。它不是原始FixedSplit两次岭回归串联的参数修补；原方法和现版均作为对照保留。

1. 用独立校准道集和公开层位几何估计Q、主频及必要的小幅速度修正。完整校准估计在所有采集域统一使用。这里的Q来自校准观测，算法不读取合成真实Q。
2. 构建全时间网格的零相位Ricker字典W，前向矩阵为 G(Q,v,h)W。列归一化后求解 `0.5*||B*x-D||² + lambda*||x||₁`，其中 `lambda=0.5*sigma*sqrt(2*log(nt))`。sigma由观测噪声窗MAD估计。事件数、位置和幅度都不预先给定。
3. 在观测选出的活动位置上重估振幅，使用条件数保护的微小岭项，允许残差中有足够证据的候选补入。稀疏阶段记录相对KKT违约量，停止阈值为lambda的2%；振幅重估检查正规方程残差。
4. 将相距不超过校准主频半周期的活动系数连接为组。逐一比较删除组并重拟合后的残差增量；若增量不足 `sigma²*(组内系数数+2)*log(nt)`，删除证据最弱的组，再继续检查。该规则作用于全时窗，不使用已知尖灭位置。它是固定复杂度准则，不是已验证的显著性检验。
5. 输出 `S=W*r`，保留所选支持集、反射系数、校准诊断、迭代和残差，便于复查。输出道集不作逐道归一化或人工增益修饰。

本研究适用范围为当前四层建模、11道输入、独立且几何已知的校准资料，以及零相位Ricker子波近似。公开配置包含采样、偏移距、速度、层厚和名义频率；未知层位、任意子波及实测资料仍需额外验证。反射组筛选可能删除证据不足的真实弱反射，因而弱反射和AVO指标与整体误差同时验收。
