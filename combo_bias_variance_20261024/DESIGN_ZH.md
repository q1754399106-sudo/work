# 完整组合的偏差—方差实验（设计稿，未冻结）

起草：2026-10-24。状态：**设计稿**。阶段 0（复现与计时）通过后，按实测耗时确定 R，再改名为 `PLAN_ZH.md` 冻结并记录哈希，然后运行阶段 1。

## 问题

上一轮重复噪声实验（`qscan_bias_variance_20261024`）只比较了 FullCalRefit 与 QScanRefit：QScan 在 F1/F2 上都是“偏差增、方差减”。当前推荐的方法是 **QScan＋相干标准版**，而相干收缩本身就会降方差。本轮回答：

1. **相干收缩之后，QScan 还在解决什么问题？** 它的方差收益是否被相干收缩替代，偏差代价是否保留？
2. Q 可信（Q0）时，组合相对相干标准版的精度代价落在哪里：强反射的振幅，还是晚时窗的噪声？
3. Q 低估（过补偿）时，组合的收益是否来自偏差下降？

已见的单次结果（第三轮，归档噪声，F1/F2 为开发数据）已经提示了替代关系：

| 场景（Q0） | FullCalRefit | 标准版 | QScanRefit | QScan＋标准版 |
|---|---:|---:|---:|---:|
| F1/Moderate | 0.397 | 0.392 | 0.464 | 0.477 |
| F2/Moderate | 0.385 | **0.276** | 0.369 | 0.330 |
| F1/Strong | 0.541 | 0.495 | 0.548 | 0.545 |
| F2/Strong | 0.666 | 0.395 | 0.530 | 0.394 |

F2/Moderate 中，没有相干收缩时 QScan 降低误差 4%；有相干收缩时，QScan 反而让误差升高 20%。在 Q −30% 下，组合在四个场景里都把误差降到标准版的 0.47–0.65 倍。这些都是单个噪声实现，本轮用重复噪声来确认并分解。

## 估计量（2×2 析因，配对）

每个噪声实现、同一观测与同一 σ 上同时计算以下四个估计量：

| | 名义 Q（所用 Q） | QScan 选出的 Q×ĉ |
|---|---|---|
| 无相干收缩 | **A** FullCalRefit | **C** QScanRefit |
| 相干标准版（λ 0.5–16，邻道半宽 2，倾角 0.25 周期） | **B** 标准版 | **D** QScan＋标准版 |

实现与 `round3_20261024/run_combo.m` 逐句一致：refit_state → coherence_scores → apply_gain。SoftGroupRefit 与 QScan＋Soft 的计算不增加成本，作为附带输出，只描述。

| 场景 | 所用 Q | SNR | R | 种子 |

## 指标

**分解**：MSE = 偏差² + 方差，口径与上一轮相同：99 道全时段，有限 R 无偏修正，两者之和严格等于经验 MSE，结果除以 ‖x⋆‖²。

**析因量**：
- QScan 在没有相干收缩时的效应：Δ_raw = C − A。
- QScan 在相干收缩之后的效应：Δ_coh = D − B。
- 交互作用：I = Δ_coh − Δ_raw。

以上对 MSE、偏差²、方差分别计算。I>0 表示相干收缩削弱了 QScan 的收益（替代关系），I<0 表示两者互补。

**区域**（只由真值定义，用于评分）。记 L = √movmean(x⋆², 21 个样点)：
- 强反射：L ≥ 0.25·max L；
- 弱信号：0.02·max L ≤ L < 0.25·max L；
- 安静区：L < 0.02·max L，即第三轮的 leak 口径。

**时窗**：早 0.30–0.80 s，中 0.80–1.20 s，晚 1.20–1.80 s。每个区域、每个时窗报告偏差²、方差及其析因量，除以全道 ‖x⋆‖²，因此各区域可以相加。

**振幅**：强反射区内的平均输出增益 g = ⟨x̄, x⋆⟩/⟨x⋆, x⋆⟩，以及逐实现增益的均值与标准差。g>1 为过补偿，g<1 为欠补偿或被收缩压低。

**不确定度**：把 R 个实现分成 5 批，各批独立做分解，用批间离散作标准误。ΔMSE 另报逐实现配对差的均值与标准误。

## 预先判定（冻结时连同阈值一起固定）

Q0 主场景为 S1–S4。

- **J1 方差收益是否被替代**：ρ_V = ΔVar_coh / ΔVar_raw。在 ≥3/4 个 Q0 主场景中 ρ_V < 0.5，判为“相干收缩替代了 QScan 的方差收益”；在 ≥3/4 个中 ρ_V ≥ 0.5，判为“互补”；其余判为“混合”。
- **J2 偏差代价是否保留**：ρ_B = ΔBias²_coh / ΔBias²_raw。在 ≥3/4 个 Q0 主场景中 ρ_B ≥ 0.5，判为“偏差代价保留”。
- **J3 Q 低估时的机制**：在 S5–S8 中 ΔMSE_coh < 0 且 ΔBias²_coh < 0 的场景 ≥3/4，判为“组合在 Q 低估时通过降偏差起作用”。
- **J4 高信噪比**：S9、S10 的 ΔMSE_coh 都 > 0，判为“Q 可信且噪声低时，组合中的 QScan 纯属代价”。
- **J5 Q0 代价的位置**：对 S1–S4 合计的 ΔMSE_coh，报告强反射、弱信号、安静区以及三个时窗各自的份额。强反射份额 > 50% 且 g_D < g_B 时，判为“代价主要是强反射振幅被欠补偿”。

## 结果对应的下一步

| 判定组合 | 含义 | 下一步 |
|---|---|---|
| J1 替代、J2 保留、J3 成立 | 相干收缩之后，QScan 只在 Q 有误时有用；Q0 时只剩偏差代价 | 是否启用 QScan 应由“Q 是否有误”决定，而不是由方差大小决定。B0 一类诊断应把标签改为 D 与 B 的比较。先做阶段 2，判断选择器还有没有改进空间 |
| J1 互补 | QScan 在相干收缩之后仍降方差 | Q0 代价由偏差与方差两边共同决定，选择机制是主要杠杆，直接进入阶段 2 |
| J3 不成立 | 组合在 Q 低估时的收益另有来源 | 先查明来源，再谈稳健性论证 |
| J5 强反射欠补偿 | 保幅受损 | 研究让强反射保留名义补偿的设计（例如按事件可信度决定 ĉ 的作用范围），用弱反射与断层终止处的指标对照 |

## 阶段 2（同一框架，单独登记）：选 Q 目标与最终输出的差距

预设规则：若最优固定因子相对 D 的平均 MSE 下降 ≥5%，再研究新的选择机制；否则选择器改进空间有限，不再投入。阶段 2 的成本约为阶段 1 的 4 倍/实现，在阶段 1 结果出来后再定 R。
