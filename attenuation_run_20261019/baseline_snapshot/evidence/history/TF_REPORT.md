# 同一道内按时间和频段调整补偿 / Time-frequency adaptive compensation

## 用简单的话说

程序已支持同一条道不同时间段、不同频带采用不同补偿约束。相邻时间窗平滑重叠；用噪声估计和完整吸收算子构造的初始解判断哪些区域可信，再自动选择整体强度。深部、高频不会被预设为必须更强补偿。

**当前时频分步版本没有提高全网格平均波形精度；应保留为研究选项，继续以原整道参数版本作对照。**

这里调整的是反演中的惩罚强度，不是把时间—频率图直接乘一个增益。浅深目前由理想 NMO 零偏移时间代表，尚未做实际深度转换。

同一套原始 11 道观测，整道参数法平均误差 **0.4965**，时频分步法 **0.5007**，相对升高 **0.8%**。这组道集仅是一组实现，不能代替多种子检验。

一步法在 Q 不准时同样会明显退化。整道参数一步法在全网格的平均误差，Q 正确时约 0.5382，Q 低估 20% 时约 1.1223，Q 高估 20% 时约 0.6511。整道参数分步对应约 0.5345、1.0873、0.6507；时频分步约 0.5361、1.0987、0.6512。因此这组试验没有显示“分步或时频权重能够消除 Q 误差”。

原固定参数分步在 Q 低估的汇总中反而较保守，平均误差约 0.8169，但在正确 Q 时约 0.6538，弱于自动方法。单一条件下更保守的结果不能据此认定整体更优。已知真实噪声的一步参照仍受到 Q 模型错误影响：知道噪声强度不等于知道正确吸收算子。

从方程看 d=Gtrue s+n，而反演使用 Gassumed；残差同时包含随机噪声和 (Gtrue−Gassumed)s。当前残差目标主要依据噪声范数，因此不能完整识别这部分模型误差。后续若加入 Q 不确定性，应明确建模或检验它，而不是仅继续减小正则化参数。本轮尚未实现 Q 联合估计、逐层随机 Q 误差或模型误差协方差。

## 为什么这一版没有稳定改善

局部权重来自已经受正则化影响的 pilot。弱深部信号在 pilot 中可能被低估，继而在新惩罚中受到更大约束；同时，全局 λ 会随整个 R 重新选择，局部相对权重变小并不保证实际惩罚也比旧方法小。

为检查这个机制，固定使用原 11 道数据，在三个真实事件模板方向计算二次惩罚比值，并与恢复振幅一起记录。真值模板只用于本次事后诊断，不反馈给权重或 λ：

例如，零炮检距第三事件的模板方向惩罚约为原方法的 1.32 倍，恢复振幅比约由 0.439 降为 0.425；而 750 m 第三事件振幅比由 0.567 升为 0.572。前者与过度抑制弱深部信号的解释一致，但这些冻结模板诊断不构成整个自适应方法的因果证明。

当前证据支持进一步研究更可靠的局部信号强度估计或结构先验，而不是继续按这批真值调整频带、窗口来宣称改善。

## 公式、设计参数及验证含义

详细推导、所有自选参数、接口与来源见 [方法说明 / Method](TF_METHOD_ZH_EN.md)。核心为

$$\min_s\|\widetilde Gs-\widetilde d\|_2^2+\lambda s^TRs,$$

$$R=\beta I+(1-\beta)\sum_{j,b}w_{jb}W_jP_bW_j.$$

时间窗 0.24 s，间距 0.12 s；频带 0–30、30–60、60–90、90–125、125–250 Hz；相对权重限制 0.25–4，β=0.1。全部为计算前固定的自选参数，不是从真值拟合的最佳设置。TFDirect 与 TFSplit 使用同一个 R，因此一步反演没有被故意削弱。

MATLAB 数学核验通过：统一权重退回原问题的解误差 **9.04e-15**，时频能量恒等式误差 **1.84e-16**，整体放大 7 倍的比例误差 **7.53e-14**，一般正则化正规方程误差 **8.35e-16**，精确白化下与一步法的等价误差 **7.29e-15**。零输入、行列向量、正定性及不读取合成真值均通过。

独立 NumPy 使用同一 MATLAB 含噪观测和完整吸收算子，以显式复 Fourier 行构造惩罚矩阵并重新求解；最大矩阵差异 **2.48e-14**，最大恢复解差异 **2.53e-14**。这验证实现代数一致性，不证明方法更优。旧 uniform 默认输出与上一轮 11 道输出逐值一致。

frozen_error_budget.csv 在指定三个例子中记录固定已选权重/λ 后的偏差、模型失配和噪声分量；这是逐实现代数恒等式，不是数据自适应流程的无条件偏差—方差证明。分量范数不能直接相加，交叉项单独记录。

## 结论能支持到哪里

本轮证明了同一道内的时间—频率权重已经实现并经过实际数值验证；是否更好，应同时看全量波形、事件振幅和 Q 偏差条件。局部 SNR 来自有偏 pilot，可能压制本来就弱的深层信号。时间频率权重不能纠正错误 Q，也不能自动恢复已经被噪声淹没的信息。

本轮没有按结果调窗口或权重范围，也不宣称这是新颖方法、分步优于一步或实测有效。当前完整算子一步法仍是强基线；精确白化且惩罚相同时，分步与一步仍可等价。
