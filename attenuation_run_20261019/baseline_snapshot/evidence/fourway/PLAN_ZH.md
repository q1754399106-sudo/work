## 四种方法的固定定义

1. Direct：Baseline/Direct，正确构造的完整非稳态吸收算子一步反演，无多道结构约束。
2. Split：Baseline/Split，常规分步，第一步固定lambda_x，第二步考虑传播噪声协方差并自动选参，无多道结构约束。它不是最初两步均固定参数的历史版本，也不是原论文完整流程。
3. Frozen：Frozen/Split，保守先导倍数4，结构强度gamma=10，AVO域保护，残差目标倍数1。
4. Target08：Tuned/Split，冻结既有调参选择；结构及先导与Frozen相同，残差目标倍数0.8。

同一观测、同一估计有效Q、同一逐道噪声估计、同一初始lambda规则和运动学先验。结构约束和残差目标是待比较的算法差别，不人为统一掉。整体kappa由一步路线的残差选择，再给对应分步路线复用；明确记录这种选参依赖。
