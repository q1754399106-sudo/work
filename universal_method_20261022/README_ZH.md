# 统一方法优化实验

目标是交付同一入口、同一套规则，而不是为各个模型分别调参数。本轮候选在 `core_p1/matlab_src/universal_candidate.m`：谱约束仅由采样间隔和校准主频构造；候选不接收模型名、场景名、真实反射时间或真实振幅。固定参数在 `core_p1/inputs/universal_plan.json`。

当前为开发实验，不是已经验证完成的可替换默认版。完成结果见 `RESULTS_ZH.md`；候选必须通过所有预定门槛才能进入 `VALIDATION_RESERVED.json` 的新增模型验证。后续生产入口只应冻结通过验证的一套规则，不能运行时按模型名称选优。

复现实验：使用 MATLAB R2024b，将此前比较实验的 `matlab` 原始结果目录配置到 `universal_plan.json` 的 cache 字段，运行 `run_universal_screen('新的绝对输出目录')`。已有目录不会覆盖。原始观测、基线输出、校准估计保持相同；本轮只改变正则机制。Python脚本 `scripts/run_local.py` 记录源码SHA256快照并启动隐藏的独立MATLAB进程；`scripts/analyze.py` 要求全部60组完成后才输出准入结论。

旧对比实验的结果及原始包保持原样。本目录保存新实验、失败运行记录及其源码，避免把方法候选与可直接采用的版本混淆。

补充开发轮登记在 `CONSENSUS_PLAN.json`：只检验一个固定50/50的输出融合，不搜索权重，不按模型选分支。全部结果及门槛判断均保留在报告中。原始运行目录以源码快照为准；当前代码目录还包含之后增加的补充轮入口。
