# 按深度分段的 Q 校正（预登记）

登记时间：2026-10-24，在任何分段扫描运行之前。

**来由**：`qscan_criterion_20261024` 发现，QScan 的偏差主要来自"整个道集只用一个共同因子"的假设。在 Q 随深度变化的 F4 上，选出的因子偏离理想值约 1.7 倍；换用其他选择准则都没有改善。

**文献依据**：Cheng, Yuan, Wang (2020, IEEE GRSL)——按层位分层，逐层优化等效 Q，每次迭代只优化一层。

## 方法（`core/layer_scan.m`）

- **L0**：共同因子 c₀，即原 QScan 目标在 25 点网格（0.5–2.5）∪ {1} 上的最小值，与准则研究中的 A0 相同。
- **L1**：从 c₀ 出发，自浅到深逐层做坐标下降，共两轮。每层因子 c_l = c₀·g，g ∈ exp(linspace(−0.7, 0.7, 11))。目标为原 QScan 的 lasso 目标值 J，不加惩罚。
- **L2_β**：同 L1，目标改为 J + β·(活道数)·Σ_l ln(c_l/c₀)²，β ∈ {1, 5, 25}，即向 c₀ 收缩的分层先验。
- 水层（Q > 1e5）不参与扫描。最终输出为用所选 Q 运行 FullCalRefit 的结果。
- **复现检查**：开发集上 L0 的 c₀ 必须与准则研究中 A0 选出的因子逐位一致。
- 全部从 `upstream/` 快照运行（哈希见 `UPSTREAM_SNAPSHOT_SHA256.txt`），避免运行途中稀疏检出变化带来影响。

## 资料

- **开发集**：primary、complex、F1、F2（都已看过），两档噪声，Q 误差 {−50, −30, 0, +30, +50}%。
- **确认集**（新生成，开发阶段不看）：
  - F5：第 2 层低 Q，第 4 层 Q 反转，含碳酸盐层多次波；
  - F6：Q 随深度交替变化；
  - 正演与 F1–F4 相同，地质模型与种子全新。
- **实测**（描述性）：测线 4508-32 和 3677-32，起始 Q 为 Q_SR × {0.5, 0.7, 1.0, 1.4, 1.6}。

## 指标

- 各变体的波形相对误差，以及它与 L0 之比；
- 优于 L0 的案例比例；
- 最坏情况比值：5 档 Q 误差中的最大误差，除以 FullCalRefit 的最大误差；
- Q0 比值：Q 误差为 0 时的误差，除以 FullCalRefit 的误差。

## 开发选择规则

- **可行条件**：在 primary 和 complex 上，最坏情况比值均值 ≤ 0.95，且 Q0 比值均值 ≤ 1.02。
- 在可行变体（L1、L2_1、L2_5、L2_25）中，选"与 L0 之比"均值最小者。
- 只有当这个均值 < 0.97（即至少改善 3%）时才晋级；否则判定"分段没有带来改进"。

## 确认门槛（F5/F6，晋级变体，全部满足才算通过）

- H1：与 L0 之比的均值 ≤ 0.97；
- H2：优于 L0 的案例 ≥ 60%；
- H3：最坏情况比值均值 ≤ 0.95；
- H4：Q0 比值均值 ≤ 1.02。

## 实测（描述性）

- 两条测线上各层隐含的 Q 是否一致；
- 是否选到扫描范围的边界。

## 边界

- 层界沿用公开的四层几何；
- 确认集只有 2 个地质模型 × 2 档噪声，组合之间不独立；
- 不报告显著性检验；
- 不根据确认结果调整方法。
