# 更换模型之后：结论与数据

已实际连接ResearchMATLAB完成全部预设试验。补偿算法及常数未改，新模型和种子在执行前指定。结论是：**保守先导＋适用域AVO保护有一定迁移收益，但未达到稳定通用；三项组合也不稳定优于基线。**

## 正确Q、18dB的主结果

以下为分步路线、五情景等权、全部六个新种子的平均相对波形误差，越低越好。

| 模型 / Model | 无结构基线 / Baseline | 旧多道 / Raw H | 先导＋AVO保护 / AVO protected | 三项组合 / Combined | AVO版本相对基线降幅 / Reduction |
| --- | ---: | ---: | ---: | ---: | ---: |
| 强吸收软地层 / Soft low Q | 1.28665 | **0.96633** | 0.98219 | 1.04254 | 23.66% |
| 速度反转 / Velocity reversal | 0.55167 | 0.56180 | **0.54954** | 0.55310 | 0.39% |
| 薄层高频 / Thin high frequency | 0.60790 | 0.61982 | **0.60496** | 0.61018 | 0.48% |

AVO版本在各模型30个情景/种子配对中，误差较基线低的比例依次为70%、70%、60%，不是每个样例都改善。不能把场景和种子复用当成独立重复，也没有据此宣称显著性。

强吸收模型的23.66%降幅主要受相干噪声场景的大误差下降影响；这不是对所有场景都大幅改善。旧多道H在该模型中的平均误差还更低，所以最新方法不是所有模型上的最优解。

## “数值稳定”与“恢复稳定”必须分开

- 求解器：1200条方法结果和全部选参候选最终标志均为0，最大法方程相对残差约1.00e-7，未触发Cholesky回退，kappa未选到端点。说明本轮方程求解可靠。
- 恢复：强吸收主试验中AVO版本仍有2/30个道集误差>2、12/30个误差>1；最差2.47133。不能因均值下降就称恢复稳定。
- 分层Q误差＋相干干扰时，AVO版本分步最差4.69689，同一输入基线5.24555。相对基线改善仍不足以获得可信恢复。
- 速度反转与薄层高频在本次主试验及两类压力条件下，AVO版本没有整体波形误差>1的道集；这仅描述本次有限合成条件，不构成一般保证。

相对误差定义为||恢复−无吸收真值||F/||真值||F。误差>1表示恢复误差能量超过真值能量；它是严重退化标志，不等同于“没有任何可见反射”。

## 局部代价

- 三套新模型中，AVO版本的尖灭尾部泄漏均比基线大。先导预测仍会把不应连续的终止反射向邻道传播。
- 薄层高频的弱反射振幅相对误差：基线1.54311，AVO版本1.64180。整体波形的小幅收益不能代替弱反射恢复。
- 速度反转连续AVO的梯度误差：基线0.65419，AVO版本0.67112，旧H为0.56436。子空间保护不是AVO参数准确性的保证。
- 断层邻域并非一致改善：薄层模型该指标基线0.63484，AVO版本0.63970。

上述指标都为主试验全部六种子的均值，没有只展示有利样例。

## Q与噪声压力

压力仅包括连续AVO与相干噪声AVO两情景，不能和主试验五情景的均值直接比。以下均为分步路线：

| 模型 / Model | 压力条件 / Stress | 基线 / Baseline | AVO版本 / AVO protected |
| --- | --- | ---: | ---: |
| 强吸收 / Soft low Q | 12dB、正确Q / 12dB, correct Q | 1.89381 | 1.13186 |
| 强吸收 / Soft low Q | 分层Q误差 / Layerwise Q errors | 2.95656 | 2.14768 |
| 速度反转 / Reversal | 12dB、正确Q / 12dB, correct Q | 0.69973 | 0.69238 |
| 速度反转 / Reversal | 分层Q误差 / Layerwise Q errors | 0.57528 | 0.56444 |
| 薄层高频 / Thin high frequency | 12dB、正确Q / 12dB, correct Q | 0.70077 | 0.68485 |
| 薄层高频 / Thin high frequency | 分层Q误差 / Layerwise Q errors | 0.73787 | 0.70015 |

分层Q误差是各层乘[0.8,1.2,0.8,1.2]，不是已覆盖任意Q误差。强吸收相干噪声场景即使噪声估计接近真值、残差目标满足，仍可能严重退化。因此不能仅靠进一步细化lambda搜索解决全部问题；观测残差中的模型误差和相干干扰值得单独建模。这是本次结果支持的研究切入点，并非已经完成的改进。

## 验证与使用边界

主试验720条、压力432条、原模型回归48条，共1200条方法结果。回归指标与旧版完全一致；原MATLAB路径、目录、RNG、基础工作区元数据和图窗数量检查均保持。首次新增检查程序的初始化错误及修复日志保留，未据此调整模型或算法。

NumPy独立核对新模型几何，最大事件角sin²差2.22e-16；没有进行本轮完整反演网格的双语言核验。AVOProtected在横向剖面只使用PilotH，不施加AVO投影。

模型参数全部自选。仍为Shuey二项、理想NMO、列时变吸收矩阵及示意横向剖面。远道角度约58–67度，仅作为当前合成定义，不据此宣称大角度物理保真、实测有效或方法创新。

完整逐情景数据、六种子SD及全部风险见RESULTS_ZH.md与results/analysis/；执行前设计见PLAN_ZH.md。7组图件均有中英说明与图例。
