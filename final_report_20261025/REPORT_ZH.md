# 地震衰减补偿研究线：最终报告（2026-10-19 → 2026-10-25）

> 状态：**草稿**。第 8 节（二维有限差分复验，`fd2d_20261025`）等该实验归档后补入，其余各节已定稿。本报告只汇总已归档的结果，没有重跑任何实验；每个数字都注明了出处目录。

## 摘要

- **课题**：把被地层吸收衰减的道集恢复成无吸收的弹性响应。评分统一用整体相对波形误差 ‖输出 − 目标‖/‖目标‖，越低越好。
- **得到的方法**：
  - 核心是 FullCalRefit：反射系数估计＋振幅重拟合，取代最初的分步滤波。
  - 在它之上，用“邻道相干引导的软收缩”（相干标准版）压噪声。
  - 再用 QScan（对全道集共同的 Q 校正因子做扫描）应对 Q 有误的情况。
- **合成数据上的效果**：
  - 冻结后新生成的独立数据（F3/F4，28 个场景）上，QScan＋相干标准版的平均误差为 0.468，最初分步法为 1.051，降低 55%，28/28 个场景更好。
  - 封存的复杂模型 V5（14 个场景）上，降低 41%，14/14 个场景更好。
- **使用规则**（多轮实验一致支持）：
  - Q 可信时只用相干标准版，不要叠加 QScan；
  - Q 可能有误时用 QScan＋相干标准版。
- **两条站得住的机制发现**：
  1. 有了相干收缩之后，最优补偿强度就在真 Q 处；
  2. QScan 的选择偏移是每个模型确定的属性，但方向和大小因模型而异，−4 到 +4 个网格步长都有，无法用常数或无真值特征去偏。
- **实测：无法判定。** 两次实测（U1320A、Volve 15/9-F-15A）都没能区分方法优劣。原因有两个：一是 VSP 的 Q 没有通过可识别性门槛；二是井上指标的分辨力与判定阈值相当。
- **创新性**：方法组成部分在文献中都有先例。与最接近的文献基线（结构约束 SC 的独立实现）对照，相干标准版没有通过优势门槛：平均误差比是 1.055，8 个场景中只赢 4 个。站得住的贡献是上面两条机制发现，以及 Q 校正与降噪之间“相互替代”的偏差—方差分析。

## 2. 主要结果（合成数据）

冻结后新生成的数据：

| 数据 | 方法 | 平均误差 | Q 正确时 | 最坏 | 优于最初方法 |
|---|---|---:|---:|---:|---:|
| F3/F4（28 个场景） | 最初分步法 | 1.051 | 0.884 | 1.730 | — |
| | FullCalRefit | 0.875 | 0.548 | 2.331 | 22/28 |
| | 相干标准版 | 0.713 | **0.458** | 2.329 | — |
| | **QScan＋相干标准版** | **0.468** | 0.472 | **0.479** | **28/28** |
| V5（14 个场景） | 最初分步法 | 0.918 | 0.704 | 1.640 | — |
| | FullCalRefit | 1.331 | 0.605 | 4.727 | 10/14 |
| | **QScan＋相干标准版** | **0.540** | **0.543** | **0.564** | **14/14** |

出处：`progress_summary_20261024/SUMMARY_ZH.md`、`fixed_baseline_round3_20261024`。

- 收益分两部分：
  - Q 正确时，反射系数估计＋振幅重拟合加上相干收缩，使四层模型的误差降低 74–76%；
  - Q 有误时，QScan 让误差不再失控。Q 低估 30–50% 时，没有 QScan 的方法会比最初方法还差。
- 复杂模型提升较小。剩余误差来自三方面：60 层薄层调谐、四层 Q 标定代替横向变化的 Q、子波的横向变化。见第 5 节。

## 3. 使用规则：何时叠加 QScan

| 证据 | Q 可信（Q0） | Q 有误（Q0×0.7） | 出处 |
|---|---|---|---|
| 偏差—方差分解（F1/F2，20–100 个噪声实现） | 组合比标准版差 21–50%（F2/8 dB 例外，好 6.5%） | 组合好 63–79%，每个实现都更好 | `combo_bias_variance_20261024` 阶段 1 |
| 8 个新开发模型 G1–G8 | 标准版在 7/8 个模型上更好 | 组合在 8/8 上更好，标准版高出 47–357% | `qscan_offset_20261025` |
| 组合层面的准则对照 | 标准版在 8–10/10 个模型上胜过任何准则 | 只有 A 系列准则保持稳健 | `critcombo_20261025` |

机制（`combo_bias_variance_20261024`、`novelty_evidence_20261025` 复算）：
- QScan 的收益主要是降方差，而相干收缩已经取代了其中的 33–75%；
- QScan 的偏差代价（强反射欠补偿，振幅增益从 0.80–1.00 降到 0.62–0.86）却几乎全部保留，ρ_B = 1.01–1.07；
- 两者在全部 10 个场景中都是互相替代，而不是互补。

## 4. 两条机制发现

### 4.1 相干收缩使最优补偿回到真 Q

- F1/F2 上，完整流程误差最小的有效 Q 比为 1.00–1.03（14 dB）。没有相干收缩时，FullCalRefit 的最优点为 1.00–1.15（14 dB）和 1.11–1.54（8 dB）。（`combo_bias_variance_20261024` 阶段 2）
- 8 个新模型上，无噪声最优都在 1.000 或 1.031，Q0×0.7 时为 0.999。（`qscan_offset_20261025` O3）
- 物理诊断：名义 Q 本身是对的，各变体的误差最优因子都在 0.98–1.03。（`physics_bias_20261024`）

### 4.2 QScan 的偏移是模型的确定属性，但因模型而异

- F1/F2 上，QScan 确定性地选在 1.24–1.28×Q0。无噪声时也是这样，20 个实现中有 16–20 个选同一网格点。（`qscan_bias_variance_20261024`、阶段 2）
- 偏差的主要来源是**密集反射系数与 lasso 稀疏先验的失配**：把细层合并成块状层后，偏差降低约 60%；多次波和透射损失不是来源。（`physics_bias_20261024`）
- 8 个新模型上，偏移为 −4 到 +4 步。同一模型内几乎不随噪声实现变化，从 Q0 或 Q0×0.7 出发时也相同。（`qscan_offset_20261025` O1）

由此排除的修正路线：

| 路线 | 结果 | 出处 |
|---|---|---|
| 常数去偏 κ | 平移 1 步最坏 +34%，2 步最坏 +90%；**用户决定结束** | `qscan_offset_20261025`、`combo_bias_variance_20261024/DECISION_KAPPA_ZH.md` |
| 无真值特征预测偏移 | 13 个规则中没有一个通过 P1 | `qscan_predictor_20261025` |
| “有把握才修正”规则 | 新模型 K1–K8 上 A1 通过（平均 −13.4%），A2 未通过（最坏 +14.1%）；20 dB 下不安全 | `qscan_abstain_20261025` |
| 换选择准则（残差、BIC、AIC、证据、GCV、留出、频谱斜率） | 都不比 QScan 好 | `qscan_criterion_20261024`、`qcriteria_20261024` |
| 组合层面换准则（A0–A3、C1–C4） | 都没通过 W1；A1、A3 平均持平，但最坏差 39–62% | `critcombo_20261025` |
| 按深度分段的 QScan | 用真值挑选的上限也只好 5.7%；只用数据时差 11.1% | `round4_20261024`、`qscan_layered_20261024` |

改进空间：最优固定因子比 QScan＋标准版好 24–33%（`combo_bias_variance_20261024` 阶段 2），但至今没有任何不依赖真值的选择器能拿到这部分。

## 5. 复杂模型的瓶颈

- **Q 标定**是主要瓶颈之一：换成每道真实衰减后，相干标准版误差降低 17.5%；其中约六成来自四层 Q 估得不准，约四成来自四层模型太粗。（`trueq_20261025`）
- 标定偏差的原因是**标定模板里没有震源鬼波**。
  - SharedGhost 在开发集上让剖面误差降低 6.9%，但参数门槛未通过；
  - 在新模型 C1–C3 上做的探索性确认中，K2–K4 三项全部未通过，最坏变差 17.4%，所以不采用。（`calq_20261025`、`calq_confirm_20261025`）
- **薄层与稀疏模型的极限**：真 Q、真子波、无噪声时，误差仍有 0.312。（`trueq_20261025`）
- **子波不是瓶颈**：子波相位只贡献约 2%，换成真子波只再降 0–1%。（`round3_20261024`、`trueq_20261025`）

## 7. 实测：无法判定

两次实测都没能区分方法优劣，结论记为**无法判定**，不作“方法有效”或“方法无效”的推论。

| | 实验 4：U1320A（IODP 308） | 实验 5：Volve 15/9-F-15A |
|---|---|---|
| VSP 单程跨度 | 0.12 s（87–292 mbsf） | 0.79 s（191 级） |
| VSP 估 Q | R² 中位数 0.04，斜率区间跨 0，**G1 不通过** | Q_int = 128（区间 110–155），但 R² 中位数 0.13，**G1 不通过**；顶层 G1b 也不通过 |
| 补偿输入 | 1988 年偏移叠加，两条过井测线 | ST0202R08 原始 PSDM 叠加（未做反 Q 补偿），沿井轨迹的幕帘线 |
| 井上指标 | 标定相关 0.3–0.4；两条线方向相反 | 走廊叠加相关 0.13–0.23，测井合成相关 0.18–0.34；11/36 个时移顶在搜索边界 |
| 描述性观察 | QScan 在一条线上停在网格上限 | VSP 的 Q＋标准版比 QScan＋标准版低 0.054 / 0.036；QScan 朝更强补偿方向移动（隐含 Q 66–115），与合成数据上的方向相反 |
| 出处 | `field_vsp_u1320a_20261024` | `field_vsp_volve_20261025` |

无法判定的原因：
1. 两口井的独立 Q 都没通过可识别性门槛；在 Volve，顶层 Q 很可能偏高，承包商给出的是 46，本实验用的是 128。
2. 井上指标的分辨力与 0.02 的阈值同一量级。例如 Q 只从 64 变到 66，T1 就变化了 0.025。
3. 走廊叠加只有 6–70 Hz；输入与走廊叠加之间还有约 90° 的相位差，零相位假设没有解释它。

唯一可以带走的实测信息：QScan 在 Volve 上的偏移方向与合成数据相反。这与 4.2 节“偏移方向因模型而异”一致，所以“QScan 系统性少补偿”不能推广为实测上的规律。

如果要在实测上分辨方法，需要以下之一：全频带、相位可信的 VSP 上行波成像；多口井；或者通过可识别性门槛的分层 VSP Q。

## 9. 创新性与文献定位

- **已有先例**：
  - 扫描 Q 补偿：Cheng et al. 2025, Geophysics 90(5):R275；
  - “扫描 Q＋多道”：Ma 2018（bSBL＋lp）、Cheng 2020, Acta Geophys 68:675；
  - 用相干度调节 Wiener 增益：麦克风阵列中的 McCowan & Bourlard 2003。
- **对照最接近的文献基线**（马雄等 2023 式的结构约束 SC，独立实现，不是作者原版）：
  - 8 个已见场景上，SC 平均误差 0.394，相干标准版 0.416，比值 1.055；标准版赢 4/8，最坏逐场景比值 1.41。
  - 未通过优势门槛，因此**不能声称相干标准版优于这一基线**。（`novelty_evidence_20261025`）
- **可以主张的**：
  - 具体构造上的差异：由未收缩的反射事件组的邻道相干来调节噪声收缩，邻道不直接加权进入目标道；
  - 4.1、4.2 两条机制发现；
  - Q 校正与降噪“相互替代”的偏差—方差分析（第 3 节）。
- **理论**：增益 g = E/(E + λV) 逐组精确最小化一个可观测的二次代理目标，但这不是无偏 MSE 估计；不同组的增益可能破坏原子之间的抵消。（`novelty_evidence_20261025/THEORY_ZH.md`）

## 10. 边界

- 全部定量结论都来自合成数据：准一维卷积、一维 Kennett 细层正演、复杂横向模型；二维有限差分复验见第 8 节。场景之间共享生成器，不报告显著性检验。
- 很多比较对象是已见模型，例如 novelty_evidence 的 8 个场景；只有预登记的确认集（F3/F4、V5、U1–U4、K1–K8、C1–C3、G1–G8 中用于确认的部分）算未见数据。
- 组合方法 QScan＋相干标准版从来不是预登记的门槛对象。通过正式门槛的是它的两个组成部分：相干软收缩 v1 和 QScanRefit。
- 实测无法判定（第 7 节）。
