## 1. 偏差原因（诊断）

标定道集只有 3 个反射（第 1–3 层底界面），只在其 ±0.12 s 时窗内拟合。

| 情况 | V3 ln(Q/Q真) 第 1–4 层 | V5 ln(Q/Q真) 第 1–4 层 |
|---|---|---|
| 现行，8 次噪声重复平均 | +0.13 / +0.15 / +0.03 / +0.42 | +0.12 / +0.19 / −0.03 / +0.46 |
| 现行，无噪声 | +0.09 / +0.10 / +0.03 / 撞上界 200 | +0.09 / +0.09 / +0.06 / 撞上界 200 |
| 无噪声，去掉震源鬼波（只留相位） | 0.00 / 0.00 / 0.00 / −0.06 | 0.00 / 0.00 / 0.00 / −0.07 |

**原因是标定模板没有震源鬼波**（生成器 −0.16@12 ms、+0.04@25 ms）。第 4 层只影响第 3 个反射的尾部，几乎不可辨识；只看数据项时最优在上界，平滑先验把它拉回 134–164。

用真值拆分（仅诊断）：第 4 层 Q 偏高对剖面影响 ≤2%；前三层准确可使相干标准版误差降低 6%（V3）–15%（V5）。
