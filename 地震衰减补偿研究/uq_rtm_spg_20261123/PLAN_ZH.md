# 预注册方案：镜面孔径与 Poynting 结构倾角门控 UQ-RTM（`SPG-UQ-RTM`，`uq_rtm_spg_20261123`，开跑前提交）

## 0. 物理动机与第 0 步先验事实

基于 `wsuq_rtm_20261123`（T2.1）与本轮 3 项第 0 步诊断，已定位现行频率域 UQ-RTM（`uq_rtm_20261117`）在复杂二维波场与实测资料上的两类尚未解决的波场级瓶颈（且与兄弟分支正在运行的 `fld45` / `B=300` 严格正交、不重复）：

1. **排列外非镜面炮的虚假 $t^*$ 截断与画弧放大**：现行 `two_way.m` / `fld_tstar.m` 将所有炮都纳入补偿叠加，并对镜面检波点 $x_{\text{mir}} = 2x - x_s$ 落在实际检波排列之外的炮强行截断到端点赋予虚假 $t^*$。实测 Volve 储层窗内高达 **`36.5%`** 的 `(像点, 炮)` 对落在实采检波排列之外；二维气烟囱单炮解剖显示，非镜面炮的浅层偏移画弧被虚假高 $t^*$ 放大达 `3×`。
2. **结构倾角与反射张角的物理分离**：第 0 步公平消融表明，盲目做覆盖次数归一化（除以 `mean(w)`）会抬高边缘翼部振幅并破坏 `W_deep` 与 `E_amp`（已淘汰）；而不归一化的镜面孔径门控 `SA` 与 Poynting 倾角门控 `POY` 在气烟囱 2D RTM 上大幅提升 `E1`（`+0.03~+0.08`）与 `SNR_img`（`+1.2~+2.4 dB`），且在 $m=0.5$ 过补偿处将 `UQW1` 相对公平基线 `W1` 的稳健优势进一步拉宽。为避免提前截断绕过气烟囱的大张角镜面射线，本方案严格区分：
   - **活排列镜面掩码 `SA`**：仅门控 $x_{\text{mir}}$ 是否落在该炮**真实活检波排列 $[x_{r,\min}(s), x_{r,\max}(s)]$** 内（外推平滑过渡带 `[-80, +120] m`），并仅对近掠射直达/潜波（$\theta_s \in [70^\circ, 80^\circ]$）做温和衰减，**不截断** $40^\circ\text{–}65^\circ$ 大张角镜面射线；
   - **Poynting 结构倾角门控 `POY`**：由源程函射线方向 $\mathbf{p}_s = \nabla T_s / |\nabla T_s|$ 与（含噪盲测）反传检波波场局部 Poynting 方向 $\mathbf{p}_r \propto \operatorname{Re}(V_s^* \nabla V_s / (i\omega))$ 合成偏移法向 $\mathbf{m} = \mathbf{p}_s + \mathbf{p}_r$，仅对陡倾画弧倾角 $|\phi_{\text{dip}}| = \operatorname{atan2}(|m_x|, m_z) \in [30^\circ, 50^\circ]$ 做余弦衰减（完全保真 $\le 30^\circ$ 陡倾反射层与大张角平层绕射射线，只压制 $>50^\circ$ 非镜面偏移画弧与相干噪声）；
   - **联合算子 `SPG-UQW1`**（$w_{\text{SPG}} = w_{\text{SA}} \cdot w_{\text{POY}}$，不除覆盖次数），在门控域内采用与门控一致的盲炮极性翻转估噪 `iv`（天然兼容横向相关噪声）。

## 1. 预注册实验矩阵

### Part A：4 个全新未见 2D 全波动方程复杂模型（`G1–G4`，零反演犯罪，与第 0 步及 `C1–C8` 零重叠）

所有模型均采用精确二维黏声 Helmholtz 复速度正演、平滑背景速度 `v_mig` 双程波反传、34 个无混叠频点（`4:1:37 Hz`, `df = 1.0 Hz`, 周期 `1.0 s > T_max`）、5 档 $Q$ 乘子 $m \in \{0.5, 0.7, 1.0, 1.4, 2.0\}$、2 档噪声（`clean 15 dB` 与 `noisy 3 dB`），同场对 **3 种门控模式（`RAW` / `SA` / `SPG`）× 4 种算子（`R0` / `IQ70` / `W1` / `UQW1`）共 12 组合**做严格公平对比（所有基线享受与 `UQW1` 完全相同的门控与盲估噪）：

1. **`G1`（强气烟囱＋背斜，`seed = 20261131`）**：居中 $Q_{\text{chim}}=12$ 气烟囱与深部背斜三界面，检验强横向 $Q$ 异质性下 `SPG_UQW1` 的波形、分辨率、信噪比与烟囱振幅保真度。
2. **`G2`（断层＋陡倾 `18°` 地层＋深部低 Q 透镜，`seed = 20261132`）**：含正断层错断与 $18^\circ$ 倾角反射层，专门检验 `POY` (`30°–50°` 倾角窗) 与 `SA` 是否无损保留陡倾构造与断面反射。
3. **`G3`（单边拖缆海洋观测系统＋横向 Q 梯度，`seed = 20261133`）**：模拟真实 Volve 拖缆的非对称单边活检波排列（每炮单侧 `960 m` 活拖缆，约 `35–45%` 储层炮对落在活排列之外），叠加横向渐变 $Q(x)\in[35, 110]$，专门检验 `SA`/`SPG` 消除排列外虚假 $t^*$ 放大的实效。
4. **`G4`（横向相关噪声 `l30`＋气烟囱＋`+3%` 偏移速度误差，`seed = 20261134`）**：检波点方向高斯相关噪声（$\sigma_{\text{tr}} = 3$ 道 $= 60\text{ m}$）叠加 $+3\%$ 系统速度偏高与 $Q_{\text{chim}}=15$ 气烟囱，检验 `SPG`＋炮翻转估噪在双重恶劣实测条件下的稳健性。

### Part B：Volve Stage 4 实测缺口只读定量审计（`scripts/volve_stage4_audit.m`）

严格只读 `uq_rtm_20261117/cache/fld`（绝不触碰运行中的 `fld45`），固化归档三项定量诊断：① 储层窗活排列外镜面炮占比；② `[1000–1600 m]` 至 `[2600–3200 m]` 实测 $\Delta t^*_{\text{emp}}$ 与 $(2\pi f)^2$ 预白化谱比；③ `1D-UQ` 叠后增益与逐炮 `PerShot-UQW1` 井震相关逐 $m$ 差值。

## 2. 预注册机械判定准则（`scripts/judge_spg.py`，开跑前冻结，绝不事后修改）

评价主窗 `W_deep`（$x\in[180, 1420]\text{ m}, z\in[560, 950]\text{ m}$），参照为未门控全孔径弹性（$Q=\infty$）真值成像 `I_ref`，四个无饱和指标为 `E1`、`E1_HF`（$k_z \ge 10\text{ cyc/km}$）、`SNR_img_dB`、`E_amp`（仅气烟囱模型 `G1, G4`）：

- **`G1_SPG_vs_RAW`（相对现行仓库冠军 `RAW_UQW1` 的净提升）**：在 `G1–G4` 全部 4 个未见模型 `noisy (3 dB)` `W_deep` 上，`SPG_UQW1 − RAW_UQW1` 满足：
  - 4 模型平均 $\Delta E_1 \ge +0.025$，至少 `3/4` 模型 $\ge +0.015$，且 `4/4` 非负；
  - 4 模型平均 $\Delta\text{SNR}_{\text{img}} \ge +0.80\text{ dB}$，且 `4/4` 为正。
- **`G2_Fair_UQ_Margin`（相对同门控公平基线 `SPG_B+ = max(SPG_R0, SPG_IQ70, SPG_W1)` 的贝叶斯优势）**：在 `G1–G4` `noisy (3 dB)` `W_deep` 上，`d = SPG_UQW1 − SPG_B+` 满足：
  - 过补偿侧 $M_1 = \mathrm{mean}_{m\in\{0.5, 0.7\}} d$：4 模型平均 $\ge +0.050$，且 `4/4` 模型 $\ge +0.030$；
  - 准确点 $M_2 = d(m=1.0) \ge -0.025$（`4/4` 模型）；
  - 欠补偿侧 $M_3 = \min_{m\in\{1.4, 2.0\}} d \ge -0.040$（`4/4` 模型）。
- **`G3_SteepDip_Safety`（`G2` 陡倾与断层无损检验）**：在 `G2` 的 `clean` 与 `noisy` 两档 `W_deep` 上，`SPG_UQW1 − RAW_UQW1` 的均值 $\Delta E_1 \ge -0.005$ 且 $\Delta E_{1,\text{HF}} \ge -0.005$。
- **`G4_Chimney_Amp_Safety`（`G1, G4` 气烟囱振幅保真检验）**：在 `G1` 与 `G4` 的 `noisy` `W_chim` 上，去除了过早 $55^\circ$ 张角截断的 `SPG_UQW1` 的 `E_amp` 不高于 `RAW_UQW1 + 0.030`。
