### 4.1 UQ-W / CBL：合成确认通过，实测相反

**目录：** `qunknown_comp_20261109/`（设计、阶段 0–2、W、MMR、CB、CBL、两次确认）、`field_qperturb_20261113/`（实测）、`uqw_improve_20261113/`（改进，开发中）。

**方法：**

```text
u = 1/c（真 1/Q 相对模型 1/Q 的乘子），u ~ 对数正态，σ = 0.447（“Q 只知道在 ×2 以内”）
G(a) = exp[−π f a + i 2 f ln(f/f_ref) a]，a = u·a_m(t)（a 为相对子波窗锚点的 t*）
H = conj(E[G]) / (E|G|² + ρ)，ρ = s + E|G|²/snr(t, f)，snr 由邻道相干估计
σ → 0 时退化为稳定化反 Q（IQ70）；期望用 Gauss–Hermite 求积
```

CBL：在 36 点 u 网格（约 0.1–2）上的目标先验，只在 u = 2 截断，对 [0.5, 2] 上 17 个剖面加后悔上限，τ = 0.5。推导见 `RESULTS_MMR_ZH.md`（可分平方损失下联合后悔、联合最坏、逐点后悔都是同一贝叶斯形式，只差先验）。

### 4.2 UQ 逆时偏移（叠前 RTM）：阶段 2 开发进行中

**目录：** `uq_rtm_20261117/`。入口 [README.md](uq_rtm_20261117/README.md)。

**做法：** 频率域四阶 Helmholtz 逆时偏移；在成像条件中逐点施加 UQ-W 期望算子（路线 A）。两程 t* 由快速扫描法程函方程按 Fermat 原理求（检波点一支用镜像检波点）；成像域信噪比用“两遍扫描、频带求和的随机极性”估计（`est_noise.m`）。对照路线 C 为叠前逐道 UQ-W。

**阶段 1（开发模型 P1，三轮）：** 前两轮查出路线 C 代码错误、单频成像域噪声估计失效；第 3 轮按事先规则选路线 A（比路线 C 高 0.207）。m30（道上 −30 dB）深部：Q 偏小一侧 M1 = +0.115，Q 准确 M2 = −0.045，Q 偏大最差 M3 = −0.056。见 `RESULTS_STAGE1_ROUND3_ZH.md`。

**阶段 2（方案 `PLAN_STAGE2_ZH.md`，bee53e0，评分前提交）：** 新模型 D1–D4；数据 m30、m40（主）、g30（加面波型相干噪声）；Q 误差形式 E1 整体比例（9 档）、E2 平均 Q、E3 平滑、E4 深浅反向；速度误差 ±4%（D1、D3）。可行基线 R0、PH、IQ30、IQ70、LP（Zhu 等 2014 型低通）、W0；B* 为可行基线逐情景的上包络。

### 4.3 UQ-AVO：第一关通过（11-18）

**目录：** `uq_avo_20261118/`。方案 `PLAN_GATE1_ZH.md`（db594a9，评分前提交），结果 `RESULTS_GATE1_ZH.md`。

**问题：** 叠前逐道 UQ 补偿时，远道路径 t* 更大，绝对不确定度也更大，补得更少，会不会造出负的假 AVO 梯度？

**结果（72 单元：M12–M15 × 2 子波 × 3 λ × 3 事件，孤立事件、理想拉平、无噪声）：**

| 判定 | 结果 | 门槛 |
|---|---|---|
| G1：UQ 引起的逐事件 G/A 偏差 \|D\| 中位数 | 0.161 | ≥ 0.092 |
| G2：D < 0 的比例 | 94.4% | ≥ 80% |
| P1：闭式 Γ 对数值，斜率 / R² | 0.974 / 0.999 | 0.9–1.1 / ≥ 0.95 |

**研究者自己指出的限制：**

- 效应强烈依赖 λ：λ = 10⁻² 时只有 0.052；σ = 0.25 时只有 0.053。
- 补测（描述性，`scripts/lam_scan.py`）：第 2b 步残差原则实际选出的 λ 在 10⁻³～10⁻²，此时 D 约 −0.03～−0.13，**落在门槛两侧**；同一范围内一步 Tikhonov 自身的 |dGA| 是 0.42–0.75，比 UQ 的增量大 5–20 倍。高信噪比（24–30 dB）下的 λ 是外推。
- UQ 只在 Q 错一倍（u = 0.5、2）时 AVO 更好；在 0.7–1.4 范围内更差。
- 炮检距一致的 OC 变体在 u 网格平均上最好（0.48），但零偏差点偏到 u ≈ 0.8，近道分辨率损失约 35%。

**请审核：**

### 7.2 符号与缩写

| 符号 | 含义 |
|---|---|
| Q、c、u、m | 品质因子；c 为 Q 的乘子（真 Q = c × 模型 Q）；u = 1/c；m 为补偿所用 Q 相对真 Q 的乘子（m < 1 为 Q 偏小、过补偿） |
| t*、a | 累积衰减时间 ∫dt/Q；a 为相对锚点的 t* |
| σ | u 的对数正态标准差；0.447 对应“×2 以内” |
| ρ、s、snr、γ | Wiener 稳定项、常数部分、信噪比；γ 为 UQ-W 中相位项的混合参数（γ = 1 时噪声主导下趋于相位校正） |
| SC、SC-a、SC0 | 文献结构约束反演（马雄等 2023）及本研究的实测适配版、无结构项版 |
| QScan、SR | 扫描 Q 选择（lasso 残差＋稀疏度）；多窗口相干谱比估 Q |
| IQ30 / IQ70 | 增益上限 30 / 70 dB 的稳定化反 Q |
| VDB | van der Baan 2012：相位反 Q＋时变 Wiener 谱整形（振幅不用 Q） |
| PH、LP、W0、W1 | 只校正相位；完全补偿＋低通；σ = 0 的 Wiener（γ = 0 / 1） |
| UQ-IQ、UQ-W、UQW0/UQW1、CBL | 常数稳定项版；数据估噪声项版；RTM 中 γ = 0/1 版；保留低衰减尾部的受限贝叶斯版 |
| B*、B⁺ | 可行基线逐情景上包络；B⁺ 再加 W1 |
| M1–M4（RTM） | m < 1 平均差；m = 1 差；m > 1 最差差；最差 S 对各基线之差 |
| S、T2、dGA | 对理想剖面的相关得分；井震相关；逐事件 G/A 偏差 |
| F1–F4、V1–V5、H1–H12、Z/Y、D1–D4、P1、M1–M15 | 各数据集或模型名，定义见各自目录 |
