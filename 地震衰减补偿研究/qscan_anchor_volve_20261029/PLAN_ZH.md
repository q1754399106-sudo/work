# 实验 14 方案：QScan 选 Q 被压缩的机制——子波锚定与稀疏权重

2026-10-29 写成。冻结前只用了开发数据：实验 12 的 20 个留出剖面（已见），以及三个探索性原型（`qscan_reg_pilot_20261029`、`qscan_bandcv_pilot_20261029`、`qscan_sparsity_mech_20261029`）。**本实验的检验数据在冻结前没有生成，也没有看过。**

## 1. 要回答的问题

QScan（`lib.qscan`，实验 7–13 原样使用）在 15 个 Q 系数上最小化 lasso 目标。原型显示，它选出的 c 被压向中间值（实验 12 数据上，log 选择对 log 真 c 的斜率只有 0.29）。原型给出的机制：

1. **子波锚定**：`lib.wavelets` 用浅层（1.2–1.6 s）频谱除以模型 Q（c = 1）在 1.4 s 的衰减来估计输入子波，`lib.qscan` 对所有 c 共用这一个子波。于是 c ≠ 1 时，字典在浅层就和数据对不上，选择被拉向 1。每个 c 重估子波后，斜率升到 0.6–1.3。
2. **稀疏权重**：权重越大，选择越偏低、斜率越小（原型：权重 0.5、0.125、2⁻⁴、2⁻⁶ 的偏差为 −0.57、−0.29、−0.21、−0.07）。
3. 反射系数稀疏度影响很小（原型 1），本实验不再检验。

本实验在全新数据上检验 1、2，并检验第三个实用问题：在开发集上定出的恒定偏差，能否原样搬到新数据上，使"子波重估＋小权重＋偏差校正"不劣于同样做了偏差校正的 SR。

## 2. 数据

开发集（只用于校准偏差）：实验 12 的 20 个留出剖面（c = 0.65–1.5，种子 9701–9704），读取 `baselines_volve_20261029/cache/out` 的 float32 副本。

检验集（全新）：
- 构造线 **inline 10227**，噪声线 **10149 / 10273 / 10355**，数据里只加 10149 的噪声。这些线在实验 8–12 中都没有用作构造或噪声，冻结前已确认四条线都完整（未被替换）。
- **T 组（主组）**：实验 8/10/11/12 的配方（F-11 T2 测井反射系数块自助，沿构造铺开，真 Q = c × 模型 Q，实测噪声，信噪比按实测标定）。c = 0.6、0.8、1.0、1.2、1.45，种子 9901–9904，共 20 个。
- **S 组（压力组）**，共 12 个：
  - L：中心道用 F-12 / F-14 的长 Gardner 测井（实验 11 的 `signal_L`，反射系数颜色不同），c = 0.75、1.2，种子 9911，4 个；
  - N：T 组配方，噪声乘 0.5 或 2.0，c = 0.75、1.2，种子 9921、9922，8 个。

## 3. 方法

| 名称 | 内容 | 角色 |
|---|---|---|
| QScan | `lib.qscan` 原样（权重 0.5，一个按 c = 1 估的子波） | 现流程 |
| QScan-W(λ) | 同一目标、求解器、σ、K、网格，但每个 c 用 Q×c 重估输入子波；λ = 0.5、2⁻²、2⁻⁴、2⁻⁶ | 被检验的机制／方法 |
| QScan-W(λ)_cal | QScan-W 的选择乘 exp(−开发集偏差(λ)) | 实用版本（H3 用 λ = 2⁻⁴） |
| SR | `sq.estimate`（实验 10），nboot 0 | 对照 |
| SR_cal | SR 乘 exp(−SR 在开发集上的偏差)，开发集偏差取实验 12 的 SR 结果 | 公平对照（同样做偏差校正） |

- FISTA 上限从 5000 提到 20000 步，同一权重下用上一个 c 的解做热启动，以减少原型中的不收敛（`lib.qscan` 在 0.5 时本来就收敛，此改动不影响它）。
- 代码：`scripts/run14.py`（dev、test 两阶段）、`scripts/analyze14.py`（校准与判定），冻结时一并提交。实验 7–13 的程序从实验 13 的输入快照导入，不作改动。
- 偏差只在开发集上算，写入 `analysis/calibration.json`；检验集不参与校准。

## 4. 指标与判定

对每个数据集，误差 e = log(选出 c / 真 c)。组内指标：斜率（log 选择对 log 真 c 的最小二乘斜率）、平均偏差、平均 |e|、|e| ≤ log 1.25 的比例。区间用组内数据集的自助重抽样（2000 次，种子 20261030，90% 百分位区间）。

| 判定 | 组 | 比较 | 支持 | 相反 |
|---|---|---|---|---|
| **H1 锚定** | T | 斜率：QScan-W(0.5) − QScan | 点估计 ≥ 0.2 且区间下限 > 0 | 区间上限 < 0 |
| **H2 权重** | T | λ 从 0.5 → 2⁻⁶：偏差与斜率是否都单调上升；两端之差的区间 | 两个序列都单调，且偏差差、斜率差的区间下限都 > 0 | 任一区间上限 < 0 |
| **H3 可迁移（主组）** | T | 配对 \|e\|：QScan-W(2⁻⁴)_cal − SR_cal | 区间上限 ≤ +0.02（不劣） | 区间下限 > +0.02（劣） |
| **H4 可迁移（压力组）** | S | 同 H3 | 同 H3 | 同 H3 |

其余情况为"无法判定"。另外报告（描述）：
- 所有方法在两组的斜率、偏差、|e|、±25% 比例；
- 与未校正 SR 的配对差；
- 各权重的收敛比例；
- 开发集上 QScan-W 的描述统计。

## 5. 解释规则

- H1 支持：子波锚定是压缩的成因，这是机制结论的核心。
- H2 支持：稀疏权重控制偏差与斜率，选 Q 结果不能脱离正则参数来解释。
- H3/H4 支持：偏差校正后的 QScan-W 可作为 SR 之外的另一种估 Q 方式；任一相反或无法判定，就只作为机制结论，不推荐为方法。
- 不收敛比例若超过 10%，在结果中单独说明，并给出只用全部收敛数据集的敏感性结果（描述）。

## 6. 运行

`run14.py dev K N` 与 `run14.py test K N` 并行，共约 6 个进程（开发 2、检验 4）；完成后运行 `analyze14.py`。预计 4–6 小时。
