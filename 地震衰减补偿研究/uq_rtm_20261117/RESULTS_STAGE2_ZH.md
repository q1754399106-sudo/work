## 2. 其他 Q 误差形式（m30，W_deep，UQW1 − B⁺）

| 模型 | E2 平均 Q（m = 0.7 / 1 / 1.4） | E3 平滑（0.7 / 1 / 1.4） | E4 深浅反向（0.7 / 1.4） |
|---|---|---|---|
| D1 | +0.021 / −0.032 / −0.026 | +0.051 / −0.020 / −0.030 | −0.029 / −0.015 |
| D2 | +0.028 / −0.025 / −0.031 | +0.057 / −0.027 / −0.037 | −0.018 / −0.003 |
| D3 | +0.041 / −0.002 / −0.022 | +0.051 / −0.006 / −0.024 | −0.012 / −0.005 |
| D4 | −0.010 / −0.025 / −0.009 | +0.022 / −0.014 / −0.025 | −0.026 / −0.014 |

- **E2、E3** 在 m = 0.7 时多为正，在 m = 1、1.4 时为 −0.002 到 −0.037。这两种形式都会抹掉低 Q 体，体下方实际是欠补偿，而 UQ 在欠补偿一侧不占优。
- **E4** 在 m = 0.7 时四个模型都为负（−0.012 到 −0.029）。浅层欠补偿、深层过补偿同时存在，算子只按总 t* 加阻尼，分不出误差在哪一层。这是方法的局限。

## 3. 速度误差（偏移速度 ±4%，m30，E1，m = 0.7 / 1 / 1.4，W_deep，UQW1 − B⁺）

| 模型 | 速度 ×0.96 | 速度 ×1.04 |

- 速度有 4% 误差时，UQ 的相对优势不减，Q 准确时反而略好（+0.004 到 +0.017）。速度误差使成像散焦，UQ 的保守性在这时代价更小。
- 只有 D3 在 ×0.96 的 W_body 上，Q 准确时落后 −0.024。

## 4. 其他

- **g30（面波型相干噪声）：** 与 m30 的分数几乎相同。这种噪声偏移后不落进评价窗，没有区分力，阶段 3 要换。
- **LP：** 截止频率规则在 m40 上有三个模型选到 10 Hz，成像失效（S ≈ 0）；D4 选到 32.5 Hz，正常。
- **噪声主导时最强的可行基线**是 W0、W1 和 PH。增益上限型反 Q（IQ30、IQ70）放大噪声。

## 5. 结论与对阶段 3 的建议

1. **主方法改为 UQW1**（σ = 0.447、γ = 1）。依据是 8 个单元的整体表现，不是挑单个模型：
   - 最差情形明显更好（M1 −0.018 对 −0.069，M2 −0.023 对 −0.107）；
   - 其余单元与 UQW0 基本持平；
   - 机理清楚：噪声主导时退化为带不确定度阻尼的相位校正。
2. **阶段 3 判定规则建议**（主窗 W_deep，E1，单元为模型 × 噪声档 m30、m40）。阈值依据阶段 2 中 UQW1 的结果，留有约 0.02 的余量：
   - **M1：** 单元平均 ≥ +0.05，且至少 6/8 个单元 ≥ +0.03；
   - **M2：** 每个单元 ≥ −0.04；
   - **M3：** 每个单元 ≥ −0.06；
   - **M4：** 至少 7/8 个单元 > 0。
   - 基线口径为 B⁺（含 W1）。
   - 这比最初草案的 M1（+0.05）、M2/M3（−0.05）在 M2 上更严，在 M3 上放宽 0.01。理由：阶段 2 中 M3 的最差值是 −0.041，而 −0.05 只留 0.009 的余量，单个噪声实现的波动就可能超过它。
3. **次要判定或只描述：** E2–E4、速度误差、相干噪声。E4 是已知局限，不作为判定。
4. **阶段 3 数据：** 新模型（新构造类型、新种子），从未参与开发；相干噪声换成横向相关的随机噪声或多次波型。
