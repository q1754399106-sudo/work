## 只描述的项

1. **B = 1 在横向相关噪声上低估约 13–28 倍**（log₂ −3.7 到 −4.8），比阶段 3 C 模型上按中位数 1/snr 比较的约 1/5 更严重；这里是逐像素比值的中位数，两者口径不同。
2. **B = 300 对独立噪声略有高估**（m30 +0.29 到 +0.84，约 1.2–1.8 倍），符合方案预期的单炮信号残留：每炮只有一个符号，同一炮的反射弧不被打乱。B = 8、32 在 m40 上反而比 B = 300 差（D2 m40 B = 32 为 +1.42），中等块长既没有保住横向相关，也没有压住信号残留。
3. **g30 与 m30 几乎相同**（各 B 下差 ≤ 0.14，D4 完全相同）。W_deep 内面波型相干噪声的成像能量很小，真值 1/snr 与 m30 只差 1–3%，所以这一窗口看不出估计对 g30 的影响。
4. 单频值波动大（例如 D1 l30 B = 300 在 10 Hz 为 +4.77、40 Hz 为 −1.68），判据用 10–50 Hz 中位数，不受单频影响。逐频曲线在 json 的 `e_f` 中。

**第二步通过（开发结论）。**按方案，确认需要新建 C5 起的模型，另行冻结方案。

**只描述：**
1. l30 上 UQW1 的分数（5 个 m 平均）从 0.520 升到 0.581，W0、W1 也升约 0.09（0.40 → 0.49–0.50）；PH、IQ、R0 不用噪声估计，不变。B⁺ 在 l30 上多由 PH 决定，所以 d 的改善基本来自 UQW1 本身。
2. LP 在 l30 上变差（0.383 → 0.194）：B = 300 的估计说明 10 Hz 起信噪比就低于 1（真值 1/snr 在 10 Hz 约 2，第一步表中的 `median_true`），按规则截止频率降到 10 Hz。原来 55 Hz 的截止是估计把噪声低估约 20 倍造成的。
3. 独立噪声 m30 上两种 B 几乎相同（第一步中 B = 300 高估 1.2–1.8 倍，对成像影响 ≤ 0.005）；m40 上 D2 由负转正（M1 −0.018 → +0.032）。
4. 阶段 3 记下的局限“横向相关噪声下噪声项失效”在开发数据上被消除：l30 上 Q 准确时 M2 从 −0.03 到 −0.07 变为 −0.010 到 +0.020。
