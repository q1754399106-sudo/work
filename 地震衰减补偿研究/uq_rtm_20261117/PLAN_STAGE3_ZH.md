## 1. 方法（冻结）

**UQW1：** 频率域两程（逆时）偏移，成像条件中逐点施加期望算子

  H = (A + s·P·C + P/snr) / (1 + s·C + 1/snr)

| 量 | 取值 |
|---|---|
| A、C、P | 对 u = 1/c 取对数正态期望，σ = 0.447，41 点 Gauss–Hermite 求积；锚点在地表 |
| s | 70 dB 增益上限对应的值 |
| 两程 t* | 补偿 Q 模型下的程函方程 dT/dε（ε = ±0.5），检波点一支取镜像检波点 |
| 1/snr(x, f) | 两遍扫描：未补偿成像与随机极性成像（种子 20261118）在 ±5 Hz 内求和，400 m 方窗，下限 snr 10⁻³ |

代码：`scripts/migrate2.m`、`est_noise2.m`、`uq_tab.m`、`two_way.m`、`tstar_fields.m`、`helm_op.m`，版本即本方案提交时的版本。

## 4. 判定规则（冻结）

- **指标：** S 的定义与预处理同前；主窗 W_deep 为 x 300–2100 m、z 820–1550 m。
- **单元：** 模型 × 主判定数据集，C1–C4 × {m30, m40}，共 8 个。
- **对每个单元计算**（UQW1 − B⁺）：
  - M1 = m < 1 各档差值的平均；
  - M2 = m = 1 时的差值；
  - M3 = m > 1 各档差值的最小值；
  - M4 = 各档中 UQW1 的最小 S，减去每个可行基线各自的最小 S，再对所有基线取最小。

| 判据 | 内容 |
|---|---|
| **C1** | 8 个单元的 M1 平均 ≥ +0.05，且至少 6 个单元 M1 ≥ +0.03 |
| **C2** | 每个单元 M2 ≥ −0.04 |
| **C3** | 每个单元 M3 ≥ −0.06 |
| **C4** | 至少 7 个单元 M4 > 0 |

**结论规则：**
- C1–C4 全部成立：**确认通过**。
- C1 成立而 C2 或 C3 不成立：主张收窄为“严重过补偿时的稳健方案”，并报告代价。
- C1 不成立：**确认不通过**。

**只描述：** W_body 窗（C1：气烟囱下方 x 1450–1750 m，z 800–1300 m；C2：第二透镜下方 x 1050–1550 m，z 980–1350 m；C3：浅层透镜下方 x 850–1150 m，z 360–750 m；C4：低 Q 层下方 x 300–2100 m，z 1250–1550 m）、UQW0 的同样指标、E2–E4、l30、LP 选出的截止频率。
