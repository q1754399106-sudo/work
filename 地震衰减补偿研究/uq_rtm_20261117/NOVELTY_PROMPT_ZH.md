# 待查新的方法
**名称**：Q 模型不确定时的期望补偿算子（叠后反 Q 与叠前 Q 补偿逆时偏移）

**要解决的问题**：Q 补偿需要 Q 模型，但实际上 Q 往往只知道一个大致范围（误差可达 ×2）。常规稳定化反 Q 用人为指定的增益上限或截止频率来防止放大噪声，这些参数与 Q 准不准无关。Q 估偏小时会过补偿，造成的损害大于欠补偿。

**技术方案**：
1. 设 u 为相对模型 Q 的 1/Q 比例因子，给 u 一个先验：对数正态 ln u ~ N(ln û, σ²)，σ 由 Q 估计方法的误差模型给出（例如 σ = 0.447，对应约 ×2 的不确定度）。
2. 衰减传播算子 G(t, f) = exp[b(f)·Δa(t)·u]，其中 b(f) = −πf + iθ(f)，θ(f) = 2f·ln(f/f_ref)（Kolsky 型频散），Δa(t) 是相对子波窗的累计 t*。
3. 补偿算子取 Wiener 型的期望形式：H(t, f) = S·E[G]* / (S·E|G|² + N)。u 服从高斯分布时有闭式；服从对数正态时用 Gauss–Hermite 求期望。
4. 性质：σ → 0 时严格退化为普通稳定化反 Q；σ > 0 时振幅上自动多出约 exp(−1.5π²f²Δa²σ²) 的因子，相当于一个随深度、随不确定度变窄的时变频带 f_Q(t) ≈ 1/(√1.5·π·Δa(t)·σ)，不需要另设增益上限或截止频率。
5. 由 Jensen 不等式，期望算子对过补偿的惩罚大于欠补偿，用来解释"Q 偏大（补偿偏弱）更安全"的经验现象。
6. **UQ-W（叠后）**：噪声功率 N(t, f) 由数据的道间相干信噪比估计。
7. **CBL（叠后）**：以对数正态先验下的期望损失为目标，加一条约束——在一族 Q 比例剖面（17 个点）上，任何一个剖面的平均后悔都不超过上限（受限贝叶斯，Hodges–Lehmann 类）；先验只在过衰减一侧（u = 2）截断，保留低衰减一侧的尾部。
8. **UQ 逆时偏移（叠前）**：频率域二维逆时偏移，用程函方程算两程 t* 场，在互相关成像条件中逐点乘上上述期望算子；成像域噪声由第一遍随机极性叠加估计。不需要指定增益上限或低通截止频率。

**我认为的创新点**（请逐条判断）：
1. 对 Q（1/Q）的不确定度取期望，得到含频散的闭式（或 Gauss–Hermite）反 Q 算子，σ → 0 时退化为稳定化反 Q。
2. 稳定程度（等效时变频带）由 Q 的不确定度和信噪比共同算出，不再人为指定增益上限或截止频率。
3. 用期望算子的 Jensen 不对称，统一解释"过补偿比欠补偿更伤"和"保守补偿更稳"。
4. 把受限贝叶斯（期望损失＋最坏后悔上限）用于 Q 补偿，并对先验做单侧截断。
5. 在 Q 补偿逆时偏移的成像条件中逐点施加 Q 不确定度期望算子，成像域噪声由两遍扫描估计。
