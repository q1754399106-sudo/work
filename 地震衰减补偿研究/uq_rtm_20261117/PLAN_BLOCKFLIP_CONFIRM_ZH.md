# 确认方案：分块极性估噪（B = 300）在新模型 C5–C8 上（2026-11-22，冻结，任何新模型运行前提交）

## 1. 依据

开发集 D1–D4 上第一步（估计精度）与第二步（成像）都通过（`RESULTS_BLOCKFLIP_ZH.md`）：横向相关噪声 l30 上 ΔM2 平均 +0.060、ΔM1 +0.073；独立噪声 m30、m40 不受影响。B\* = 300 由开发集选定，这里不再改。

## 2. 新模型（从未用于任何开发或确认）

在 `make_model.m` 中新增，几何与 D、C1–C4 都不同：

| 模型 | 结构 | 宏观层 Q | 异常体 |
|---|---|---|---|
| C5 | 倾斜层 + 正断层 | 55 / 45 / 75 / 100 | 两个低 Q 透镜（Q 20 浅、24 深） |
| C6 | 背斜 | 65 / 50 / 70 / 100 | 横向 Q 梯度（左 ×1.5 → 右 ×0.7） |
| C7 | 浅部薄低 Q 层 | 25 / 65 / 75 / 100 / 120 | 气烟囱（Q 24） |
| C8 | 高低 Q 交替 | 95 / 40 / 100 / 35 / 110 | 深部透镜（Q 22） |

body 窗写在 `s2_cfg.m`（只描述）。种子 2026112201–2026112231。

## 3. 流程（与开发完全相同，代码在运行前提交）

1. `fd_shots`（51 炮）→ `prep_data`：m30、m40 与阶段 3 同配方；l30 为阶段 3 配方（`prep_data.m` 中 C 模型的横向相关噪声，−30 dB，σ = 5 道）。
2. `est_block(name, [], '', [1 300])`：只算 B = 1 和 B = 300；B = 300 的符号种子规则与开发相同（`P.flip_seed + 300`）。
3. `run_block2(name, 1)`、`run_block2(name, 300)`：E1，m = 0.5、0.7、1、1.4、2，方法与开发相同。
4. `judge_block2.py C5 C6 C7 C8` → `analysis/blockflip_C.json`；`score_block_c.m` 给出估计精度（只描述）。

## 4. 判定（门槛与开发第二步相同，不改）

- **K1**：l30 上 4 个模型 ΔM2 平均 ≥ 0.03，且 ΔM1 平均 ≥ 0.03（Δ 为 [B = 300] − [B = 1] 的 d 指标，d = UQW1 − B⁺）。
- **K2**：m30、m40 分别算，ΔM1 平均 ≥ −0.02；B = 300 下每个（模型 × m30/m40）单元 M2 ≥ −0.04、M3 ≥ −0.06。
- 两条都成立 → **确认**：UQ-RTM 的默认噪声估计改为 B = 300，阶段 3 的局限“横向相关噪声下噪声项失效”在合成数据上解除。
- K1 成立、K2 不成立 → 只对横向相关噪声推荐，独立噪声保留 B = 1。
- K1 不成立 → 不确认，照实报告。

**预测：**按开发结果，l30 上 ΔM2 约 +0.04 到 +0.08、ΔM1 约 +0.05 到 +0.10；m30、m40 的变化在 ±0.02 以内。

## 5. 只描述

估计精度 e（B = 1、300）；UQW1 与 B⁺ 的绝对分数；LP 截止频率；body 窗分数。实测上的效果另议：实测噪声在炮间是否独立无法核实（`direction_theory_20261121/RESULTS_FIELDNOISE_ZH.md`）。

## 6. 运行

单个 MATLAB 进程串行（同机内存约 14 GB，与其他会话共用）；每步失败后等 10 分钟从断点续跑，最多重试 12 次。正演约 1 小时/模型，估噪 2–6 小时/模型，成像 2 × 1.5–4 小时/模型，合计约 1.5–3 天。
