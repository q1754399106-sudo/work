## 2. 随机极性噪声估计同样失效

- 无噪声数据 att 上，1/snr 中位数在 25 Hz 以上多数频率达到上限 1000：随机极性成像的功率不小于正常成像。
- 原因与奇偶炮估计相同：**单个频率的成像没有聚焦**。深度方向的聚焦来自对频率求和，所以单频时相干叠加与非相干叠加的功率相当。
- 第 1 轮诊断中的真成像信噪比是用“含噪成像减无噪成像”算的，有定义，但无法从数据单频估出。
- **结论：** 成像域噪声项必须用频带内求和后的成像来估计，这需要先扫描一遍（未补偿、正常与随机极性两套）存下频带成像，第二遍再补偿。

## 4. 小结与待定

1. Q 不确定度部分（σ = 0.447）对严重过补偿（m ≤ 0.6）的保护很强，这一点在三种噪声下都成立。代价是 Q 准确与偏大时低 0.03–0.08，比叠后大。可能的原因：锚点在地表，整个 t* 都被视为不确定。
2. 噪声项在偏移中需要频带成像估计。两种单频估计（奇偶炮、随机极性）在无噪声数据上都失效。
3. 噪声主导时，只校正相位就是很强的基线，阶段 2 的判定必须包含它。
4. 路线：按事先规则是 C，但比较受第 2 点干扰。**请用户决定：**
   - (a) 接受 C；
   - (b) 先做两遍扫描的频带噪声估计，再重做 A 对 C 的比较（约 4–5 小时）；
   - (c) 路线 A 不用噪声项（UQIQ 或 γ = 1 形式），改为与 PH 比较。
