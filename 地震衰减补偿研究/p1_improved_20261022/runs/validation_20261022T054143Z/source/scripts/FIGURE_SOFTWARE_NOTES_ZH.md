# 图形软件与方法说明

图形脚本 `plot_validation.py` 使用本项目独立 Python 环境，不更改用户全局 Python。确切依赖见 `figure_requirements.lock.txt`。环境目录本身不纳入数值源码包；依赖记录和可复现脚本会纳入。

输出面向一般研究报告，尚未指定投稿期刊，不宣称满足某一期刊的格式或无障碍认证。图形生成后还必须检查实际 PNG、PDF 的标签、裁切、图例及数据一致性。

图形流程参考本地 scientific-visualization 技能的证据保留、配对不确定性及固定示例展示要求。技能库文献已于 2026-10-22 核对 arXiv 记录，记录最新修订为 2026-09-02；该文献仅用于说明辅助软件流程，不作为本研究方法有效性的证据：

Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026). *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*. https://doi.org/10.48550/arXiv.2609.00065
