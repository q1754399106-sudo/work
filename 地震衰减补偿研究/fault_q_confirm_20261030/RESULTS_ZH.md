# 实验 15 结果：断层与复杂 Q 下的确认检验

方案 `PLAN_ZH.md` 在开跑前提交（b79fc73）。检验数据为新半合成数据中封存的构造 B、C，共 24 个数据集：Z 组 12 个、孪生 Y 组 12 个。全部按方案运行，没有改参数、没有剔除数据集，24 个数据集都没有报错。单个数据集约 53 分钟（12 进程并行）。

## 判定（Z 组 12 个数据集，90% t 区间）

| 判定 | 比较 | 平均差 | 90% 区间 | 正数个数 | 构造 B / C | 结论 |
|---|---|---|---|---|---|---|
| **H1 调小 a** | QSCa_tuned − QSCa | +0.123 | [0.066, 0.180] | 12/12 | +0.125 / +0.121 | **支持** |
| **H2 SR 型补偿胜过原流程** | SCa_SR − QSCa | +0.128 | [0.059, 0.197] | 10/12 | +0.125 / +0.131 | **支持** |
| | IQ70 − QSCa | +0.237 | [0.165, 0.309] | 12/12 | +0.184 / +0.290 | |
| **H3 补偿有用** | IQ70 − Input | +0.747 | [0.674, 0.819] | 12/12 | | **支持** |
| | SCa_SR − Input | +0.638 | [0.557, 0.719] | 12/12 | | |
| **H4 压缩外推** | 1/c_QS = A·u_QS + C | A = 0.364，C = 0.647 | A：[0.277, 0.427] | | | **支持** |
| **H5 SR 更准** | \|e_SR\| − \|e_QS\|（对 c_eff_cum） | −0.030 | [−0.108, 0.049] | 5/12 | | 无法判定 |

H1–H4 在 Q 非比例、横向变化、有断层和气藏的未见数据上都得到确认，没有相反结论。

- **H1**：用户流程（QScan＋SC-a）把 a 从 0.125 调到 2⁻¹³，S 平均提高 0.123，12 个数据集全部提高。幅度介于实验 12 事后补跑（+0.179）和实验 13 实测（+0.063）之间。
- **H4**：理论预测 A = 1 − κ = 0.325、截距 C = κ + β ≈ 0.675（β = 0 时）。实测 A = 0.364、C = 0.647，Y 组 A = 0.335、C = 0.675。理论在比例 Q 上推出，在 Q 剖面与模型不同形时，用理论加权的有效 Q（u_QS）仍能预测 QScan 的选择。
  - 注意：QScan 只选到了 3 个网格值（1/c = 0.877、1.0、1.14，见 `figures/compression.png`）。斜率估计受网格量化限制，区间宽度反映的是这个限制。选择从未落在网格边界上。
- **H5**：|误差| 的平均值 SR 为 0.123，QScan 为 0.152；对 c_eff_dif 分别为 0.105、0.152。方向与实验 14 相同（SR 更准），但差别不显著。
  - SR 对噪声实现很敏感。构造 B 换成第二条噪声线（r = 1）时，c₀ = 1.05 的 c_SR 从 1.10 变成 1.35，c₀ = 1.4 的从 1.48 变成 1.91。
  - QScan 的选择较少随噪声实现变化（Z 组 6 对中 4 对相同），这是它在 H5 上不吃亏的原因。

## 描述性结果

**各方法平均 S**（`figures/scores.png`）：

| 组 | Input | IQ30 | IQ70 | SCa_SR | VDB | QSCa | QSCa_tuned | SCa_oracle | IQ70_oracle |
|---|---|---|---|---|---|---|---|---|---|
| Z | 0.112 | 0.676 | **0.859** | 0.750 | 0.779 | 0.622 | 0.745 | 0.765 | 0.890 |
| Y | 0.126 | 0.690 | **0.875** | 0.762 | 0.775 | 0.658 | 0.758 | 0.787 | 0.899 |

1. **70 dB 反 Q 明显领先 SC-a。** IQ70 − SCa_SR = +0.109，90% 区间 [0.062, 0.155]，11/12 为正（构造 B +0.058、C +0.159）。实验 12 中两者只差 0.024（0.888 对 0.864）。
   - 这个差距不是 Q 估得不准造成的：用真值有效 Q 的 SCa_oracle 也只有 0.765。
   - 也不是 Q 复杂度造成的：Y 组差距同样是 0.114。
   - 差距集中在构造 C（6 个数据集 SC-a 都只有 0.71–0.84，IQ70 为 0.89–0.96）和构造 B 的第二条噪声线。原因可能是 SC-a 在本数据的反射系数或断层上的稀疏假设，也可能是噪声线的特性，本实验没有分开。
   - 冒烟测试用的开发构造 A 上两者相同（0.902、0.906）。
2. **Q 复杂度本身的代价小。** Z − Y 的 S 差在 −0.035 到 +0.004 之间。用户原流程 QSCa 代价最大（−0.035，区间 [−0.056, −0.015]），调小 a 后只剩 −0.012。QScan 在 Z、Y 上的选择 12 对全部相同；理论预测的选择差为 −0.020 到 +0.009，远小于网格步长（0.09–0.16），与方案的判断一致。
3. **气藏下方损失集中。** 透镜下方 0.05–0.40 s 的相关（Z 组）：
   - IQ70 为 0.715，孪生 Y 中同一位置为 0.867，差 −0.15；
   - VDB 差 −0.13，SCa_SR 差 −0.08，QSCa_tuned 差 −0.05；
   - 透镜旁的道上，IQ70 的 Z、Y 都在 0.87–0.88。
   单一 Q 无法补偿局部强衰减；增益上限越高的方法在阴影区丢得越多，但仍然高于其他方法或与之相当。
4. **断层附近没有明显额外损失。** 断面 3 道以内与 15 道以外的相关差在 ±0.06 内。对 IQ70 来说，断面附近反而略高（0.63 对 0.57）。补偿是逐道进行的，断层只通过子波和 SC-a 的横向估计间接起作用。
5. **用真值 Q 能多得的不多。** 在 Z 组上，SCa_oracle 比 SCa_SR 高 0.015（区间 [−0.000, 0.030]），IQ70_oracle 比 IQ70 高 0.031（区间 [−0.007, 0.068]）。提高 Q 估计精度的空间小于换方法或调参数（0.11–0.24）的空间，这与实验 12 "参数比 Q 准确度更重要"的结论一致。

## 结论

- 对用户流程的建议在未见的复杂 Q 数据上成立：至少把 SC-a 的 a 调小（+0.12）；更好的是用 SR 估 Q 后做 70 dB 稳定化反 Q（比原流程 +0.24，比调小 a 的流程 +0.11）。
- 锚定理论的压缩斜率 1 − κ 在非比例、横向变化的 Q 上也成立（A = 0.36，理论 0.33）。它不依赖"真 Q 与模型 Q 同形"的假设。
- 新发现：本数据上 SC-a 的上限（oracle 0.77）明显低于反 Q（0.89），实验 12 中的"两者相当"不能推广。原因尚未确定。
- SR 是否比 QScan 更准，在这里无法判定。
