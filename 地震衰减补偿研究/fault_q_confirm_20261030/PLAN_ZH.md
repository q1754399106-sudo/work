# 实验 15 方案：断层与复杂 Q 下的确认检验

2026-10-30 写成，开跑前提交。检验数据是新半合成数据（`semisynth_fault_q_20261030`，提交 0de5325）中封存的构造 B、C；冻结前没有在 B、C 上运行任何补偿或选 Q 方法。开发构造 A 只用来做冒烟测试（`ZA_c1.05_r0`，计时和代码检查）。

## 1. 要回答的问题

实验 12、13 和锚定理论都建立在"真 Q = c × 模型 Q、横向不变、无断层"的数据上，并反复使用同一套生成配方。本实验在 Q 非比例、横向变化、有断层和气藏的未见数据上确认：

1. 用户流程（QScan＋SC-a）把稀疏权重 a 从 0.125 调到 2⁻¹³ 的收益（实验 12 事后补跑 +0.179，实验 13 实测 +0.063，6/8）是否仍然成立；
2. 以 SR 估 Q 的补偿（70 dB 反 Q、小 a 的 SC-a）是否胜过用户原流程；
3. 补偿是否仍比不补偿好；
4. 锚定理论的压缩：真 Q 不再是模型 Q 的倍数时，QScan 对"理论加权有效 Q"的 1/c 斜率是否仍约为 1 − κ；
5. SR 与 QScan 谁更接近补偿所需的有效 Q。

孪生 Y 组（同断层、同噪声、旧配方的横向不变 Q）用来描述 Q 复杂度本身的代价。

**为什么不把 Z−Y 选择差作为理论主检验**：冻结前只用真值算过理论预测的 Z−Y 差（1/c 空间）：B、C 只有 −0.020 到 +0.009，A 为 0.05–0.08，而 QScan 网格一步为 0.09–0.16，B、C 上无法分辨，因此只作描述。

## 3. 方法（参数全部来自实验 12 的 `dev_selection.json` 与实验 13，不重新调参）

| 名称 | 内容 |
|---|---|
| Input | 不补偿 |
| IQ30 / IQ70 | 稳定化反 Q（振幅与频散，`lib12.iq`），增益上限 30 / 70 dB，Q = 模型 Q × c_SR |
| SCa_SR | SC-a，a = 2⁻¹³，mu_relative = 10，Q × c_SR（实验 12 的 B2） |

| SCa_oracle / IQ70_oracle | 用真值的 c_eff_cum（最好的单一比例 Q），只作描述 |

c_SR 由 `sq.estimate`（实验 10，nboot 0）给出；子波、σ、K 由 `sc11.prepare_sc` 估计。程序：`scripts/lib15.py`、`scripts/run15.py`、`scripts/analyze15.py`，与本方案一起提交。

## 4. 指标

- **S** = (M1 + M1_lag)/2（实验 12）：2.30–2.80 s 各道输出与理想目标相关的中位数，M1_lag 允许 ±20 ms 整体时移。
- 局部（描述）：2.0–3.0 s 内断面 3 道以内 / 15 道以外的样点相关；气藏底下 0.05–0.40 s 的透镜道 / 透镜外的道（Y 用 Z 孪生的透镜位置）。
- Q 估计：e = ln(c_est / c_eff_cum)；另报对 c_eff_dif 的误差。
- 理论：u_QS = Σa(T − T₁.₄)/Σa(a − a₁.₄)，T 为各道平均真 t*，a 为模型 Q 的累积 t*，求和在 1.2–3.0 s；比例 Q 时 u_QS = 1/c。κ = a₁.₄Σa/Σa² = 0.675。

## 5. 判定（Z 组 12 个数据集）

配对差的 90% t 区间（自由度 11）；"支持"还要求 B、C 两个构造各自的平均差同号。

| 判定 | 比较 | 支持 | 相反 |
|---|---|---|---|
| **H1 调小 a** | S(QSCa_tuned) − S(QSCa) | 区间下限 > 0，且两构造均值 > 0 | 区间上限 < 0 |
| **H2 SR 型补偿胜过原流程** | S(SCa_SR) − S(QSCa)；S(IQ70) − S(QSCa) | 两个区间下限都 > 0，且两构造均值都 > 0 | 任一区间上限 < 0 |
| **H3 补偿有用** | S(IQ70) − S(Input)；S(SCa_SR) − S(Input) | 两个区间下限都 > 0 | 任一区间上限 < 0 |
| **H4 压缩外推** | 拟合 1/c_QS = A·u_QS + C，按数据集自助 2000 次（种子 20261030） | A 在 0.33 ± 0.2 内，且 90% 区间上限 < 0.75 | 区间下限 > 0.75 |
| **H5 SR 更准** | \|e_SR\| − \|e_QS\| | 区间上限 < 0 | 区间下限 > 0 |

其余为"无法判定"。另报（描述）：IQ70 − SCa_SR 的比较；Y 组的同样数字；各方法的 Z−Y 代价 S(Y) − S(Z)；oracle 与 SR 的差距；局部窗口；QScan 选在网格边上的次数；理论预测的 Z−Y 选择差与实测差。

## 6. 解释规则

- H1 支持：调小 a 的收益不依赖旧配方，可以作为对用户流程的稳定建议。
- H2 支持：SR 估 Q＋调好增益的补偿在复杂 Q 下仍优于原流程；相反则推荐需要按数据类型区分。
- H4 支持：压缩来自子波锚定的几何，不依赖 Q 剖面与模型同形；相反说明理论只在比例 Q 下成立。
- H5：区分"SR 更准"在复杂 Q 下是否仍成立。
