# 世界真值修正后的 B0：未见新模型确认（冻结方案）

登记：2026-10-24，开发选择之后、新模型生成之前。开发声明：[DEV_PLAN_ZH.md](DEV_PLAN_ZH.md)；开发结果：`analysis/dev_selection.json`。

## 开发结论（已见数据，44 个 Q0 道集）

- 原 B0 重算后与上一轮封存值逐位一致。
- 规则 1（阈值 0 下 F2/Moderate 三个都判“更好”，F1/Moderate 三个都判“更差”）三个候选都不满足：
  - B0M 在 F2/Moderate 为 +0.013、−0.003、+0.011；
  - B0C 为 +0.014、−0.010、+0.023。
- 按补充规则 5，三个候选在明确场景上都完全可分，相对间隔为 B0 0.51、B0M 0.92、B0C 0.83。
- **选定 B0M（自助均值作世界真值），阈值 τ = 0.17076479629367916。** τ 是“更好”道集最大值 0.0128 与“更差”道集最小值 0.3287 的中点。
- 阈值 0 下明确场景正确率：B0 0.914、B0M 0.943、B0C 0.943。

## 冻结的诊断

- 先在原 B0 世界（真值为观测上的 FullCalRefit 输出）做 K=6 次模拟，取 c=1 输出的平均 m*。
- 再以 m* 为真值、以所用 Q 正演、加同一噪声模型，重新模拟 K=6 次，比较 c=1 与 c=ĉ 的 MSE*。
- **ΔMSE*/MSE* > τ 判 QScan 更差。**
- 噪声模型、K、种子规则（1.4e9 + 1000·道集编号）、估计量与上一轮相同。代码：`scripts/diagnose2.m`、`bootstrap_world2.m`。
- 同时报告、不作门槛：B0、B0M、B0C 在阈值 0 和各自开发阈值下的结果（B0 0.163、B0C 0.135）；只看方差 V；第三轮门限 G。

## 预先判定

- **C1**：明确场景道集上，冻结规则的符号正确率 ≥ 0.80。
- **C2**：在同一批道集上，冻结规则的正确率不低于原 B0（阈值 0）、V 和 G。
- 描述：边界场景正确率；场景均值与期望 ΔMSE 的 Spearman；各变体对照。
- 若没有明确场景：记为不可检验。

## 结论规则

- C1 与 C2 都通过：所用 Q 可信时，“自助均值作世界真值 + 开发阈值”这一无真值检查在未见模型上得到确认。Q 有误时的问题不在本轮范围内。
- 否则：不确认，分析失败原因。

## 不做

- 看到新模型的任何结果后，不改变量、阈值、K、噪声窗口或种子。
- 不改 FullCalRefit、QScan。
- 新模型只用于本次确认；用过之后不再称为未见数据。
