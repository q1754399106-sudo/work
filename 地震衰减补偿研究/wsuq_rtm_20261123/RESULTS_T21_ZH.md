  1. **正面验证**：在真实程函（Volve F-5 124 炮、D2 51 炮）与全波动方程 2D 强气烟囱 RTM 上，`WS_UQ1` 与 `WS_VA_UQ1` 在**高频相关 `E1_HF` 与输出图像信噪比 `SNR_img_dB`** 上均严格优于老算子 `UQW1_old` / `VA_old`（2D 气烟囱强噪档平均 `+0.57 dB`，过补偿 $m=0.5$ 处达 **`+0.95 dB`**；真实 Volve F-5 3 dB 档上 MMSE 版 `WS_UQ0` 高频 `SNR_HF` 超 `UQW1_old` **`+1.69 dB`**、超 `R0` **`+3.54 dB`**，`E1_HF` 提升 `+0.063`）；
  2. **核心负向物理发现（为何三项门控未通过）**：
     - 在程函基准上，老算子 `UQW1_old` 在高噪高频段已因贝叶斯收缩退化为等权纯相位叠加（$|H_s|\approx 1$）而非 `IQ70_old` 的 $e^{+\pi f t_s^*}$，因此非阻尼版 `WS_UQ1` ($\gamma=1$) 相对 `UQW1_old` 的真实优势约 $\sqrt{R_{\text{CS}}}$（`+0.03 ~ +0.29 dB`），低于预注册 `+1.0 dB` 门槛（而相对 `IQ70_old` 优势高达 **`+11.6 ~ +22.1 dB`**）；
     - 在**全波动方程 2D 气烟囱 RTM** 上，尽管 `WS_UQ1` 通过了 `SNR_img_dB`（`+0.57 dB >= +0.5 dB`）与 `E1_HF`（`+0.0042 > 0`），但**宽频 `E1` 下降 `-0.026`、烟囱内外振幅比误差 `E_amp` 从 `0.264` 恶化至 `0.352`**。物理根源是 **2D 驻相镜面孔径冲突**：烟囱正下方平层/背斜反射面的有效驻相信号恰恰来自穿烟囱的高 $t_s^*$ 近炮，而低 $t_s^*$ 远翼炮虽有球面波源照明 $|U_s|^2$ 却处于非镜面画弧区；盲目按 $e^{-\pi f t_s^*}$ 全局跨炮压权在提升信噪比的同时抑制了烟囱内部有效镜面炮贡献。

## 3. 机制判决与下一代算法指向

1. **三项预注册门控结果**：
   - `T21_Eik_Volve`: **FAIL**（`WS_UQ1` 对 `UQW1_old` 的 `E1_HF` 为正 `+0.0086`，但 `d_SNR = +0.03 dB < +1.0 dB`；仅 MMSE 版 `WS_UQ0` 达到 `+0.88 dB` 全带 / `+1.69 dB` 高频）；
   - `T21_RTM2D_Gain`: **FAIL**（`d_E1_HF = +0.0042 > 0` 与 `d_SNR_img = +0.57 dB >= +0.5 dB` 两项子条件均通过，但宽频 `d_E1(m=0.5) = -0.0264 < 0` 未过）；
   - `T21_RTM2D_NoHarm`: **FAIL**（`clean m=1.0` 上 `d_E1 = -0.0263 < -0.01`）。
2. **重要理论结论**：多炮匹配滤波（`WS-UQ1` / `WS-VA-UQ1`）在真实 2D 全波 RTM 中确能打破单道零和壁垒、带来 **`+0.5 ~ +1.05 dB` 图像域信噪比净增益与高频保真度提升**；但**不可直接在全炮孔径上裸用**，因为烟囱下方有效镜面驻相炮恰是高 $t_s^*$ 炮，全局 $e^{-\pi f t_s^*}$ 压权会相对放大非镜面翼炮的画弧并削弱烟囱内部振幅恢复（`E_amp: 0.264 -> 0.352`）。后续若推进，必须在**角度域共成像点道集（ADCIG）或倾角滤波驻相菲涅耳带内**施加匹配滤波，而非跨非镜面全炮孔径。
