# 推导：QScan lasso 目标对 v、v_a 的精确曲率

符号沿用 `qscan_anchor_theory_20261030/PAPER_DRAFT_ZH.md`：v = 1/c 为扫描参数，v_a 为锚点，a(t) 为模型 Q 下的累积 t*，a₀ = a(1.4 s)。代码实现在 `scripts/core.py`。

## 1. 扫描目标的等价写法

扫描对每个 v 解（逐道独立，μ_rel = 0）

  min_x ½‖d_j − Bx‖² + Σ_k pen_kj|x_k|，B = B̃/scale，pen_kj = λ√(2ln n)·σ_j·median(scale)/scale_k，

目标 J = Σ_j F_j/σ_j²（有效道）。令 y_k = x_k/scale_k，则 Bx = B̃y，pen_kj|x_k| = μσ_j|y_k|，

  **μ = λ√(2ln n)·median_k‖B̃_k‖。**

所以扫描等价于在**未归一化**字典 B̃ = G·W_in 上用单一权重 μσ_j 的 L1。归一化没有消失：它全部集中到标量 μ 上，而 μ 由列范数中位数所在的那一列决定。μ 随 v（传播衰减）和 v_a（子波高频提升）变化。子波整体幅度在 μ 重算时严格抵消。

## 2. 固定活跃集上的值函数与包络定理

活跃集 A、符号 s 固定时 y_A = G_A⁻¹c，c = B̃_Aᵀd − μσs，G_A = B̃_AᵀB̃_A，

  F = ½‖d‖² − ½cᵀG_A⁻¹c。

对任一字典参数 p（μ 固定），记 r = d − B̃_A y_A：

- 一阶（包络定理）：F_p = −rᵀ(∂_pB̃)y。
- 二阶：F_pp = ‖(∂_pB̃)y‖² − rᵀ(∂²_pB̃)y − hᵀG_A⁻¹h，h = B̃_Aᵀ(∂_pB̃)y − (∂_pB̃)_Aᵀr。

前两项是“直接项”：系数不动，只有活跃原子的能量进入（用户设想的 φ₂ ∝ 活跃能量对应这里）。第三项是**耦合项**，恒 ≤ 0：活跃系数重拟合，吸收掉一部分扰动。它就是用户提到的 −(∂D_A r)ᵀ(D_AᵀD_A)⁻¹(…) 修正。

## 3. 按时刻的参数 θ 与解析 Hessian

令传播矩阵 G 的第 m 列为 irfft(exp[b(f)(a_m v + θ_m)]·移位_m)，B̃ = G·W_in。则 ∂/∂v = Σ_m a_m ∂/∂θ_m（μ 固定时严格）。记 G₁、G₂ 为各列对 θ 的一阶、二阶导，z = W_in[:,A]y_A（子波卷积后、衰减前的波场），则

  H = Σ_j w_j [ Z(G₁ᵀG₁)Z − diag(z∘G₂ᵀr) − H_cᵀG_A⁻¹H_c ]，H_c = (B̃_AᵀG₁)Z − W_in[:,A]ᵀdiag(G₁ᵀr)，

Z = diag(z)，w_j = 1/σ_j²。实现在开发种子上与闭式有限差分逐方向相符（< 0.1%）。

## 4. 选择斜率

v_sel 满足 J_v(v_sel, v_a) = 0，所以

  **α ≡ ∂v_sel/∂v_a = −J_{v v_a}/J_vv。**

两锚点实验测的就是它（有限差分版）。若锚点严格等价于“所有原子均匀倾斜 −a₀Δv_a”（δ 模型），则 J_{v v_a} = −a₀·aᵀH1，α = a₀·aᵀH1/aᵀHa；H 取对角就回到论文的 α = a₀Σφ₂a/Σφ₂a²。所以“精确 Hessian”在 δ 模型下与两锚点量同义；能检验的是 (a) δ 模型是否成立，(b) H 的哪一部分决定 α。

δ 模型有两处近似：锚点子波是零相位，只改振幅 e^{πfa₀Δv_a}，而 θ 同时改振幅和频散相位；子波在 W_in 中、衰减在 G 中，非平稳时两者不严格交换。

## 5. 加上 μ(v, v_a)：三块分解

J(v, v_a) = J̃(v, v_a, μ(v, v_a))，J̃ 为 μ 固定的值函数。链式法则：

- J_vv = J̃_vv + 2J̃_vμ μ_v + (J̃_μμ μ_v² + J̃_μ μ_vv)
- J_{v v_a} = J̃_{v v_a} + (J̃_vμ μ_{v_a} + J̃_{v_a μ} μ_v) + (J̃_μμ μ_v μ_{v_a} + J̃_μ μ_{v v_a})

依次记为 θθ、θμ、μμ 三块，各块的曲率 C 与“分子” N = −J_{v v_a} 分量，α = ΣN/ΣC。J̃_μ = Σ_j ‖y_j‖₁/σ_j > 0（包络定理）。

**μμ 块的 α 是 a₀/a_*。** 列 k* 的范数 ‖B̃_{k*}‖ = ‖G·W_in e_{k*}‖ 近似只依赖于该列附近的衰减 a_* v 与子波的高频提升 a₀v_a，且后者以 e^{−πf(a_* v − a₀v_a)} 的形式组合，所以 μ = g(a_* v − a₀v_a)。于是 μ_v = a_*g′、μ_{v_a} = −a₀g′、μ_vv = a_*²g″、μ_{v v_a} = −a₀a_*g″，μμ 块

  N/C = a₀a_*(J̃_μμ g′² + J̃_μ g″) / a_*²(J̃_μμ g′² + J̃_μ g″) = **a₀/a_***，

与 g、J̃_μ、J̃_μμ 都无关。median 列在分析窗中点附近（列范数随深度单调减小），a_* ≈ a(t_mid)。

所以：若 μμ 块在曲率中占主导，α ≈ a₀/a(t_mid)，与 φ₂(t) 的分布基本无关；θθ、θμ 两块给出与数据拟合有关的修正。均匀公式 a₀⟨a⟩/⟨a²⟩ 在 a(t) 近线性时（r ≈ 1）与 a₀/a(t_mid) 相差很小，在 a(t) 下凸（r > 1，深层强吸收）时 ⟨a²⟩/⟨a⟩ 被拉向深处、a₀⟨a⟩/⟨a²⟩ 变小，而 a₀/a(t_mid) 不受影响——这正是 D、X2 上均匀公式低估、实测仍在 0.6 附近的形态。以上解释是在开发种子上看出、在本方案第 3 节检验的机制，其定量形式 a₀/a(t_med) 是事后的。

## 6. (|y|−λ)₊² 与能量包络

列近似正交时 lasso 解是软阈值 x_k = sign(y_k)(|y_k| − pen_k)₊，y_k = b_kᵀd，所以 (|y|−λ)₊² ≈ x_k²，即 11-19 的能量包络。按第 2 节，x² 只对应直接项的对角部分；它忽略了耦合项（活跃系数重拟合）和 μ 项，因此不是曲率。
