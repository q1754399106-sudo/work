## 0. 第 0 步核对：哪些已经做过

1. **(|y|−λ)₊² 权重与已测的能量包络实质相同。** 对列归一化字典，单道 lasso 在列近似正交时的解是软阈值 x_k = S(b_kᵀd, pen_k)，所以 (|y|−λ)₊² 就是 x_k²。11-19 `anchor_active_curv_20261119` 已用锚点解的 x² 包络（0.1 s 平滑）在同一 12 个剖面上算过：D 从 −0.304 改到 +0.101，但 r ≤ 1 的 7 个剖面全部高估 +0.07~+0.27，D2、X1、X3 变差。非零密度（N1）也已算过（全体约 +0.05 偏高）。**结论已知，不再作为判定对象**；本次只在同一批解上顺带算出 (|y|−pen)₊²（y = b_kᵀd，不经过求解），作为“近似相同”的复核。
2. **完整二次型 a₀·aᵀH1/aᵀHa 等于局部两锚点斜率。** `RESULTS_SEGPHI_ZH.md` 已指出：一般形式 α = a₀·aᵀH1/aᵀHa 的分子就是两锚点实验测的量，所以“精确 Hessian 预测 κ”在 δ 模型严格成立时是同义反复，不是预测。本次的新内容不是这个公式，而是：
   - 把 H 在**固定活跃集**上解析写出（包络定理二阶项，含 D_A 子矩阵耦合修正），分成“直接项”（只含活跃能量）与“耦合项”（活跃系数重拟合），看能量型权重为什么偏浅；
   - 检查 δ 模型本身（锚点等价于对所有原子的均匀谱倾斜）是否成立；
   - 检查 lasso 权重 pen_k ∝ median(scale)/scale_k 中 **median(scale) 随 v、v_a 变化**这一项。分段扰动（segphi）与逐时刻拆分都把它混在 J 里，没有单独看过。
3. **开发种子 9940（D 剖面，c = 1）上的实现检查（本方案写作前已运行，不进任何表）**：解析 θ-Hessian 与闭式有限差分相差 < 0.1%；重解有限差分 α_R = 0.520（h = 0.03、0.05、0.10 一致到 0.01），固定活跃集闭式 α_F = 0.529；该种子两锚点（0.9/1.1）实测 0.536（`PAPER_DRAFT_ZH.md` 5.6）。L1 权重固定时 α = 0.719，δ 模型 H 给 0.828，只倾斜振幅（锚点子波是零相位）给 0.708。曲率分解中 μ 项最大，其 α 等于 a₀/a(t_med) = 0.581（t_med 为列范数中位数所在原子，2.10 s）。
4. **事后公式声明。** 看到第 3 条后，我用 `PAPER_DRAFT_ZH.md` 表 1 已发表的 K 算了 a₀/a(t_med)（t_med = 2.10 s，分析窗中点），12 个剖面误差 −0.051 到 +0.052（均匀公式最大 0.304）。这是在**用过多次的数据**上、看过结果后挑出的公式，**只能叫事后**，本次不对它下任何确认结论；确认方案见第 5 节。

## 1. 问题

在每个数据集的选择点（锚点 c_a = 1，v₀ = 原扫描的抛物线顶点）上：

1. 用有限差分算真实 J(v, v_a) 的 J_vv、J_{v v_a}，得局部斜率 α_R = −J_{v v_a}/J_vv（“真值”）；
2. 推导并计算固定活跃集上的精确曲率，与 α_R 对比；按深度分解；
3. 比较四种预测：均匀权重、能量包络、(|y|−λ)₊²、精确活跃集 Hessian（δ 模型 a₀·aᵀH1/aᵀHa），找出 r ≤ 1 高估的机制。

## 2. 计算（`scripts/run.py`，每个数据集一次，写死）

- 数据：与 11-19 相同的 100 个数据集（基准 10、S/D/D2/M 各 12、R1–R4/X1–X3 各 6），按原配方重新生成；不含截短窗。
- v₀：基准取 `results/<id>__a1.0.json` 的 λ = 1/2 目标值的网格最小及相邻两点抛物线顶点（与 `qprofile.py` 规则相同），其余取 `results7/10/26` 的 v_sel。
- **R（真值）**：重解 lasso（热启动自 v₀ 处的解，KKT 容差 1e-3），步长 h = 0.05：J(v₀±h, 1)、J(v₀±h, 1±h)。
- **F（固定活跃集闭式）**：在 v₀ 处的解上取活跃集与符号，闭式 J_A = Σ_j [½‖d‖² − ½cᵀ(B̃_AᵀB̃_A)⁻¹c]/σ_j²，步长 3×10⁻³。L1 权重 μ = λ√(2ln n)·median‖B̃_k‖ 四种处理：
  - pipe：μ 随字典重算（与扫描相同）；
  - fix：μ 固定为 μ₀，锚点方向用实际子波变化；
  - fix_theta：μ 固定，锚点方向换成 δ 模型的“所有原子均匀倾斜（振幅＋相位）”，应与解析 H 的 α_H 相同（实现校验）；
  - fix_amp：μ 固定，均匀倾斜只作用于振幅；
  - **干预**：μ 的参考列换成列范数第 25、75 百分位（乘常数使 v₀ 处 μ 不变，解不变，只改变 μ 随 v、v_a 的变化）。
  - μ 的偏导 J_μ、J_μμ、J_vμ、J_{v_a}μ 与 μ(v, v_a) 的导数，用于把 J_vv、J_{v v_a} 精确分成 θθ、θμ、μμ 三块。
- **H（解析 θ-Hessian，μ 固定）**：θ_m 为传播列 m 的附加 t*。H = Σ_j w_j[Z(G₁ᵀG₁)Z − diag(z∘G₂ᵀr) − H_cᵀ(B̃_AᵀB̃_A)⁻¹H_c]；直接项 H_d = 前两项。记录 α_H、α_Hd、对角近似 α_diagH、α_diagHd，深度剖面 diag H、Ha、H1，8 段与 0.1 s 块和。
- **W（对角权重，0.1 s 平滑，同 11-19）**：均匀 U、能量包络 E（x²）、(|y|−pen)₊²（Y）、非零密度 N、子波卷积后的波场能量 z²（Z）。
- 程序：`scripts/core.py`、`scripts/run.py`、`scripts/analyze.py`；codex 自带 Python 3.12，3 个进程，各 1 个 BLAS 线程。

## 3. 判读（运行前写死；全部是已用过的数据，结论只叫“机制诊断”）

参考值 K_ref 与 r 沿用 11-19 方案第 2 节的表（12 个剖面）。每个剖面取各数据集中位数。

- **M1（局部曲率能代表实测 K）**：|α_R − K_ref| ≤ 0.05 的剖面 ≥ 10/12。不成立则局部 Hessian 不能解释 K，后面各条只作描述。
- **M2（固定活跃集足够）**：所有数据集 |α_F,pipe − α_R| 的中位数 ≤ 0.02，且 ≥ 90% 的数据集 ≤ 0.05。成立则活跃集变化不是机制的一部分。
- **M3（四种预测）**：逐剖面列出 U、E、Y、α_H 的误差（对 K_ref）。“精确活跃集 Hessian 能统一 r ≤ 1 与 r > 1”定义为：α_H 在 12 个剖面上 |误差| 都 ≤ 0.10。开发种子上 α_H = 0.83 对 0.54，预期不成立。
- **M4（L1 权重归一化项）**：μ 相关项（J_μ μ_vv + J_μμ μ_v² + 2J_vμ μ_v）占 J_vv 的比例，逐剖面报告；干预预测：α_q25 < α_pipe < α_q75 在 ≥ 90% 数据集成立（参考列越深，a(t_q) 越大，α 越小）。这是新条件下的方向预测，但开发种子已看到同方向，且数据用过。
- **r ≤ 1 高估机制**：描述直接项与耦合项随深度的比例（耦合吸收率 1 − diag H/diag H_d）、能量型权重与 H 各块的位置差，不设门槛。
- 事后公式 a₀/a(t_med) 的误差照列，标“事后”，不判定。
