# 方向 1 第一关：叠前逐道 UQ 补偿会不会自己造出假 AVO 梯度？（看结果前提交）

日期：2026-11-18。用户在“叠前 Q 补偿创新”的四个方向里选了方向 1：把 UQ-W/CBL 的期望算子和 `avo_bias_theory_20261106` 的闭式 AVO 增益 Γ(x) 合起来。这一关只问一个量级问题，决定要不要继续。

## 1. 假设

UQ 的先验是把所有 1/Q 乘一个对数正态的 u（锚点在地表，同 UQ-RTM 和 UQ-W 的 `dx_hat = x_hat`）。叠前道 x 上事件的路径 t* 是 a(x) = a₀ + a_x，所以 t* 的绝对不确定度 ∝ a(x)，随炮检距变大。UQ 算子

```text
H = conj(E[G]) / (E|G|² + ρ)，G(a) = exp[−π f a + i 2 f ln(f/f_ref) a]，a ~ a_m·u，u = exp(σe)
```

（UQ-W 的 γ = 0 形式，确认时就是 γ = 0；σ = 0 时退化为一步 Tikhonov）在远道上补得更少，因此 E[Γ(x)] 随炮检距下降，**预测出负的假梯度，而且这部分只来自 σ，与 Q 是否给对无关**。

如果这个假梯度的量级可以忽略，方向 1 没有立足点，就停下来。

## 2. 设置

- 几何、事件、子波：`core.py`（从 `avo_bias_theory_20261106` 原样复制）：炮检距 0–1500 m，11 道；事件 0.38、0.65、0.90 s；Shuey 两项 AVO；理想拉平；Ricker 60、40 Hz。
- 判定模型：M12–M15（第 2b 步用过；这一关是确定性的解析与数值计算，不加噪声、不选参数，不消耗“未见数据”）。M1 只作描述。
- ρ = λ ∈ {10⁻⁴, 10⁻³, 10⁻²}，全道集共用（UQ-W 的 ρ = s + E|G|²/snr，白噪声下就是常数 N/S）。
- σ = 0.447（UQ-W、CBL、UQ-RTM 的冻结值），对数正态，41 点 Gauss–Hermite。σ = 0.25 只作描述。
- 真值 u：判定只用 u = 1（Q 给对）。u ∈ {0.5, 0.7, 0.8, 1.2, 1.4, 2} 只作描述。

## 3. 指标

**逐事件 G/A 偏差** dGA = B′/A′ − B/A。(A′, B′) 是 co_j(x)·Γ_j(x) 对 sin²θ_j(x) 的最小二乘拟合，co_j 是 Shuey 系数。它和第 2b 步的“无噪逐事件 G/A”是同一个量（孤立事件、无噪声时）。

两种算法：

- **数值（判定用）**：按 UQ-W 的写法逐行构造时变算子（每行用该拉平时刻、该炮检距的 a_m(t, x)），作用在只含单位反射系数孤立事件的道上，用零相位子波在事件 ±0.12 s 窗内做匹配滤波读振幅。
- **闭式（保护用）**：Γ_j(x) = ∫S² Re[G(u·a_j(x)) H_j(x)] df / ∫S² df。

**UQ 引起的部分：** D = dGA(σ = 0.447) − dGA(σ = 0)，同一 λ、同一子波、同一事件，u = 1。

## 4. 判定（72 个单元：M12–M15 × 2 子波 × 3 λ × 3 事件，数值）

| 判定 | 内容 | 门槛 |
|---|---|---|
| **G1 量级** | 单元 \|D\| 的中位数 | ≥ 0.092 |
| **G2 方向** | D < 0 的单元比例 | ≥ 80% |
| **P1 公式（保护）** | 闭式对数值的 dGA，UQ σ = 0.447，M12–M15，u 全网格（504 个点）：回归斜率、R² | 0.9–1.1，≥ 0.95 |

- **0.092 的来历**：第 2b 步频率饱和阻尼的有噪逐事件 G/A 是 0.046（R3），取它的 2 倍。也就是说，只有 UQ 造成的假梯度比“Q 已知时最好方法在 12–18 dB 噪声下的总误差”还大一倍，这个问题才值得做成方法。门槛是我定的经验值。
- **G1、G2 都过**：进入第二关（设计并检验炮检距一致的 UQ 算子，另写方案）。**任一不过**：停下来汇报，方向 1 不再推进。
- **P1 不过**不影响 G1、G2 的判定，但说明 Γ 公式在 UQ 算子上不可靠，第二关的设计就不能依赖闭式，要改用数值。

## 5. 只作描述

- 按模型、子波、λ、事件分组的 D；σ = 0.25；M1。
- u ≠ 1 时 Tikhonov（σ = 0）与 UQ 的 |dGA|，以及 u 网格上的平均——UQ 在 Q 给错时是否反而减小 AVO 误差（这决定第二关要权衡什么）。
- **炮检距一致的 UQ（OC，第二关候选的雏形）**：每个拉平时刻、每个频率，把期望传递函数 T = |E G|²/(E|G|² + ρ) 在全道集上拉平到最小值 T*，H = T*·conj(E G)/|E G|²。按构造，E_u[传递]与炮检距无关；u = 1 时不严格为零。报告它的 dGA 和近道 Γ 的下降（分辨率代价）。这一项是开发信息，不是检验。

## 6. 我开跑前的预期（可能是错的）

- G2 大概率过：推导直接给出负号。
- G1 我估计会过：40 Hz、a ≈ 0.016 s 时 πfaσ ≈ 0.9，|E G|²/E|G|² 约 0.45；远道 a 大 20–40%，这个比值降到约 0.3，Γ 在 sin²θ 0–0.4 内相对下降几十个百分点，对应 |D| 0.2–0.5。最可能让 G1 失败的情况：λ 大时 Tikhonov 自己已经把带宽压低，UQ 再压的那部分在 S² 加权后变小；以及浅层事件 a 小。
- 最深事件、60 Hz 子波、λ 小时 |D| 最大。
- P1 不确定：UQ 算子的频带边缘随 t 变化更快，平稳近似可能比 Tikhonov 时差一些。
- OC 预计在 u = 1 时把 |dGA| 压下去不少，但浅层事件远道角度大，近道分辨率代价会很大，实际要加切除。

## 7. 局限

- 孤立事件、理想拉平、无噪声；NMO 拉伸和速度误差不在这一关（第 1、1b 关已知它们更大）。
- 锚点在地表；锚点在深处时远道路径的上覆部分怎样处理，没有考虑。
- 先验是全局乘子 u（各层同比例），不含分层独立的不确定性。
- 只是量级关，不说明任何方法更好。
