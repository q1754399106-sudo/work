# AVO 梯度对 Q 绝对水平的一阶灵敏度（论文提纲待补第 1 项，2026-11-19，描述性）

## 公式

炮检距一致的补偿算子用模型 Q 时，各道通带传递 ρ(f) 相同。若真实路径 t* 是模型的 u 倍（u = Q_模型/Q_真），道 x 多乘 exp[−πf(u−1)a(x)]，于是

```text
ln Γ(x) ≈ 常数 − π f_eff (u−1) a_x(x)，      f_eff = ∫W ρ f df / ∫W ρ df（W = 子波谱² × 带通²）
ΔG/A ≈ −k (u−1)，   k = π f_eff κ [1 + (B/A)β − (B/A)²α]
```

κ 是 a_x 对 sin²θ 的斜率；α、β 是 sin⁴θ 对 sin²θ 回归的截距和斜率。方括号是 Shuey 拟合 co·Γ 时多出的 B·sin⁴θ 项，**依赖反射层自身的 B/A**。不加它（只用 π f_eff κ）时，预测与数值的 R² 只有 0.17。

物理含义：Q 绝对水平每错 10%，逐事件 G/A 偏 0.1·k；k 等于“通带有效频率 × 远道多出的 t* 随 sin²θ 的增长率 × π”，再乘一个反射层因子。Q 偏小（u > 1）时远道补偿不足，梯度偏负。

## 检验

**1. 对闭式 Γ 的数值斜率**（17 个 Q 模型 × 2 子波 × 3 个 λ × 3 事件 = 306 点，σ = 0 的炮检距一致算子）：

| 事件 | 预测对数值的斜率 | R² | 预测/数值中位数 |
|---|---|---|---|
| 中、深（0.65、0.90 s） | 0.995 | 0.997 | 1.01 |
| 浅（0.38 s，sin²θ 到 0.78） | 1.76 | 0.74 | 1.09 |
| 全部 | 0.92 | 0.80 | 1.02 |

浅层事件偏离，推测是远道 a_x 大、算子的噪声饱和使远道没有被完全校正，灵敏度变小（未单独验证）。

**2. 对第二关实测**（不校准的频率饱和阻尼，events_aligned，无噪、带符号的逐事件 G/A，B/A 取生成器的精确 Zoeppritz 系数；192 点）：

| | 实测对预测的斜率 | R² |
|---|---|---|
| 全部 | 1.23 | 0.75 |
| 事件 0 / 1 / 2 | 1.06 / 1.20 / 1.90 | 0.89 / 0.96 / 0.82 |

按 c 的中位数（预测 / 实测）：0.5 为 −1.14 / −1.63，0.7 为 −0.49 / −0.61，1.4 为 +0.33 / +0.38，2.0 为 +0.58 / +0.65。符号全对，量级一致；Q 偏小一倍（c = 0.5）时，线性公式低估约 30%（非线性区）。改用 ln u 代替 u − 1 后整体差不多（斜率 1.35，R² 0.77）。

有噪、取绝对值的指标（`ga`）与预测的相关 R² 0.85，但实测约为预测的 1.8 倍，因为它还包含噪声和 3 个事件绝对值平均，不宜直接对照。

## 结论

- 闭式条件下，公式对中、深事件几乎精确；在独立的正演、精确 Zoeppritz、残差原则选 λ 的端到端数据上，量级和符号正确，实测约为预测的 1.2 倍。可以作为论文的“误差预算公式”，并写明约 ±30% 的精度和浅层大角度、强衰减时的偏差方向。
- σ_lnQ 的误差预算：ΔG/A 的均方根 ≈ k·σ_lnQ。k 在本文模型上为 0.4–1.9（`theory_k.json`）。
