# 补测结果：24、30 dB 下残差原则选出的 λ

日期：2026-11-18。方案在运行前提交（`4fc2dd2`，`PLAN_LAMHI_ZH.md`）。数字来自 `results/lam_hi_verdict.json`。单进程，1346 s，没有一个单元退到网格最小值。

## 结论

**按事先写下的规则：24 dB 拉平场景下 |D| 中位数 0.206 ≥ 0.15 → 建议进入第二关，适用范围写 24 dB 以上。**

**复现检查通过：** 重跑 18、12 dB 得到的 8 个 log₁₀λ 中位数（2 种子波 × 2 信噪比 × 拉平/NMO）与第 2b 步的结果全部一致。

## 选出的 λ 与对应的 D（σ 0.447，u = 1，闭式查表）

\* 30 dB、60 Hz、拉平有 10/120 个单元选到 λ = 10⁻⁵，在闭式表的网格（10⁻⁴·⁵ 起）之外，未计入中位数。那些单元的 |D| 只会更大，所以星号处偏保守。

规律：每增加 6 dB，λ 下降约半个数量级（18 → 12 dB 时也是这样）。

## 读法

- 第一关末节里 24–30 dB 的外推（λ 10⁻³·⁵ 到 10⁻⁴，|D| 0.17–0.36）基本被测量证实：实测 |D| 为 0.17–0.29。
- **NMO 场景的 λ 比拉平大半档，|D| 相应变小**：24 dB NMO 合并 0.131，60 Hz 只有 0.087（低于 0.092）。拉伸后的道集在残差原则下更“像噪声”。
- 12–18 dB 下的结论不变：60 Hz 子波基本没有问题，40 Hz 子波约 0.13。

## 对第二关的约束

1. 主检验信噪比取 24、30 dB；18 dB 作为边界档，报告但不作主判定。
2. NMO 必须单列。24 dB NMO、60 Hz 子波时问题本身已经小于门槛，第二关在那里不应期望有优势。
3. 闭式表需要向下扩到 10⁻⁵ 以下。
