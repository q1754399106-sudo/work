# 研究任务书：Q 模型不确定时的稳健 Q 补偿偏移

状态：用户已于 2026-11-17 同意目标和阶段划分，任务书生效。第 10 节第 3、4 项仍待确认，不影响阶段 1–3。

## 1. 任务名称

Q 模型不确定时的稳健 Q 补偿偏移：把 Q 不确定度下的期望算子（UQ）从叠后反 Q 滤波推广到叠前深度偏移和逆时偏移。

## 2. 背景与依据

- Q 补偿偏移是当前衰减补偿的主流方向。它的稳定化方法（低通滤波、增益限、自适应稳定因子）都默认 Q 模型准确，针对的是数值不稳定和高频噪声放大。
- 本项目已确认：Q 只知道在 ×2 以内时，UQ-W 和 CBL0.5 在叠后数据上比常规稳定化反 Q 更稳（`qunknown_comp_20261109`）。
- 先导试验（本目录 `NOTE_ZH.md`，二维合成、单个模型、探索性）：
  - 常规稳定化 Q 补偿偏移对 Q 偏小很敏感：目标区 E 在 Q 准确时为 0.99，Q × 0.7 时为 0.63–0.85，Q × 0.5 时为 −3.5 到 0.21。频域逆时偏移的基线形状相同。
  - UQ 式增益（σ = 0.447）五个乘子为 0.78–0.98，Q 准确时低约 0.03，Q 偏大时低 0.01–0.04。
- 两次网页检索没有查到按 Q 模型不确定度设计稳定化的偏移工作。这不是查新结论。

## 3. 研究目标

1. 给出可在逆时偏移中实现的 UQ 式稳定化，并说明它与 Kirchhoff 实现的一致性。
2. 在多个模型、多种 Q 误差形式上，用预先冻结的判定规则确认：Q 误差在 ×2 以内时，它的最差情形明显好于常规稳定化，Q 准确时的代价有界。
3. 在一条实测测线上做描述性检验。
4. 形成一篇方法论文的初稿材料（方法、合成确认、实测例子、局限）。

## 4. 研究内容与技术路线

### 阶段 1：逆时偏移中的 UQ 式增益（二维合成，开发）

- 两条候选路线，各做最小实现后择一：
  - A. 按时间步（或按频率、按累计 t*）施加稳定化增益，用 UQ 增益律代替增益限公式。
  - B. Q 最小二乘偏移的期望算子形式：正规方程中用 E[L] 和 E[LᴴL]，迭代求解。
- 代码检查：σ → 0 时与常规稳定化 Q-RTM 一致；与 Kirchhoff 的 UQ 成像在先导模型上对比。
- 产出：实现、检查日志、择一的理由。两条都不可行时，主线退回 Kirchhoff Q 补偿叠前深度偏移，并在记录中写明。

### 阶段 2：扩展开发集

- 模型：至少 4 个新模型（不同构造、不同低 Q 体的位置和强度），不含先导模型。
- Q 误差形式：整体乘子；只有低 Q 体错；低 Q 体位置或范围错；背景与低 Q 体误差方向相反。
- 速度误差：光滑速度 ±3% 作为附加情形。
- 噪声：白噪声之外加一种相干噪声。
- 基线的调参方式改为实际可行的做法（不看参照成像），另保留“在真 Q 上调到最优”的乐观版本作对照。
- 在开发集上定下 UQ 的噪声项和 σ 的声明方式，之后不再改。

### 阶段 3：冻结方案与确认

- 写 `PLAN_CONFIRM_ZH.md`：数据、方法版本（提交号）、判定规则、预测，提交后再生成确认数据。
- 确认数据：新模型、新噪声种子，开发阶段没有碰过。
- 判定规则草案（阶段 2 结束后定稿）：
  - M1：Q 乘子 ≤ 0.7 时，UQ 的目标区 E 比最好的可行基线高 ≥ 0.05，模型胜率 ≥ 75%。
  - M2：Q 准确时，UQ 比最好的可行基线低不超过 0.05。
  - M3：全部 Q 误差情形里，UQ 的最差值高于每个基线的最差值。
  - M4：Q 乘子 ≥ 1.4 时，UQ 比最好的可行基线低不超过 0.05。
- 结果如实报告，判定不通过也归档。

### 阶段 4：实测检验（描述性）

- 数据：Volve ST10010 叠前数据的一条二维测线；Q 取 VSP 结果（储层以上 60–90）和处理方的 120 作为范围。
- 内容：常规稳定化与 UQ 在 Q 取范围两端时的成像差异、井旁道与测井合成记录的对比。
- Volve 的井在叠后试验里已用过，这里只作描述，不作判定。有条件时换一个没用过的数据集。

### 阶段 5：整理

- 结果文档、图件、论文初稿材料；正式查新（Q 补偿偏移稳定化、Q-LSRTM、Q 不确定度传递）。
