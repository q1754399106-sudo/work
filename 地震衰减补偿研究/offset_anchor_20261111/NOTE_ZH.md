# 炮检距谱比定衰减绝对水平：合成先导试验（2026-11-11，探索性）

没有预先提交判定规则。脚本 `scripts/offq.py`（`core.py` 从 `decouple_pilot_20261106` 原样复制），日志 `logs/offq.log`，逐次结果 `results/offq_rows.json`。单进程。

## 想法

叠后资料只能辨识衰减的深浅之差，绝对水平与子波谱、反射系数颜色混在一起（`limits_breakthrough_20261109/NOTE_ZH.md`）。同一 CMP 的各炮检距道反射系数相同，远道与零炮检距道的谱比只含额外路径的衰减，所以能定累计 t* 的绝对水平。`decouple_pilot_20261106` 的 K2 试过，但做了 NMO，拉伸使估计低到真值的约 15%。这里**不做 NMO，沿时距曲线取窗**，子波不被拉伸。

先例：QVO（Dasgupta 和 Clark，1998）、PSQI（Reine 等，2012，τ-p 域避开拉伸）。本试验不主张估计方法本身是新的。

## 设置

- 模型和反射系数生成同 K2；每次 200 个 CMP，8 个种子，Q 乘子 c 取 0.7、1.0、1.4；切除拉伸比 1.3 以外的窗。
- 与 K2 的差别：远道的反射系数用傅里叶移位放到时距曲线上（K2 的线性插值会削高频）；自适应频带（功率高于噪声 3 倍、从 15 Hz 起连续）；可选蓝谱反射系数（f 的 0.7 次方）；取窗位置和预测的额外路径用带误差的速度。
- 对照：零炮检距道的垂向窗谱比（相当于叠后谱比法）。
- 表中数字是 log(ĉ/c) 的均值，括号内是种子间标准差。

## 结果

| 情形 | 炮检距谱比 | 垂向谱比 |
|---|---|---|
| 无噪声，白谱 | +0.05 到 +0.07（0.02–0.05） | +0.01 到 +0.02（0.03–0.06） |
| 白谱 30 dB | +0.05 到 +0.09（0.02–0.05） | −0.01 到 +0.02（0.05–0.10） |
| 白谱 18 dB | +0.06 到 +0.08（0.03–0.09） | c 0.7 时 −0.65（0.65），其余 +0.01 到 +0.02 |
| 白谱 10 dB | +0.06 到 +0.16（0.04–0.20） | c 0.7、1.0 时 −0.74、−0.41，c 1.4 时 +0.01 |
| 蓝谱 18 dB | +0.03 到 +0.06（0.03–0.10） | c 0.7 时 −0.50（0.53），其余 +0.02 |
| 蓝谱 10 dB | −0.03 到 +0.04（0.08–0.16） | c 0.7、1.0 时 −0.82、−0.17 |
| 蓝谱 18 dB，颜色趋势 +0.02 | −0.01 到 +0.04 | **−0.06、+0.58、+0.92** |
| 蓝谱 18 dB，颜色趋势 −0.02 | +0.06 到 +0.09 | **−0.87、−0.33、−0.45** |
| 蓝谱 18 dB，速度 +2% / −2% | 0.00 到 +0.03 / +0.05 到 +0.09 | 变化不到 0.02 |
| 蓝谱 18 dB，速度 +5% / −5% | −0.04 到 −0.01 / +0.09 到 +0.12 | 变化不到 0.05 |

- 炮检距谱比在所有情形下 |偏差| ≤ 0.16，多数 ≤ 0.09；颜色趋势 ±0.02 只让它移动约 0.03，而垂向谱比移动 0.3–0.9。
- 速度误差 ±5% 使它移动约 ∓0.06。
- 无噪声时仍有 +0.05 到 +0.07 的系统偏差，原因没查（候选：窗内衰减变化、压缩后的窗加权）。
- 垂向谱比在低信噪比强衰减下崩掉，是因为它没有用自适应频带（照 K2 原样），这一项对比对它不公平；颜色趋势两行的对比不受此影响（c 1.0、1.4 时它在无趋势下正常）。

## 没包含的

振幅随炮检距和频率的变化、各向异性、非双曲时差、多次波、真实覆盖次数和炮检距分布、横向变化的 Q、实际叠前噪声。模型浅（0.35–1.2 s），额外路径的 π·t* 平均只有 0.005。
