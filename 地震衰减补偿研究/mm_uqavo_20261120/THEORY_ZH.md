# 第 0 步：矩匹配 UQ-AVO 算子（MM）的推导核对与可行性判断（算之前写）

日期：2026-11-20。用户提出的“创新方向 3”：在 UQ 期望算子上加一个“子波加权总增益的先验期望与炮检距无关”的约束。这一步只核对推导，并用闭式 Γ 在已用过的开发模型（M1、M12）上判断它有没有可能赢 Tikhonov、频率饱和阻尼和炮检距谱比校准。**不加噪声、不做判定、不消耗任何未见数据。** 如果理论上赢不了，就写清原因后停下。

## 1. 拉格朗日解（核对用户公式）

记号（逐道 x、逐事件）：ḡ = E_u[G(u a(x), f)]，m₂ = E_u|G|²，W(f) = S²(f)/∫S²df，Γ(x;u) = ∫W·Re[G(u a(x)) H] df（第一关 P1 已验证闭式，斜率 0.974、R² 0.999）。

```text
J(H) = ∫ ( E_u|H G − 1|² + ρ|H|² ) df = ∫ ( |H|²(m₂+ρ) − 2 Re[H ḡ] + 1 ) df
约束：E_u[Γ(x)] = ∫ W Re[H ḡ] df = Γ₀
```

J 对 H 严格凸，约束对 (Re H, Im H) 是实线性的，所以 KKT 点唯一且就是最优。取 L = J − 2ν(∫W Re[Hḡ]df − Γ₀)，逐频对 H* 变分：

```text
(m₂+ρ) H − (1 + ν W) ḡ* = 0   ⇒   H_MM = ḡ*·(1 + ν W)/(m₂ + ρ) = E[G*]·(1 + ν S²/∫S²)/(E|G|² + ρ)
```

代回约束：E_u[Γ] = ∫W(1+νW)T df = I₁ + ν I₂，T = |ḡ|²/(m₂+ρ)，

```text
I₁ = ∫ S² T df / ∫S²，  I₂ = ∫ S⁴ T df / (∫S²)²，  ν = (Γ₀ − I₁)/I₂
```

**结论：用户的闭式解、ν 和 I_k 都对。** 乘子项的形式是 ν·E[G*]·W/(m₂+ρ)，即 ν W 乘在 UQ 算子上（不是 ν E[G*] S²/∫S² 单独加一项——两者写法等价，因为它就是 UQ 算子乘 (1+νW)）。“S⁴ 加权”的说法要说准确：算子里的修正是 S² 加权的；它对 Γ 的效果 I₂ 是 S⁴ 加权的。

其他几点：

- 取 Γ₀ = I₁(0) 时 ν(0) = 0，近道算子就是 UQ。所以“近道零损失”是**相对 UQ** 而言；UQ 本身的近道已比 Tikhonov 窄（第一关）。
- 远道 I₁(x) < I₁(0)，ν > 0：修正是在子波主频带上**放大**远道，远道噪声增益随之上升（`far_noise` 报告）。ν 有量纲（Hz），要求 1 + νW > 0，这里 ν ≥ 0 自动满足。
- 这是“带内积分版”的 UQ-A。UQ-A（`uq_avo_20261118/scripts/ua.py`）逐频让先验期望传递与炮检距无关，因而 E_u[Γ(x)] 也与炮检距无关；MM 只约束积分，是满足同一个均值约束的最小 J 解。两者约束的都是**先验均值**。

## 2. 为什么预计赢不了（看数字之前）

**(a) 均值约束不保证 Q 给对时无偏。** E_u[G(u a)] 被弱衰减（小 u）的实现支配（对数正态 u 时 E[e^{−cu}] 远大于 e^{−c}）。让 E_u[Γ] 平，等于让“比模型弱的衰减”平。UQ-A 与 OC 已经看到零偏差点漂到 u ≈ 0.7–0.8、u = 1 时 dGA −0.18 到 −0.34。MM 预计同样。

**(b) 灵敏度是算子无关的。** 对任何**不看数据**的线性算子 H，若它在带内大致补偿了 G，

```text
d ln Γ(x;u)/d ln u ≈ −π f_eff · u a(x)  ⇒  d(dGA)/d ln u ≈ −k，  k = π f_eff κ [1 + (B/A)β − (B/A)²α]
```

（`uq_avo_20261118/THEORY_K_ZH.md`；k 在本文模型上 0.4–1.9）。f_eff 只弱依赖 H。所以在先验 u ~ 对数正态(0, σ) 下，dGA 的离散 ≈ |k|σ 与算子无关，**算子只能平移这条误差曲线的零点**。σ_lnQ 对称时，零点放在先验中位数 u = 1（就是频率饱和阻尼 / sat~）已接近使 |dGA| 的 68% 分位数最小；MM 把零点移向 u < 1，只会让 68% 分位数变大或持平，并在 u = 1 时引入偏差。对数正态在 u 上的偏斜和 dGA 的非线性可能让最优零点略偏离 1，但这是 O(σ²) 的效应，同时作用于所有算子。

**(c) 不可能赢谱比校准。** 谱比校准用数据缩小了 σ 本身（ln(ĉ/c) 均方根 0.069–0.096，`offset_q_avo_20261118` A2/A3），AVO 误差降到 0.06–0.18。MM 不使用任何关于 u 的数据，误差下限是 |k|σ_prior。σ = 0.447 时 68% 分位数下限约 0.27–0.57（`DEV_GATE2_ZH.md` 更正节），比校准后的 0.08–0.10 大 3–6 倍。校准后再用 MM（σ = 0.09）：均值与中位数之差 ∝ σ²/2 ≈ 0.004，MM 对 sat 的修正可以忽略。

## 3. 小算例（`scripts/step0_mm.py` → `results/step0_mm.json`）

M1、M12 × 子波 60/40 Hz × λ ∈ {10⁻⁴, 10⁻³·⁵, 10⁻³} × σ ∈ {0.447（不校准）, 0.09（校准后）}；算子 tik、uq、oc、sat（≈频率饱和阻尼）、uqa、mm（用户方案）、mm0（σ = 0 的 MM，约束 u = 1 时的 Γ）、mmsat（频率饱和阻尼核 + 均值矩匹配）。指标：先验 |dGA| 68% 分位数（截断 ±3σ）、先验均值、u = 1 的 dGA、u 网格、灵敏度 s = d(dGA)/d ln u、近道 Γ 与远道噪声增益（都相对 tik）。

**开算前的预期（可能错）：**

1. mm 的 s 与 sat、tik 相差在 ±30% 内（(b)）。
2. σ = 0.447：mm 在 u = 1 时 dGA 为负，量级与 uqa 相当（0.1–0.3）；68% 分位数不低于 min(tik, sat) 减 0.03。
3. σ = 0.09：mm、mmsat 与 sat 的 68% 分位数差 ≤ 0.01，都 ≈ |k|·0.09·1（0.04–0.15）。
4. mm 远道噪声增益高于 uq。

**停下的规则：** 如果 1–3 都成立，即 MM 在先验下最好也只与 sat/Tikhonov 打平、在 Q 给对时更差、在校准后没有增量，就不做开发与确认，写 RESULTS 后停下。若 σ = 0.447 时 mm 的 68% 分位数比 min(tik, sat) 低 0.05 以上（在 ≥ 6/12 个单元），再写正式的 PLAN_ZH.md 去做有噪开发与确认。
