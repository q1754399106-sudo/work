# 地层吸收解耦分步补偿的创新：小试探记录

日期：2026-11-06。用户明确要“地层吸收分布补偿法”的创新，即炮检距吸收和深度吸收解耦的分步法（`original_fixed_split_20261022`）。**全部是探索性的，没有预先提交判定规则，只用来决定思路值不值得写方案，不能当结论引用。** 模型、公式和默认参数都来自原始程序（`scripts/core.py` 是 NumPy 移植）：3 个孤立事件、Shuey 两项 AVO、理想 NMO 拉平、11 道、0–1500 m。一步法用的是正确的完整算子，所以对一步法有利。

## 试探 K1：分步和一步的 AVO（`k1_avo.py`，20 个种子）

指标：每个事件的模板振幅对 sin²θ 拟合截距 A 和梯度 G，看 G/A 与真值的差。各方法取使波形误差最小的 λ（用了真值）。

| SNR | Q | 方法 | 波形误差 | G/A 误差 | 截距相对误差 |
|---|---|---|---|---|---|
| 18 dB | 正确 | 分步 | 0.580 | **0.039** | 0.322 |
| | | 一步 | 0.460 | 0.384 | 0.126 |
| 18 dB | ×0.8 | 分步 | 0.710 | 0.221 | 0.409 |
| | | 一步 | 0.676 | 0.667 | 0.288 |
| 18 dB | ×1.2 | 分步 | 0.649 | 0.218 | 0.520 |
| | | 一步 | 0.569 | 0.429 | 0.411 |
| 12 dB | 正确 | 分步 | 0.706 | 0.044 | 0.514 |
| | | 一步 | 0.562 | 0.534 | 0.235 |

分步的 G/A 在全部 6 个条件、20/20 个种子上都更好，但波形误差都更大（+0.035 到 +0.144），截距误差也更大。

**同一 λ 时机制最清楚（18 dB，Q 正确）：** λ 从 10⁻⁴ 增大到 1，一步法 G/A 误差从 0.384 涨到 0.931，分步从 0.061 降到 0.019。λ = 10⁻³ 时两者波形误差接近（0.580 对 0.563），G/A 误差是 0.039 对 0.602。

解释（机制假设，未证明）：一步法对各道用同一个 λ，而远道衰减更强，高频被压得更早，等于对远道多做了一次低通，振幅随炮检距下降，形成假的 AVO 梯度。分步先把各道拉平，第二步对所有道用同一个算子。

## 试探 K1b：一致正则，以及仓库早期的自适应版本（`k1b_consistent.py`，12 个种子）

炮检距一致正则：一步法的阻尼改为 λ·exp(−2π fc ax(t, x))，让各道在频率 fc 处的截止回到零炮检距的位置。

| 方法（18 dB，Q 正确） | 波形误差 | G/A 误差 |
|---|---|---|
| 一步，固定 λ | 0.461 | 0.387 |
| 一步，逐道残差原则选 λ | 0.491 | 0.240 |
| 协方差分步，逐道残差原则选 λ | 0.500 | 0.193 |
| 一致正则 fc = 40 Hz | 0.465 | 0.211 |
| **一致正则 fc = 60 Hz** | **0.520** | **0.086**（λ = 10⁻³ 时 0.521 / 0.066） |
| 一致正则 fc = 80 Hz | 0.594 | 0.118 |
| 分步，固定 λ | 0.580 | 0.040 |

**没有两全其美。** fc = 60 比分步的波形好 0.06，G/A 差约 0.03–0.05；比一步法的 G/A 小很多，波形差 0.06。

**对 fc 敏感：** Q×0.8 时最好的是 fc = 40（G/A 0.108，fc = 60 为 0.399，分步 0.213）；Q×1.2 时是 fc = 80（0.186，分步 0.228）。这些 fc 都是用真值看出来的，所以固定 fc 的方法现在还不稳健。

**这可能解释了早期结论：** 自适应版本的 G/A（0.240、0.193）接近，波形也接近，所以早期“分步和一步几乎一样”的比较里，分步的这个优势没有显现。这是推断，早期程序（consistent 分步、结构先验）没有在这里重跑。

## 试探 K2：用炮检距差分估 Q（`k2_offset_q.py`，每个估计 20 个 CMP，8 个种子）

同一 CMP 的反射系数相同，所以 ln P_x − ln P_0 只含额外路径损失，理论上和颜色、子波无关。这在数学上就是 QVO 的思路。

log(ĉ/c) 的平均值和标准差（c = 0.7、1.0、1.4）：

| 条件 | 趋势 s | 炮检距判据 | 垂向窗口（类似 SR） |
|---|---|---|---|
| 理想拉平，30 dB | 0 | −0.24，sd 0.52 | −0.01，sd 0.39 |
| | +0.02 | −0.22，sd 0.43 | +0.83，sd 0.85 |
| | −0.02 | −0.29，sd 0.67 | −0.41，sd 0.33 |
| 理想拉平，18 dB | 0 | −0.72，sd 0.75 | −0.48，sd 0.78 |
| NMO 拉伸，30 dB | 0 | **−1.89**，sd 0.14 | −0.01，sd 0.39 |

**不受颜色影响确实成立**（炮检距判据几乎不随 s 变），但这个形式不可用：信号太小（π·ax 平均 0.005，垂向约 0.025），18 dB 时已不稳定；未校正的 NMO 拉伸使 c 的估计低到真值的约 15%，直接压过了衰减信号。拉伸校正、更多 CMP、更大炮检距都没有试。这里的 18 dB 和 20 个 CMP 也是我选的，没有对应实际覆盖次数。

## 还没有验证的，也是最关键的

- NMO 拉伸也会改变远道振幅和频谱，K1 没有包含。K2 显示它的影响可能很大。
- 只有 3 个孤立事件，都是同一个模型、理想算子、Shuey 两项。密集反射系数、薄层、Zoeppritz、独立正演都没有试。
- 模板振幅用真子波形状，分辨率不同时可能有偏。
- 没有和 FullCalRefit、SC、AVO 保护版（Frozen）比较。它们如果已经保住 AVO，这个优势就不算新。
- fc 和 λ 都是用真值选的，没有不用真值的选法。
