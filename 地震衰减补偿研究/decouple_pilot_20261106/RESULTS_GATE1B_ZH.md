# 第 1b 关结果：炮检距步同时校正吸收和拉伸

日期：2026-11-06。定义在运行前提交（`66f3b70`，`GATE1B_ZH.md`）。全部用合成数据，λ 用真值选。数字来自 `results/gate1b_summary.json`。诊断脚本 `gate1b_diag.py`、`gate1b_valid.py` 是看过结果后做的，不影响判定。

## 结论

**第 1b 关不通过，R1、R2 都没过。** 按方案，这个做法无效，不再往下调。

| 规则 | 要求 | 结果 | 判定 |
|---|---|---|---|
| R1 模板 G/A（`events_nmo`）`split_st` / `split` | ≤ 0.5 | 1.317 | 不过 |
| R1 梯度相关增益 | ≥ +0.10 | +0.123 | 过 |
| R2 E_G 上 `split_st` 好于 `direct_st` 的单元 | ≥ 80% | 31.5% | 不过 |
| R2 比值中位数 | ≤ 0.8 | 1.022 | 不过 |
| R2 差值中位数 | ≥ +0.05 | −0.041 | 不过 |

**另外三点：**

- 拉伸校正在 18 dB 下只能部分起作用。
- 校正之后，分步相对一步法没有优势。
- 这一关的 `split_st` 有参数缺陷（见下），但修掉后 R2 的结论不变。

## 设计缺陷

λx = 10⁻³ 是从原方法沿用的，那里的算子奇异值接近 1。F_s 含子波，奇异值衰减快得多，所以 10⁻³ 太大，第一步基本没做拉伸校正：`split_st` 的结果几乎不随 λ 变，等于 λ = 10⁻³ 的 `direct_st`（`gate1b_valid.py`）。这是我的设计错误，判定按提交的规则不改，也没有重跑。

把 λx 设成 λ 后（3 个种子，18 dB，M1，描述）：

| λ | `direct_st` 波形 / E_G | `split_st_lx=λ` 波形 / E_G |
|---|---|---|
| 孤立事件，10⁻⁵ | 0.572 / 1.705 | 0.544 / 1.704 |
| 孤立事件，10⁻⁴ | 0.519 / 2.065 | 0.534 / 1.979 |
| 密集，10⁻⁵ | 0.666 / 0.482 | 0.614 / 0.480 |
| 密集，10⁻⁴ | 0.543 / 0.538 | 0.555 / 0.502 |

两者几乎一样，所以调好 λx 也拿不到分步优势。这个调整没有独立验证，只有 3 个种子。

## 开跑前的预期

- R1 大概率通过：**错了。** 上面的缺陷是原因之一。
- R2 不确定：结果是不通过。
- 失配时优势缩小，尤其子波失配：**错了。** 子波 ±10% 影响很小，速度 ±2% 影响很大。

## 误差来源（事后，只作描述）

M1、Q 正确，`split`，E_G（`gate1b_diag.py`、压力组）：

| 情形 | 孤立事件 | 密集 |
|---|---|---|
| 拉平，60 dB | 0.083 | 0.020 |
| 拉平，18 dB | 0.407 | 0.250 |
| 拉平 + 切除掩膜，18 dB | 0.771 | 0.351 |
| NMO + 切除 1.3，60 dB | 2.739 | 0.762 |
| NMO + 切除 1.3，18 dB | 2.614 | 0.755 |
| NMO，几乎不切除（2.5），18 dB | 2.994 | 0.850 |
| NMO，速度 ×0.98（压力组种子） | 8.046 | 2.630 |
| NMO，速度 ×1.02 | 7.245 | 2.325 |

- **NMO 拉伸比噪声和切除都大：** 无噪时 E_G 仍是 2.7（孤立事件）。这支持第 1 关“拉伸是主因”的判断。真梯度比截距小，所以即使拉伸只改变很小的振幅，相对误差也很大。
- **速度 ±2% 的影响更大：** E_G 约为无速度误差时的 3 倍。这些都是真速度附近的小失配，所以实际数据上，这部分可能盖过吸收补偿的差异。
- **子波主频 ±10%** 影响很小（只影响用子波的方法：`split_st` 密集 0.75–0.80，无失配 0.77）。
- 实际 AVO 流程常用更严的切除或不拉伸的 NMO。这里都没有试。

## 还成立的和不成立的

- **仍成立（描述）：** 已拉平、没有速度误差时，同 λ 一步法产生假 AVO 梯度，分步明显更好。
- **不成立：** 把这件事当成实际流程中 AVO 精度的主要矛盾。NMO 拉伸和速度误差的影响都大得多。
- **没试：** 不拉伸的 NMO、偏移域角道集、更小的切除比、λ 更细的网格。
