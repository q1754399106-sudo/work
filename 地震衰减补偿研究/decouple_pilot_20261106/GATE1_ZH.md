# 第 1 关：加入现实因素后，分步的 AVO 优势还在不在（看结果前提交）

日期：2026-11-06。用户说“开始”。试探 K1、K1b 只用了 3 个孤立事件、理想 NMO，反演和正演用同一套算子。这一关只问：**加入 NMO 拉伸、密集反射系数、薄层和独立正演后，分步比一步法更保 AVO 这件事是否还成立？** 不选参数，也不比较 FullCalRefit 等基线（第 2 关）。

## 正演（`scripts/gate1.py`，和反演算子独立）

逐反射点在频率域合成，不用反演用的列时变矩阵：

```text
D(f, x) = Σ_k R_k(x) S(f) exp[−π f a_k + i 2 f ln(f/fref) a_k] exp(−i 2π f t_k(x))
```

a_k、t_k(x) 由精确分层射线得到（几何沿用原始模型的速度和时间）。S 是 60 Hz Ricker。噪声按原程序的定义加到每道（叠前域）。

**场景：**

| 场景 | 反射系数 | NMO |
|---|---|---|
| `events_aligned` | 3 个界面，精确 Zoeppritz | 无（直接放在 t0） |
| `thin_aligned` | 每个界面换成间隔 16 ms 的正负双层，幅度相同 | 无 |
| `dense_aligned` | 3 个界面加上密集小反射（每 2 ms 样点 30%） | 无 |
| `events_nmo`、`thin_nmo`、`dense_nmo` | 同上 | **有**：在 t_k(x) 合成，加噪声，按真速度做 NMO 回到 t0，拉伸比 t_x/t0 > 1.3 切除 |

密集小反射的 AVO：A ~ N(0, 0.05²)，B = −0.8A + N(0, 0.03²)，R = A + B sin²θ，局部 sinθ = p·v。

**模型（只变 Q）：** M1 原始 Q = [40, 50, 70, 100]；M2 低 Q，×0.7；M3 反转，[100, 70, 50, 40]。

**其他：** 信噪比 18、12 dB；反演用 Q ×0.8、×1、×1.2；10 个种子；11 道、0–1500 m。反演算子仍是原来的列时变矩阵，并假设数据已拉平，这是实际流程的做法，所以 NMO 场景里算子有失配。真速度 NMO，没有剩余时差。

## 方法

- `split`：第一步 λx = 10⁻³，第二步 λ。
- `direct`：完整算子一步，λ 对所有道相同。
- 只作描述：`consistent` fc = 40、60、80 Hz；`direct_disc`、`covsplit_disc`（逐道残差原则）；`observed`。

λ 网格 10⁻⁵ 到 1，共 9 个。每个方法在每个单元（场景、模型、信噪比、Q）取平均波形误差最小的 λ，**用了真值**，所以这一关不能说明方法可用。

## 指标

真值是同一反射序列、不衰减、不拉伸的道集。输出和真值都先带通 10–60 Hz。每个时间样点对有效炮检距（未切除且至少 4 道）拟合 y = A + B sin²θ，分析范围 0.25–1.1 s。

- b_A = 估计截距对真截距的投影系数，b_G 同理。
- **主指标 M_G = |b_G / b_A − 1|**：梯度相对截距的增益误差。
- 同时报告：|b_A − 1|、|b_G − 1|、梯度相关系数、波形相对误差（有效样点内）。

## 通过标准

只看三个 NMO 场景（3 场景 × 3 模型 × 2 信噪比 × 3 Q = 54 个单元），每个单元取 10 个种子的平均：

- **P1：** split 的 M_G 小于 direct 的单元 ≥ 80%，且 M_G(split)/M_G(direct) 的中位数 ≤ 0.67。
- **P2：** M_G(direct) − M_G(split) 的中位数 ≥ 0.05。

两条都满足才通过，进入第 2 关。否则停下来向用户汇报，由用户决定。

这些门槛是我定的经验值，只用来决定是否继续，不是统计检验。

## 我开跑前的预期（可能是错的）

- 没有拉伸时优势基本保持。
- 拉伸会增大所有方法的 M_G，优势缩小。P1 可能勉强通过，也可能在 `dense_nmo` 上失败，因为密集反射的波形干涉更强。
- 分步的波形误差仍大于一步法。

## 检查

先用原始算子正演（`orig` 场景：M1、18 dB、Q 正确）复现 K1b 的量级：模板 G/A 误差 split 约 0.04、direct 约 0.39，这些数已看过。运行时再把 `orig` 打印出来核对。除此之外，冒烟只看退出码和耗时。

检查结果：`orig` 场景的模板 G/A 误差 split 0.040、direct 0.387，与 K1b 一致。冒烟只在 `dense_nmo` 的 4 列数据上确认能运行，输出有限，没有打印分数。
