# 生成器因子实验：三个因子都没能复现 V 组的翻转

**结论：**
- **复现检查不通过。** 24 个新模型、全部 8 个格子中，Q 有误时都是 QScan＋SC 更好，Q 正确时都是 SC 更好。仿 V4 的格子 (A, B, C) = (1, 1, 1) 也是如此：L_wrong 平均为 −0.170，即 QScan＋SC/QScan＋标准版约 0.84。按方案，因子判定只作描述。
- **这三项差别都不能解释 round3 的分化**：稀疏块状反射系数、横向倾角和断层、求解器自身的正演算子，单独或合在一起都没有让标准版反超。
- 横向构造（B）和求解器算子（C）会**缩小** Q 正确时 SC 的优势（各约 5%、9%，且有正交互）。叠满后，SC/标准版从 0.76 升到 0.86，离翻转（> 1）还差很远。V4 上这个比值是 1.03–1.49。
- 剩下没有被排除的解释：V 系列的具体场景设计。V4/V5 与相干规则的开发场景 V1–V3 同属一个场景家族：弱事件紧邻强事件、尖灭、断层，偏移距 450 m；V5 还有标定 Q 和相干噪声。也就是说，标准版的优势更可能来自开发时对这一场景家族的适配，而不是一项可以单独分离的物理差别。这一条本轮没有检验。

## 判定

主指标 L_wrong：模型 4 个 Q 有误行上 ln(QScan＋SC / QScan＋标准版) 的平均，> 0 表示 QScan＋标准版更好。
次指标 L_0：模型 2 个 Q 正确行上 ln(SC / 标准版) 的平均。

| | 结果 |
|---|---|
| 复现：格子 111 的 L_wrong 平均 > 0 | −0.170，**不满足** |
| 复现：格子 000 的 L_wrong 平均 < 0 | −0.148，满足 |
| **复现了分化** | **否** |

因子作用（每个因子 12 个配对，比值 = exp(配对差平均)，> 1 表示该因子取 V 一端时对标准版更有利）。因为复现不通过，以下只作描述：

| 因子 | L_wrong（Q 有误） | L_0（Q 正确） |
|---|---|---|
| A 稀疏块状 | 反向作用：0.930，0/12 > 0 | 无明确作用：0.964，2/12 |
| B 横向构造 | 无明确作用：1.035，10/12 | 有作用：1.050，11/12 |
| C 求解器算子 | 无明确作用：0.993，5/12 | 有作用：1.092，12/12 |

只用收敛行的敏感性分析结论相同。全部 144 次 QScan＋SC 和 Q 正确时的 SC 都收敛；只有 1 次名义 Q 的 SC（Z2_010，Moderate，Q−30）未收敛，它不进入 L_wrong 或 L_0。

## 描述性观察

- **24 个模型无一例外**：L_wrong 在 −0.093 到 −0.309 之间，L_0 在 −0.109 到 −0.389 之间，全部为负。
- **交互**：C 对 L_0 的作用在 A=1 时更大（0.112 对 0.065），在 B=1 时也更大（0.103 对 0.074）。三项叠加，SC 的优势缩到最小，但仍未翻转。
- **QScan 的作用不随格子改变**：每个格子里 QScan＋SC 都比名义 Q 的 SC 好得多（Q 有误时 0.25–0.49 对 0.53–0.65）。
- **与 round3 V4 的差距**：V4 上标准版/SC 为 0.67–0.97（即 SC/标准版 1.03–1.49）；本轮 111 格子的 SC/标准版为 0.858。三项因子能解释的部分不到这个差距的一半。

## 对研究方向的含义

- 现有证据中，SC 一侧更好的数据有：Kennett F3/F4、二维有限差分 H1–H6、本轮 24 个因子模型（包括仿 V4 的格子）。标准版更好的只有 V4/V5，而它们与标准版开发所用的 V1–V3 属同一场景家族。
- 所以 round3 的分化更像是**开发数据家族的特性**，不是某项可分离的物理条件。“Q 可信用 SC，Q 有误用 QScan＋SC”的推荐比 round3 之后更稳了。
- 要直接检验“开发家族适配”这个解释，需要在新种子、但按 V1–V3 的场景设计（`gen_layered_scene`、偏移距 450、同类事件布局）生成的数据上重做比较。这是本轮之外的事。

## 边界

- 每个因子只有两个水平，且捆绑了多个细节（见 PLAN_ZH.md）。没复现只说明这三组差别不够，不排除别的组合。
- 3 个种子，每个因子 12 个配对，配对共享种子；不报告显著性检验。
- 一维逐道正演，不含绕射和二维效应。
