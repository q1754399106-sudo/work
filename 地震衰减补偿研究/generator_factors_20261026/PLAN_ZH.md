# 为什么 V 组偏向相干标准版：生成器因子实验（预登记）

登记时间：2026-10-26。在生成任何新模型、做任何求解之前写入。

## 问题

`qscan_sc_round3_20261026` 的结果按生成器分化（Q 有误，各 24 行）：

- Kennett 组 F3/F4：QScan＋SC 稳定优于 QScan＋标准版（比值 0.804，24/24）；
- V 组 V4/V5：反过来，QScan＋标准版稳定更好（QScan＋SC 比值 1.206，0/24）。

Q 正确时，SC 对标准版也按同样的方式分化（`novelty_evidence_20261025`）。二维有限差分 H1–H6 上是 SC 一方更好。

本轮要找出 **是生成器的哪一项差别** 让结果翻转。逐项对比 F3/F4 与 V4，可以单独操纵的差别有三项：

| 因子 | F 系列（偏向 SC 的一端，记为 0） | V4（偏向标准版的一端，记为 1） |
|---|---|---|
| A 反射系数结构 | 密集细层：3–15 m 细层，每道上百个界面（`make_F34.m` 的 `fine_log`） | 稀疏块状：60–160 m 厚层，每道约十几个界面，强弱混合 |
| B 横向结构 | 近水平：层厚拉伸 ≤ 6%，加一个气砂楔（`make_F34.m` 的 `lateral`） | 有构造：在 0 的基础上加倾角和两条断层 |
| C 正演 | Kennett 精确正演：含层间多次波、透射损失，细层 Q 有散布 | 求解器自身的模型：一次反射落在采样点上，用宏观 4 层 Q 和求解器的衰减算子 `attenuation_matrix` |

三个对应的假设：
- **A**：孤立强弱事件对“去偏重拟合＋组收缩”有利，ℓ1 收缩会压低弱事件；
- **B**：SC 只用一个全道集共用的 5×5 预测滤波器，跟不上倾角和断层，而标准版的相干度允许局部时移；
- **C**：正演模型与字典一致时，无偏重拟合最优；有多次波和细层 Q 时，重拟合会把模型误差也拟合进去。

V5 是复杂模型（褶皱、断层、相干噪声、静校正、标定 Q），本轮不复制它的全部特征。

## 数据（全新模型，从未被任何方法用过）

- **种子**：3 个基础种子 2026102611、2026102621、2026102631。每个种子生成一个宏观 4 层模型，再按 A × B × C 的 8 种组合各生成一个道集，共 **24 个模型**。同一种子的 8 个模型共用宏观模型、细层或块状层序列和噪声种子，只在所操纵的因子上不同（配对设计）。
- **宏观模型**：参数范围仿照 F3/F4。vp 在 [1750, 1810]、[2300, 2400]、[2700, 2950]、[3300, 3450] 内随机取，h 在 [210, 250]、[300, 340]、[320, 360] m 内取，Q 在 [40, 75]、[40, 85]、[35, 60]、[85, 125] 内取。
- **A=0 密集细层**：`make_F34.m` 的 `fine_log`，逐字使用，不加碳酸盐层。
- **A=1 稀疏块状**：厚度 60–160 m 的层。每个界面的速度跳变按概率 0.6 取弱跳变（相对 1.2–3%，反射系数约 0.007–0.02），按概率 0.4 取强跳变（6–12%）。累计偏离宏观层速度超过 5% 时往回跳，否则符号随机。宏观层之间另有宏观速度的跳变。Q 等于所在宏观层的 Q。气砂层按 F 系列的做法设在第 2 宏观层的第 2 个子层（速度 ×0.86，Q = 18，厚 20 m）。
- **B=0 近水平**：`make_F34.m` 的 `lateral`，逐字使用，包括气砂楔。
- **B=1 有构造**：在 B=0 的拉伸系数上增加三项：
  - 顶层厚度乘以 1 + 0.25x + 0.03 sin(3πx)，x 为 0–1 的道位置，即倾角；
  - 第 2 宏观层在第 35 道及以后加厚 12%，形成一条断层，断距约 30 ms；
  - 第 3 宏观层在第 75 道及以后减薄 12%，形成第二条断层。
- **C=0 Kennett**：`round3_20261024/core/kennett_trace.m`，逐字使用。目标为同一模型 Q = ∞ 的弹性响应，与 F3/F4 相同。
- **C=1 求解器模型**：
  - 正入射反射系数 r = (Z₂ − Z₁)/(Z₂ + Z₁)，Z = ρv，ρ = 0.31v^0.25，放在四舍五入到采样点的双程时上；
  - 目标为 Ricker 子波矩阵 W 乘以反射系数，与 `gen_layered_scene` 相同；
  - 观测为 `attenuation_matrix(a)` 乘以目标，a = `ray_absorption(t, 0, config)`，config 取宏观 vp、h、Q。这与 V4 的生成方式相同：所有道用求解器同一个衰减算子。
- **公共设置**：与 F3/F4 相同：dt = 4 ms，451 个样点，99 道，fpeak = 32 Hz，nfft = 4096，fref = 100，solver_offset = 0。
- **噪声**：与 F3/F4 相同：AR(1)=0.45 时间相关加 10% 道间共同分量。Moderate 14 dB（种子 = 基础种子 + 101），Strong 8 dB（种子 = 基础种子 + 102）。σ 用 `estimate_trace_snr` 估计。
- **求解器配置**：与 F3/F4 相同：config.vp、config.h 取宏观值；config.Q 在 C=0 时取第 50 道的上尺度 Q，在 C=1 时取宏观 Q（即真值）。
- 生成脚本 `scripts/make_models.m` 随本方案一起冻结。模型存入 `models/`，真值存入 `truth/`，求解端看不到真值。

## 方法

- **相干标准版、QScan＋标准版、FullCalRefit、QScanRefit**：用 `round3_20261024/run_combo.m` 及其 `core/`、`source/`，从 HEAD 逐字复制到 `cache/runner/`。唯一的改动是把误差档从 7 档改为 {−30, 0, +30}%，生成 `run_combo3.m`。改动由快照脚本完成，并断言替换的文本恰好出现一次。MATLAB R2024b，每个进程 4 线程，最多 2 个进程。
- **SC、QScan＋SC**：与 `qscan_sc_round3_20261026/scripts/run_sc.py` 相同：
  - novelty ff95a69 的 `benchmark.solve`、`predictor` 和 `common.dictionary`；
  - a = 0.125，mu 相对强度 = 10；KKT ≤ 0.02，最多 5000 次迭代；
  - QScan＋SC 用 `run_combo3` 归档的 `scanned.Q`。

共 24 个模型 × 2 档噪声 × 3 档 Q 误差 = 144 行；MATLAB 跑 144 行，SC 求解 288 次。

## 指标

- 相对波形误差 ‖X − T‖/‖T‖，全部道、全时段。
- **主指标**（每个模型一个值）：L_wrong = 该模型 4 个 Q 有误行（±30% × 2 档噪声）上 ln(QScan＋SC 误差 / QScan＋标准版误差) 的平均。大于 0 表示 QScan＋标准版更好。
- **次指标**：L_0 = 该模型 2 个 Q 正确行上 ln(SC / 标准版) 的平均。

## 判定

**1. 复现检查**（先判，决定后面因子结论能否解释 round3 的分化）：

- “V4 型”格子 (A, B, C) = (1, 1, 1) 的 3 个模型 L_wrong 平均 > 0；
- “F 型”格子 (0, 0, 0) 的 3 个模型 L_wrong 平均 < 0。

两条都满足才算 **“复现了分化”**。否则因子判定照常计算，但结论写为“因子设计没有复现 round3 的分化，以下只作描述”。

**2. 因子作用**（对 A、B、C 各判一次，主指标 L_wrong）：

- 每个因子有 12 个配对（3 个种子 × 其余两个因子的 4 种组合）。配对差 d = L(该因子取 1) − L(该因子取 0)。
- **主要驱动**：d 的平均 ≥ ln 1.10，且 d > 0 的配对 ≥ 10/12；
- **有作用**：d 的平均 ≥ ln 1.05，且 d > 0 的配对 ≥ 9/12；
- **反向作用**：把上面两条的符号反过来（d 的平均 ≤ −ln 1.05，且 d < 0 的配对 ≥ 9/12）；
- 其余记为 **无明确作用**。

**3. 次指标**：对 L_0 用同样的规则各判一次，即 Q 正确时 SC 对标准版的分化由哪个因子驱动。

## 只描述

- 8 个格子的 L_wrong、L_0 平均，以及两两交互（配对差在另一因子两个水平下的平均）；
- 各方法在每格每档的平均误差；
- QScan 选择的因子；
- SC 的收敛情况。

## 收敛与失败处理

- 未收敛的 SC 输出照常计入，并标出；另报只用收敛行的敏感性分析。不加大迭代次数，不改容差。
- MATLAB 或 Python 程序出错需要重跑时，记录原因，不改设计。
- 模型生成后不论长什么样都使用；不因为某个模型“看起来不像”而替换。

## 不做

- 不为任何方法调参。不改 QScan、标准版或 SC 的任何参数。
- 看到任何结果后，不改因子定义、门槛、指标或模型。
- 不使用 F1–F4、V1–V5、H1–H6、G1–G8、K1–K8、U1–U4。

## 边界

- 每个因子只有两个水平，而且每个水平捆绑了多个细节：
  - C=1 同时意味着无多次波、无透射损失、宏观 Q 无散布、反射在采样点上；
  - A=1 同时改变了界面数量和强弱比例。
  - 所以结论只能说“哪一组差别起作用”，不能细分到单一物理量。
- 3 个种子，每个因子 12 个配对，配对之间共享种子，不是独立样本；不报告显著性检验。
- 只用一维逐道正演，B=1 的构造是逐道层厚变化，不含绕射。二维效应不在本轮范围。
