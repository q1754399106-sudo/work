用户要求：先做理论推导，慎重考虑后再定方向。本文件只用推导、闭式计算和已缓存的分数，没有新的偏移或补偿运行。脚本在 `scripts/`，数字在 `analysis/`。

## 0. 结论摘要

1. **把 σ 从数据里定窄（上一轮的首选方向）不值得单独立项。** 理论上，Q 信息的价值只出现在 ρ ≳ 1 的频段（定理 1），而且在相关类指标下只来自"中心偏了"那一部分（定理 2）。缓存分数给出的上限是：m30 平均 +0.024~+0.038（σ_c = 0.1，无偏），盈亏平衡在 σ_c ≈ 0.3；噪声主导的 m40 上反而 −0.029~+0.010，因为宽先验在 Q 正确时也在帮忙。这与 OU 随机场只得到 +0.03 上界（11-20 已淘汰）是同一个量。
2. **相关类指标（E1、T2、井旁相关）的最优算子是"Wiener × 参照子波"。** 由此可以统一解释三件事：VDB 在实测上占优、UQ-W 加整形后在 m ≈ 1 无增益、实测井上分不出 Q。Q 错 30% 时，相关只变约 0.013–0.018；实测自助区间宽 0.2–0.45，再怎么比也分不出 Q。
3. **随机极性估噪的偏差有闭式表达。** 逐道翻转把横向相关噪声低估 3.4–14 倍；代入估计式后，1/snr 的预测值是 0.22，阶段 3 实测为 0.20–0.23（事后核对）。事先预测：B = 300 时 l30 的 e ≈ +0.05~+0.07，独立噪声档 e(B300) − e(B1) ≈ +0.04~+0.16，第一步的 A1、A2 都应通过，B* = 300。前提是噪声在炮间独立；实测是否满足，要另做诊断。
4. **结论：** 合成数据上，已没有理论上限大的"改 Q 模型"类新方法。剩下最大的可得收益在估噪（l30 上 m = 1 时 +0.04~+0.09）。实测缺口来自算子形式（频散参考、谱形）和评价指标，不来自 Q 不确定度建模。

## 1. 定理 1：期望算子的风险分解

单频、单道：D = H R + N，R 与 N 独立，功率 S、n；H = exp(−u z)，z = α − iβ，α = πf t*，β = 2f t* ln(f/f_r)（与 `uq_tab.m` 同号约定，只用到 |z|）。u 是真实衰减对模型的倍数，先验为 π(u)。

期望算子 K = E[H]* S / (E|H|² S + n)。它的贝叶斯风险（对 u、R、N 求期望，再除以 S）可写成：

  R_B = 1 − c·ρ̃/(1 + ρ̃) = 1/(1 + ρ̃) + (1 − c)·ρ̃/(1 + ρ̃)

其中

- ρ̃ = E|H|² S / n，是先验平均意义下的信噪比；
- c = |E H|² / E|H|²，是传递函数在先验下的相干度，取值 [0, 1]。

这是恒等变形，对任何先验都成立。第一项是"已知平均功率"的噪声风险，第二项是 Q 不确定度带来的附加风险。

**高斯先验 u ~ N(ū, s²) 时有闭式解：** c = exp(−s²|z|²)。蒙特卡罗（2×10⁶ 次）与闭式在 6 组参数上相差 ≤ 0.0005（`analysis/t_bayes.json` part1）。代码用的是对数正态先验，此时 c 要数值求；s|z| ≳ 0.7 时与高斯闭式差 0.09–0.28。分解式本身照样成立。

**推论 1a（噪声主导时 Q 信息没有价值）：** ρ̃ ≪ 1 时，附加项 ≤ ρ̃，与 s 无关。所以 σ 定得再准，在噪声主导频段也什么都得不到。

**推论 1b（价值集中在哪里）：** 附加项要大，需要同时满足 ρ̃ ≳ 1 和 s|z| ≳ 0.5。

在频带边缘，ρ(f) = 1 处有 πf t* ≈ ½ ln(SNR₀)。30 dB 时约 3.45 Np，σ = 0.447 对应 s|z| ≈ 1.5，σ = 0.1 对应约 0.35。所以 MSE 意义下，缩小 σ 的收益集中在频带上缘。第 2 节说明，相关类指标几乎不计这部分收益。

## 2. 定理 2：相关类指标下的最优算子

仓库里的评分（E1、T2、实测井旁相关）都是归一化相关：常数增益不计；E1 和井旁相关还允许 ±2–3 个样点的时移。设参照为 W(f)·R(f)，W 是参照子波（实测井旁为箱形带通）。成像为 K(H₀R + N)，相关为

  ρ = Re Σ_f W* K H₀ S_f / √( Σ|W|²S_f · Σ(|K H₀|² S_f + |K|² n_f) )

由加权 Cauchy–Schwarz 不等式，最大值在下式取得：

  K* ∝ W · H₀* S / (|H₀|² S + n)，  ρ_max² = ⟨ρ_f/(1 + ρ_f)⟩，权重为 |W|² S_f

Q 不确定时同理，K*_UQ ∝ W · E[H]* S/(E|H|² S + n)，ρ_max² = ⟨c_f ρ̃_f/(1 + ρ̃_f)⟩（同一权重）。

**推论 2a：UQ 在 Q 正确时代价小。** 中心正确时，UQ 只是给每个频率乘一个平滑的实系数（c 的效应）。在相关指标里，这只改变频率权重，不引入相位误差。缓存分数中 m = 1 时 UQW1 − W1 为 −0.020~−0.003（m30），与此一致。

**推论 2b：UQ-W 加整形后，在 m ≈ 1 没有增益。** 最优算子已经是"Wiener × W"；整形把输出谱定成 W 以后，UQ 部分剩下的作用只是对 SNR 权重的微调。这解释了 `uqw_shaping_confirm_20261119` 中 m ≈ 1 时 UQW_TI 比只整形低 0.014，以及"UQ 部分只在 Q 给错时有用"。

**推论 2c：VDB 在实测上占优。** VDB 的时变维纳整形正是在逼近 K* 中的 W 因子。T2 偏爱输出谱接近参照子波的方法，这是定理本身的结论，不是指标的偶然偏差。11-18 消融（差距几乎全来自整形）是它的实例。

**推论 2d：实测的分辨下限。** 对 u 的相对误差 d，输出相对最优的偏差是对数振幅倾斜 A(f) = d·πf t* 和相位 φ(f) = d·2f t* ln(f/f_r)。常数增益和线性相位（时移）被指标吸收以后，小误差下：

  1 − ρ ≈ ½ Var_w[A] + ½ E_w[φ⊥²]

其中 φ⊥ 是去掉最佳线性拟合后的相位。对下表三种实际情形，d = 0.26 时这个近似与精确值相差 ≤ 0.0006；d = 0.69 时近似偏高 0.015–0.024，表中用精确值（`analysis/t_floor.json`）。φ⊥ 只有 1–4°，所以几乎全部来自振幅倾斜。

| 情形 | 频带 | 被补偿的 t* | Q 错 30%（d = 0.26） | Q 错 2 倍（d = 0.69） |
|---|---|---|---|---|
| Volve RTM，F-5 井旁 | 4–25 Hz | 0.033 s | 0.013 | 0.082 |
| 叠后 Volve，锚点以下 | 10–62 Hz | 0.0153 s | 0.018 | 0.104 |
| 合成 RTM 深部窗 | 5–50 Hz | 0.016 s | 0.015 | 0.088 |

这是无噪声、只计信号形状的下限。过补偿一侧还有噪声放大，损失大得多：合成上 W1 在 m = 0.5 时低 0.30。但欠补偿一侧和小误差时，Q 错 30% 只差约 0.015，而实测自助区间宽 0.2–0.45（实验 7、9、13）。**实测井旁相关在理论上就分不出 30% 的 Q 误差。** 这解释了实验 9、13 中"c = 0.77 与 SR 分不出、方法间差 0.01–0.07"的现象。要分辨，需要频带更宽（下限 ∝ 带内频率方差）、t* 更大，或者换参照（VSP 直达波谱比）。

**推论 2e：频散参考频率错位。** 只差一个时移 τ = t* ln(f_used/f_true)/π，外加很小的非线性相位。Volve RTM 若真参考为 25 Hz 而用 100 Hz，τ ≈ 14.6 ms（双程）；叠后为 6.8 ms。井旁评价只允许 ±3 个样点时移，吸收不完。这与阶段 4 事后检查中"f_ref 改 25 Hz 收回约一半差距"同量级。但"只补振幅仍低于不补偿"这件事，本节解释不了，仍未解决。

## 3. 缩小 σ（谱比校准后验）的价值上限

由定理 1、2，校准的价值 = E_真值[score(宽先验 UQ, m)] − E[score(校准后, m_eff)]。用 C1–C4 深部窗 E1 的缓存分数估上限：

- 校准后残差 ln m_eff ~ N(b, σ_c²)。
- 校准后的分数近似为 W1(m_eff)，即 σ_post → 0 的极限，在 ln m 上线性插值。
- 对照是 UQW1 在 m 网格上的平均和最差值（`analysis/t_bayes.json` part2）。

| 数据 | UQW1 平均（最差） | 校准 σ_c 0.1 | 0.2 | 0.3 | b = ±0.15、σ_c 0.1 |
|---|---|---|---|---|---|
| m30 | 0.835（0.738） | 0.864（逐模型 +0.024~+0.038） | 0.853 | 0.835 | 0.849–0.865 |
| m40 | 0.623（0.545） | 0.614（逐模型 −0.029~+0.010） | 0.603 | 0.587 | 0.599–0.611 |
| l30 | 0.598（0.553） | 0.530 | 0.519 | 0.504 | 0.491–0.548 |

解读：

1. **m30：** 平均最多 +0.03，盈亏平衡在 σ_c ≈ 0.3；最差情形从 0.738 升到约 0.86（+0.12），这是唯一大的收益。offset_q_avo 在 24 dB、50 个 CMP 上谱比校准的 ln 误差均方根为 0.091，所以 σ_c ≈ 0.1 在合成上做得到。
2. **m40：** 校准反而不利。m = 1 时 UQW1 比 W1 高 0.004–0.043，即宽先验在 Q 正确时也在起正则作用。这与 `uqw_rho_ablation_20261119` 一致：噪声主导时左尾 u ∈ [0.1, 0.5] 是主因。把 σ 定窄就去掉了这层保护。
3. **l30：** 估噪坏了，W1 本身就差，校准帮不上。
4. **结构偏差（没有算进上表）：** 炮检距谱比测的是远、近道路径差上的加权 1/Q，权重 w_off(z) 与成像点需要的 w_img(z) 不同。非标量误差（如 E4 深浅反向）会产生偏差 b = Σ(w_off − w_img)ε(z)，量级可达 ε 本身，而后验很窄，等于"自信地错"。要修就得逐层剥离做 Q 层析，那是已有方向（波动方程 Q 层析、ADCIG 谱比），新意很少。
5. **信息匹配（正面结论）：** 炮检距谱比对 u 的 Fisher 信息，按频率的权重约为 (πfΔt*)²·ρ²/(1+ρ)²；补偿价值的权重为 ρ/(1+ρ)。两者都在噪声主导频段消失，所以不会出现"校准有信息却没价值"的情形。代价在杠杆比 Δt*/t*：偏移距/深度 ≈ 1 时约 0.1，测量噪声被放大约 10 倍。Volve CIP 道集定不了储层段，就在这里。

**判断：** 平均上限（+0.03）与 OU 随机场被淘汰时的上界相同，噪声主导时为负，还有结构偏差风险。不立项。只有当用户明确把"最差情形"作为目标时，才值得重新考虑。

## 4. 定理 3：随机极性估噪的偏差，以及分块翻转的事先预测

### 4.1 推导

某成像点、某频率，炮 s 的噪声像为 Σ_j g_sj n_sj，g 是源、检两侧格林函数之积的共轭。噪声的检波点间协方差为 C(j − k)，炮间独立。

- 真值：N_t = Σ_s Σ_jk g_sj g_sk* C(j−k)。
- 每 B 道共用一个随机符号：N_B = 只对同块的 (j, k) 求和。B = 1 时 N_1 = Σ|g|²C(0)；B = 300 时 N_300 = N_t。
- 信号泄漏（期望）：L_B = Σ_s Σ_块 |Σ_块内 s_sj|²。叠加信号为 S = |Σ s|²。
- 估计式（`est_noise2.m`、`est_block.m`）：p = S + N_t，pf = N_B + L_B，1/snr_est = pf/(p − pf)，真值为 N_t/S。

记 t = N_t/N_1（横向相关放大倍数），q = N_1/S，λ_B = L_B/S，r_B = N_B/N_1，则

  est / true = (r_B q + λ_B) / [(1 + t q − r_B q − λ_B) · t q]

在波数域，t ≈ ⟨Ĉ(k_x)⟩：对各检波点局部水平波数 k_x = f sinθ/v 求平均，Ĉ 是 C 的离散傅里叶变换（l30：C(Δ) = exp(−Δ²/4σ²)，σ = 5 道，Ĉ(0) = 17.7）。t 随频率下降，因为高频时 k_x 落到 Ĉ 的通带之外。

**B = 1 时两个误差叠加：** 分子少了 t 倍；分母 p − pf 里多出 (t − 1)q。q ≈ 1、t ≈ 5 时，est ≈ 1/(1 + 4) = 0.2，而真值约为 5，低估约 25 倍（log₂ ≈ −4.6）。

### 4.2 数值（`scripts/t_blockflip.py`）

计算设置：常速度 2300、2700 m/s，二维远场格林函数，`rtm_setup.m` 的观测系统（300 道 × 8 m、51 炮 × 40 m），W_deep 内 13 × 7 个成像点，10–50 Hz；信号用穿过成像点的水平反射层；e 先对点取中位数，再对频率取中位数。

- **横向相关放大倍数** t = 5.7–6.7（10 Hz 时 13.6–14.5，50 Hz 时 3.4–4.0）。
- **保留比例** r_B/t：B = 8 为 0.80–0.85，B = 32 为 0.94–0.97，B = 300 为 1。
- **信号泄漏** λ_B：B = 1 为 0.003–0.004，B = 8 为 0.02，B = 32、300 为 0.03。

| 数据（q = N₁/S） | B = 1 | B = 8 | B = 32 | B = 300 |
|---|---|---|---|---|
| l30，q 0.3 / 1 / 3 | −3.8~−6.9 | −0.5~−2.6 | −0.1~−1.0 | +0.05~+0.07 |
| m30，q 0.3 / 1 / 3 | +0.01~+0.02 | +0.04~+0.14 | +0.06~+0.18 | +0.06~+0.18 |

（区间覆盖两个速度；完整数字见 `analysis/t_blockflip.json`。）

**事后核对（阶段 3）：** q ≈ 1、40 Hz 处 t ≈ 4.3–5，代入得 l30 估计值 ≈ 0.19–0.23，实测 0.20–0.23。

### 4.3 事先预测（第一步，`PLAN_BLOCKFLIP_ZH.md` 第 3 节的门槛）

- P1：B* = 300。按 max|e| 最小选，B = 32 在 q 较大的 l30 上 |e| 接近或超过 1。
- P2：A1 通过，B = 300 时 l30 的 4 个模型 |e| ≤ 1，预测在 +0.0~+0.3 之间。
- P3：A2 通过，m30、m40 上 e(B300) − e(B1) 在 0 到 +0.3 之间（远小于 +0.5）。
- P4：B = 1 时 l30 的 e 在 −3 到 −7 之间，低频端更负。

**适用范围：** 模型忽略了 ±5 Hz 频带求和和 400 m 方框平滑（只影响方差）、速度变化、多层反射与透镜（只影响 λ_B），也忽略了单个实现的随机涨落：B = 300 只有 51 个独立符号，方差最大。如果实测 e 与 P2 差到 1 以上，最可能的原因是泄漏被低估（真实单炮像中的画弧能量）或涨落。

### 4.4 推到实测的条件

B = 300 的无偏性要求噪声在炮间独立。按定理 3，凡是在炮间相干的部分都会被算作"信号"：涌浪、船噪声若跨炮相干，多次波、面波，以及速度误差造成的残余画弧都在内。阶段 4"把画弧当信号"属于这一类。

所以在把方法推到实测之前，应先做一个廉价诊断：在 Volve 第 79 序列的初至前或信号后时窗，量出噪声的炮间相关和检波点间相关。这批数据已在本地 `cache/volve_seq079`。

## 6. 未检验的假设

- 定理 1、2 是逐频独立的标量模型，忽略了偏移中各频率共用的空间聚焦。
- 第 3 节用 W1 代替"后验 UQ"，是 σ_post → 0 的极限。后验 UQ 在 m40 上应介于 W1 和 UQW1 之间，所以"m40 为负"的结论对于 σ_post 较大的情形偏悲观。
- 第 4 节是常速度、单层反射的几何模型，q 是自由参数。
