# 第 1 步：稳定化的闭式一致正则（看结果前提交）

日期：2026-11-06。用户说“开始”。上一轮 T4 不过，原因是残差原则选 λ 时噪声不稳。这一步加噪声下限，并冻结做法，到新模型上检验。

## 方法（冻结）

对每道独立求解（一步反演）：

```text
ŝ(x) = [G'G + λ diag w(t, x)]⁻¹ G' d(x)

w(t, x) = max( exp[−2π fc*(t) a_x(t, x)], w_n(t, x) )
fc*(t) = ∫S²ρ(1−ρ)f df / ∫S²ρ(1−ρ) df，ρ = 1/(1 + λ e^{2π f a₀(t)})
w_n(t, x)：使 N²(a₀ + a_x, w) ≤ γ² N²(a₀, 1) 的最小 w，N²(a, w) = ∫ β² / (β² + λ w)² df，β = e^{−π f a}
```

**γ = 6。** 全道集共用一个 λ，取残差 ≤ σ√(n·NX) 的最大 λ（网格 10⁻⁶ 到 1，13 个）。σ 已知。
