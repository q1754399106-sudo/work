# 第 2b 步：频率饱和阻尼的冻结检验（看结果前提交）

日期：2026-11-06。来由见 `DIAG_ZH.md`。这一步问：**把单频阻尼换成频率饱和算子后，在没用过的模型上，带内 AVO 是否真的比分步一致，同时波形不差？**

## 方法（冻结）

`(G'G + λ L'L) s = G'd`，L 符号 `exp[−π min(f, f_n(t,x)) a_x(t,x)]`，`exp(−2π f_n a_x) = w_n(t,x)`，w_n 同 `stable.py`，**γ = 6 沿用第 1 步，不重新选**。开发时 γ = 10 也有吸引力，但重新挑选等于多一次事后选择，所以不改。全道集一个 λ，残差原则选，网格 `logspace(−6, 0, 13)`，σ 已知。不用子波谱。

实现：`scripts/satdamp.py`、`scripts/step2b.py`。

## 设置

- 新模型，全部没用过：M12 Q = [55, 40, 100, 70]，M13 [28, 65, 40, 90]，M14 [70, 28, 35, 50]，M15 [40, 120, 60, 30]。
- 子波 60、40 Hz；场景 `events`、`thin`、`dense`，各 `aligned`、`nmo`；信噪比 18、12 dB；Q ×1、×0.8、×1.2；10 个种子。共 288 个单元。
- 比较：频率饱和、分步、单频阻尼（第 1、2 步的方法）、一步法。各自用残差选 λ。

## 指标

- **逐事件 G/A 误差**：事件 ±3/f_p 窗口内，⟨B, A_t⟩/⟨A, A_t⟩ 减去真值的同样比值，三个事件取绝对值平均。带通 10 Hz 到子波主频（60 Hz 子波 10–60，40 Hz 子波 10–40）。无噪版本：同一 λ 和算子作用在无噪数据上。
- 只在 `events`、`thin` 上算；`dense` 窗口内有其他反射，不适用。
- 波形误差、E_G、M_G、局部归一化 E_G、梯度相关，定义同前（带通同上）。

**这个主指标是诊断后才加的。** 理由是 M_G、E_G 的全局归一化混入了时变分辨率（`DIAG_ZH.md`）。旧指标继续报告，并以 R5、R7a 作为保护。

## 判定（每单元取种子平均，再取中位数）

| 判定 | 内容 | 单元 | 门槛 | 开发值（饱和 / 分步） |
|---|---|---|---|---|
| **R1** | 无噪逐事件 G/A | 拉平、Q 正确、events+thin（32） | 饱和 ≤ 分步 × 0.5 | 0.003–0.007 / 0.015–0.029 |
| **R2** | 无噪逐事件 G/A 好于分步的单元比例 | 同上 | ≥ 80% | |
| **R3** | 有噪逐事件 G/A | 同上 | 饱和 ≤ 分步 | 0.049、0.047 / 0.063、0.049 |
| **R4** | 波形 | 拉平、Q 正确、全部场景（48） | 饱和 < 分步 | 0.597 / 0.649 |
| **R5** | E_G（旧指标，保护） | 同上 | 饱和 ≤ 分步 × 1.1 | 0.591 / 0.570 |
| **R6a** | 波形，Q 错 | 拉平、Q 错（96） | 饱和 ≤ 分步 | 0.780 / 0.802 |
| **R6b** | 有噪逐事件 G/A，Q 错 | 拉平、Q 错、events+thin（64） | 饱和 ≤ 分步 × 1.1 | 0.325 / 0.334 |
| **R7a** | E_G，NMO（保护） | NMO（144） | 饱和 ≤ 分步 × 1.1 | 2.262 / 2.261 |
| **R7b** | 波形，NMO（保护） | NMO（144） | 饱和 ≤ 分步 + 0.01 | 0.744 / 0.742 |
| **R8** | 单元波形比（饱和 / 分步）的最大值，防噪声放大 | 全部（288） | ≤ 1.5 | 开发最大 1.013 |
| **R9** | 无噪逐事件 G/A | 同 R1 | 饱和 ≤ 单频阻尼，且 ≤ 一步法 | 0.003–0.007 / 约 0.06–0.10、约 0.5 |

**R7b 的容差：** 第 2 步的 U2 要求严格不差于分步，结果因 0.001 不过。这里事先给 0.01，因为 NMO 下只要求“没变成害处”，而 0.01 远小于方法之间任何有意义的差别。这是看过 U2 结果之后才放宽的，这里写明；它不改第 2 步的判定，第 2 步对单频阻尼的结论仍是不通过。

全部通过：频率饱和阻尼取代单频阻尼，作为后面和基线比较的方法。任何一条不过：停下来汇报，不改方法重跑。门槛是我定的经验值。

**通过也只说明：拉平数据上带内 AVO 比分步更一致、波形不差。不说明解决了拉伸或速度误差，也不说明比 FullCalRefit、SC 好。**

## 只作描述

按场景、子波、模型、信噪比、Q 分组的同样统计；有符号的逐事件 G/A；M_G、局部归一化 E_G、梯度相关；λ 退到网格最小值的次数。

## 我开跑前的预期（可能是错的）

- R1、R2 大概率过，这是推导直接预测的，除非强非平稳（浅层低 Q）破坏平稳近似。
- R3 不确定：开发时薄层几乎打平，40 Hz 子波下偏差本来就小，差异可能被噪声盖住。这是最可能的失败点之一。
- R6b 也可能不过：开发时 Q ×0.8 比分步差。M13、M14 的低 Q 层是对 R8 的考验。
