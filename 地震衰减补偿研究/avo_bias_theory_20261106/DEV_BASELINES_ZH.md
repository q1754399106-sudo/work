# 基线比较的开发结果（不是冻结检验）

日期：2026-11-06。**只用已经用过的模型，只作描述，不算证据。** 目的是在写第 3 步规则之前看清楚格局。冻结检验没有开跑。

## 基线怎么放到炮检距道集上

这些基线大多是为共偏移距剖面设计的，放到道集上需要适配，所以下面不是它们主场上的表现。所有方法都用相同的 Q 和已知 σ。

| 名称 | 做法 | 说明 |
|---|---|---|
| `FCR` | 仓库原始 `reflectivity_refit_prepared`，每个炮检距一个字典 | 只是 FullCalRefit 的反演部分，没有标定；字典用真子波，除非另说明 |
| `SC` | `novelty_evidence_20261025` 的 Ma 等 2023 式 17 实现，参数冻结 a = 0.125、μ = 10，改成逐炮检距字典，用炮检距轴代替侧向轴 | 在原文件之外重写了一份（`base_common.py`）；密集场景常到 5000 次还没收敛，比如 M1 Q 正确 3 个种子里有 2 个、6 列中 3 列 |
| `SC0` | 同上，a = 0.5，无结构项，即单道 lasso | |
| `Frozen` | 原始 `prepare_models_v2`、`uq_select`，Offset 域；跳过 Q 估计，σ 改为已知 | 其余不变 |
| `band3` | **我按 Ratnett 等 2019 的思路实现**：加窗 Fourier 反 Q，不限增益，到频率上限后高切 | 原文没有公式。原文按峰值频率定上限，噪声大时我实现的版本不可用（波形 1.9–3.5）。我改用信噪比规则：道集平均谱超过 3 倍噪声的最高频率，**k = 3 是在 M1 上挑的**，有意给它最好的条件；这不是他们的原方法 |

相干标准版、QScan 没有放进来，因为它们依赖侧向相干或共偏移距假设。

## 三个模型上的上限检查（M1、M10、M11，5 个种子，均值）

## 怎么理解

1. **有稀疏结构时，稀疏类方法赢得很彻底。** 孤立事件和薄层上 `SC0`、`FCR` 的波形是 0.06–0.2，新方法 0.5 以上。主频错 20% 时它们的 E_G 和波形大多仍更好。
2. **带内指标上，简单的限频反 Q 是最强的对手。** Q 正确或偏高时，它的 E_G 比新方法好，最优 λ 也追不上（孤立事件、薄层）。我的解释是：限频在上限内增益是平的，而 Tikhonov 型的 ρ(f) 从低得多的频率就开始下降。这个解释没有单独验证。
3. **新方法还站得住的地方：**
   - 逐事件 G/A 误差较小（0.069 对 0.085 等），子波错时明显小于稀疏类方法；
   - Q 偏低时稳定（波形 0.83–0.94，`band3` 1.4–2.6）；
   - NMO 下 E_G 更好（1.028 对 1.106，Q ×0.8 时 1.092 对 1.300）；
   - 线性、无稀疏假设、不用子波谱。
4. **`band3` 的 k = 3 和新方法的 γ = 6 都是在用过的模型上定的，这里都没有独立验证。**

## 局限

全部是开发数据；M1 表只有 3 个种子；只有 60 Hz；`band3` 是我的实现和我的上限规则，不等于 Ratnett 等的方法；基线不在主场。
