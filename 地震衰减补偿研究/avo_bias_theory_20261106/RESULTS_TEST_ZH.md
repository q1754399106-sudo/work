# 闭式增益和 fc*(t)：新模型检验结果

日期：2026-11-06。方案在运行前提交（`8568aec`，`THEORY_ZH.md`）。模型 M4、M5 和种子此前没有用过。数字来自 `results/verdict.json`。全部是孤立事件、理想拉平的合成数据。

## 结论

**按预设规则总判定不通过：T1、T2、T2b、T3 都过了，T4 没过。** T4 没过的原因只在波形：残差原则选 λ 时，M5 上 fc* 的噪声放大明显更大。

闭式公式和固定 λ 下的方法性质都在新模型上复现了。这是目前这条线最强的结果，但方法还不能算成立：还没有可靠的不用真值选 λ 的办法，Q 偏低时比分步差，NMO 拉伸和速度误差也都没有解决。

## 描述

**平均 |偏差|，18 dB（λ = 10⁻³ / 10⁻²）：**

| Q | fc* | 分步 | 一步法 |
|---|---|---|---|
| 正确 | 0.016 / 0.015 | 0.077 / 0.057 | 0.853 / 1.134 |
| ×0.8 | **0.584 / 0.409** | 0.392 / 0.382 | 1.003 / 1.255 |
| ×1.2 | 0.368 / 0.319 | 0.393 / 0.360 | 0.811 / 1.071 |

Q 取小时 fc* 比分步差，这和开发结果一致，是已知弱点。Q 错误带来的偏差（约 0.3–0.6）比正则化偏差大得多，所有方法都一样，只有提高 Q 精度才能解决。

**残差原则下的情况（`t4_look.py`，事后）：**

| 模型 | 方法 | λ | 波形 | |偏差| |
|---|---|---|---|---|
| M4 | fc* | 3.2×10⁻³ | **0.456** | 0.020 |
| | 分步 | 3.2×10⁻³ | 0.558 | 0.027 |
| | 一步法 | 1.0×10⁻³ | 0.432 | 0.604 |
| M5 | fc* | 5.6×10⁻⁴ | **1.069** | 0.024 |
| | 分步 | 5.6×10⁻⁴ | 0.577 | 0.147 |
| | 一步法 | 1.8×10⁻⁴ | 0.590 | 0.901 |

M4 上 fc* 的波形和偏差都好于分步。M5 浅层 Q = 30，a_x 大，权重 exp(−2π fc a_x) 把浅层远道的阻尼压得很小，噪声被放大，而残差原则看不出来（放大的噪声对数据残差贡献很小，这和 EI 实验的现象类似）。这是推断，没有单独验证。Q×0.8、M5 时，fc* 的波形达到 8.06，是严重的不稳定，实际使用前必须解决。

**子波谱错误（计算 fc* 时用错主频，18 dB，λ = 10⁻³ / 10⁻²）：** ×0.8 时 0.102 / 0.151，×1 时 0.014 / 0.013，×1.2 时 0.048 / 0.108。主频错 20% 时偏差增大，优势大体消失，比一步法仍好很多。

**一阶公式：** 只在开发集上看过，R² 约 0.54，不用于设计。

## 局限

- 孤立事件、理想拉平、独立正演但几何相同。第 1 关显示 NMO 拉伸和速度误差的影响更大，fc* 不解决这两点。
- 真子波谱已知（子波错误只作描述），残差原则用已知的 σ。
- 只有 2 个新模型，判定门槛是看过开发结果后定的。
- 没有和 FullCalRefit、SC、Frozen 比较。
- 新颖性未核实：WoS、CNKI 没查，两步法论文全文没读。
- λ 网格固定 4 个值的结果里，极小 λ 的情形没有实际意义。
