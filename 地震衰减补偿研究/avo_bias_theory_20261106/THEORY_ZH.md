# 吸收补偿中炮检距一致正则的闭式设计：理论和检验方案

日期：2026-11-06（看新模型结果前提交）。用户要方法创新。

## 1. 问题

叠前道集上，道 x 的事件 t 经过的吸收路径 a(t, x) = a₀(t) + a_x(t, x)。对每道做 Tikhonov 补偿：

```text
ŝ = (G'G + λI)⁻¹ G' d
```

同一个 λ 对远道的高频压得更早，所以振幅随炮检距下降，形成假 AVO 梯度。这个偏差和噪声无关。

## 2. 闭式增益

局部平稳近似下，事件频谱乘以

```text
net(f, x) = H(a_t) H*(a_m) / (|H(a_m)|² + λ w)，H(a) = exp[−π f a + i 2 f ln(f/f_ref) a]
```

a_t 是真路径，a_m 是模型路径。用子波 S 做匹配滤波，读到的振幅是 r(x) Γ(x)：

```text
Γ(x) = ∫ S² Re net df / ∫ S² df
```

它没有拟合参数。把 r(x)Γ(x) 对 sin²θ 拟合，就得到预测的 G/A。分步法的 net 换成两步的乘积。

Q 正确时记 ρ = |H|²/(|H|² + λ)，有 ∂ln Γ/∂a = −2π ⟨f(1−ρ)⟩，权重 S²ρ。

## 3. 方法：闭式一致频率 fc*(t)

把阻尼改成随时间和炮检距变化：

```text
λ w(t, x) = λ exp[−2π fc(t) a_x(t, x)]
```

此时 ∂ln Γ/∂a_x = −2π ⟨(f − fc)(1−ρ)⟩。令它等于零：

```text
fc*(t) = ∫ S² ρ(1−ρ) f df / ∫ S² ρ(1−ρ) df，ρ = 1/(1 + λ e^{2π f a₀(t)})
```

**即 fc*(t) 是正则过渡带的谱质心。** 它只用模型 Q、λ 和子波谱，不用真值和反复试算。求解仍是一步反演，不需要分两步。

这也解释了之前的现象：Q 取小时 a₀ 变大，过渡带移向低频，所以最优 fc 变低。

## 4. 已见的开发结果（M1–M3，不是证据）

调试时看到（`results/dev.json`）：

- 闭式 G/A 预测：一步法斜率 1.004，R² 1.000；分步 1.013 / 0.998（60 dB）。
- 一阶公式（线性于 a_x，小角度）差得多，R² 约 0.54。它只用于解释，不用于设计。
- fc*(t) 18 dB、λ = 10⁻³：|偏差| 0.022，波形 0.675；分步 0.081 / 0.720；一步法 0.821 / 0.586。
- **Q 错误时 fc*(t) 的 |偏差| 0.49，分步 0.38，一步法 0.80。**

## 6. 局限

- 孤立事件、理想拉平。第 1 关显示 NMO 拉伸和速度误差的影响更大，这一步**不解决**这两点。下一步要在 NMO 场景里看。
- 真子波谱已知，模型 Q 已知（Q 错误只作描述）。
- 残差原则用已知的噪声 σ。
