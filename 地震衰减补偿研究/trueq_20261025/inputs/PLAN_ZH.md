# 登记：复杂模型“真 Q 上限”诊断

登记时间：2026-10-25，运行之前。

## 问题

复杂模型上收缩规则只改善约 1%，子波相位（单独）、干扰、多次波已排除。剩余瓶颈是 Q 标定（四层平均 Q 代替二维横向变化的 Q，深层标定偏差大）还是薄层调谐 / 稀疏模型极限？

## 数据

V5（已见数据，coherence_soft_v2 封存验证用过）。用冻结生成器的副本 `core/gen_complex_truth.m` 重新生成同一模型（必须逐值复现归档观测），额外取出每道真实衰减 a(t)（含偏移距路径因子，与正演完全相同）、每道主频与相位。

三类输入：
- 含噪 Moderate、含噪 Strong（归档观测）；
- 无噪声一次波 primary_att（无多次波、无干扰、无噪声，Moderate 的增益与静校正），σ 用归档 Moderate 的估计。

## 三种字典

| 字典 | 衰减 | 子波 |
|---|---|---|
| Cal | 四层标定 Q（现行做法） | 零相位 Ricker，标定主频 |
| TrueQ | 每道真实 a(t) | 零相位 Ricker，标定主频 |
| TrueQW | 每道真实 a(t) | 每道真实子波（主频、相位 24±7°、鬼波） |

每种组合计算 FullCalRefit、SoftGroupRefit 与相干标准版（λ 0.5/16；相干度用 Ricker 贡献计算）。评分：全道、低能量区、断层、尖灭、深部误差。

## 判断规则

以含噪数据两种噪声的平均全道误差 E 计：

- Q 标定的贡献 = (E_Cal − E_TrueQ) / E_Cal。≥10% 判为 Q 标定是主要瓶颈之一，下一步改进标定（横向 / 深层 Q 约束）。
- 子波的贡献 = (E_TrueQ − E_TrueQW) / E_Cal（在真 Q 下再看子波，与 round3 只换相位不同）。
- 无噪声一次波 + TrueQW 的误差即“模型完全已知时”的极限：若仍 >0.30，判定薄层调谐 / 稀疏模型极限是主要瓶颈。
- 标准版相对 FullCalRefit 的改善在三种字典下分别报告，看收缩的作用是否随 Q 变准而变化。
