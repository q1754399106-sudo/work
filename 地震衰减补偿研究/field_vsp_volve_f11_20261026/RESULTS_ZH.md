## 结论

> **实测仍为“无法判定”。** 这口井同样没能给出可识别的 Q。即使改用事后修正的 Q，井上指标也区分不了方法：不补偿的输入在主指标上就是最高的，两条走廊叠加之间的差距（0.064）是判定阈值 0.02 的 3 倍，而且两口井的方向相反。使用规则“Q 可信用 SC，Q 可能有误用 QScan＋SC”在实测上**既没有得到支持，也没有被否定**。

1. **登记的 Q 估计不可用（G1、G1b 都不通过）。**
   - 段 RS：Q = 10.1，90% 区间 3.3–147。段 NI：Q = 11.5，区间下限 5.4、上限无穷大。顶层估出的 t\* 为负。
   - 原因是登记的剔除规则有缺陷：每一级都和“上一个保留级”比较初至时差。承包商在原始叠加上的拾取噪声较大（RSVSP 相邻级之间会跳 +26 ms、−6 ms），一旦剔掉一级，后面各级与它的时差会越积越大，于是连锁地全部剔除。两段各只剩 7 级，Δτ 最大只有 0.04 s 和 0.03 s。代码是照方案文字实现的，缺陷在规则本身，运行后才发现。
   - 按方案，G2–G5 全部只作描述。用 Q≈10 跑出的所有补偿结果严重失真（2–3 s 内 60–100 Hz 的能量放大 10⁹–10¹⁴ 倍）；SC 在 10 个运行中都没有收敛。这些结果没有解释价值，只在 `analysis/scores.csv`、`analysis/gates.json` 中如实保留。

2. **事后修正的 Q（不登记，只作描述）。** 只剔死道，其余与登记代码相同（`scripts/posthoc_vsp_q.m`）：

| | 段 RS（RSVSP 上段，98 级） | 段 NI（NIVSP，152 级） |
|---|---|---|
| Q（90% 区间） | **78.5（69–90）** | 135（77–472） |
| 单级 R² 中位数（门槛 0.5） | 0.491 | 0.19 |
| 斜率区间下限 > 0 | 是 | 是 |

| Δt\* 对 Δτ 回归的 R² | 0.58 | 0.03 |
| G1 | 不通过（只差第 1 条） | 不通过 |

   - 段 RS 是 3 次实测中最接近通过的一次：斜率稳定、CFS 一致，只有单级 R² 中位数差 0.009。
   - 顶层仍不通过（t\* 为负）。这个参照级在套管段，水听器参照的谱比可能受套管鸣震影响。

3. **井上指标区分不了方法（事后 Q 运行，只作描述）。**

   - **不补偿的输入在 V0 上最高。** G3 对 SC、QScan＋SC、标准版都不通过；只有 V+30 的标准版高出输入 0.046。
   - **分辨力不够。** 同一口井，Input 对 1C（W1）和 3C（W3）两条走廊叠加的相关差 0.064，是阈值 0.02 的 3 倍。许多运行的最佳时移落在 −20 ms 的搜索边界上。
   - 描述上，G2（SC − QScan＋SC，V0）为 +0.139，SC 更好；G2b（SC − 标准版）为 +0.045；G5 有 3/4 个错误起点 SC 更好，与使用规则的后半句**相反**。
   - G4 通过：5 个起点的 QScan 隐含比例 0.65–0.90，都在 Q_NI 的宽区间内。QScan 一致选择比 VSP 估计更强的补偿，与 F-15A 的方向相同。但这个区间宽到 0.57–3.49，不说明 QScan 找回了真 Q。
   - T2（合成记录，2.32–2.80 s）上，Input 只有 0.081，各方法 0.09–0.26。G2 在 T2 上为 +0.037（SC 更好），G2b 为 −0.011。

4. **F-15A 补算（只作描述）方向相反。**

   - F-15A 的 V0 上 QScan＋SC 比 SC 高 0.061，与 F-11 事后运行（SC 高 0.139）方向相反。
   - 4 个错误起点上，QScan＋SC − SC 为 −0.004、+0.041、−0.026、−0.041，没有一致方向。
   - SC 与标准版在 F-15A 上相当：V0 差 +0.008，R0 差 +0.015。

## 对研究方向的含义

- 三次实测（U1320A、F-15A、F-11 T2）都没有得到可识别的 VSP Q，而且井上相关的分辨力（两条合理参照之间差 0.06）比方法之间的差别更粗。再找同类单井资料，大概率还是“无法判定”。
- 要在实测上分辨方法，需要的不是更多的井，而是一个分辨力更高的参照：例如用 VSP 上行波成像直接比较同一位置的子波，或者有全频带、相位可信的近井标定。
- 登记规则的教训：初至剔除不能“与上一个保留级”比较，否则会连锁剔除；以后的方案应与原始相邻级比较，或者只剔死道。
- 事后看来，段 RS 的 Q≈79（69–90）是这口井最可信的独立 Q 估计。它与实验 5 中 F-15A 的 Q_int = 128（110–155）在同一数量级，但不能把它当成通过门槛的结果。
