### 为什么固定孔径 `B-OSR` 制造了“完美吻合 VSP”的错觉？

1. **多次波低通旁瓣泄漏定理（已由实测单调下降直接证实）**：固定物理半孔径 $H$ 对慢度差 $\Delta p$ 的多次波/非一次波相干能量具有频率依赖响应 $|B(f \Delta p H)|^2$：在低频 `12–25 Hz` 尚未进入阻带而漏过，在高频 `30–55 Hz` 进入阻带被压制。这在 `12–30 Hz` 注入巨大伪正斜率并制造强正曲率 $c_2 > 0$。随着 $H$ 从 `100 -> 150 -> 200 m` 加宽，阻带截止频率下移，伪正斜率单调衰减：
   - Raw `a`：`FE` 从 **`+24.28 -> +16.87 -> +11.85`**，低频子带 `12–30 Hz` 从 **`+53.0 -> +40.6 -> +30.5`**，曲率 $c_2/\Delta\tau$ 从 **`+3.47e-3 -> +2.29e-3 -> +0.96e-3`**；
   - Raw `pz_up`：`FE` 从 **`+11.14 -> +9.78 -> +7.64`**，低频子带从 **`+45.0 -> +38.8 -> +32.1`**，曲率从 **`+2.66e-3 -> +1.82e-3 -> +1.29e-3`**。
   - **关键排除**：速度误差涂抹假象应随 $H^2$ 增大（`H200` 应为 `H100` 的 $4\times$）且 $c_2 < 0$；实测恰恰相反（`H100 > H200` 且 $c_2 > 0$，且 `AutoBlock` 与 `Fixed1D` 几乎重合），精准指向**多次波旁瓣低通泄漏**而非速度涂抹！
2. **误差相消的惊险陷阱**：当采用等波数波束 `CW-BOSR` ($f \cdot H(f) \equiv C_0$) 彻底消除波束响应的频率依赖后，两档尺度 `CW3600` 与 `CW4800` 几乎完全重合（Raw `a` 差 `0.47`、Raw `pz_up` 差 `1.07`、Raw `b` 差 `1.18`），而全频带 `12–60 Hz` 全部跌回负/近零。这证明 T1.0 中固定孔径 `B-OSR` 落入 VSP 区间 `[5.6, 17.4]` 属于**固定孔径低通伪正斜率与 `30–55 Hz` 真实负斜率相互抵消**的巧合。
3. **Volve 叠前负 $Q$ 的最终归因与可用频带边界**：
   - 无论原始未处理道集（`a / b / pz_up`）还是处理后 `seq079_dline5081` PreMig 道集，也无论非相干还是等波数相干波束，**`30–55 Hz` 高频段一致呈现 `-14 ~ -19` 的强负表观 $1000/Q$**（与 T1.0 D4 实测井 F-12 / F-14 1D 叠前薄互层/层间多次波正演给出的 `-8.0 ~ -18.6`，叠加高频远偏散射/环境噪底完全吻合；此外 `CW-BOSR` 在高频收缩孔径使非相干噪声按 $f^{+1}$ 略增，亦进一步压低高频斜率）。
   - 相反，在主波信噪比最高、尚未触及薄层调谐/高频噪底的 **`12–30 Hz` 低中频段**，`CW-BOSR` 在 `pz_up`（`+13.2 / +11.9`）、`b`（`+20.2 / +22.4`）与 `Proc seq079`（`+22.4 / +24.2`）上均给出**尺度不变的稳定正衰减**（其中 `pz_up` `+11.9 ~ +13.2` 直接命中 VSP 区间 `[5.6, 17.4]`）。
   - **方法学与工程启示**：① 任何采用固定空间孔径的局部斜率叠加/波束形成用于叠前谱比 $Q$ 估计时，**必须做等波数 $f\cdot H(f)=\text{const}$ 核查与子带分裂检验**，否则极易把多次波低通旁瓣泄漏误当成真实物理 $Q$ 恢复；② Volve 叠前 OSR 的物理可信窗口存在明确高频截止（$\lesssim 30\text{ Hz}$），强行全带拟合至 `60 Hz` 不可恢复可靠常 $Q$。
