## 1. D1：TRID 11 vs TRID 12 分量识别与 P-Z 耦合诊断

- **海底鬼波梳状周期**：$\tau_0 = 2 z_w / v_w = 0.1213\text{ s}$（陷波间隔 $1/\tau_0 = 8.24\text{ Hz}$）。
- **分量身份确证**：
  - `TRID 11 (A)` 在整数倍 $k/\tau_0$ 呈显著陷波（`at_int_k = -0.428` vs `at_half_k = +0.344`，`diff = -0.772`）$\implies$ **确认为水听器压力分量 $P$**；
  - `TRID 12 (B)` 呈轻微相反极性（`diff = +0.035`）$\implies$ **确认为检波器垂直速度分量 $Z$**。
- **P-Z 耦合失配发现**：在近偏移距（$|x| \le 350\text{ m}$），TRID 11 与 TRID 12 间 12–50 Hz 相干度中位数仅 **`0.071`**，互相关峰值位于 **`+3` 样点（`+12 ms`）**（`r = -0.194`），中位相位差 `-39.8°`，振幅域合成最优符号为 `pz_sign = -1`（将近偏梳状指数从 `0.162` 降至 `0.132`）。这解释了为何未经波束聚焦前的简单零时移振幅叠加 `incoh pz_up` 反而因耦合噪声和时移差略劣于单水听器 `incoh a`。

### 关键诊断证据

1. **`M0_repro` 说明（程序判定 `false` 的唯一原因）**：`incoh a = -1.94` 与 `incoh b = -16.70` 与历史 `field79raw`（`-1.94`, `-16.70`）精确一致至 `0.00`；`incoh pz_pow = -8.42` 相对 `-7.80` 偏差 `0.62`，仅因 `D1` 计算 `c0sq = 1.712` 时限定了 `1.0–2.0 s`，而 `field79raw` 在全窗 `0.6–2.2 s` 上计算 `c0sq = 2.114`（已在 T1.1 Part A 中按全窗口径修正复核）。
2. **`M_Near` (PASS)**：释放近偏移距自由截距（`FE-OSR`）立刻将 1.2–1.6 s 中深窗 `pz_pow` 从 `-6.03` 拉回 **`+9.50`**（`TRID 11` 达 `+15.64`），证实浅/中深窗（尤其 Z 分量与 PZ 功率和）的负截距主要源于近偏低频干扰。
3. **`M_Mult` (PASS)**：在 2.0–2.2 s 深窗，慢度扫描直接测得水层/浅层多次波导向束（$v=1600\text{ m/s}$）显著**蓝于**一次波束：
   - `TRID 11 (a)`: `sl_mult - sl_prim = -0.0090 /Hz`（45 Hz 多次波/一次波功率比从 1.4 s 的 `0.17` 飙升至 2.0–2.2 s 的 **`0.63`**），`B-OSR` 使 2.0–2.2 s 的 $1000/Q_{\text{eff}}$ 抬升 **`+24.6`** 单位（`-7.09 -> +17.50`）；
   - `pz_up`: `sl_mult - sl_prim = -0.0050 /Hz`（45 Hz 功率比 `0.12 -> 0.37`），抬升 **`+22.9`** 单位（`-11.68 -> +11.25`）。
4. **`M_Recover` (PASS)**：`B-OSR` 将全部三分量（`a`, `b`, `pz_up`）完整翻正并落入 VSP 区间 `[5.6, 17.4]`（`b` FE 90% CI `[6.8, 12.6]` 宽度仅 `5.8`，`pz_up` FE `[4.1, 11.4]` 宽度 `7.3`）。**但须注意**：T1.0 采用固定 1D 速度模型与单一孔径 $L=400\text{ m}$，必须经 T1.1 的孔径缩放与主波走廊自聚焦排他检验，才能排除速度失配波束涂抹贡献。

## 3. D4：F-12 / F-14 实测测井 1D 叠前正演

基于 F-12 / F-14 实测反射系数执行 1D Kennett 层递推（含全部层间多次波 + 角度调谐 + 动校压缩）：
- **F-12**：$Q=\infty$ 给出 `-8.04`（2.0–2.2 s `-5.10`），叠加 $Q_{\text{VSP}}=(60,90,100)$ 给出 `+9.05`（2.0–2.2 s `+17.36`）；
- **F-14**：$Q=\infty$ 给出 `-18.61`（2.0–2.2 s `-29.97`），叠加 $Q_{\text{VSP}}$ 给出 `-8.04`。
这表明**储层薄互层/层间多次波在单井 1D 层面确有蓝移负偏潜力**，但在 Volve 真实 2D 地震面上（经 2 km 测线横向平均），`B-OSR` 2.0–2.2 s 为强正值（`+11.2 ~ +17.5`），故 `M_Tune = false`（并非主要拦路虎）。

## 4. D5（路线 3A 结案）：原始 vs 处理后近偏曲率 $c_2$ 对比（`Curv_Proc = PASS`）

在 `10–55 Hz` 频带（深窗 2.3–2.8 s 对浅窗 1.2–1.6 s）测量对数谱比二次曲率 $c_2$：

| 数据源与分量 | 二次曲率 $c_2$ ($\times 10^{-3}\text{ /Hz}^2$) | 相对叠后存档 `+1.322e-3` 比例 |
| :--- | :---: | :---: |
| **Volve 叠后存档参考**（`sid_uq`） | **`+1.322`** | `1.00x` |
| **原始未处理近偏 `TRID 11 (A)`** | `+0.345` | `0.26x` |
| **原始未处理近偏 `TRID 12 (B)`** | `+0.174` | `0.13x` |
| **原始未处理近偏 `PZ_pow`** | `+0.309` | `0.23x` |
| **原始未处理近偏 `PZ_up`** | `+0.388` | `0.29x` |
| **处理后 `seq079` 叠前近偏** | `+0.190` | `0.14x` |

**结论**：原始未处理近偏道与处理后 `seq079` 叠前近偏道的 $c_2$ 均仅为 `+0.17 ~ +0.39 × 10^{-3} /Hz²`，**比叠后体小 3.4–7.6 倍**。路线 3A 明确结案：Volve 叠后剖面的强正曲率（$c_2 = +1.322 \times 10^{-3}$）**不是**原生地震衰减非常 $Q$ 物理，也不是 PZ 叠加/早期去噪产物，而是产生于 **PreMig 道集之后的三维偏移、动校叠加或叠后谱均衡流程**。
