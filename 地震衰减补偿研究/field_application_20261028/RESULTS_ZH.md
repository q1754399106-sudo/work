## 结论

> **按登记门槛，“在本工区可用于实际资料”没有成立**：两口井上，SC-a 和 QScan＋SC-a 都通过了 A2（井震标定没有变差到分辨力以外）和 A3（频带变宽），但都没有通过 A1（60–100 Hz 能量比 ≤ 10）。
>
> **A1 本身设计错了**（运行后发现，不改判定）：在 Q≈100、2.5 s 处，70 Hz 的振幅衰减到约 1/80。正确的补偿本来就会把这一频段的能量放大上千倍，所以“能量比 ≤ 10”区分不了补偿和噪声放大。事后改用“每个频带的相干信噪比是否下降”来检查（只作描述）：SC 类方法补偿后各频带的信噪比与输入持平，相干标准版则把信噪比降低到 1/2–1/6。
>
> **实际效果**：在 inline 10141 和两条沿井剖面上，补偿后 5%–95% 能量频带从约 5–29 Hz 拓宽到约 10–62 Hz，同相轴明显变细，薄层更容易分开（`figures/IL10141_sections.png`）。与井的相关仍然分不出方法优劣：所有方法相对输入的 90% 区间几乎都跨 0。

### 3. 适配到底改变了什么

- **子波与频带**：两口井和测线的目标窗口（2–3 s）里，相邻道相干信噪比 ≥ 1 一直延续到 75–82 Hz，与处理中 82 Hz 的高切一致。所以按信噪比限带后，输出频带只比原始 Ricker 字典窄一点点。
  - 原始 SC 在 85 Hz 以上留有 0.1%（F-11）和 0.006%（F-15A）的能量，这一段数据里不可能有信号；SC-a 为 0。
  - 在 70–90 Hz，SC-a 的放大倍数是原始 SC 的 1/3.5（F-11）和 1/4.3（F-15A）。
  - 其余指标与原始 SC 几乎相同（T1：0.304 对 0.298，0.155 对 0.165）。在这个工区，适配是“去掉多余的那一点”，不是大的改变。
- **一个设计缺陷**：浅层窗口在沿井幕帘上的信噪比一直到 118–125 Hz 都 ≥ 1。原因是幕帘道由相邻面元双线性插值得到，噪声在相邻道间相关，相干信噪比被高估。目标窗口和 inline（用原始面元道）不受影响；由于输出频带取浅层与目标两者的较小值，实际起作用的是目标窗口的 75–82 Hz。
- **QScan**：两口井和测线上分别选 0.77、0.675、0.77，都没有落在网格边界，并且一致要求比 VSP 估计更强的补偿。实验 5、6 中也是同一方向。

### 4. 事后：放大的是信号还是噪声（只作描述）

2.0–3.0 s 内各频带的相邻道相干信噪比：

| | 30–50 Hz | 50–70 Hz | 70–90 Hz |
|---|---|---|---|
| 输入（F-11 / F-15A / 测线） | 8.4 / 13.1 / 7.3 | 3.4 / 4.7 / 3.1 | 2.6 / 2.9 / 1.9 |
| 相干标准版（F-11 / F-15A） | **2.4 / 5.7** | **0.9 / 1.7** | **0.4 / 0.9** |
| SC-a（F-11 / F-15A / 测线） | 8.6 / 12.5 / 7.9 | 3.3 / 5.6 / 4.2 | 2.3 / 3.5 / 3.5 |
| QScan＋SC-a | 8.9 / 12.7 / 8.5 | 3.5 / 6.3 / 3.8 | 2.6 / 3.6 / 2.8 |

- SC 类方法对相干部分和不相干部分的放大倍数接近，所以各频带的信噪比保持在输入水平。
- 相干标准版对不相干部分的放大是相干部分的 3–6 倍，信噪比下降。这是实测上 SC 类优于相干标准版的一个旁证，与合成数据上的结论（`sc_neutral`）方向一致。
- 注意：SC 含横向结构正则项，它本身会提高输出的相干性，所以这个比较不能完全证明放大的是反射信号。

## 给实际应用的建议

1. **在这类数据上可以用 QScan＋SC-a 做补偿**，它在本实验的所有检查中都没有出现失真：频带拓宽到约 60 Hz，各频带信噪比不下降，井震标定在分辨力内不变。不建议用相干标准版，它在实测上会降低信噪比。
2. **最高补偿频率要由数据决定**（本工区为 75–82 Hz），并用原始面元道估计，不要用插值道。
3. **噪声检查要看各频带的信噪比，不要看能量比**。
4. **“比不补偿更准”目前在实测上证明不了**：与井的相关的自助区间宽 0.2–0.45。要证明需要分辨力更高的参照（见实验 6 结果）。
