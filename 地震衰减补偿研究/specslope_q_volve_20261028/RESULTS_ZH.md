# 实验 10 结果：用频谱衰减估计 Q 系数（SR）

完成于 2026-10-28。方案见 `PLAN_ZH.md`（冻结于 d7989e2）。冻结后代码没有任何改动；作图时只调整了一处文字标注的位置。数字来自 `analysis/summary.json`、`results/synth/*.json` 和 `results/real/*.json`。

## 一句话结论

**SR 能估出 Q 系数，QScan 不能。** 在新构造、新噪声、新 c 的检验数据上：
- SR 有 92% 的估计误差在 ±25% 以内，平均 |log 误差| 为 0.09；QScan 为 0.24。
- 用 SR 的 Q 做补偿，零时移相关比用 QScan 的 Q 高 0.06。
- 在 Volve 实测上，SR 给出 **c ≈ 1.0**（25 条测线中位数 1.05），说明 F-11 VSP 的 Q 基本正确，**QScan 选的 0.77 补偿过头了**。

## 判定（检验集 H：构造取自 inline 10301，噪声取自 10011、10031、10051，c = 0.55、0.7、0.9、1.2、1.4，4 个新种子）

| 判定 | 结果 | 数值 |
|---|---|---|
| E1 准确 | **成立** | 60 个估计中 91.7% 在 ±25% 以内（门槛 80%）；平均 log 偏差 −0.005，标准差 0.114 |
| E2 比 QScan 准 | **成立** | 配对差 \|log 误差\|(SR) − \|log 误差\|(QScan) = −0.15，90% 区间 [−0.23, −0.07]；平均 0.089 对 0.238 |
| E3 区间可信 | **成立（勉强）** | 90% 区间覆盖率 76.7%（门槛 75%），区间中位宽度为 ±18%（log 0.36） |
| E4 补偿更好 | **SR 更好** | 30 dB 反 Q 的零时移 M1：SR − QScan = +0.058，90% 区间 [+0.001, +0.115] |

各个 c 上，SR 落在 ±25% 以内的比例：0.55 为 100%，0.7 为 100%，0.9 为 100%，1.2 为 83%，1.4 为 75%。真 Q 越高（衰减越弱），频谱衰减越小，估计越难。

QScan 在 c = 0.55、0.7、0.9 时选的值都在 0.77–1.0 之间，在 c = 1.2、1.4 时选 0.88–1.30。它的选择与真 c 有关联，但被强烈拉向 0.8–1.0，与实验 8 的结论一致。

## 颜色压力组 W（描述）

W 组的反射系数用 11 口 Volve 井的整段测井随机拼接，保留了真实的井间和深度间颜色差别。15 个估计**全部**在 ±25% 以内，平均 log 偏差 +0.044，区间全部覆盖真值。真实井段的颜色差别没有让 SR 变差。

## 补偿效果（20 个重数据集，描述部分）

| M1 均值 | 零时移 | 允许 ±20 ms 整体时移 |
|---|---|---|
| 输入 | −0.12 | 0.35 |
| 30 dB 反 Q，模型 Q（c = 1） | 0.50 | **0.69** |
| 30 dB 反 Q，QScan | 0.53 | 0.65 |
| 30 dB 反 Q，**SR** | 0.59 | 0.60 |
| 30 dB 反 Q，真 Q | **0.61** | 0.61 |
| SC-a，SR | **0.63** | 0.66 |

- **零时移**：SR 比模型 Q 高 0.085（区间 [0.03, 0.14]），只比真 Q 低 0.025。正确的 Q 主要改善的是**时间位置**（频散校正），这与实验 8 一致。
- **允许整体时移**时排序反过来：模型 Q 最高，SR 比 QScan 低 0.056，真 Q 也只有 0.61。原因是 30 dB 反 Q 在 Q 偏高（补偿偏弱）时放大的噪声更少，而整体时移又抵消了频散造成的时间误差。所以，**Q 准确的价值在于时间和相位对得上**；如果只看波形形状，补偿保守一点反而更稳。
- SC-a（SR）与 30 dB 反 Q（SR）大体持平（零时移 +0.04，区间跨 0）。

## Volve 实测（描述）

在整个数据体上每隔 16 条取一条 inline（共 25 条），加上应用测线 10141：

- **c 的中位数为 1.05**（四分位 0.95–1.10，范围 0.85–1.37）。每条线的 90% 区间大多跨过 1.0。
- 有一个空间趋势：inline 10241 以前多为 1.0–1.17，10257 以后多为 0.85–0.95。
- **inline 10141：c = 1.015，90% 区间 0.82–1.25。** QScan 在同一条线上选 0.77，落在 SR 区间之外。对应的有效 Q 约为 80（上部两层）和 137（下部两层），与 F-11 VSP 的事后 Q（78.5 / 135.2）几乎相同。
- 与实验 8 真实性检查的"c ≈ 0.8"不一致。那个数是用单一反射系数实现的半合成数据当标尺得到的，而本实验已说明单一实现的颜色会带来 ±0.1–0.15 的偏差，所以以 SR 为准。

补偿 inline 10141 后，2.0–3.0 s 的相干信噪比 ≥ 1 的频带上限：输入约 74 Hz；30 dB 反 Q 用 SR 的 c 约 80–90 Hz；用 QScan 的 c，以及 SC-a 用 SR 的 c，约 100 Hz。注意：75 Hz 以上信噪比的上升可能部分来自时变算子把浅层的高频能量带进窗口，或来自算子自身，不能直接当作恢复了信号。

剖面上，SR（c ≈ 1.0）和 QScan（0.77）的 30 dB 反 Q 差别不大；后者补偿更强，高频噪声略多。

## 含义

1. **QScan 应换成 SR。** SR 在检验集上准确，计算量小得多（只做谱分析，不需要像 QScan 那样在 15 个 Q 上各解一次稀疏反演），还带有可信的区间。
2. **Volve 上 VSP 的 Q 基本正确**（c ≈ 1.0 ± 0.2）。实验 7 的 QScan 系数 0.77 偏强。在实测应用中，可以直接用 F-11 VSP Q，或用 SR 逐线估计。
3. 正确的 Q 主要改善同相轴的时间和相位（零时移相关），对波形形状的帮助有限。在噪声较大的数据上，30 dB 反 Q 稍微保守一点更稳。
4. 对实验 9（多井标定）：现在有了独立的 Q，可以比较"模型 Q / SR Q"和"QScan Q"在多口井上的井震时间与相位误差，而不只是比较相关系数。

## 局限

- 半合成数据的 Q 形状是模型的整体缩放。实测中 Q 随深度的变化可能与模型不同，那时一个 c 只代表 1.2–3.0 s 的平均。
- 衰减越弱，估计越难：c = 1.4 时有 25% 超出 ±25%。区间覆盖率 77%，低于名义上的 90%。
- 实测的空间趋势（东侧 c 偏低）可能是真实的 Q 变化，也可能是构造或数据处理的差别，本实验无法区分。
- 实测没有真值，结论只作描述。
