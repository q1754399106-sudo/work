## E4-1：VSP 估 Q

- **时窗**：直达波取初至前 10 ms 到初至后 90 ms，两端各加 10 ms 余弦渐变；噪声取初至前 210 ms 到前 110 ms。
- **频谱**：补零到 1024 点做 FFT，振幅谱 5 点滑动平均。
- **频带**：10–120 Hz 内，所有道的信号振幅都不低于噪声 3 倍的频点。频带宽度不足 20 Hz 则判定失败。
- **谱比法（SR）**：以最浅的 87 mbsf 为参考道，对每一道拟合 ln(A_k/A_ref) = c_k − πfΔt*_k，得到 Δt*_k 和拟合优度 R²_k。再对 Δt*_k 与单程时差 Δτ_k 做带截距的最小二乘，Q_SR = 1/斜率。
- **不确定性**：按道重采样 2000 次，取 Q 的 5%–95% 区间。
- **中心频率偏移法（CFS，Quan & Harris 1997）**：Q_CFS = π·σ²_ref / (f_c,ref − f_c,k 对 Δτ 的回归斜率)。
- **G1 可识别门槛（三条全部满足）**：
  1. 各道 R² 的中位数 ≥ 0.5；
  2. 斜率的 90% 区间 > 0；
  3. Q_CFS/Q_SR 在 [0.5, 2] 之间。

  G1 不通过时，下游比较仍用 Q_SR 运行，但只作描述性报告，不作方法结论。

## 测线准备（数据驱动，所有方法共用）

- **时窗**：1.900–3.700 s，451 个样点，4 ms 采样。
- **海底时间**：99 道海底反射包络峰值时间的中位数，记为 T_sf。
- **子波**：把各道海底反射对齐后取平均（±48 ms）。在 5–100 Hz 内用 Ricker 振幅谱拟合主频 f_p；再在 1° 网格上搜索常相位旋转 φ，使其与零相位 Ricker 的相关最大。所有道统一旋转 φ 后，才交给各方法。
- **速度模型（四层，偏移距 0）**：
  - 第 1 层为水，速度 1500 m/s，厚度 h₁ = 1500·T_sf/2，Q = 1e6；
  - 第 2 层（0–150 mbsf）和第 3 层（150–300 mbsf）的速度取自 VSP 初至的区间速度；
  - 第 4 层速度取第 3 层的 1.1 倍，为假设值；
  - 第 2–4 层的 Q 都取 Q_SR。300 mbsf 以下的 Q 为外推值。
- **噪声 σ**：水柱已被切除，因此每道用盲 Haar MAD（`estimate_trace_snr` 的 `haar` 方法）在时窗内估计。

## 方法

| 方法 | 说明 |
|---|---|
| Input | 只做相位旋转，不补偿 |
| FullCalRefit | 主版本 |
| SoftGroupRefit | 组软收缩 |
| QScanRefit | 数据选 Q 校正因子 |
| QEnsembleMean | s = 0.10 |

全部方法在沉积层 Q 误差 e ∈ {−50, −30, 0, +30, +50}% 下各运行一次；水层的 Q 不变。

- **G2**：5 个起始值中至少 4 个的隐含 Q 落在 VSP 的 90% 区间内。

## E4-3：井震标定

- **合成记录**：测井按 0.1524 m 统一采样，7 点中值去尖峰，缺口线性插值。阻抗为 VCO × RHOM。
- **时深关系**：用 VSP 初至的单程时间插值；87 mbsf 以上用测井速度积分（0–62 mbsf 假设为 1.55 km/s），得到海底处的单程时 τ_sf。双程时 TWT(z) = T_sf + 2(τ(z) − τ_sf)。
- 阻抗在 0.5 ms 上算反射系数，与零相位 Ricker(f_p) 褶积后降采样到 4 ms。
- **对比道**：每个方法取井旁道 ±2 共 5 道的平均。在测井覆盖的时窗内，允许 ±20 ms 整体时移（1 ms 步长，每个方法同样处理），取最大 Pearson 相关。
- **G3**：Q 误差为 0 时，FullCalRefit 和 QScanRefit 的标定相关都比 Input 高至少 0.02。
- **G4（稳健性）**：5 档 Q 误差中最差的标定相关，QScanRefit ≥ FullCalRefit。

## 描述性指标

- 各方法输出与输入在 2.6–3.6 s 内的 60–100 Hz 能量比，作为高频或噪声放大的参考；
- 输出的 5%–95% 能量频带；
- 交叉测线 3677-32 上 QScan 选出的因子。
