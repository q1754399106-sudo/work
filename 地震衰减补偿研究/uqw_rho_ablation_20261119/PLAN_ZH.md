# UQ-W 先验与噪声项消融：方案（2026-11-19，开跑前提交）

性质：**机制诊断**。只用已用过的开发数据，结果不能称为确认，也不改变任何方法的标签。

## 0. 起因

外部审核提出：UQ-W 的稳健性可能主要来自对数正态先验在 u → 0（极弱衰减）一侧的左尾，而不是来自“Q 只知道在 ×2 以内”。依据是 `qunknown_comp_20261109/RESULTS_CB_ZH.md`：先验截断到 [0.5, 2] 后 FD 14 dB 得分下降 0.067（0/6），`RESULTS_CBL_ZH.md` 保留 [0.1, 0.5] 后恢复。另外，ρ = s + E|G|²/snr 让噪声项也随先验缩放，可能和“先验期望”的作用混在一起。

这一说法没有核实过。CB/CBL 的截断先验用的是 17 点或 36 点网格，与 UQ-W 的 41 点 Gauss–Hermite 求积不同，而且都和后悔上限一起出现。所以那两次的归因同时改了不止一件事。本方案把这几件事拆开，每个变体只改一件。

## 1. 要回答的问题

UQ-W 相对 VDB、IQ70 的优势，各有多少来自：

- (a) 先验期望本身，即对 u 在 ×2 范围内取平均；
- (b) u < 0.5 的左尾；
- (c) ρ 中噪声项随先验缩放，即用 E|G|² 而不是固定的 |G(û)|²。

## 2. 现行 UQ-W 的定义（V0，不改）

`qunknown_comp_20261109/scripts/uqw.py` 的 `uqw(..., gamma=0)`，σ = 0.447，对数正态，70 dB 下限 s，即 `RESULTS_CONFIRM_W_ZH.md` 确认的版本：

- u/û = exp(σe)，e ~ N(0, 1)，41 点 Gauss–Hermite 求积。节点上 u/û 从 0.0056 到 180。
- 每行的衰减 x = x̂ + Δx̂·(u/û − 1)，Δx̂ = x̂(t) − x̂(锚点)。锚点：半合成 1.4 s，FD 0 s。
- H = E[G*] / (E|G|² + ρ)，ρ = s + E|G|²/snr(t, f)。snr 用输入数据的相干信噪比估计，取 0.4 s 窗、0.1 s 步长。
- 对数域计算，逐行滤波，irfft 后作时变褶积。

## 3. 变体（每个只改一件事，其余与 V0 逐行相同）

| 名称 | 只改什么 | 实现 |
|---|---|---|
| **V0** | 不改（现行 UQ-W） | 直接调用 `uqw.uqw` |
| **V1** | ρ 的噪声项固定：ρ₀ = s + \|G(u=1)\|²/snr，\|G(u=1)\|² = exp(−2πf x̂) | 41 点 GH，与 V0 相同 |
| **V2** | 先验截断到 u/û ∈ [0.5, 2]，重新归一化；ρ 公式不变（期望改为截断先验下的期望） | 区间上 256 点 Gauss–Legendre，权重 = w_GL·φ(e)，归一化 |
| **V3** | 先验截断到 u/û ∈ [0.1, 2]（CBL 保留的范围） | 同 V2 |
| **V4** | σ = 0.25 时重复 V0、V1（记 V0s25、V1s25）；σ = 0.447 即 V0、V1 | 41 点 GH |
| 求积对照 V0d | 不截断，但用 V2/V3 的 Gauss–Legendre 求积（覆盖 GH 节点的整个跨度 \|e\| ≤ 11.6，1024 点） | 只用于第 6 节有效性条件 |
| 参照 W0 | σ = 0（没有先验展宽；此时 V0 = V1） | 描述用，不进判读 |
| 对照 VDB、IQ70 | 定义同阶段 0（半合成）与阶段 2b（FD） | |

说明：

- **截断为什么不用 GH 节点直接去掉区间外的点？** σ = 0.447 时，[0.5, 2] 内只有 7 个 GH 节点，实际边界是 0.519 和 1.926，保留的概率质量是 0.916，准确值应为 0.879。这样截断不准，所以 V2、V3 用区间上的 Gauss–Legendre 求积，边界准确。
- 这样 V2、V3 相对 V0 除了截断，还换了求积。所以另设 **V0d**：不截断、用同类求积。V0d − V0 量出求积本身的影响，见第 6 节。
- V1 中 \|G(u=1)\|² 是 u = û 处的传播功率。u = û 在 V0 的节点上，V0、V1 用的是同一组节点。

## 5. 指标与汇总

- **S**：沿用仓库定义。半合成用 `stage0.score`，即 ½(M1 + M1_lag)，对理想剖面。FD 用 `fdcheck.score_fd`，窗口 1.0–1.75 s。
- **T2**：只用于半合成，沿用 `uqw_improve_20261113/scripts/probe.py` 的 t2：输出道与“真反射系数 * Ricker(fpeak)”在 ±20 ms 内的最大相关，2.3–2.8 s，每 5 道取 1 道。**FD 不适用**：FD 真值只有目标剖面，没有单独的反射系数，仓库也从未在 FD 上定义过 T2。T2 只作描述，不进判读。
- **m** 取 0.5、0.7、1、1.4、2。声明的 Q 乘子：半合成 c = m·c_eff_cum，FD c = m，与以前各阶段相同。
- **独立模型分层**：
  - 半合成按构造 A–F 分成 6 个模型，每个模型含 4 套数据（c₀ × r）。
  - FD 每个噪声档按 H1–H6 分成 6 个模型，每个模型含 3 个噪声实现。
  - 每个模型先对它的数据集（或实现）和 5 个 m 取平均，得到一个数。
  - 报告这 6 个数的均值、中位数、最差值（最小值），以及为正的模型数。
  - 同一模型的多个 m、多个实现不当作独立样本。
- 另给逐 m 的表：先在模型内平均，再对 6 个模型取平均，只作描述。
- **三类数据分开报告和判读**：半合成、FD 14 dB、FD 8 dB。CB 的结果显示这一效应依赖信噪比和锚点，所以不把三类合并。

## 6. 预先写定的判读规则

记某类数据上“6 个模型平均的差”为 Δ，例如 Δ(V1 − V0)。

**规则 N（噪声项缩放）**
- 若 |Δ(V1 − V0)| < 0.01：该类数据上，噪声项缩放不重要。
- 否则：无法判定。

**规则 L（左尾）**
- 若 Δ(V0 − V2) ≥ 0.03，且 |Δ(V3 − V0)| < 0.01：该类数据上，左尾是主因，“×2 以内”的说法需要改。
- 否则：无法判定。

**其余情形一律写“无法判定”，不做解释。**

**判读的汇总方式**
- 规则 N：三类数据都成立，才写“噪声项缩放不重要”。只在部分类别成立时，逐类写明成立与否，总判读为“无法判定（随数据类别而异）”。
- 规则 L：只要有一类数据成立，就要修改 `DESIGN_ZH.md` 及 UQ-W 相关说明中“Q 只知道在 ×2 以内”的表述，并写明是在哪类数据（信噪比、锚点）上成立。三类都不成立时，不改表述。
- **主判读用 σ = 0.447。**V4（σ = 0.25）按规则 N 同样判一次，只用来限定适用范围：
  - 若与 σ = 0.447 的判读不同，结论写成“只在 σ = 0.447 时成立”；
  - V4 不单独推翻主判读。

**门槛的依据（工程判断，不是统计检验，开跑后不改）**
- **0.01**：仓库里“不输”的容差一直取 0.01，例如阶段 W 的 S1、CB/CBL 的 T2、确认阶段的“不差 0.01 以上”。差值小于它，按以往口径就算持平。
- **0.03**：阶段 0 判“有没有空间”的门槛（DESIGN_ZH.md 第 3 节）。它与“SR 换成真值 Q 只多 0.015–0.031”同一量级，是本系列中“值得当成一个机制”的最小效应。CB 归因中截断造成的 FD 损失（−0.067）远大于它，半合成整体（−0.008）远小于它。
- 只用模型平均判，不用最差值判。6 个模型太少，最差值波动大，只作报告。

**有效性条件（预先写定；不满足时按下面处理，不改规则）**
1. **重算一致**：本次重算的 V0、W0、IQ70、VDB 与存档结果在同一数据、同一 m 上逐条比较。存档为：阶段 W 的 UQW_g0（σ 0.447）和 W0；阶段 0 的半合成 IQ70、VDB；阶段 2b 的 FD IQ70、VDB。
   - S 的最大差 ≤ 1×10⁻⁶。
   - 若超出：不出任何判读，先报告环境差异。本次因原 Python 缺 scipy，在仓库忽略的 `.venv` 中补装了 scipy 1.16.3；numpy 仍是 2.3.5。
2. **求积对照**：若某类数据上 |Δ(V0d − V0)| ≥ 0.005，说明 V2/V3 与 V0 的差里混有求积差别。此时该类的规则 L 再以 V0d 为基准判一次，即用 V0d 替换 V0；两次判读不一致时，该类写“无法判定（求积敏感）”。
3. 任一输出含非有限值：该情景记为失败，报告数量，不剔除重算。

## 7. 描述性分解（回答 (a)–(c) 的量，不进判读）

每类数据给出以下各项的均值、中位数、最差值和为正的模型数：

- **总优势**：V0 − VDB，V0 − IQ70。
- **(a) 先验期望**：
  - V2 − W0：只有 ×2 范围内的平均，相对完全没有先验展宽；
  - V2 − VDB，V2 − IQ70。
- **(b) 尾部**：
  - V3 − V2：[0.1, 0.5] 的左尾；
  - V0 − V3：u/û < 0.1 与 u/û > 2 的其余尾部；
  - V0 − V2：全部尾部。
- **(c) 噪声项缩放**：V0 − V1；V1 − VDB，V1 − IQ70；σ = 0.25 时的 V0s25 − V1s25。
- **求积**：V0d − V0。

这些差不可加：先验与 ρ 有交互，各项相加不等于总优势，只逐项报告。

## 8. 求解侧不读真值

`scripts/ablate.py` 的 `compensate()` 只接收以下输入：
- 输入数据 D；
- 模型（含模型 Q 剖面）；
- 声明的 c；
- 时间轴与锚点；
- 由 D 估计的 1/snr；
- VDB 的输出子波：半合成取自 `sc11.prepare_sc(D)`，FD 取已知震源 Ricker，同阶段 2b。

理想剖面、反射系数、FD 目标剖面和数据集元数据只在打分一侧使用。

c = m·c_eff_cum 由外层形成。它是实验条件（声明的 Q 等于有效真值乘以 m），与以前各阶段相同，不是求解器从真值中读出来的。

## 9. 开跑前的冒烟检查（不出分数）

`ablate.py smoke`，日志 `logs/smoke.log`：
- 用通用求积路径、GH 节点算的 V0 与 `uqw.uqw` 逐值一致（相对 ≤ 1×10⁻¹⁰），半合成与 FD 都查。
- 1/snr = 0 时 V1 = V0；σ = 0 时 V1 = V0（≤ 1×10⁻¹⁰）。
- V2、V3 的节点数加倍后输出相对变化 ≤ 1×10⁻⁶；V0d 同样检查。
- FD 上所有变体的输出都是有限值。

冒烟结果写在第 11 节，提交前填好。

## 10. 运行与产出

- 共 60 个任务：半合成 24 个 + FD 6 个模型 × 2 档 × 3 个实现 36 个。
- 每个任务算 5 个 m × 10 种输出。
- 多进程并行，每个进程单线程。任务是确定性的，进程数不影响结果。
- 原始结果：`results/raw/<任务>.json`。
- 逐情景 CSV：`analysis/per_scenario_<变体>.csv`，每个变体和对照一个文件。每行是一个数据集（或 FD 实现）× m，含 S、T2（FD 为空）、模型、c₀、r、噪声档。
- 汇总：`analysis/summary.json`，由 `scripts/analyze.py` 生成。
- 报告：`RESULTS_ZH.md`，写明本方案的 commit。
- 不修改 `qunknown_comp_20261109/` 下任何已有文件。不因结果改变变体定义、门槛或汇总方式。

## 11. 冒烟检查结果

运行于 2026-11-19，共 1341 秒，日志见 `logs/smoke.log`。只比较输出，不出分数。数据为半合成 ZA_c0.75_r0（m = 0.5、2）和 FD H1（冒烟专用噪声种子 1，与正式种子不同）。

- 通用求积路径用 GH 节点算的结果与 `uqw.uqw` 完全一致：半合成和 FD 的相对差都是 0。
- 1/snr = 0 时 V1 与 V0 相对差 0；σ = 0 时 ≤ 1.3×10⁻¹⁵。
- 节点数加倍后输出的相对变化：V2 ≤ 4.9×10⁻¹⁵，V3 ≤ 4.1×10⁻¹⁵，V0d ≤ 2.9×10⁻¹²。三者都已收敛。
- 截断边界准确：V2 节点 u/û 为 0.500–2.000，V3 为 0.100–2.000，权重和为 1。
- FD 上所有变体的输出都是有限值。单个 c 约 160 秒（4 线程）。
- **V0d 与 V0 的输出差很大**：最大相对差在 m = 0.5 时为 0.26，m = 2 时为 0.098。
  - 也就是说，现行 UQ-W 的 41 点 GH 求积本身没有收敛，而密集求积已经收敛。
  - 这是开跑前就知道的事实。它不改变规则，只说明第 6 节的有效性条件 2 很可能被触发。
  - 输出的最大差可能落在评分窗以外（例如半合成锚点以上的浅层行），对 S 的影响要看正式结果。
  - 无论结果如何，都在 RESULTS 中单独报告 V0d − V0。
