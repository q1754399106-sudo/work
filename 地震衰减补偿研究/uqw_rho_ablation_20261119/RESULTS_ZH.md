# UQ-W 先验左尾与噪声项缩放消融：结果（机制诊断）

- **方案**：`PLAN_ZH.md`，运行前提交 **d956aa9**（d956aa9b76d38160b4535df2485ca3fb6694230f）；运行前哈希 `PRE_RUN_HASHES.txt` 提交于 **ca709c0**。运行开始后没有改变方案、变体定义、阈值和分析代码。
- **性质**：只用过的开发数据（半合成 DEV 至少第 11 次，FD 14 dB 至少第 7 次，FD 8 dB 至少第 3 次）。问题本身来自这批数据上的 CB、CBL 结果，因此**只能叫机制诊断，不是确认**。
- **运行**：`scripts/ablate.py run k 6`（k = 0–5，6 个进程，每进程 2 线程），60 个作业（半合成 24 套，FD 6 模型 × 2 档 × 3 实现），共 3000 条记录；作业累计 18.8 h，墙钟约 4 h。`scripts/analyze.py` 产出 `analysis/per_scenario_<变体>.csv`（10 个）和 `analysis/summary.json`。求解侧（`ablate.py` 中的 `compensate`、`uqw_var`）只用数据、声明的 Q 和噪声估计，不读真值；真值只在打分时读入。

关于 (2) 的补充（事后检查，不在方案内，`scripts/post_quaddiag.py`、`logs/post_quaddiag.log`）：冒烟测试中 V0d 与 V0 的输出最大相对差为 0.26（m = 0.5）和 0.098（m = 2）。这些差异只出现在半合成锚点 1.4 s 以上，即 t = 1.20–1.38 s；t ≥ 1.4 s 时只有 10⁻¹³ 量级。原因是锚点以上 Δx̂ < 0，u 大的节点给出负衰减（增益），41 点 Gauss–Hermite 在这一段没有收敛。S 和 T2 都在 2.30–2.80 s 上计算，所以不受影响。FD 的锚点为 0，没有这一段。**结论：41 点求积不收敛只影响锚点以上，不影响本文任何判读。**

## 2. 预先写定规则的判读

规则 N 和规则 L 都对每类数据的 6 个模型均值进行判断。括号中依次给出为正的模型数和最差模型值。

| 数据类别 | 规则 N：Δ(V1 − V0) | σ = 0.25 时 Δ(V1s25 − V0s25) | 规则 L：Δ(V0 − V2) | 规则 L：Δ(V3 − V0) | 规则 N 判读 | 规则 L 判读 |
|---|---|---|---|---|---|---|
| 半合成 | **+0.0060**（6/6，最小 +0.0034） | +0.0021 | +0.0112（6/6，最小 +0.0097） | −0.0010 | **噪声项缩放不重要** | **无法判定**（下降 < 0.03） |
| FD 14 dB | **−0.1767**（0/6，最差 −0.2318） | −0.1911 | **+0.0811**（6/6，最小 +0.0315） | −0.0013 | **无法判定** | **左尾是主因** |
| FD 8 dB | **−0.1613**（0/6，最差 −0.2169） | −0.1399 | **+0.0786**（6/6，最小 +0.0255） | −0.0010 | **无法判定** | **左尾是主因** |

**总判读：**
- **规则 N：无法判定（随数据类别而异）。** 只有半合成成立。σ = 0.25 时三类数据的成立与否与 σ = 0.447 相同，所以不需要加“只在 σ = 0.447 时成立”的限定。
- **规则 L：在 FD 14 dB 和 FD 8 dB（噪声主导，锚点 0）上成立；在半合成（信噪比合适，锚点 1.4 s）上无法判定。** 按方案，“Q 只知道在 ×2 以内”的表述需要修改，并写明成立的数据类别（见第 5 节）。

关于规则 N 的写法：任务原文写的是“V1 − V0 < 0.01”。方案在运行前把它写定为 |Δ| < 0.01，因为如果按有符号的比较，FD 上 V1 比 V0 低 0.16–0.18 也会被判成“不重要”。规则只预设了“不重要”这一种结论，所以 FD 上只能写“无法判定”，数字见下文。

## 4. 描述性分解（不进判读）

UQ-W 相对 VDB 的优势可以拆成两项：V0 − VDB = (V2 − VDB)（截断先验本身）+ (V0 − V2)（左尾）。

| 类别 | V0 − VDB | = V2 − VDB（截断先验） | + V0 − V2（左尾） | V0 − IQ70 | 其中 V2 − IQ70 | V2 − W0（截断先验相对直接代入） | V0 − V1（噪声项缩放） |
|---|---|---|---|---|---|---|---|
| 半合成 | +0.0107（3/6） | −0.0004（3/6） | +0.0112 | +0.0409 | +0.0298 | +0.0298（6/6） | −0.0060（0/6） |
| FD 14 dB | +0.0925（5/6） | +0.0114（3/6） | +0.0811 | +0.4489 | +0.3678 | +0.1476（6/6） | +0.1767（6/6） |
| FD 8 dB | +0.0699（4/6） | −0.0086（2/6） | +0.0786 | +0.3361 | +0.2575 | +0.1153（6/6） | +0.1613（6/6） |

逐项回答方案第 1 节的三个问题（均为描述）：
- **(a) 先验期望本身（截断到 [0.5, 2]）**：相对 VDB 的贡献三类都接近 0（−0.009 到 +0.011，模型间正负各半）。相对 IQ70 和 W0，它贡献了大部分好处：半合成 +0.030；FD 两档 +0.12 到 +0.37。
- **(b) u < 0.5 的左尾**：几乎提供了 UQ-W 相对 VDB 的全部优势。三类数据上分别为 +0.011、+0.081、+0.079，6/6 个模型为正。半合成上只有 0.011，不到规则 L 的 0.03。
- **(c) ρ 中噪声项的缩放**：在半合成上不重要，固定 ρ0 反而高 0.006。在 FD 上去掉缩放损失 0.16 到 0.18（6/6），比截断左尾的损失还大，此时 V1 低于 VDB（0/6）。

T2（仅半合成，描述）：V1 − V0 = −0.0057，V0 − V2 = +0.0052，V3 − V0 = −0.0006，V0 − VDB = +0.0320（6/6）。规则相关的三个差值都在 0.01 以内。规则 N 的符号与 S 相反，但幅度都很小。

## 5. 对现有表述的影响

- 规则 L 在 FD 两档成立，因此按方案要改“Q 只知道在 ×2 以内”的说法。σ = 0.447 的对数正态先验约有 12% 的质量在 [0.5, 2] 之外，其中 u < 0.5 一侧约 6%。噪声主导时，UQ-W 的优势来自 u ∈ [0.1, 0.5] 这一段（比声明弱的衰减），而不是来自“×2 以内”的设定：严格截断到 ×2 后，相对 VDB 的优势基本消失（+0.011 和 −0.009）。
- `DESIGN_ZH.md` 中没有“×2 以内”的原文。相关位置是第 2.3 节表格中“只有区域经验值 | 模型 Q | 0.5 或更大 | 声明的先验范围”一行，以及第 2.2 节第 3 点“自动偏向弱补偿”。这句说法的原文出现在 `PLAN_STAGE1_ZH.md`、`PLAN_CONFIRM_W_ZH.md`、`RESULTS_CONFIRM_W_ZH.md` 第 69 行、`RESULTS_CONFIRM_CBL_ZH.md` 第 155 行和 README 第 222 行。`RESULTS_CONFIRM_W_ZH.md` 第 94 行已有一条“机制表述更正”，与本结果一致。
- 按任务要求，本次**没有修改任何已有 RESULTS 文件，也没有修改 DESIGN_ZH.md**。建议在 DESIGN 第 2.3 节加一条注，由用户决定是否写入：
  > σ = 0.447 对数正态不等于“Q 在 ×2 以内”：约 12% 的先验质量落在 [0.5, 2] 之外（u < 0.5 一侧约 6%）。噪声主导（FD 14、8 dB，锚点 0）时，UQ-W 相对 VDB 的优势几乎全部来自 u ∈ [0.1, 0.5] 的弱衰减一侧；截断到 [0.5, 2] 会损失 0.08（6/6）。噪声项 ρ 随 E|G|² 缩放在该类数据上同样必要（固定后损失 0.16–0.18）。信噪比合适时（半合成，锚点 1.4 s），两者都只有约 0.01 的作用。（`uqw_rho_ablation_20261119`，机制诊断）

## 6. 无法判定或未覆盖的部分

1. **FD 两档上的规则 N**：V1 比 V0 低 0.16–0.18（0/6），而规则只预设了“不重要”这一种结论，所以写“无法判定”。总判读为“无法判定（随数据类别而异）”。
2. **半合成上的规则 L**：左尾的作用为 +0.011（6/6 为正），但不到 0.03，写“无法判定”。
3. **左尾与噪声项缩放的交互**：本方案没有“截断先验 + 固定 ρ0”的变体。截断改变了 E|G|²，因而也改变了噪声项，所以 (b) 和 (c) 不能相加，也分不清左尾的作用有多少是通过噪声项实现的。
4. 结论只限这批用过的开发数据，以及 σ = 0.447、0.25 两个取值；没有新数据确认，也没有实测数据。
