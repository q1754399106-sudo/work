# QScan 选择准则修正（预登记）

登记时间：2026-10-24，在任何候选准则运行之前。

**来由**：QScan 在独立正演数据（F1/F2）上系统性地选出比理想值高约 28% 的校正因子，偏向少补偿；在实测测线 4508-32 上则停在网格上限 2.2。假设：原准则 J = ½‖D−Bx‖² + λ‖x‖₁ 中的 ℓ1 项惩罚补偿后的振幅，因而在模型失配时偏向少补偿。

**与其他工作的关系**：同仓库的 `qscan_bias_variance_20261024`（另一会话，"不改算法"）在分解同一偏差的来源。本实验修改准则，只读引用它的结论，不改动它的目录。

## 候选准则（都对全部活道求和）

| 代号 | 准则 | 说明 |
|---|---|---|
| A0 | 原 lasso 目标值 | 对照组 |
| A1 | 只看 lasso 残差 ‖D−Bx‖²/σ² | 去掉振幅惩罚 |
| A2 | 去偏重拟合的 BIC：‖D − G·S‖²/σ² + k·ln n | k 为 FullCalRefit 的支撑原子数 |
| A3 | 去偏重拟合的 AIC：同上，复杂度项改为 2k | |

## 共用设置

- **网格**：c ∈ exp(linspace(ln 0.5, ln 2.5, 25)) ∪ {1}，相邻步长约 6.9%。A0 放在新网格上也作为对照，用来把"网格变宽变密"与"准则改变"两种效应分开。
- 每个 c 都运行一次完整的 FullCalRefit，并保存输出（`core/qscan_stats.m`）。
- **理想因子 c***：已知真值时，网格上使波形误差最小的 c。只用于评分。
- **复现检查**：A0 在原 13 点网格上，必须与已归档的 QScan 选择逐位一致（F1 Moderate，Q 误差 −50 / 0 / +50%）。

## 资料

- **开发集**（都已看过）：primary 和 complex（soft_refit 场景），F1 和 F2（实验 3 的独立正演）；两档噪声；Q 误差 {−50, −30, 0, +30, +50}%。
- **确认集**（新生成，开发阶段不看）：F3（低 Q 且随深度增大）、F4（Q 随深度减小、含碳酸盐层多次波）。正演与实验 3 相同，地质模型和种子全新（`make_confirm.m`）。
- **实测**（只作描述）：U1320A 附近的测线 4508-32 和 3677-32。起始 Q 为 Q_SR × {0.5, 0.7, 1.0, 1.4, 1.6}。

## 指标

- 因子误差：|ln(c_sel / c*)|；
- 相对理想：波形误差 ÷ 理想因子下的波形误差；
- 最坏情况比值：5 档 Q 误差中的最大波形误差，除以 c=1（即 FullCalRefit）的最大误差；
- Q0 比值：Q 误差为 0 时，波形误差除以 c=1 的误差；
- 选到网格边界的次数。

## 开发选择规则

可行条件：在 primary 和 complex 上，最坏情况比值均值 ≤ 0.95，且 Q0 比值均值 ≤ 1.02。在可行准则中，选全部开发案例上"相对理想"均值最小者。若选中的是 A0，就判定"没有找到改进"。

## 确认门槛（F3/F4，选定准则对比 A0；全部满足才算通过）

- H1：因子误差均值 ≤ A0 的 0.7 倍；
- H2："相对理想"均值不高于 A0；
- H3：最坏情况比值均值 ≤ 0.95；
- H4：Q0 比值均值 ≤ 1.02。

## 实测（描述性）

- 两条测线隐含的 Q 是否相差在 1.3 倍以内；
- 是否选到网格边界。

## 边界

- 理想因子只在合成数据上有定义；
- 确认集只有 2 个地质模型 × 2 档噪声，组合之间不独立；
- 不报告显著性检验；
- 不根据确认结果再调整准则。
