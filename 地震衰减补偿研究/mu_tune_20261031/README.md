# 实验 17：在开发数据上选 SC-a 的相干项权重，再在封存数据上确认

- 方案：[PLAN_ZH.md](PLAN_ZH.md)（选择规则与判定在运行前提交）
- 结果：[RESULTS_ZH.md](RESULTS_ZH.md)
- 开发数据：第一、二批断层＋复杂 Q 半合成数据，共 24 个（已用过）
- 检验数据：[第三批](../semisynth_fault_q3_20261031/DATA_ZH.md)，构造 G、H、I 共 12 个，封存

实验 16 事后发现 mu_relative = 1 比 0 和 10 都好。本实验在开发数据上按网格 {0, 0.25, 0.5, 1, 2, 4, 10} 分别为 SR 路线和用户的 QScan 路线选出 mu，冻结后在未见数据上确认，同时检验选好 mu 的 SC-a 能否胜过 70 dB 反 Q。

结果：
- 开发阶段两条路线都选 mu_relative = 0.25，各构造、批次、c₀ 单独选时也一致。
- 未见数据上，SR 路线比 mu 10 高 +0.096（12/12），QScan 路线高 +0.075（12/12），都支持。
- QScan＋调小 a＋mu 0.25 比用户原流程高 +0.212（12/12），支持。
- 与 70 dB 反 Q 比 +0.016，无法判定，构造 G 的气藏最强，反 Q 在那里更好。
- 改动默认值前，还需在实测测线上做井旁检查。
