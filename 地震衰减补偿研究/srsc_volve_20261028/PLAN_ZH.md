# 实验 11 方案：改进 QScan＋SC——用 SR 校正相位，振幅保守补偿

2026-10-28 写成。冻结前只用过实验 10 的检验集 H（已见，作为本实验的开发数据），**没有生成或看过本实验的检验数据**。

## 1. 背景与改进思路

- 实验 8：用真 Q 的 SC-a 最好；QScan＋SC-a（QSCa）输在 Q 估不准。
- 实验 10：SR 估 Q 比 QScan 准得多。
- 但实验 10 也发现，按零时移相关，准确的 Q 最好；允许整体时移后，补偿偏弱的反而更好，因为放大的噪声更少。

开发阶段（第 5 节）进一步发现：**Q 同时决定振幅补偿的强弱和频散（相位）校正，这两件事的最优值不同。**
- 相位要按准确的 Q 校正，否则同相轴的时间和波形都会偏。
- 振幅宁可保守一点，以少放大噪声。

所以改进后的流程是：
1. 用 SR（实验 10，冻结版）估 Q 系数 c_SR；
2. 用 SC-a 以 c_SR × 1.3 做补偿，即振幅偏保守；
3. 再做一个**只改相位**的时变算子，把频散校正从 c_SR × 1.3 改成 c_SR。这一步振幅不变，计算量很小。

记为 **SRSCa_1.3+ph**。

## 2. 检验数据（全新）

- **T 组（主）**：实验 8/10 的半合成方法（F-11 T2 测井反射系数块自助，沿真实构造铺开，真 Q = c × 模型 Q，真实噪声，信噪比按实测标定）。
  - 构造线换成 **inline 10263**，噪声线换成 **10095 / 10215 / 10335**，数据里只加 10095 的噪声。这些线在实验 7–10 中都没有用作构造或噪声，也不在实验 10 的 25 条 SR 实测线里。
  - 若某条线不完整，按 read_lines 的规则换成下一条奇数线，实际所用的线记在结果里。
  - c = 0.6、0.75、0.95、1.15、1.45，种子 9501–9504，共 20 个数据集。c 值与开发集（0.55–1.4）不同。
- **L 组（地层颜色压力）**：井道反射系数用 F-12、F-14 的长段 Gardner 反射系数（实验 9 的 synth.py，测井段以外是同一口井的块自助）。实验 9 的开发显示，这种颜色会让 SR 偏 15–44%。
  - c = 0.75、1.15，种子 9601–9602，2 口井，共 8 个数据集。

## 3. 方法（每个数据集）

| 名称 | 内容 | 角色 |
|---|---|---|
| QSCa | QScan 选 c，再做 SC-a | 现流程（对照） |
| **SRSCa_1.3+ph** | SC-a 用 c_SR×1.3，再相位校正到 c_SR | **改进方案（主）** |
| SRSCa | SC-a 用 c_SR | 描述 |
| QSCa+ph | QSCa 再相位校正到 c_SR | 描述 |
| IQ30_SR | 30 dB 常规反 Q，用 c_SR | 描述 |
| SCa_true | SC-a 用真 c | 参照（oracle） |
| Input | 不补偿 | 参照 |

- SR 按实验 10 冻结版运行（5 个窗，200 次自助）。QScan 和 SC-a 是实验 7 的程序（`lib.qscan`、`lib.solve`，参数 SEL_SC），不作改动。
- 相位校正 `sc11.phase_fix`：在每个输出时刻 t 构造 exp(−2i f Δt*(t) ln(f/100 Hz))，其中 Δt* = t*(Q·c_SR) − t*(Q·c_SR·1.3)。这与实验 8 `inverse_q` 的频散项相同，只是不含振幅项。

## 4. 指标与判定

指标与实验 8/10 相同（`run.m1`）：
- **M1**：2.30–2.80 s 内各道与理想目标（真实反射系数、真实子波，限在真实频带内）的零时移相关，取各道中位数。
- **M1_lag**：允许一个 ±20 ms 的整体时移后的 M1。

d = SRSCa_1.3+ph − QSCa，按数据集配对，用 90% t 区间。

| 判定 | 数据 | 成立条件 |
|---|---|---|
| **P1（主）**：零时移更好 | T 组 20 个 | d(M1) 平均 > 0，且区间下限 > 0 |
| **P2**：允许时移时不变差 | T 组 | d(M1_lag) 区间下限 > −0.02 |
| **P3**：颜色压力下不变差 | L 组 8 个 | d(M1) 和 d(M1_lag) 的区间下限都 > −0.05 |

三条都成立，才推荐用改进方案替代 QScan＋SC-a。P1 成立而 P2 或 P3 不成立时，结论写成"改进只在某些条件下成立"。

描述性内容：其他方法的同样对比；SR 在 T、L 两组的准确度；按 c 分组的结果。

**实测应用（描述）**：在 inline 10141 上，用实验 10 的 c_SR = 1.015 运行全部方法，记录 2.0–3.0 s 的相干信噪比和 5–95% 能量频带，与实验 7/10 相同。

## 5. 开发阶段的结果（已见数据，`analysis/dev_summary.json`）

数据是实验 10 的检验集 H：构造 10301、噪声 10011，c = 0.55–1.4，共 20 个数据集。每个数据集上运行：
- SC-a 用 c_true × 0.75 / 1 / 1.33；
- SC-a 用 c_SR × 1 / 1.15 / 1.3；
- QSCa。

然后对输出做相位校正。

| 方法 | M1 | M1_lag | 相对 QSCa（M1 / M1_lag） |
|---|---|---|---|
| QSCa（现流程） | 0.497 | 0.687 | — |
| SRSCa | 0.629 | 0.661 | +0.132 / −0.026 |
| SRSCa_1.15+ph | 0.665 | 0.687 | +0.168 / 0.000 |
| **SRSCa_1.3+ph（选定）** | **0.680** | **0.698** | **+0.183 / +0.011** |
| QSCa+ph | 0.667 | 0.687 | +0.169 / 0.000 |
| SCa_true（oracle） | 0.668 | 0.670 | +0.171 / −0.017 |
| SCa_true_1.33+ph（oracle） | 0.704 | 0.712 | +0.207 / +0.025 |

**选择规则**（先定好再算）：在 SRSCa、SRSCa_1.15+ph、SRSCa_1.3+ph、QSCa+ph 四个候选中，取 (M1 + M1_lag)/2 平均最大者，结果是 SRSCa_1.3+ph。

- 选择是在开发集上做的，M1_lag 的 +0.011 很可能被高估，所以 P2 只要求不变差。
- SC-a 对 Q 误差不对称：c 偏小（补偿过强）时零时移相关下降最多。真 c×0.75 时，M1 在几个数据集上降到 −0.14 到 −0.02。这也是振幅要保守的原因。
