# Yan 2023 选 Q 准则同样有因模型而异的偏移，而且偏得比 QScan 更多

**结论：Y1 判为“Yan 准则在全部权重下偏移都因模型而异”。** 在 14 个模型（一维 Kennett G1–G8、二维有限差分 H1–H6）的 Q0/14 dB 场景下，φ 从 0 到 1 的 11 个取值，没有一个满足“极差 ≤ 1 且众数 ≥ 11/14”：

- 极差为 4–9 步；
- 出现最多的偏移值最多只覆盖 7/14 个模型。

所以研究线的第二条机制发现——选 Q 偏移是每个模型确定、但因模型而异的——**不是 QScan 目标函数特有的**。最接近、且公开了方法的文献准则也是这样，这说明它更像“残差＋稀疏度”这一类选 Q 准则的共性。

另外两点（描述性）：

- **在本轮约定下，Yan 准则在每一个 φ 下都比 QScan 偏得更多**：平均 |偏移| 为 2.50–6.64 步，QScan 为 2.07 步。
- **偏移的模型排序与 QScan 高度一致**：φ = 0 时，14 个模型上两者偏移的秩相关为 0.89；φ = 0.3、0.5 时为 0.83。也就是说，哪些模型容易被选偏，主要由模型本身决定，而不是由准则决定。秩相关是事后计算的。

## 描述性结果

- **稀疏度项系统性地偏向少补偿**：φ 越大，选的 Q 越高。φ ≥ 0.8 时几乎总是选网格上限 2.2；逐道选择时，选中下标的中位数从 φ = 0 的 7.6 升到 φ = 1 的 13（上限）。这与 `physics_bias_20261024` 的机制诊断一致：稀疏先验偏爱补偿不足的解，因为补偿越少，反演出的反射系数越平滑、越稀疏。
- **用 Yan 的选择接相干标准版，误差都比 QScan 选择大**（归一化平方误差，读自扫描缓存的误差曲线）：
  - Q0/14 dB：QScan 0.181，Yan 最好（φ = 0）0.196，误差最优点 0.133；
  - Q0/8 dB：QScan 0.262，Yan 最好（φ = 0.2）0.299；
  - Q0×0.7：QScan 0.178，Yan 最好（φ = 0）0.190。
- **其他场景和归一化方式下结论相同**：
  - Q0/8 dB 下极差 8–13，Q0×0.7 下极差 4–7，没有任何 φ 稳定；
  - 换成“除以最大值”的归一化，Q0/14 dB 下也没有任何 φ 稳定（极差 3–7）；
  - 两种生成器分开看：G、H 两组里，Yan 准则在主场景下也都不稳定。
- **偏移的符号模式与 QScan 相同**：QScan 偏移为负的模型（G4、G6、H2，都是碳酸盐模型），在 Yan 小 φ 时也是负的或最小的。G2 是唯一明显的例外：QScan +1，Yan φ = 0 时 −3。

## 对研究方向的含义

- 第二条机制发现由“QScan 的性质”上升为“残差＋稀疏度选 Q 准则的共性”。至少对这个公开的文献准则而言，偏移的大小和方向主要由模型决定。这使它成为一条有分量的发现：靠调权重或换归一化的“残差＋稀疏度”方案，都消除不了因模型而异的偏移。
- 在本轮约定下，QScan 的目标函数（按道噪声归一化的 lasso 目标）比 Yan 准则偏得少。这只说明在相同反演、相同网格下 QScan 的规则更好，不说明比 Yan 2023 的完整方法更好。
- 还没有对比的是 Cheng et al. 2025（用浅深一致性选 Q）这类不基于“残差＋稀疏度”的准则。它是否也有同样的现象，仍然未知。

## 边界

- 检验的是 Yan 准则接在我们的 lasso 反演上，不是 Yan 2023 的完整方法：原文用 p = 1/2 匹配追踪、逐段选 Q，并且没有给出 φ、归一化、λ 和停止条件。本轮按方案中的约定处理，并对 φ 做了全扫描、对归一化做了一种替换，但别的约定可能给出不同结果。
- 14 个模型，不报告显著性检验。G1–G8 曾用于 QScan 的开发分析，但从未用于 Yan 准则。
- 偏移以相干标准版的误差最优网格点为参照，与 `qscan_offset`、`fd2d` 的定义相同。
