# 相干干扰压制与真实地震资料试验

## Material Passport

类型：合成资料受控对照与真实炮集去噪探索。当前结果为研究尝试，不替换原补偿入口。

## 方法与试验过程

第一版宽频长孔径相干检测未达到0.65相似性门槛，未改变输入，完整记录在attempt_v1_broadband。第二版在按观测f90划分的频带内检测长直线相干波，预测时按道RMS预条件化，减除前恢复原幅度单位。
全孔径扫描视速度>=400m/s，1201个斜率，至少70%有效孔径，峰值相似性>=0.65，每频带最多3个波包；减除比例0.60。斜率、到时由观测估计，没有读生成器中的1850m/s、10000m/s或轨迹。
补偿与标定冻结，预处理后重新估计噪声水平。两个原复杂样本属于开发资料，不能据此宣称独立泛化。纯净输入控制只用于评分，不用于选取参数。

## 真实资料去噪结果

| 炮集 | 长孔径分频减掉的范数比例 | 软f–k基线减掉的范数比例 |
|---|---:|---:|
| wz25 | 0 | 0.117725 |
| alaska_111 | 0 | 0.378872 |
| alaska_120 | 0 | 0.107144 |
| alaska_130 | 0 | 0.170972 |

长孔径候选在四个实测炮集上均未触发，不能称为实测去噪成功。额外软f–k基线按1200—2500m/s过渡、观测f90的0.4—0.8倍频率过渡压制低频慢速谱锥，最大减除0.60；属于另一个探索基线，没有冒充主候选。
f–k减掉的能量可能包含真实直达波、折射波或反射分量，不能用去除量代替SNR或保幅改善。图中显示原始、候选、f–k和被减分量。t²只用于全部面板的同一显示增益，不参与处理；共用99.5%分位色标，显示截幅比例记录在诊断文件。
这些真实资料没有配套的独立Q标定道集和已确认的层厚/速度、真实无衰减参考。实测试验因此限于去干扰；没有填入假定Q冒充估计Q，没有宣称完成可信的实测Q保幅补偿对比。当前真实炮集还未经动校正，不能直接把横向地质/到时变化当AVO归一化。
