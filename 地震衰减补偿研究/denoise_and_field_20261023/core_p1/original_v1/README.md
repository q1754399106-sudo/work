# 地层吸收解耦与分步补偿：研究基线 v1

## 使用

将整个文件夹放到 MATLAB 工作目录，执行：

```matlab
run_rebuild
```

无需额外工具箱。参数集中在 `config_model.m`。默认 601 个采样点、11 道；改为 `0:50:1500` 可生成 31 道。密集矩阵是为了清楚核查算子，暂未面向大规模实测资料优化。

结果自动写入 `results/`：MAT 数据、道集图、误差图、方法指标、Q 敏感性和数值检查结果。执行会覆盖该目录下同名结果。

## 复现边界

本版本根据所提供论文 PDF 第 3 章重新实现思想，是自选参数的可检验研究基线，不是原程序或原图逐点复现。原代码未提供。

论文来源：用户提供《地层吸收解耦与分布补偿方法研究》，PDF 第 32–34、38–41 页；关键式 (3.1)–(3.18)、(3.19)–(3.24)。

保留：水平分层模型、深度/炮检距吸收分解、非稳态积分核、Tikhonov 反演。速度、密度和 Q 采用表 3-1；自选零偏移走时 0.38/0.65/0.90 s，据此反算层厚。主频 60 Hz，参考频率自选 100 Hz。dt=2 ms，终止时间 1.2 s，避免原讨论中 801 ms 记录容不下 900 ms 反射的问题。18 dB 明确定义为每道含吸收无噪信号能量与噪声期望能量之比，不声称等于论文未明确定义的“18.0”。

差异：

- 使用 Shuey 两项 AVO 近似，不是论文的精确 Zoeppritz；大角度下仅作算法测试，不作可靠 AVO 物理结论。
- 输入直接生成在理想 NMO 拉平坐标；并未实现 NMO 算法，不包括拉伸、透射、几何扩散、多次波、散射或波动方程模拟。
- 正演是对理想带限地震道施加列时变矩阵 Gt，严格定义为 d=Gt*s+n。它不同于逐反射界面使用常数传播滤波的非稳态子波模型，未来应加入后者作独立正演验证。
- 分步中两步都使用正则化矩阵反演；未实现论文介绍的 Wang 波场延拓算法。FixedSplit 表示固定正则化的分步基线，不等于论文原程序。
- v1 没有稀疏反射系数反演、PINN、真实 Q 估计，也不声称自适应方法必定更好。

## 物理量与傅里叶约定

每个参考时间 t0 对应穿过各层的垂直双程时间 tau_i。精确射线参数 p 通过二分法满足：

`x = sum(tau_i*v_i^2*p / sqrt(1-p^2*v_i^2))`

`a0 = sum(tau_i/Q_i)`；`ax = sum(tau_i/(Q_i*cos(theta_i))) - a0`。

小角度参考：`p_small=x/sum(tau_i*v_i^2)`，`ax_small=0.5*p_small^2*sum(tau_i*v_i^2/Q_i)`。与论文式 (3.11)–(3.18)一致的二阶形式。近地表 t0=0 为无反射的人造边界，ax 用首层水平传播极限给定；小角度相对误差只在 0.25–1.05 s 报告。

MATLAB 正变换采用 exp(-i*2*pi*f*t)，正频率传播核定义为：

`H(f,a)=exp[-pi*f*a + i*2*f*log(f/fref)*a]`。

这是带内 Kolsky 型吸收/频散近似；频散正负号必须与傅里叶约定一起解释。负频率取共轭、DC=1、Nyquist 强制实数。FFT 长度至少四倍记录长，随后截取观测窗；有限时间窗和带限仍会造成边界误差，不能视为无限域精确传播。

## 方法和公平性

1. Observed：原始含噪道。
2. Step1：Bx*d；其评价目标是 G0*s，不是无吸收 s。
3. FixedSplit：B0*Bx*d，两步 lambda 都固定。
4. AdaptiveUnweighted：第二步根据第一步后噪声期望范数选择 lambda，未白化。
5. CovarianceSplit：Cunit=Bx*Bx'，L=chol(Cunit+floor*I)，用 L\G0 和 L\y 做第二步。lambda 在统一网格上按残差原则选择。
6. Direct：用正确完整 Gt 一步反演、残差原则选择 lambda，作为公平的强基线；不能只同“错误调用 Q”的传统方法比较。

所有自适应方法使用已知合成噪声 sigma，不使用干净信号选择 lambda。属于 oracle-noise 基准，不是可直接应用于实测的噪声估计方法。协方差公式只描述固定线性 Bx 的随机噪声传播，不含正则化偏差、算子分解误差、Q 模型误差；这些误差可能使残差原则失效。lambda 的白化前后尺度不同，比较方法不能只比较 lambda 数字。若选到网格端点，需在后续研究中判断是噪声假设失配还是网格范围不足。

## 步间误差

`e1 = Bx*d - G0*s`

`s_hat-s = (B0*G0-I)*s + B0*e1`

固定分步算法逐道验证这一恒等式。第一步误差包括噪声、正则化偏差和 Gt-Gx*G0 造成的建模失配。绝不能把频率响应逐点 Htot=Hx*H0 的成立，直接当成两个列时变矩阵也严格相乘等价。

`diagnostics.csv` 提供：小角度近似误差、矩阵分解误差、第一步误差、固定分步的实际噪声增益、误差恒等式残差。

`q_sensitivity.csv`：零偏移和最大偏移道，在相同观测数据上，将所有 Q 同比例设为 0.8/1/1.2 倍，只检验 CovarianceSplit 的敏感性。它不是所有方法的完整鲁棒性比较。

## 研究下一步

优先研究题目：考虑算子分解误差与步间噪声传播的稳定分步吸收补偿。

1. 独立正演：用逐反射界面非稳态子波合成，反演仍用列时变矩阵；再开展精确 Zoeppritz 与薄层试验。
2. 分解误差：区分小角度截断误差、矩阵复合误差和有限窗误差；比较不同偏移距与分层速度/Q 对比度。
3. 第二步：除协方差加权外，研究误差容限或模型误差项。不能把全部第一步残差都当白噪声处理。
4. 实际噪声：从静音段或残差估计协方差，再与已知噪声上限基准比较。
5. 完整实验矩阵：至少三个 SNR、多个独立随机种子、Q 偏差、子波误差、薄层间距；报告均值和波动，而非挑选最好的一次。
6. 保幅评价：v1 的 `event_metrics.csv` 已输出事件带符号模板振幅、相对振幅误差和局部谱峰；继续加入 AVO 截距/梯度、时间偏移和带内谱误差。模板振幅也会受相位误差影响，不能仅凭该指标宣称 AVO 保真。
7. AI 的位置：在上述诊断成立后再考虑学习正则化参数或误差模型。加入神经网络本身不是创新证明。

这是候选研究方向，不是“无人研究过”的结论。后续需单独系统检索并与最相关论文逐项对比。
