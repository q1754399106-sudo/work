# UQ-W 改进：开发记录（探索性，未冻结）

起因：实测 Q 扰动试验（`field_qperturb_20261113`）中 UQ-W 的井震相关不如 VDB。用户选定的顺序：先让开发数据复现实测上的失败（第 3 步），再修噪声项（第 1 步），再接谱整形（第 2 步）。改进只在半合成和有限差分数据上做；Volve 的井已看过结果，定稿后再跑只算第二次使用。

## 1. 实测上的缺陷（`field_qperturb_20261113/logs/diag_nyq_10105.log`，不涉及井）

inline 10105：75 Hz 以上输入比峰值低 55–89 dB，但相干法估出的信噪比为 0.1–10，UQ-W 的增益达 37–65 dB。维纳形式下增益约为 (1/G)·snr/(1+snr)，相干估计分辨不了“信噪比为 0”和“信噪比 0.1–0.3”，带外又有相干的残留，于是带外被大幅放大。

## 2. 第 3 步探查：半合成开发集加井震相关式指标（`scripts/probe.py`，`logs/probe_dev.log`）

24 套已用过的开发数据（ZA–ZF），Q 乘子相对真值。T2：输出道与“真反射系数 * Ricker(fpeak)”在 ±20 ms 内的最大相关，2.3–2.8 s，每 5 道取 1 道，与实测井上相同的函数。S：与理想剖面的得分（阶段 0 的指标）。

输入 T2 0.416，理想剖面 T2 0.908；VDB 的带外能量占比恒为 0。

UQ-W 减 VDB：S 为 +0.178、+0.110、−0.012、−0.099、−0.122（胜 24、24、4、1、1 套）；T2 为 +0.048、+0.039、+0.061、+0.033、−0.021（胜 21、23、24、21、7 套）。

读法：
- Q 偏大一侧 UQ-W 不如 VDB，半合成上本来就有（S 上明显，T2 上只在 m=2），与实测 R5 同向。
- 实测上 m ≤ 1 时 VDB 也不输（m=1：0.519 对 0.466），半合成上换成同一指标后并不复现（m=1：0.856 对 0.917）。所以“指标偏爱谱整形”不能单独解释实测结果。
- 半合成的带外能量占比远小于实测（实测 m=1 时 UQ-W 的 95% 能量频率在 122 Hz）。带外放大是目前唯一查到的、半合成没有而实测有的差别；它对实测井震相关的影响尚未测量。
- 其他未检验的可能：实测基线 Q 不是真值（VSP 储层以上 60–90）；真实测井合成记录与地震的失配。

## 3. 实测截频检验（事后、描述性；`field_qperturb_20261113/scripts/tie_lp.py`，`logs/tie_lp.log`）

用户同意后做。Volve 已有输出（全部方法和输入）做零相位低通（70 Hz 以下通过，85 Hz 以上为零，截频在计算前定），重算 8 组井的井震相关。冻结方案的 R1–R5 判定不变。

| | 原始 | 低通后 |
|---|---|---|
| UQ-W，m=1 | 0.466 | 0.468 |
| IQ70，m=1.2 | 0.459 | 0.466 |
| VDB，各 m | 不变 | 不变 |
| 9 个 m 平均 UQ-W − VDB | −0.071 | −0.070 |
| Q 偏大一侧 UQ-W − VDB | −0.135 | −0.135 |
| m=1 UQ-W − VDB | −0.053 [−0.100, −0.006] | −0.051 [−0.097, −0.004] |

结论：带外放大不是实测上 UQ-W 不如 VDB 的原因（影响 ≤ 0.007）。它仍是该修的缺陷，但修了不会改变实测排名。

到此已排除两个解释：指标偏爱谱整形（第 2 节：半合成上同一指标 UQ-W 仍高）、带外放大（本节）。未检验的候选：
- 实测的子波／振幅谱不符合半合成的生成假设（半合成按估计子波和 Q 模型正演，反 Q 类方法在真 Q 下恰好还原；实测上真 Q 补偿后谱仍不是目标子波，VDB 的整形顺带修掉了这部分，与 Q 无关）；
- 实测基线 Q 不是真值；
- 测井合成记录与地震的失配。
