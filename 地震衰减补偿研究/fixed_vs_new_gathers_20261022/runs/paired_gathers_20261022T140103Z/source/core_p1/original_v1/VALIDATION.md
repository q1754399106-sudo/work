两列不是同一种误差：第一列只比较相对吸收积分 ax，并不等于整道数据误差；第二列是 ||Gt-GxG0||F/||Gt||F，包含列时变算子及有限观测窗的影响。不要把前者的百分数当成补偿结果误差。

## 进一步研究的具体目标

1. 先复核 MATLAB 与 NumPy 的相同参数结果，并增加完整 AVO 评价。
2. 对于第一步残差，分离随机噪声、正则化偏差和模型误差，不把它们全部塞进一个噪声协方差。
3. 研究用真实完整正演算子约束最终输出的分步迭代，而非只串联两次独立求逆。
4. 加入独立正演模型、噪声估计和多随机种子，再评价相对一步反演的计算成本、保幅、鲁棒性是否有实际收益。

研究方向可暂定为“考虑算子分解误差与步间噪声传播的分步吸收补偿”。新颖性尚未经过系统文献核验。
