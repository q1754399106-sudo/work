# 补充检验：哪种数据与模型的失配能抬高 β₀（2026-11-02，开跑前提交）

## 问题

实测比半合成多出的 β 中，约 0.24 在 λ → 0 时仍存在（`RESULTS_BETALAM_ZH.md`），所以来自最小二乘意义下的失配，而不是稀疏偏好。反射系数谱色和噪声已排除（`BETA_ZH.md` 第二步）。半合成配方中有三处与实测可能不同，而且它们主要影响 lasso 的波形拟合，对只看振幅谱的谱比法（SR）影响小：

1. **频散相位**：半合成用与扫描字典完全相同的常 Q 频散相位正演。实测资料若在处理中做过相位校正（例如只校正相位的反 Q 滤波、零相位化），或实际频散与模型不同，字典的相位就不匹配。
2. **子波相位**：半合成的震源是零相位（与扫描用的子波估计一致）。实测子波的相位未知；U1320A 井震标定给出约 −43°。
3. **多次波**：半合成只有一次反射。Volve 水深约 80 m，残余的水层鸣震周期约 0.108 s。

## 变体（`scripts/misfit.py`，结果 `results24/`）

基准配方与 `betalam.py` 的半合成相同（基准剖面、构造线 10227、噪声 ×0.5、锚点在真值），种子 9971、9972 × c = 0.7、1.0、1.4，共 6 个数据集：

- **R0** 基准：扫描取 `results23/`（λ = 1/16、1/2）；这里只补算 SR。
- **P1** 正演不含频散相位（只有振幅衰减 exp(−πf t*)），扫描字典不变。
- **P2 / P3** 震源相位旋转 −45° / +45°，扫描子波估计不变（仍为零相位）。
- **M1** 反射系数加水层多次波：每道沿时间做 y(t) = r(t) − 0.25·y(t − 0.108 s)（海面 −1 × 海底反射系数 0.25），再正演。

每个变体重新标定噪声水平（与原配方相同的做法）。每个数据集在 λ = 1/16、1/2 各扫一次（共 48 次），并算一次 SR（`sq.estimate`）。

## 分析（`scripts/analyze_misfit.py`）

- β(λ) = v_sel − u；β₀ = β(1/16) − [β(1/2) − β(1/16)]/7（两点直线外推到 λ = 0）。R0 用同样的两点算法。
- 每个数据集配对差 Δβ₀ = β₀(变体) − β₀(R0)，取 6 个的中位数。
- 描述量：Δβ(1/2)；SR 的偏差 1/c_SR − u 及其相对 R0 的变化；按实测口径（以 SR 为真值）的 β_SR = v_sel(1/2) − 1/c_SR 相对 R0 的变化。

## 判读规则（与 `BETA_ZH.md` 第二步同一套档位）

- 中位数 Δβ₀ ≥ 0.15（实测多出的 0.24 的六成以上）：记为"可能的主要来源"，需另做确认；
- 0.05–0.15：记为"部分贡献"；
- < 0.05（含负值）：记为"不是来源"。

同时看 β_SR 的变化：若某个变体的 Δβ₀ 小，但 Δβ_SR ≥ 0.15（即主要通过把 SR 带偏），另行注明，因为实测的 β 是以 SR 为准的。
