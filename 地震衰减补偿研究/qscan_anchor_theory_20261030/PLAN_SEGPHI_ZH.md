# 补充检验：分段扰动测 φ₂（2026-11-02，开跑前提交）

## 动机

逐时刻拆分目标函数的曲率失败了（`RESULTS_PHI2_ZH.md`）：v 变化时系数在时刻之间转移，逐时刻的归属不唯一。这里换成不需要归属的做法：**只改变某一时间段内原子的衰减，其余原子不动，每次都完整重解 lasso，看总目标 J 的曲率**。这样得到的是该段的敏感度（二阶模型中为 Σ_段 φ₂a²，含段内耦合），不存在把 J 拆给各时刻的问题。

## 做法（`scripts/segphi.py`，结果 `results22/`）

- 基点：v_a = 1、λ = 1/2 下的选择 v₀（U1320A 取 `results18/`，Volve 取 `results19/`），子波同原扫描。
- 分析窗等分 8 段。对第 b 段，段内原子的累积 t* 取 a(t)(v₀ + h)，段外取 a(t)v₀（U1320A 的水层 t* 固定不随 v 变，与原扫描一致；按逐原子 t* 复制的字典与 `lib.dictionary` 逐位一致）；h = −0.5、−0.25、0、0.25、0.5。另做一组所有原子一起扰动（均匀扰动）。每个点都完整求解，热启动自 h = 0 的解。
- 情形：U1320A 两条测线 × 两个子波窗；Volve 五个剖面（基准、S、D 用种子 9971，D2、M 用 9981）× c = 0.7、1.0、1.4，共 19 个。

## 分析（`scripts/analyze_segphi.py`）

- C_b：5 个 h 上 J 的最小二乘二次拟合，C_b = 2 × 二次项系数；C_u 为均匀扰动的同一量。
- 段内 φ₂ 取常数时，Σ_段 φ₂a = C_b · (Σ_段 a / Σ_段 a²)，所以
  **κ_seg = a₀ Σ_b C_b·(Σ_b a/Σ_b a²) / Σ_b C_b**，a₀ 为子波窗中心的累积 t*（与 a 同一口径）。
- 描述量：各段份额 C_b/ΣC_b；段间耦合比例 1 − ΣC_b/C_u（二阶模型若各段独立应接近 0）；负的 C_b 个数。

## 对照值（两锚点 κ̂，开跑前已知）

U1320A：3677-32 浅窗 0.211、深窗 0.816；4508-32 浅窗 0.255、深窗 0.607。Volve 两锚点中位数：基准 0.693、S 0.854、D 0.592、D2 0.624、M 0.614。

## 判据

1. **S1**：U1320A 四个组合 |κ_seg − κ̂| 都 ≤ 0.10。
2. **S2**：κ_seg(4508-32 深窗) ≤ κ_seg(3677-32 深窗) − 0.10。
3. **S3**：Volve 五个剖面上 κ_seg 的中位数（3 个数据集）与两锚点中位数之差都 ≤ 0.10。

S1、S3 都满足：分段扰动可以测 φ₂，κ 的偏离来自敏感度的实际时间分布；再加上 S2，则 4508-32 偏低可由各段份额说明。S1 或 S3 不满足：如实报告，这一做法不作为 κ 的预测方法。某个情形有未收敛的求解时如实报告，判定仍按结果。
