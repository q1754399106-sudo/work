# 待查新的工作
**名称**：扫描 Q 方法中子波窗假设衰减造成的选择偏差（"锚定"）——闭式选择方程、两锚点诊断与机制分析

**背景**：扫描 Q 类方法从资料浅部（子波窗）估计子波，然后在一组候选 Q 中按某个准则（残差＋稀疏度、l_p 范数、深浅层谱的相对误差等）选出全局 Q。子波估计时总要隐含假设子波窗处的衰减水平。

**主要结果**：
1. **闭式选择方程**：选出的 Q 满足 1/c_sel = (1 − κ)/c_true + κ/c_a + β，其中 c 为相对模型 Q 的系数，c_a 是子波窗假设的衰减，κ = a₀⟨a⟩/⟨a²⟩ 由模型 t* 曲线 a(t) 和子波窗位置 a₀ 算出，β 是与准则和稀疏权重有关的平移。由此，选出的 Q 对真 Q 的斜率被压缩为 1 − κ（例子中 κ ≈ 0.675，理论斜率 0.33，实测 0.19–0.30）。物理上是因为反射资料只约束 t* 的深浅之差。
2. **预先提交的预测检验**：κ 的数值在运行前写下，再在新数据、移深的子波窗、换吸收剖面、两个实测工区上检验（实测 κ̂ = 0.678 对预测 0.675；深锚窗 1.19 对 1.14；第二工区 0.21–0.26 对 0.218），并给出适用边界（深层强吸收时公式失效）。
3. **两锚点诊断**：用两个不同深度的子波窗各选一次 Q，在实测资料上直接测出 κ̂ 和 β，无需真值。
4. **绕不开**：调稀疏权重只平移 β；迭代反馈（用选出的 Q 重估子波）按 κ 收敛，极限等于一步反解 (v₁ − κ)/(1 − κ)，并把稀疏偏差放大约 3 倍；每个候选 Q 都重估子波只能部分恢复斜率。
5. **QScan 偏差的物理来源**：lasso 稀疏先验与密集反射系数不匹配，造成确定性的 Q 偏差（无噪声时也选 1.24–1.28 倍 Q），细层合并成块状层后偏差降约 60%；多次波、透射损失被排除。
6. **选择偏移因模型而异**："残差＋稀疏度"类准则（包括 Yan 等 2023 的准则，在全部 11 个权重下）选出的 Q 偏移随地质模型变化，因此常数去偏不可行；两种准则偏移的模型排序高度一致。已在独立的二维黏声有限差分数据上复现。
7. **频率比偏差**：Cheng 2025 式 17 型准则在 Wang 等 2021 的合成数据上近似满足 Q_sel ≈ Q_true·(f_w/f₀)^s（s ≈ 1.0–1.15）。

**我认为的贡献**（理论本身已知是地震学权衡的具体形式，请判断应用层面是否新）：
1. 震源谱–t* 权衡在"浅层子波窗＋全局 Q 扫描"勘探方法中的闭式选择方程，以及 κ 的显式表达式。
2. 用预先提交的数值预测检验该方程（含实测）。
3. 两锚点诊断：在实测资料上直接测 κ 与 β。
4. 证明调稀疏权重、迭代反馈、重估子波都不能消除锚定。
5. 稀疏先验与密集反射系数失配是扫描 Q 确定性偏差的来源。
6. "残差＋稀疏度"类选 Q 准则的偏移因模型而异，常数去偏不可行。
