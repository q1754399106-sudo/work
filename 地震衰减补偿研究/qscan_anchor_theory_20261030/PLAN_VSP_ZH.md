# 补充检验：用预先登记的稳健估计重算 VSP Q，裁决实测上的真 c（2026-11-02，开跑前提交）

## 问题

`BETA_ZH.md` 第七步用归档的 VSP Q 做了事后换算：F-11 T2 的 RS 段给出分析窗等效 c 0.92–1.08，F-15A 给出 1.09–1.53，都支持 SR（约 1.06），排除窗口配对估计的 c ≈ 0.65。但那些 Q 是当时用最小二乘、按事后放宽的剔除规则算的，而且都没过登记门槛；F-15A 的覆盖深度也没核对。本检验在看到任何新数字之前，固定估计方法和判据。

## 方法（`scripts/vsp_robust.py`）

- **不重新处理原始道集**，只用归档的逐级量：每一级相对参照级的 Δt*（直达波谱比斜率）与单程时差 Δτ。F-11 T2：RS 段 97 级（双程时 0.70–2.07 s）、NI 段 151 级（2.04–2.80 s）；F-15A：190 级。
- **主估计**：1/Q = Δt* 对 Δτ 的 **Theil–Sen 斜率**（对离群级稳健）；对照为最小二乘（应复现归档值 78.5、135、128）。
- **区间**：按深度顺序、块长 10 级的移动块自助（2000 次，种子 20261109），90% 百分位区间。
- **换算**为分析窗 1.2–3.0 s 的等效 c（窗内差分 t* 之比，模型为幕帘模型）：
  - F-11 T2：c = Δt*_模型 / (L₂/Q_RS + L₃/Q_NI)，L₂ = 2.041 − 1.2、L₃ = 3.0 − 2.041（双程时），RS 与 NI 各自自助、合在一起取区间；
  - F-15A：只换算它覆盖的那段窗（1.2 s 到其最深一级初至的两倍）。
- F-15A 的覆盖：最深一级单程初至 1.335 s（归档的 fb），即双程时 2.67 s，缺窗内最深约 0.33 s。

## 判据（Theil–Sen）

对每口井：
- 等效 c 的 90% 区间下限 > 0.75 → "排除 c ≈ 0.65，支持 SR"；
- 上限 < 0.95 → "支持 c ≈ 0.65"；
- 其余 → 无法判定。

**注意**：幕帘模型本身就取自 F-11 T2 的 VSP（最小二乘），所以 F-11 T2 的等效 c 在最小二乘下必然为 1.00；本检验的信息量在于稳健估计和区间宽度。F-15A 是独立的另一口井。

描述项：最小二乘结果与归档值的一致性；只用逐级 R² ≥ 0.3 的级时的 Theil–Sen 结果。
