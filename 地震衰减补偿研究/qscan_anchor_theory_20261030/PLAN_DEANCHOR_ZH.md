# 补充检验：去锚定估计，与真值和 VSP 对比（2026-11-02，开跑前提交）

## 想法

现流程（固定锚点 c_a = 1、λ = 1/2）的选择是 v_sel = (1 − κ)u + κv_a + β。用两锚点测出 κ̂ 后，可以解出 u：

- **E_fix** = (v_sel − κ̂v_a)/(1 − κ̂) = u + β/(1 − κ)：消掉锚定压缩，但 β 被放大 1/(1 − κ) ≈ 3 倍；
- **E_fix0** = (v₀ − κ̂v_a)/(1 − κ̂)：v₀ 是 v_sel 对 λ 的直线外推到 λ = 0 的截距，去掉 β 中随 λ 变化的部分，只剩 β₀/(1 − κ)；
- 对照 **E_cur** = v_sel(λ = 1/2)，即现流程。

本检验不需要新的扫描，数据都已在、或正在由 `PLAN_BETALAM_ZH.md` 计算；本方案在实测 λ 扫描结果出来之前提交。

## 数据

- **半合成**（有真值）：锚点实验的 10 个数据集（`results/`，c = 0.65、0.85、1.05、1.25、1.5 × 种子 9701、9702）。每个锚点都存了 λ = 1/2 与 1/16 的全网格 J。κ̂ 取 λ = 1/2 下 c_a = 0.7 与 1.4 的两锚点值；v₀ 由 c_a = 1 时 λ = 1/16 与 1/2 两点直线外推。
- **实测**：26 条 SR 测线。κ̂ 取 `results11/` 的两锚点值（λ = 1/2）；v₀ 由 c_a = 1 时 λ = 1/16、1/8、1/4（`results23/`）和 1/2（`results11/`）四点直线外推。
- 选择规则同原扫描：网格极小点加两侧邻点的抛物线顶点（v = 1/c 坐标）。

## 判据

1. **D1（半合成，E_fix0 无偏）**：10 个数据集上 E_fix0 对真值 u 的最小二乘斜率在 1 ± 0.2 内，且 |E_fix0 − u| 的中位数 ≤ 0.15。
2. **D2（半合成，优于现流程）**：|E_fix0 − u| 的中位数小于 |E_cur − u| 的中位数。
3. **D3（实测）**：26 条测线 E_fix0 换算的 c 的中位数落在 [1.02, 1.29] 内。这是 F-15A 覆盖段 90% 区间 [1.02, 3.87] 与 F-11 T2 RS 段区间 [0.81, 1.29] 的交集。两者都来自事后的稳健重算（`RESULTS_VSP_ZH.md`），都只覆盖部分分析窗，所以 D3 只是与 VSP 方向一致的检查，不是裁决。

同时报告 E_cur、E_fix 在半合成和实测上的同一组量，以及实测 E_fix0 与 SR 的逐线比较（描述）。外推截距用不可靠点（选择在网格边上）时剔除该点，少于 2 点（半合成）或 3 点（实测）则该数据集或测线剔除并报告。

脚本：`scripts/analyze_deanchor.py`，输出 `analysis/deanchor.json`。
