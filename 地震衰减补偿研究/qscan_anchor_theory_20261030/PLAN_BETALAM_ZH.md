# 补充检验：把 β 按 λ 拆成稀疏偏好项和与 λ 无关的项（2026-11-02，开跑前提交）

## 问题

以 SR 为准，Volve 实测 β̂ = 0.28（26 条测线），半合成 β 多为 0.03–0.11（`BETA_ZH.md`），VSP 稳健重算也偏向 SR（`RESULTS_VSP_ZH.md`），所以实测 β 偏大应是真的。理论上 β = Σφ₁a/Σφ₂a²，其中 φ₁ 是稀疏项对谱倾斜的偏好，随 λ 增大；U1320A 上 β 随 λ 明显变化，但外推到 λ → 0 并不为 0（`RESULTS_LAMBDA_ZH.md`）。把 β 写成 β(λ) ≈ β₀ + β₁λ：β₁λ 来自稀疏偏好，β₀ 与 λ 无关（反射系数谱色、噪声、模型误差等）。比较实测与半合成在这两部分上的差别，就知道实测多出来的 β 属于哪一类。

## 扫描（`scripts/betalam.py`，结果 `results23/`）

- **半合成**：基准剖面（`qprofile.py` 的生成器，构造线 10227，噪声 ×0.5），种子 9971–9974 × c = 0.7、1.0、1.4，共 12 个数据集；锚点取在真值（c_a = c），于是 v_sel = u + β，β 直接可得；λ = 1/16、1/8、1/4、1/2，共 48 次扫描。
- **实测**：26 条 SR 测线（`field_kappa2.py`），现流程（默认子波窗、c_a = 1）；λ = 1/16、1/8、1/4，共 78 次；λ = 1/2 取 `results11/`。
- 扫描同 `qprofile.scan`（早停、抛物线顶点），λ 同时进入求解和目标函数。选择落在网格边上记为不可靠。

## 分析（`scripts/analyze_betalam.py`）

- 半合成：β(λ) = v_sel − u。
- 实测：β(λ) = v_sel(λ) − (1 − κ̂)u_SR − κ̂，κ̂ 为该线 λ = 1/2 的两锚点值（`results11/`），u_SR = 1/c_SR。
- 每个数据集 / 测线在 4 个 λ 上做最小二乘直线 β = β₀ + β₁λ（某个 λ 不可靠时用其余点，少于 3 点则剔除）。
- 差距 G = 实测 β(1/2) 中位数 − 半合成 β(1/2) 中位数；斜率部分 P = ½(实测 β₁ 中位数 − 半合成 β₁ 中位数)；截距部分 I = 实测 β₀ 中位数 − 半合成 β₀ 中位数。
- 稳健性（描述）：只用 λ = 1/16、1/8、1/4 三点拟合的截距；二次拟合的曲率。

## 判读规则

- G < 0.10：本次运行中实测与半合成的差距不足以拆分，如实报告。
- 否则：P ≥ ⅔G 记为"多出的 β 主要来自稀疏偏好"；I ≥ ⅔G 记为"主要与 λ 无关"；都不满足记为"两者都有"。
- 不可靠的选择超过 20% 时如实报告，并注明结论的可信度降低。
