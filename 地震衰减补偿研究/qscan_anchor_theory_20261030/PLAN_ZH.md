# 子波锚定理论：预测与锚点检验方案

2026-10-30 写成，锚点实验开跑前提交。理论推导见 `THEORY_ZH.md`（结果出来后完成）；这里只写下开跑前已经定下的模型和预测。

## 模型（一阶）

记 u = 1/c_true，v = 1/c（扫描值），v_a = 1/c_a（估计输入子波时用的 Q 系数，即锚点），a(t) 为模型 Q（c = 1）下的双程累积 t*，a₀ = a(1.4 s)。

在局部平稳、对数谱线性化下，反射系数估计吸收的谱倾斜为 δ(t) = a(t)(u − v) − a₀(u − v_a)。若选 Q 准则对 δ 的依赖可写成 Σ_t [φ₁(t) δ + ½ φ₂(t) δ²]，则

  v_sel = (1 − κ) u + κ v_a + β，  κ = a₀ Σφ₂ a / Σφ₂ a²，

β 由稀疏项的偏好（φ₁）决定，随权重 λ 变化。

- 现流程 QScan：v_a = 1，斜率 1 − κ；QScan-W：v_a = v，κ 项消失，斜率 1，权重只改截距。
- φ₂ 在分析窗（1.2–3.0 s）内均匀时，由模型 Q 直接算得 **κ = 0.675**（无拟合参数）。

已有结果的事后拟合（`scripts/fit_existing.py`，`analysis/fit_existing.json`，看过）：QScan 在 1/c 空间斜率 0.19–0.30；QScan-W 斜率 1.2–1.36（权重 ≤ 1/4），截距随 λ 单调下降。

## 锚点实验

- 数据：实验 12 的 10 个剖面（c = 0.65、0.85、1.05、1.25、1.5，种子 9701、9702；`baselines_volve_20261029/cache/out`）。
- 方法：`lib.qscan` 的目标函数、σ、K、网格不变，输入子波用 `lib.wavelets(D, TW, cm_a)` 估计，cm_a 的 Q = 模型 Q × c_a，对所有扫描 c 共用；c_a = 0.7、1.0、1.4；λ = 0.5、1/16；FISTA 上限 20000 步，同一 λ 沿网格热启动（同实验 14 的 QScan-W）。
- 对每个 λ 拟合 v_sel = A u + K v_a + C（30 个点）。

## 预测（开跑前）

1. **锚点系数 K > 0 且与 κ 相当**：λ = 0.5 时 K 在 0.5–0.9 之间（均匀权重的 κ = 0.675）。
2. **平移不变（和规则）**：A + K 接近同一 λ 下 QScan-W 的斜率（开发集上 λ = 0.5 为 0.97，1/16 为 1.18），差在 ±0.2 以内。
3. **线性**：每个剖面上 v_sel 随 v_a 单调变化（允许网格离散造成的持平）。

不满足任一条，就如实报告，理论需要修正。本检验是探索性的机制验证，不是方法比较。
