# UQ-W 改进第二轮：查清整形失败的原因，得到 UQW-S（2026-11-14，探索性，开发数据）

接 `uqw_improve_20261113`。上一轮的半强度整形 UQW-H 在半合成 4 倍噪声下比 UQ-W 低 0.13–0.15（0/24），信噪比加权目标 HW50/HW100 也没救回来。本轮按上一轮的改进建议依次做：

1. 用真值分解查原因；
2. 修信噪比估计；
3. 把整形写进算子，强度由不确定度算出。

**全部只用已用过的开发数据**（半合成第一、二批 ZA–ZF 24 个，FD H1–H6），没有碰确认数据和实测井。

## 0. 环境与复现

本会话在云端容器中重建了全部输入：
- 完整拉取 git 历史，从 LFS 取回 MIG_RAW 和 FD 模型；
- `snapshot_inputs.py` 恢复实验 13 的输入快照；
- 第一、二批半合成按原脚本重建，`datasets.json` 与归档相比最大相对差为 2×10⁻¹⁴ 和 1×10⁻¹²。

重跑 `uqw_improve_20261113/scripts/dev5.py semi ZA_c0.75_r0`，与归档结果的最大差为 3×10⁻¹⁵。数据缓存都在被忽略的 `cache/` 下，没有入库。

新增 4 倍噪声的第二种噪声：`gau` 为 `semi.gaussian_noise`，横向不相关，时变谱和均方根与实测残差噪声相同，种子 20261114000 + 数据集序号。这是 UQ-MW 停止时定下的规矩，原噪声记为 `res`。

## 1. 第 1 步：相干信噪比对真值（`scripts/snr_diag.py`，`logs/snr_diag.log`，不看得分）

评分窗 2.3–2.8 s 的 0.4 s 窗，24 个数据集，取中位数。

| 噪声 | 频带 (Hz) | 真信噪比 | 相干信噪比 | 估计/真值 |
|---|---|---|---|---|
| res ×1 | 10–25 / 25–40 / 40–55 / 55–70 | 79 / 47 / 21 / 3.9 | 32 / 18 / 7.6 / 2.1 | 0.42 / 0.42 / 0.34 / 0.55 |
| res ×4 | 同上 | 4.9 / 3.0 / 1.3 / 0.25 | 4.6 / 3.0 / 0.78 / 0.15 | 0.94 / 1.00 / 0.59 / 0.54 |
| gau ×4 | 同上 | 4.0 / 2.4 / 1.0 / 0.19 | 3.3 / 2.1 / 0.59 / 0.13 | 0.82 / 0.88 / 0.55 / 0.72 |

噪声的道间相关（res）：间隔 1、2、3 道为 +0.14、−0.37、−0.24（高频段 −0.04、−0.36、−0.01）；gau 都约为 0。信号的道间相关：间隔 1 道 0.94–0.99，间隔 4 道 0.43–0.87。

**更正上一轮建议第 3 点的推断：**
- 在 10–70 Hz 带内，相干信噪比是**偏低**而不是偏高，原因是信号本身横向不完全相干。
- 噪声横向不相关（gau）时偏低的程度相同，所以"噪声邻道相关 +0.12 造成信噪比下限"在带内不成立。
- 把 UQ-W 的信噪比换成真值（UQWo）也只多 +0.007 / +0.003（S，3 个数据集，`results/dev6`）。

结论：信噪比估计不是瓶颈，第 2 步（改用远间隔互功率估计）没有做的必要，本轮不做。

## 2. 真值分解：整形失败在哪里（`scripts/dev6.py`，`logs/dev6_*_summary.log`）

4 倍噪声，变体 O，3 个数据集（ZA_c0.75_r0、ZC_c1.05_r1、ZE_c0.75_r1）。各方法减 UQ-W 的平均差：

| 方法 | res：S | res：T2 | gau：S | gau：T2 |
|---|---|---|---|---|
| H（上一轮的 UQW-H） | −0.155 | −0.134 | −0.171 | −0.187 |
| H_s：量测谱换成真信号部分 | −0.154 | −0.133 | −0.170 | −0.185 |
| H_tc：目标子波换成 1 倍噪声数据估出的 | **+0.019** | +0.005 | **+0.017** | +0.002 |
| WS50：真信号/噪声分解的维纳整形＋干净目标，λ 0.5 | +0.017 | +0.017 | +0.015 | +0.016 |
| VDB，eps 取 1e-6 到 0.3 | −0.194 到 −0.208 | −0.162 到 −0.185 | −0.208 到 −0.218 | −0.217 到 −0.233 |

**原因是目标子波，不是量测谱。**
- 4 倍噪声下，`lib.wavelets` 估出的输出子波在约 42 Hz 截止：浅层边 fs 在噪声中频凹口处停在 41–43 Hz，深层边 fd 为 42–44 Hz。0 和 1 倍噪声时 fs 为 113–125 Hz、fd 为 61–87 Hz（`logs/dev9_semi_summary.log` 中的 bands 行）。
- 整形把 UQ-W 已恢复出的 40–70 Hz 削掉了。目标换成干净的之后，整形反而有益。
- 这与 `sca_ceiling_20261030` 的机制 1 相同，只是在 UQ-W 这里没被注意到。
- 另外，VDB 的 eps 对结果几乎没有影响，但目标子波影响很大：VDB 用干净目标后，T2 从 −0.162 升到 −0.066。

## 3. 第 3 步：用数据更新振幅（两种实现都否定）

### 3.1 UQW-P：在 UQ-W 之后乘 exp(λ r)（`scripts/uqwp.py`，`dev7.py`，`logs/dev7_*_summary.log`）

- r(f) 是"锚点相干谱按输入 Q 衰减后"与"窗内相干谱"之比的对数，去掉电平。
- λ = v_p/(v_p + v_c)·w·w0。其中 v_c 是反射系数谱色引起的 r 的方差，在开发集理想剖面上测得，标准差 0.16–0.35（`logs/vcolour.log`）。

结果：
- 半合成 3 个数据集、6 种状态：T2 比 UQ-W 高 +0.008 到 +0.048，S 为 −0.003 到 +0.012。
- FD：S 低 0.023 到 0.077（0–1/6）。

### 3.2 UQW-Q：后验写进算子（`scripts/uqwq.py`，`dev8.py`，`logs/dev8_*_summary.log`）

r 只保留 f 的二次项，用加权最小二乘的方差作 v_d，λ = v_p/(v_p + v_d)。
- QM 只平移均值：半合成 +0.004 到 +0.039，但 FD 30 dB 低 0.098（0/6），14 dB 低 0.057。
- QP 同时把 σ 收窄为 σ√(1−λ)：处处更差，半合成 −0.002 到 −0.041，FD −0.097 / −0.140。

### 3.3 否定的原因

FD 数据在无噪声、真 Q 下，r 已经有 ±0.5–1（H1、H4，0.5–1.4 s）。FD 反射系数相对 Ricker 本身带谱色，比半合成测得的 v_c（0.16–0.35）大得多。

"用数据谱改振幅"依赖反射系数谱色的统计，生成器一换就失效。这与 `uqp_selfconsistent_20261110` 的结论（"反射系数颜色随深度变蓝，数据估衰减再做后验有害"）一致。此路停止。

## 4. 修目标子波：UQW-S（`scripts/uqws.py`，`dev9.py`，`dev10.py`；`logs/dev9_*`、`logs/dev10_summary.log`）

### 4.1 dev9：只修目标，不修适用频带

目标改用 `sca_ceiling` 的稳健子波（允许缺口的浅层边 fs_r，不做深层截止），并乘 √w（维纳输出的期望振幅）。4 倍噪声下 fs_r 中位数为 59–83 Hz。

结果：
- 标定噪声下比 UQ-W 高 +0.036（S，24/24）；
- 4 倍噪声下仍低 0.05–0.09，约一半数据集为正。

逐数据集看，凡 fs_r ≤ 46 Hz，差值为 −0.02 到 −0.39；凡 fs_r ≥ 58 Hz，差值全部为正（+0.008 到 +0.027）。即目标子波比 UQ-W 实际恢复出的频带还窄时，整形就伤人。

### 4.2 UQW-S 的定义

- 只在目标子波测得到的频带内整形：fs_r − 5 Hz 以下为 G0^0.5，到 fs_r 用余弦过渡到 1，fs_r 以上保留 UQ-W 原样。
- 72 Hz 以上照旧用 G0（去掉实测上发现的带外放大）。
- 目标为 |W_in,robust|·√w。
- 相对 UQW-H 没有新增自由参数：λ = 0.5 沿用上一轮，5 Hz 过渡沿用 `lib.wavelets` 的截止过渡宽度。
- 已知子波时（FD 的 Ricker）fs_r = ∞，与不加上限的版本相同。
- 代码检查：不加上限时与 dev9 的 HWin 逐值相同（相对差 0）。

### 4.3 dev10：全部 24 个开发集 × 6 种状态，加 FD H1–H6

90% 自助区间以数据集为单元。VDBin 是公平对照：VDB 用同一个稳健目标子波。

| 状态 | UQW-S − UQ-W（S） | UQW-S − UQ-W（T2） | UQW-S − VDBin（S） | UQ-W − VDBin（S） |
|---|---|---|---|---|
| O 标定 | **+0.036** [0.034, 0.039] 24/24 | +0.019 [0.016, 0.022] 23/24 | +0.035 22/24 | −0.001 |
| O res ×4 | +0.010 [0.007, 0.013] 21/24 | +0.014 [0.012, 0.017] 24/24 | +0.142 24/24 | +0.132 |
| O gau ×4 | +0.011 [0.008, 0.013] 22/24 | +0.014 [0.012, 0.017] 23/24 | +0.125 24/24 | +0.115 |
| F 标定 | **+0.051** [0.048, 0.053] 24/24 | +0.048 [0.042, 0.052] 24/24 | +0.042 24/24 | −0.009 |
| F res ×4 | +0.027 [0.022, 0.031] 24/24 | +0.032 [0.028, 0.036] 24/24 | +0.155 24/24 | +0.129 |
| F gau ×4 | +0.027 [0.023, 0.031] 23/24 | +0.033 [0.029, 0.037] 24/24 | +0.134 24/24 | +0.107 |

| FD 14 dB | +0.018 [0.004, 0.033] 4/6 | — | +0.113 6/6 | +0.096 |

按 Q 乘子（S，UQW-S − UQ-W，m = 0.5、0.7、1、1.4、2）：
- O 标定：+0.014、+0.012、+0.011、+0.061、+0.083；
- O res ×4：+0.003、−0.001、+0.000、+0.019、+0.029。

增益主要在 Q 偏大（欠补偿）一侧，正好补 UQ-W 的弱项（实测 R5）。唯一的代价是变体 O 标定噪声在 m = 1 时 T2 低 0.013。

**读法：**
1. UQW-S 是本研究线第一个在两类生成器、两种噪声结构、标定与噪声主导、变体 O/F 上都不输 UQ-W 的改进，区间全部在 0 以上。
2. 增益的大小：标定噪声 +0.036 到 +0.051，噪声主导 +0.010 到 +0.033，FD +0.006 到 +0.018。
3. 变体 F（实测谱偏离形式）上增益最大，与"整形能吸收非常 Q 形式谱变化"的预期一致。

## 5. 对已确认结论的影响：VDB 对照偏弱

VDB 用的冻结目标子波在噪声主导时同样塌缩。换成稳健目标（VDBin）后，VDB 在 4 倍噪声下的 S 提高：
- O res：+0.064；
- F res：+0.102；
- F gau：+0.103（`logs/dev9_semi_summary.log`）。

因此，UQ-W 确认（K3）和 CBL 确认（C6）里"噪声主导时胜过 VDB +0.166 / +0.171"的幅度**被高估**。开发数据上 UQ-W − VDBin 仍为 +0.107 到 +0.132（为正的数据集 17–24/24），方向不变，但幅度约小 0.05–0.10。今后与 VDB 比较时，应同时报告稳健目标的 VDB。确认数据上没有重算（它们是确认数据，留给下一次冻结检验）。

## 6. 局限

- 开发数据已多次使用；λ = 0.5 是上一轮在同一数据上挑的，"在 fs_r 处停止整形"是看了 dev9 后定的规则。所有数字都是探索性的，需要在新数据上确认。
- 只比了 UQ-W、VDB 系；没有和 CBL、SC-a 比。
- 实测井上没有跑。实测浅层信噪比高（实验 13），fs_r 预计在 72 Hz 以上，上限不起作用，那时 UQW-S 就是 HWin（稳健目标加 √w 的半强度整形）。
- 整形依赖浅层子波窗（1.2–1.6 s）代表目标层子波，在浅层强反射或调谐时可能不成立。
