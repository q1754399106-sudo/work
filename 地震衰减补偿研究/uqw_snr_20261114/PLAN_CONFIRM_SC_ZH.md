# UQW-S 与 SC 分工规则的确认方案（2026-11-17，用户已接受，冻结于在确认数据上运行 SC 之前）

**状态：已冻结。** 草案 17fb058，用户接受后冻结；脚本与本方案的 SHA-256 见 `PRE_RUN_HASHES_SC.txt`。冻结前没有在确认数据（第六批半合成、FD H13–H18）上运行过 SC 或 SC-a，也没有在这些数据上估过 SR。冒烟检查只在已用过的开发集 ZA_c0.75_r0 和 FD H1 上跑通代码路径，没有打印分数。

## 1. 要确认的规则（看到开发结果后提出，见 `NOTE_ZH.md` 第 9–10 节）

> **规则 A：** 噪声主导、噪声接近实测时，UQW-S 明显好于文献方法 SC-a。这一条无论 Q 是给定乘子，还是由 SR 从含噪数据估出，都成立。
> **规则 B：** 信噪比合适、Q 大体准确时（真 Q 或 SR 估出），SC-a 好于 UQW-S。
> **规则 C：** Q 偏小（过补偿，m = 0.5、0.7）时，UQW-S 好于 SC。这一条在两种生成器上都成立。

开发数据上的对应值：

| 规则 | 开发结果 |
|---|---|
| A | SR 路线 res4 +0.162、gau4 +0.138；给定乘子 5 个 m 平均 res4 +0.155，均 8/8 |
| B | 标定噪声 SR 路线 −0.044（2/24），m = 1 时 −0.055（1/24） |
| C | 半合成 +0.16~+0.20；FD 30 dB +0.18（两点平均），FD 14 dB +0.08 |

例外：FD 14 dB 上 Q 不偏小时仍是 SC 更好。所以规则 A 只针对半合成实测噪声提出，FD 部分只作描述。

## 3. 方法

- **SC-a（半合成）**：`lib.solve`，a = 2⁻¹³、mu_relative 0.25（实验 17 的推荐值），稳健子波（`libc.wavelets(robust=True)`，与 UQW-S 的目标相同），噪声水平由 `sc11.prepare_sc` 从数据估计。
- **SC（FD）**：`benchmark.solve`，用 FD 字典，a = 0.125、mu_relative 10（原选择；Volve 上调的参数在 FD 上不收敛）。每道噪声水平给真实噪声的标准差，这对 SC 有利。
- **UQW-S**：冻结代码，σ = 0.447。半合成上重算，并与 `results/confirmS` 核对：同一数据和同一 m 下应逐值相同，不一致先查程序。FD 上直接读 `results/confirmS`。
- **Q 的取法**：
  - 给定乘子 m ∈ {0.5、0.7、1、1.4、2}，c = m × c_eff_cum；
  - 半合成另加 **SR 路线**：在每个状态的含噪数据上用 `lib17.sq.estimate`（nboot 0，种子为数据集的 rc_seed）估 c。
  - QScan 每个数据集要十几次 SC 求解，不运行。

## 4. 判据

- 指标与开发相同：半合成用 S（2.3–2.8 s），FD 用 `fdcheck.score_fd`（1.0–1.75 s）。
- 半合成以数据集为单元（12 个），自助 2000 次取 90% 区间，种子 20261198。
- FD 以模型为单元（6 个），先对 3 个实现取平均。

| 编号 | 数据与状态 | 比较 | 要求 | 规则 |
|---|---|---|---|---|
| V1（主） | 半合成 res4，SR 路线 | UQW-S − SC-a | 区间下限 > 0 | A |
| V2 | 半合成 gau4，SR 路线 | UQW-S − SC-a | 区间下限 > 0 | A |
| V3 | 半合成 res4，5 个 m 平均 | UQW-S − SC-a | 区间下限 > 0 | A |
| V4 | 半合成 cal，SR 路线 | UQW-S − SC-a | 区间上限 < 0 | B |
| V5 | 半合成 cal，m = 1 | UQW-S − SC-a | 区间上限 < 0 | B |
| V6 | 半合成 cal，m = 0.5、0.7 平均；FD 30 dB 与 14 dB 同一分段 | UQW-S − SC | 半合成区间下限 > 0；FD 每档均值 > 0 且 ≥ 5/6 | C |

- **确认**：V1–V6 全部成立。
- **否则**：按规则 A、B、C 分别报告。

**描述（不判定）：**
- 各状态逐个 m 的差值；
- FD 5 个 m 平均和逐个 m 的差值（开发：30 dB +0.034，14 dB −0.010；m ≥ 1 时 SC 更好）；
- SR 的估计误差；
- SC 的收敛情况；
- UQW-S 与 confirmS 的核对。

## 5. 预计（冻结时写下，不作判定）
