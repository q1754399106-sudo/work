# 实验 5 方案补充（运行前登记）

登记时间：2026-10-25。写代码时发现以下几处方案文字有误或没写清楚，在运行任何估 Q、补偿或评价之前补充。补充的内容只涉及实现细节，不改变任何门槛、时窗、方法或判定规则。

1. **主频拟合中的 t\***：方案写的是“累计单程 t\*”，这是笔误。冻结代码的字典（`ray_absorption` 与 `attenuation_matrix`）对双程时 t₀ 的反射使用 exp(−πf·Σ τᵢ/Qᵢ)，其中 τᵢ 是各层中的双程时。为了让拟合与字典一致，拟合用的是 `ray_absorption(1.40, 0, cm)` 返回的双程累计量。
2. **近场水听器降采样**：从 0.25 ms 降到 1 ms 时，抗混叠滤波器在新奈奎斯特频率的 0.8–1.0 倍之间做余弦滚降，然后每 4 点取 1 点。主峰定义为 |x| 的最大值。
3. **顶层拟合所用频带**：沿用 G1 得到的频带。
4. **R4 幕帘剖面的位置与时间**：道的位置取道头字节 73/77（乘以 0.1），第一个样点对应 0 s。
5. **评价道中的井位**：检波点弧长取折线上离该检波点最近的顶点的弧长；初至相同的级取平均；评价道下标限制在 3–97 之间，保证左右各 2 道都存在。
6. **Q_int ≤ 0 或不是有限值时**（G1 不通过可能出现）：V 系列无法运行，按“不可执行”报告，R0 照常运行和评价，G2 与 G4 记为无法评估。
