# 实验 8 结果：Volve 半合成检验（真实噪声＋测井反射系数，Q 已知）

完成于 2026-10-28。85 个数据集全部算完。方案见 `PLAN_ZH.md`（提交 c12a6bf），运行后的改动见 `PLAN_ADDENDUM_ZH.md`。数字来自 `analysis/summary.json`、`analysis/table.csv` 和 `analysis/posthoc_lag.json`。

## 一句话结论

在"像 Volve 的数据"上：

- **补偿确实比不补偿更接近真实反射**，即使允许时移也成立。
- **QScan＋SC-a 胜过登记时的常规对照**，但**不比简单的 30 dB 常规反 Q 滤波更好**。
- **QScan 找不回真实的 Q**：不论真 Q 是多少，它几乎总选 0.88。
- **井上相关能看出"补偿比不补偿好"，但分不清哪个 Q、哪种方法更好。**

## 判定（P 组，每个 c 有 10 个实测噪声实现，90% 配对 t 区间）

| 假设 | 结果 | 要点 |
|---|---|---|
| H1 比不补偿更准 | **成立** | ΔM1 = 0.40 / 0.87 / 0.88 / 0.33（c = 0.64 / 0.8 / 1.0 / 1.58），区间下限都远大于 0 |
| H2 与常规反 Q 比 | 对 IQ20a：**QSC-a 更好**；对 QIQa：**不分胜负** | 对 IQ20a 的差值为 +0.05 / +0.16 / +0.05 / +0.01；对 QIQa 的差值在 c = 0.64 时区间跨 0 |
| H3 不损害频带 | **不成立** | c = 1.58 时，55–85 Hz 的相关从 0.36–0.47 降到约 0；其余三个 c 都满足 |
| H4 QScan 找回 Q | **不成立** | 在 ±25% 以内的实现数为 0 / 10 / 10 / 0 |
| H5 井上相关（描述） | 方向全对，排序不可靠 | 见下文 |

| 方法 | c = 0.64 | 0.8 | 1.0 | 1.58 |
|---|---|---|---|---|
| 输入（未补偿） | −0.21 | −0.28 | −0.20 | 0.25 |
| 常规反 Q 20 dB＋限带（IQ20a） | 0.14 | 0.43 | 0.63 | 0.56 |
| QScan＋常规反 Q＋限带（QIQa） | 0.19 | 0.42 | 0.54 | 0.56 |

## 主要发现

### 1. 补偿的改进是真的，不只是时间校正

未补偿输入的 M1 为负。原因是频散让数据相对 100 Hz 参考频率整体延迟 6–16 ms，在约 30 Hz 的主频下接近 1/3 周期。为把这部分和波形改进分开，事后对每个输出允许一个 ±20 ms 的整体时移，再算 M1。这是描述性检查，不在方案中：

| 允许时移后的 M1 | c = 0.64 | 0.8 | 1.0 | 1.58 |
|---|---|---|---|---|
| 输入（最佳时移，ms） | 0.14（16） | 0.28（12） | 0.41（9） | 0.68（6） |
| 常规反 Q 30 dB | 0.47 | 0.64 | **0.78** | **0.88** |
| QScan＋SC-a | 0.53 | 0.64 | 0.72 | 0.77 |
| SC-a | **0.56** | **0.67** | 0.76 | 0.77 |
| SC-a 用真 Q | 0.51 | 0.62 | 0.76 | 0.80 |

QSC-a 相对输入的提升仍有 +0.39 / +0.37 / +0.30 / +0.09，所以波形确实变好了。

另外，Q 错了以后，损失主要体现为**几毫秒的残余时移**，而不是波形变差。例如 c = 0.64 时，QSC-a 零时移只有 0.19，允许时移后达到 0.53，与用真 Q 的 0.51 相当。

![时移的作用](figures/posthoc_lag.png)

### 2. 稀疏反演没有稳定地胜过常规反 Q 滤波

登记的对照组 IQ20a 和 QIQa 都被 QSC-a 超过或打平。但同在方法列表里的 **30 dB 常规反 Q 滤波**（模型 Q，不限带）几乎一样好：

- 零时移下：c = 0.64 时打平，c = 0.8 时 QSC-a 领先 0.02，c = 1.0 和 1.58 时 IQ30 分别领先 0.10 和 0.08。
- 允许时移后，QSC-a − IQ30 为 +0.06 / 0.00 / −0.06 / −0.11。

规律是：实际衰减比模型强（c < 1）时，稀疏反演略好；衰减比模型弱时，常规方法更好。"稀疏反演比常规反 Q 更好"这个说法，在这组数据上不成立。

IQ20 与 IQ20a 只在 c = 1.58 时有差别，说明问题出在 20 dB 的增益上限，而不是限带。

### 3. QScan 不能估计 Q，Q 的误差是最大的误差来源

不论真 c 是 0.64、0.8 还是 1.0，QScan 在全部 30 个实现中都选 0.877；c = 1.58 时选 1.0。它的目标函数在 0.77–1.0 附近很平，最低点几乎不随真 Q 移动。

- 真 c 碰巧在 0.8–1.0 时，这个结果是对的。c = 1.0 时它反而把本来正确的模型 Q 改错了：QSC-a 0.68，SC-a 0.76。
- c = 0.64 时，QSC-a 与用真 Q 的差距是 0.32（零时移），远大于各方法之间的差别。

这改变了对实验 7 的解读：实测上 QScan 选出 0.77，**不能当作 Q 的估计**。在半合成数据上，它从未选出低于 0.877 的值。

相比之下，"浅层到目标层的频谱衰减斜率"这个简单量能清楚地区分各个 c：−0.055 / −0.045 / −0.038 / −0.028，实测为 −0.046，对应 c ≈ 0.8（见 `build.json`，登记前已记录）。它是更有希望的独立 Q 估计方法。

![QScan 与井上相关](figures/qscan_and_tie.png)

### 4. 井上相关能判断方向，不能用来选方法或选 Q

模仿实测井上评价的 T2-like 指标（中心 5 道与测井合成记录的相关，±20 ms）：

- **方向**：QSC-a 相对输入的提升，T2-like 在 40 个实现中**全部**判断正确（ΔT2-like = +0.47 / +0.41 / +0.32 / +0.19）。这个量比实验 7 的井上区间宽度大，多井标定应能检测到。
- **排序**：T2-like 与真值评价对各方法排序的 Kendall τ 只有 0.33 / 0.73 / 0.95 / 0.58。它总是偏爱高频最多的输出（30 dB 反 Q 在每个 c 下都得分最高或接近最高）。c = 0.64 时，它给 QSC-a 0.74、给用真 Q 的 SC-a 0.60，而真值评价正好相反（0.19 对 0.51）。

所以：多井标定（实验 9）可以检验"补偿是否有用"，但**不能用来挑 Q 或在稀疏反演和常规反 Q 之间做选择**。

### 5. 分频带（H3）

c ≤ 1.0 时，QSC-a 在 10–70 Hz 各频带都从负相关提高到正相关，最高到 0.97，70–85 Hz 基本不变。

c = 1.58 时，实验 7 的子波估计把浅层可用频带估成 45 Hz（真实约 90 Hz）。输出被截在 45 Hz，55–85 Hz 原有的 0.36–0.47 相关就丢了，这就是 H3 不成立的原因。限带规则依赖这个估计，估错时会直接损害高频。

![分频带](figures/summary_bands.png)

### 6. 稳健性（描述）

- **高斯噪声（G 组）**：与实测噪声的结果几乎相同，QSC-a − 输入为 +0.41 / +0.91 / +0.89 / +0.33。结论不依赖噪声类型。
- **不放大的噪声（R1 组，信噪比更高）**：排序不变。
- **子波有 30° 相位误差（PH 组，c = 1.0）**：所有方法都变差。QSC-a 降得最多（0.68 → 0.44），SC-a 为 0.76 → 0.64，IQ20a 为 0.63 → 0.55。QScan 在这里仍选 0.877。

## 对实测应用的含义

1. **补偿值得做。** 在 Volve 这样的噪声和衰减水平下，无论用哪种方法，都明显比不补偿更接近真实反射。
2. **最该改进的是 Q，不是反演算法。** Q 准确时，各方法之间只差 0.0–0.1；Q 差 36% 时，零时移相关会丢掉 0.3。QScan 应换掉，或至少不能单独用来定 Q。下一步优先考虑频谱比或衰减斜率法、VSP 或多井约束。
3. **常规反 Q 滤波（30 dB）是很强的基线**，计算量也小得多。实测报告中应与 QScan＋SC-a 并列给出。
4. **限带规则要更稳。** 子波和频带估计出错时，会把可用的高频截掉。
5. **多井标定（实验 9）的定位**：检验"补偿比不补偿好"在 7 组左右独立井上是否成立。预期效应 0.2–0.5，可以检测到。不要用它在方法或 Q 之间做选择。

## 局限

除了方案中已列出的各项，还有：

- 半合成数据没有断层，构造比实测简单。
- 82 Hz 以上没有相干能量（见 `figures/realism.png`）。
- 理想目标以 100 Hz 为频散参考频率，零时移的 M1 因此包含一个约定带来的整体时移。上面已用事后检查分开处理。
- 真 Q 与模型 Q 只在平滑程度上不同，实测地层的 Q 结构可能更复杂，那时 Q 误差的影响可能更大。
