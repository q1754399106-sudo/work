# 实验 8：用 Volve 的真实噪声和测井反射系数做半合成检验（预登记）

登记时间：2026-10-28。登记前已构建半合成数据并做了真实性检查（`analysis/build.json`），也在一块 31 道、单独种子噪声的数据上做过冒烟测试，只确认代码能跑通，没有看分数。登记前没有在任何登记数据集上运行补偿方法。

## 目的

实验 4–7 在实测上都无法回答"补偿后是否比不补偿更准"，因为没有真值，而井上相关的不确定性（90% 区间宽 0.2–0.45）比方法之间的差别大。本实验构造一个**答案已知、但其余尽量真实**的数据：反射系数来自 F-11 T2 的测井，构造、子波、信噪比和噪声来自 Volve 实测，Q 已知。用它检验：

1. QScan＋SC-a（实验 7 的实测版本）是否比不补偿更接近真实反射；
2. 它是否比常规的稳定化反 Q 滤波更好；
3. QScan 能否找回真实的 Q 系数；
4. 实测中用的井上相关，能否分辨出真实的好坏。

## 数据构建（`scripts/semi.py`、`scripts/run.py build`）

几何与实验 7 的应用测线相同：inline 10141，xline 2100–2500（201 道），1.2–3.0 s，4 ms。

**反射系数（1 ms）**：中心道（xline 2300，第 100 道，作为"井"）的 2.299–2.820 s 用 F-11 T2 的测井反射系数（实验 6 事后参照里的 `rc`，按原时间放置；第 2 个样点原为缺失值，置 0）。其余时间用这段反射系数的 40 ms 循环块自助重采样填充。横向：每道 = √(1−0.3²)·中心序列 + 0.3·独立序列，独立序列为各道独立的块自助序列，再沿测线做 σ = 5 道的高斯平滑。各道按 inline 10141 实测的构造时移放置（相邻道互相关求时差，200 ms 窗、100 ms 步长、±12 ms、抛物线插值、5 道平滑，由中心道向两侧累加）。种子 20261028。

**Q**：模型 Q 为 F-11 事后 VSP Q（四层 78.5 / 78.5 / 135.2 / 135.2）。真 Q = c × 模型 Q，且真 t* 是层状 t* 经 200 ms 滑动平均后的连续曲线，**不是**求解器使用的层状模型。c 取 0.64、0.8、1.0、1.58。0.64、0.8、1.58 不在 QScan 网格点上；1.0 在网格点上，代表 VSP Q 正确的情形。

**震源子波**：用实验 7 的方法从实测 inline 10141 的浅层（1.2–1.6 s）估计零相位子波，再按各情形的真 t* 修正 1.4 s 处的吸收。这样每个情形的浅层频谱都与实测一致。

**正演**：在 1 ms 网格上，每个反射点各自带上真 t* 的常 Q 吸收与频散响应（参考频率 100 Hz），100–120 Hz 余弦防假频后抽样到 4 ms。这与求解器的 4 ms 层状字典不同，用来避免用同一个模型既生成又反演。自检中，同一层状模型下两者的相关为 1.00000。

**振幅与噪声**：信号按 1.2–1.6 s、5–80 Hz 的相干功率与实测相等来定标。噪声有两种：
- **R（主）**：另外 10 条 inline（10041、10061、10081、10101、10121、10161、10181、10201、10221、10241）的实测噪声。做法是对每道先按局部倾角对齐两侧邻道，再做侧向二次差分 × √(2/3)。缺道或有死道的测线按 +2 顺延替换（本次未发生）。
- **G**：空间白、时变频谱与 inline 10141 自身残差相同的高斯噪声，种子 20261029–20261033。

二次差分会去掉一部分侧向相关的噪声，所以它的振幅只有相干法 (P−C) 估计的 0.41。为此，**每个 c 的噪声水平按实测校准**：取 0.5–4 之间的系数，使半合成数据在 2.0–3.0 s 的相干信噪比与实测在 10–80 Hz 的对数均方差最小。校准结果：c = 0.64、0.8、1.0、1.58 分别为 0.55、1.00、1.49、2.69（`build.json`）。

**登记前看到的真实性结果**：实测从浅层到目标层的频谱衰减斜率为 −0.046/Hz，c = 0.64、0.8、1.0、1.58 时分别为 −0.055、−0.045、−0.038、−0.028。c = 0.8 与实测最接近，与实验 7 中 QScan 在实测上选出的 0.77 一致。这是数据层面的观察，不涉及任何补偿方法的结果。

## 方法（`run.py` 的 `methods`）

所有方法只看数据和模型 Q，不知道 c 和真值；σ 按每道 Haar MAD 估计；子波和最高频率由实验 7 的 `lib.wavelets` 从数据估计；求解器和参数与实验 7 相同（a = 0.125，mu_relative = 10）。

| 方法 | 说明 |
|---|---|
| Input | 不补偿 |
| IQ10 / IQ20 / IQ30 | 常规时变稳定化反 Q 滤波（振幅与频散），增益上限 10 / 20 / 30 dB，模型 Q |
| IQ20a | IQ20 后按数据估计的最高频率（与 SC-a 相同）低通 |
| QIQa | Q 乘以 QScan 系数后做 IQ20，再低通。用来分开"QScan 的作用"和"稀疏反演的作用" |
| SC | 原始 SC（Ricker 字典，36.75 Hz），模型 Q |
| SC-a | 实验 7 的实测版本，模型 Q |
| **QSC-a** | QScan＋SC-a（实验 7 推荐的实测方法） |
| SC-a-oracle | SC-a 用真 c（仍为层状 Q），只作描述，用来区分 Q 误差和方法误差 |

## 评价（有真值）

- **M1（主）**：各道输出与"理想目标"在 2.30–2.80 s（中心道为真实测井段）的相关，取各道中位数，零时移。理想目标 = 未衰减的真反射 × 真震源子波，频带截到真信噪比 ≥ 1 的上限 f_true（由已知的信号和噪声直接算）。也就是"在这个噪声下最多能恢复到什么程度"。M1w 为 2.0–3.0 s 的同一指标。
- **M2**：分频带（10–25、25–40、40–55、55–70、70–85 Hz）带通后，输出与未衰减真响应的相关（2.0–3.0 s，各道中位数）。看补偿是否损害某个频带。
- **T2-like**：模仿实测的井上评价。中心 5 道平均，与中心道真反射 × Ricker(36.75 Hz) 的相关，±20 ms 时移，2.30–2.80 s。
- **QScan**：选出的系数与真 c 的比较。

## 假设与判定（只用 P 组；每个 c 有 10 个噪声实现，区间为配对差值的 90% t 区间）

- **H1（比不补偿更准）**：ΔM1 = M1(QSC-a) − M1(Input) 的 90% 区间下限 > 0。四个 c 全部满足才判 H1 成立。
- **H2（与常规反 Q 比较）**：报告 QSC-a − IQ20a 和 QSC-a − QIQa 的 ΔM1 区间。四个 c 的下限都 > 0，判"QSC-a 更好"；上限都 < 0，判"常规方法更好"；否则判"不分胜负"。这是比较，不是门槛，哪种结果都如实报告。
- **H3（不损害频带）**：对 Input 的 M2 均值 ≥ 0.2 的频带，要求 QSC-a 的 M2 均值 ≥ Input − 0.05。四个 c 全部满足才成立。
- **H4（QScan 找回 Q）**：|ln(系数 / c)| ≤ ln 1.25 的实现数 ≥ 8/10。四个 c 全部满足才成立。
- **H5（描述）**：T2-like 与 M1 对各方法排序的一致性（Kendall τ），以及 QSC-a 相对 Input 的 ΔT2-like 与 ΔM1 符号一致的比例。

G、R1、PH 组只报告同样的量，不做判定。

## 已知局限（登记前写明）

- 反射系数只有约 0.52 s 来自真实测井，其余是它的重采样，浅层的统计特征未必真实。
- 二次差分噪声会去掉侧向相关的噪声（如偏移划弧）。校准水平只让信噪比的频谱与实测一致，并不保证噪声的空间结构一致。
- 真 Q 与模型 Q 的形状差别只来自平滑，真实地层的 Q 变化可能更复杂。
- 震源子波由实测估计，PH 组只检验一种相位误差。
- 这里检验的是"像 Volve 的数据"。结论能否推广到实测本身，仍取决于这些近似是否成立。
