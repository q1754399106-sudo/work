# 以 UQ-W 为主、限制最坏后悔的受限贝叶斯补偿（CB）：开发方案（2026-11-10，草案，待用户审阅，未冻结）

## 动机

最小最大后悔原型（`RESULTS_MMR_ZH.md`）的结论是：两点最不利先验能改善两端，代价落在 Q 准确附近和噪声主导时。

| 开发集 | 联合后悔 RGJ − UQ-W |
|---|---|
| 半合成，欠补偿一侧（m 1.4–2） | +0.040 |
| 半合成，9 个 m 平均 | +0.029 |
| Q 准确附近（m 0.85–1.2） | 半合成 −0.022，FD −0.070 |
| FD 14 dB，9 个 m 平均 | −0.088 |

UQ-W 的对数正态先验在中间和低信噪比时更好，但对 u = 2 这一端几乎不设防。

本阶段不再用"纯最小最大"，而是：**保持 UQ-W 的期望损失为主目标，只要求任何一个比例剖面上的后悔不超过上限。**统计上这是受限贝叶斯（restricted Bayes，Hodges–Lehmann 类，文献待核对）。

## 设计

**记号**沿用 `mmr.py`。时频点 c 上，剖面 j 成立时的损失是：

l_cj(H) = |H G_cj − 1|² + ρ_cj |H|²，其中 ρ_cj = s + |G_cj|²/snr(t, f)

剖面 j 的平均后悔是 R_j(H) = mean_c [l_cj(H) − l*_cj]，取与 RGJ 相同的时频点：每隔一行，全部频率。

**问题 CB(τ)：**

min_H  mean_c Σ_k p_k l_ck(H)   使得   R_j(H) ≤ B_τ，对比例族的每个 j（17 个 u ∈ [0.5, 2]）

- 目标用 UQ-W 的对数正态先验 p_k：41 个 Gauss–Hermite 节点，σ 0.447。
- 上限 B_τ = R_mm + τ (R_UQW − R_mm)：
  - R_mm 是最小最大后悔值，即 RGJ 的对偶值，是任何算子都做不到更低的最坏后悔；
  - R_UQW 是 UQ-W 自己的最坏后悔 max_j R_j(H_UQW)。
  - 这两个量都由模型和数据的 snr 算出，不用真实 Q，也不用评分。

**解的结构**（拉格朗日对偶，写在开跑前）：

H_c = [Σ_k p_k G*_ck + Σ_j λ_j G*_cj] / [Σ_k p_k (|G_ck|² + ρ_ck) + Σ_j λ_j (|G_cj|² + ρ_cj)]，λ_j ≥ 0

- 仍是同一个贝叶斯形式，先验是"对数正态 + 非负的补充权重 λ"。
- 互补松弛：只有后悔恰好碰到上限的剖面才得到 λ_j > 0。按原型结果，预计只有 u = 2，可能还有 u = 0.5。
- τ = 1 时 λ = 0，CB 就是 UQ-W，代码中逐元素检查。
- τ = 0 时最坏后悔降到 R_mm，相当于在最小最大后悔解中挑期望损失最小的一个。
- 对偶函数在 λ 上是凹的，梯度是 R_j(H(λ)) − B_τ。用投影梯度上升（λ ≥ 0）加回溯求解，报告约束违反量和对偶间隙。

**参数：**τ 主值取 **0.5**，事先固定。τ = 0.25、0.75 只作描述，用于看取舍曲线，不用来挑参数。

## 数据与对照

数据与原型相同（都已用过，所以仍是开发判断）：
- 半合成 DEV，24 个数据集；
- FD H1–H6，14 dB，3 个噪声实现，种子同阶段 2b。

对照沿用已有结果（同一数据、同一噪声）：UQ-W、RGJ、MMJ 取自 `results/mmr/`；VDB 取自阶段 0 和 2b；W0 取自阶段 W。

统计单元与区间同原型：半合成按数据集自助 2000 次，取 90%，种子 20261117；FD 按模型，先对 3 个实现取平均。

## 判据（CB0.5，对照 UQ-W）

记 Δ = CB0.5 − UQW。

| 编号 | 检验什么 | 要求 |
|---|---|---|
| T1 | 欠补偿一侧能否改善 | 半合成 m ∈ {1.4, 1.7, 2.0} 的均值：Δ 区间下限 > 0 |
| T2 | Q 准确附近不受损 | m ∈ {0.85, 1, 1.2} 的均值：半合成 Δ ≥ −0.01，FD Δ 的模型平均 ≥ −0.01 |
| T3 | 低信噪比优势保留 | FD 14 dB 9 个 m 的均值：Δ 的模型平均 ≥ −0.01；CB0.5 − VDB 的模型平均 > 0 且 ≥ 5/6 |
| T4 | 半合成整体不退步 | 9 个 m 的均值：Δ ≥ 0，区间下限 ≥ −0.01 |

T1–T4 全部成立，算开发通过，之后另写确认方案，在新数据上检验（需要新建第六批半合成和 H13 以后的 FD 模型）。

**描述性报告：**
- τ ∈ {0.25, 0.5, 0.75} 三点，加上 UQ-W（τ = 1）和 RGJ：各 m 的 S、过补偿一侧（m 0.5–0.7）、m = 1 单点；
- λ 落在哪些 u 上、总权重多少；
- 约束是否满足：最大违反量和对偶间隙。

## 预测（开跑前）

- **T1 大概率成立，**但幅度小于 RGJ，估计 +0.01~+0.03。
- **T2 半合成部分大概率成立。**FD 部分没有把握：原型中 FD 在 Q 准确附近的损失（−0.070）比半合成大得多，减半后仍可能超过 0.01。
- **T3 是最可能不成立的一项。**FD 锚点为 0，整段衰减都不确定，u = 2 的补充权重会在低频要求更大的增益，噪声主导时这部分被放大。
- **T4 大概率成立。**
- λ 预计主要落在 u = 2，总权重随 τ 减小而增大。

若只有 FD 部分（T2 的 FD、T3）不成立，说明后悔上限应随信噪比变化，例如按 snr 加权的后悔。这需要另立方案，不在本阶段事后调整。

## 风险与局限

- 平方损失与基于相关的 S 不一致，这一点与原型相同。
- 数据中的 Q 误差是整体乘子，与比例族吻合。
- τ 主值是事先拍定的，0.5 不一定是最好的点。三点描述只用来说明取舍，不据此宣称通过。
- 新颖性：受限贝叶斯和 Γ-最小最大是经典统计原则，能主张的只是它在 Q 传播约束下的结构结果（例如补充权重只落在比例族端点）和收益。
