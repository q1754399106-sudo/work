# 阶段 1：UQ-IQ 的实现与开发检验（2026-11-09，方案，待用户确认后运行）

## 问题

阶段 0（`RESULTS_STAGE0_ZH.md`）表明，Q 错 30–40% 时，调好的 SC-a 和 70 dB 反 Q 损失约 0.24，过补偿一侧更伤；振幅不用 Q 的 VDB 在 Q 错得多时反而更好。本阶段检验三件事：

1. 对 Q 不确定度取期望的反 Q 算子（UQ-IQ），在 Q 不准时能否稳定地胜过直接代入 Q 的 70 dB 反 Q；
2. 能否胜过 VDB；
3. 它的好处是否不只是“补偿弱一点”，即能否胜过两种简单的保守做法。

数据仍是用过的开发集，所以这是开发判断，不是确认检验。

## 算子（`scripts/uqiq.py`）

**现有 70 dB 反 Q 本身是一个最小化问题的解。** `lib12.iq` 的算子是 H = e^{−ikx}(β + s)/(β² + s)，其中：
- β = e^{−πfx}，k = 2f ln(f/f_ref)，x 是时刻 t 的模型 t*；
- s 由 70 dB 增益上限确定。

正演 G = exp[(−πf + ik)x]，只校正相位的算子是 P = e^{−ikx}。可以验证，H 恰好是 |HG − 1|² + s|H − P|² 的最小解：既要把子波恢复成脉冲，又在噪声处退回“只校正相位”。

**UQ-IQ：对这个目标函数取期望。** x 不确定时，最小化它的期望，得到

  H = (E[G*] + s·E[P]) / (E|G|² + s)

不确定度为零时，它与 `lib12.iq` 完全相同，没有新增可调参数。

**只有相对子波窗的衰减是不确定的。** 子波按模型在 1.4 s 处的 t* 去衰减（`lib.wavelets`）。半合成数据 1.4 s 处的谱就是实测谱，与真 Q 无关。所以用 û = 1/c 补偿后，输出谱与子波相差

  exp{−πf [Δa(t)(u − û) + a(1.4)(1 − û)]}，Δa = a(t) − a(1.4)

后一项由 û 决定，没有不确定性；只有前一项不确定。所以

  x = x̂ + Δx̂·(u/û − 1)，Δx̂ = x̂(t) − x̂(1.4)

这与设计 2.1 节一致。u 的相对不确定度为 σ，按对数尺度计。

**两种误差分布（都跑，由开发结果选）：**
- **gauss**：u/û − 1 ~ N(0, σ²)，闭式解。记 v = (σΔx̂)²，b* = −πf − ik：
  - E[G*] = exp(b*x̂ + ½b*²v)
  - E|G|² = exp(−2πfx̂ + 2π²f²v)
  - E[P] = exp(−ikx̂ − ½k²v)
- **lognormal**：u/û = e^{σε}，ε ~ N(0, 1)，用 41 点 Gauss–Hermite 求积，在对数域求和。

**描述用的变体 gauss_abs：**不确定度加在绝对 t* 上，即 v = (σx̂)²。按上面的推导它是设错的模型，只用来说明为什么必须用 Δa。

## 冒烟（已运行，未看任何 S）

- **等价性**：σ = 0 时，ZA_c0.75_r0、ZF_c1.05_r1 × m 0.5、1、2 × 三种变体，与 `lib12.iq` 的最大相对差为 4.9×10⁻¹⁵。
- **算子的高切**：2.55 s 处 |H| 比 70 dB 反 Q 先低 6 dB 的频率（没有就记“无”）：

| 变体 | c | σ = 0.1225 | σ = 0.245 | σ = 0.447 |
|---|---|---|---|---|
| gauss | 0.75 | 无 | 54.7 Hz | 27.6 Hz |
| gauss | 1.05 | 无 | 78.4 Hz | 40.5 Hz |
| lognormal | 0.75 | 无 | 无 | 41.7 Hz |
| lognormal | 1.05 | 无 | 无 | 60.5 Hz |
| gauss_abs | 0.75 | 42.5 Hz | 19.0 Hz | 9.3 Hz |
| gauss_abs | 1.05 | 61.3 Hz | 28.3 Hz | 13.9 Hz |

  gauss_abs 在 σ = 0.245 时 19–28 Hz 就已经低 6 dB，说明不确定度加在绝对 t* 上会过度保守；这也是先发现、后推出用 Δa 的原因。两种分布差别明显：对数正态更温和，因为 u 不会取负值或接近零的值，E|G|² 不会被“几乎没有衰减”的尾部抬高。
- **数值修正**：对数正态在 1.4 s 以上的浅部几行（Δa < 0）、σ = 0.894 时，求积节点的尾部会溢出，已改为在对数域求和。修正后 σ = 0.894、m 0.5 和 2 的输出全部有限。
- **单数据集试运行**：ZA_c0.75_r0 共 148 条记录，69 秒；只看了记录数和等价性差（4.8×10⁻¹⁵），没有看 S。

## 情景与声明的 σ

误差都是整体乘子 m（c = m × c_eff_cum，与阶段 0 相同）。每个情景的声明 σ 取该情景 m 网格的 log m 均方根，也就是“误差模型正确”的情况。

| 情景 | m 网格（等权） | 声明 σ | 含义 |
|---|---|---|---|
| A | 0.7、0.85、1、1.2、1.4 | 0.245 | SR 量级的大误差（±30–40%） |
| B | 0.5、0.6、0.7、0.85、1、1.2、1.4、1.7、2.0 | 0.447 | Q 未知，只知道在 ×2 以内 |

另外计算 σ = 0.1225、0.2235（A、B 声明值的一半，声明过小）和 0.894（B 的两倍，声明过大），只作描述。

## 方法（`scripts/stage1.py`，24 个开发集）

| 代号 | 做法 | 来源 |
|---|---|---|
| UQ_gauss、UQ_lognormal | UQ-IQ，û = 1/c，σ 取 5 档；其余与 70 dB 反 Q 相同 | 新算 |
| UQ0 | σ = 0 的 UQ-IQ（等价性检查） | 新算 |
| IQ70、VDB、SCa | 直接代入 c | 阶段 0 结果（SCa 只有 5 档 m） |
| C1 | 30 dB 反 Q：更强的常规稳定化 | 新算 |
| C2 | 70 dB 反 Q，但把 Q 取大一个 σ（c × e^σ）：经验上的“Q 偏大更安全” | 新算 |
| gauss_abs | 描述 | 新算 |
| SR 路线 | c = c_SR（实验 17）：IQ70、VDB、UQ（σ = 0.245，两种分布）；SC-a 用实验 17 的分数 | 新算 |

C1、C2 是“只要补偿弱一点”的两种做法，用来判断 UQ-IQ 的好处是否来自算子本身。

## 判据（`scripts/analyze_stage1.py`，输出 `analysis/stage1.json`）

情景均值：先在每个数据集上对该情景的 m 网格取平均，再对 24 个数据集取平均。区间按数据集自助 2000 次（随机种子 20261111），取 90% 区间。X 指 UQ-IQ 用该情景声明 σ 时的结果。每个“情景 × 分布”组合分别判定。

- **P0（实现有效，先判）**：所有 24 × 9 个 (数据集, m) 上，UQ0 与 IQ70 输出的最大相对差 ≤ 1×10⁻¹⁰，S 差 ≤ 1×10⁻⁹。不满足则本阶段作废。
- **P1（胜过直接代入）**：情景均值 X − IQ70 ≥ 0.03，且区间下限 > 0。
- **P2（Q 准时代价小）**：m = 1 时 X − IQ70 的均值 ≥ −0.01。只在情景 A 作为判据；情景 B 本身就是“Q 未知”，m = 1 不比其他 m 更可能，所以只描述。
- **P3（胜过不用 Q 振幅的 VDB）**：情景均值 X − VDB 的区间下限 > 0。
- **P4（不只是保守）**：情景均值 X − C1、X − C2 的区间下限都 > 0。

**结论：**
- **继续阶段 2**：P0 成立，并且至少一个组合满足 P1–P4（情景 B 不要求 P2）。阶段 2 只确认通过的情景和分布；两种分布都通过时，用情景 B 均值较高的那种。
- **有效但有代价**：P1、P3、P4 成立，但情景 A 的 P2 不成立。报告这一权衡；阶段 2 只针对“Q 未知”的情景（若情景 B 也通过）。
- **只是保守**：P1、P3 成立，但 P4 不成立。说明好处等于“补偿弱一点”。此时 UQ-IQ 不作为新方法推进，报告这条简单规则即可。
- **停止**：其余情况。

## 预计（运行前写下，不作判定）

- gauss 在 m ≤ 0.85（过补偿）一侧明显好于 IQ70，在 m ≥ 1.2 一侧略差，m = 1 时有小损失。情景 A 的 P2 是否成立没有把握，因为声明 σ 时 54–78 Hz 已经低 6 dB。
- 对数正态更温和：m = 1 时损失更小，m = 0.5–0.6 时的改善也更小。
- 最难过的是 P4 中与 C2 的比较。C2 把 Q 整体取大，是同一方向的保守；UQ-IQ 只在深部、高频处保守，能否明显胜过 C2 没有把握。
- 声明过大（0.894）时，比 IQ70 在 m = 1 处差得多。

## 描述（不判定）

- 每种分布、每档 σ 下的 S–m 曲线；C1、C2、gauss_abs 的曲线。
- 对 IQ70 的单元胜率（数据集 × m）；在 SC 网格上与 SCa 的比较。
- 声明 σ 偏小或偏大时的情景均值。
- SR 路线：UQ-IQ 与 IQ70、SC-a、VDB 在实验 17 的 c_SR 下的 S。SR_IQ70 应与实验 17 逐位一致，同时作为检查。

## 局限（事先写明）

- 开发集已用过多次，结论需要阶段 2 在新数据上确认。
- 误差只是整体乘子 m，不含随深度变化的误差；只有一种 Q 剖面形状。
- 声明 σ 恰好等于网格的离散，是“误差模型正确”的理想情况；声明错的情况只描述。
- UQ-IQ 只针对反 Q 型算子，没有和 SC-a 结合。
