# 阶段 2b：UQ-IQ 是否依赖生成器——二维黏声有限差分数据上的检验（2026-11-09，开跑前提交）

## 问题

阶段 1、2 的数据都来自同一个半合成生成器：Volve 实测构造加一维 Kjartansson 常 Q 正演。设计稿要求另用一种独立的正演检验结论是否依赖生成器。仓库里的 `fd2d_20261025` 正好提供了这样的数据：
- 二维黏声有限差分，GSLS 衰减（4 机制，5–100 Hz 内 Q 偏差 ≤ 3.6%）；
- 每个模型有一条垂直断层，带断点绕射；
- 6 个模型 H1–H6，各 99 道，时间轴 0–1.8 s，4 ms 采样；
- 有经过相同处理的弹性（Q = ∞）目标。

这批数据在 fd2d 实验中用于 QScan 检验，**从未用于 UQ-IQ、IQ70 或 VDB**。

这批数据与半合成有一个关键差别：**子波已知的位置在 t = 0**。处理中已在震源处恢复 Ricker 谱，而不是像半合成那样在 1.4 s 处估子波。按设计 2.1 节和阶段 1 的推导，不确定度从子波已知的位置算起，所以这里锚点取 0，整段 t* 都不确定。

## 冻结的内容

- **算子**：`uqiq.operator_rows`，a941239 起未改，对数正态分布，σ = 0.447，70 dB 稳定项。
- **新代码只在 `scripts/fdcheck.py`**：把时间轴和锚点改成参数。
  - `iq_t`：与 `lib12.iq` 逐句相同，只把时间轴改成参数。在半合成时间轴上与 `lib12.iq` 的差为 0。
  - `uq_t`：取锚点 1.4 s、半合成时间轴时，与 `uqiq.uqiq` 的差为 0。
  - 时移函数与 `run.shift` 的差为 8×10⁻¹⁶。
  - 6 个 FD 模型上，σ = 0 的 UQ 与 IQ70 的相对差 ≤ 4.4×10⁻¹⁴。
  - 以上冒烟检验都没有计算任何分数。
- **对照**：参数与阶段 0–2 相同。
  - IQ70：70 dB 反 Q；
  - C1：30 dB 反 Q；
  - C2：Q 取大 e^0.447 倍；
  - VDB：相位反 Q＋时变 Wiener（`SEL["B3"]`），目标子波是该模型的 Ricker（fpeak 32 Hz）。
- **Q 乘子**：m ∈ {0.5、0.6、0.7、0.85、1、1.2、1.4、1.7、2.0}，等权。补偿用的 Q = m × 上尺度 Q0（`config.Q`）。fd2d 实验已表明，无噪声时误差最优点在 Q0 的一个网格步长以内，所以 m = 1 近似“Q 正确”。

## 数据与噪声

- **噪声**：H1–H6 的无噪声道集，加 `noise_replica.m` 的噪声过程（AR(1) 0.45、10% 道间共模、按 Frobenius 信噪比定标），但用 numpy 随机数生成器，与 fd2d 的噪声不是同一组实现。
- **随机种子**：20261113000 + 1000 × 模型号 + 10 × 档位 + r。
- **档位**：14 dB 判定，8 dB 只描述；每档 3 个实现。
- **指标**：S = ½(M1 + M1_lag)，即窗口内各道与弹性目标相关系数的中位数，以及允许 ±20 ms 整体时移后的中位数，定义与 `lib15.score` 相同。窗口取 **1.0–1.75 s**，即衰减累积最大、又避开道集末端的一段。

## 计算（`scripts/fdcheck.py run K N`，输出 `results/stage2b/`）

- **方法与 σ**：每个 (模型, 档位, 实现) 和每个 m，计算 IQ70、UQ0（等价性检查）、UQ（σ 0.447，判定用）、UQ（σ 0.245、0.894，描述用）、UQ_anchor09（锚点误取 0.9 s，描述用）、VDB、C1、C2。
- **规模**：6 × 2 × 3 = 36 个任务，每个 81 条记录。
- **运行**：2 个进程，低于正常优先级，每个进程 1 个 BLAS 线程，预计约 10–15 分钟。
- **分析**（`scripts/analyze_stage2b.py`，输出 `analysis/stage2b.json`）：先对 9 个 m 和 3 个实现取平均，得到每个模型一个值，单元是模型（6 个）。区间按模型自助 2000 次（随机种子 20261113），只作描述，因为 6 个单元太少。

## 判据（14 dB）

- **P0**：所有记录上，UQ0 与 IQ70 的最大相对差 ≤ 1×10⁻¹⁰，否则作废。
- **G1（胜过直接代入）**：UQ − IQ70 的模型平均 ≥ 0.03，且 ≥ 5/6 个模型为正。
- **G2（不比 VDB 差）**：UQ − VDB 的模型平均 ≥ −0.01。这对应阶段 2 的结论“与 VDB 持平略好”。
- **G3（不只是保守）**：UQ − C1、UQ − C2 的模型平均都 > 0，且各自 ≥ 5/6 个模型为正。

**结论：**
- G1、G3 成立：UQ-IQ 的核心结论（胜过直接代入、不只是保守）不依赖生成器。
- G2 单独报告：与 VDB 的关系是否也不依赖生成器。
- G1 或 G3 不成立：核心结论依赖生成器，报告哪一项、哪些模型。

## 预计（运行前写下，不作判定）

- 这里整段 t* 都不确定，且 1.75 s 处 t* 达 0.019–0.035 s，比半合成中相对子波窗的 t* 大。所以同样的 σ 切得更狠，m = 1 时的代价会比半合成的 0.028 大。
- G1、G3 大概率成立，G2 没有把握。
- 锚点误取 0.9 s（UQ_anchor09）时，不确定度被低估，表现会介于 IQ70 与 UQ 之间。

## 描述（不判定）

- 各方法的 S–m 曲线；m = 1 时的代价；8 dB 下的同样比较。
- σ 0.245、0.894 的模型平均；锚点误取的效果；按模型列出各项差值。

## 局限

- 只有 6 个模型，单元太少，区间只作参考。
- 噪声实现与 fd2d 不同（随机数生成器不同）。
- m = 1 只是近似“Q 正确”（上尺度 Q0 与 GSLS 有效 Q 有差别）。
