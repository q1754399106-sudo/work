# Q 误差大或未知时的补偿算法：设计（2026-11-09，草案，未冻结）

## 0. 要解决的问题

现有推荐流程是先用 SR 估 Q，再接 70 dB 稳定反 Q 或 SC-a（a = 2⁻¹³、mu 0.25）。它默认 Q 大体正确，但仓库的结果说明 Q 常常定不准：

- 叠后资料只能定衰减的深浅之差；衰减的绝对水平与子波谱、反射系数谱色混在一起（锚定理论、`BETA_ZH.md`）。
- SR 在单个实现上偏 ±20%（`RESULTS_BETASR_ZH.md`）；单井地层颜色能让它偏 ±25–50%，两口井方向相反（实验 9）。
- QScan 被子波窗锚定（κ ≈ 0.68），实测给出 c = 0.77–0.84，偏强。
- 实测井上分不出 Q 的好坏：c = 0.77 与 SR 的 c、70 dB 与 30 dB 都分不出（实验 9、13）。
- 误差不对称，补偿过强比过弱更伤（EI：Q 偏大好约 2.5 dB；限频反 Q：Q × 0.8 时波形误差 1.4–2.6；实验 11 的保守振幅有效）。

所以要的是：**Q 只知道一个大致范围时，补偿结果仍然稳定，而且 Q 越不确定，补偿越保守。保守的程度要由 Q 的不确定度算出来，而不是另调一个参数。**

## 1. 先试过、行不通的方向：用频散估 Q

频散只出现在相位里，不受振幅谱色影响，理论上可以绕开“谱色与衰减混叠”。van der Baan (2012, *Geophysics* 77(4), V133–V142) 指出，时变的、随频率变化的相位谱自由度太多，难以估计。我想用 Kolsky 频散律把它压成一个参数 u = 1/c（再加一个时不变的常相位 ψ 和时不变频散 g），用校正后数据的峰度来选 u。

小试探（`pilot_dispersion/`，探索性，没有预先提交判定规则；已用过的半合成，c = 0.7、1.0、1.4）：

- **校正算子正确**：以“只有振幅衰减”的同一份正演作参照，相关最大处的 u 为 1.375、1.0、0.75（真值 1.43、1.0、0.71）。
- **峰度判据失败**：u 从 0 扫到 2，峰度只变约 2%，曲线基本单调上升，选出的 u 系统偏大。24 条曲线（种子 10001–10004 × c 三档 × 有无噪声）的回归斜率 0.55、截距 +1.22，|log 误差| 中位数 0.65，6 条选在网格上端（u = 2）。有噪声与无噪声几乎相同（斜率 0.553 对 0.554），说明偏差来自判据本身，不是噪声；偏差还随反射系数实现变化（种子 10004 的 c = 0.7、1.0 都落在边上），所以不能事先校正。原因之一是频散对波形的影响本来就小：不做相位校正时，与参照的相关已有 0.95–0.97。
- 完整记录见 `pilot_dispersion/pilot_kurt.log` 与 `pilot_dispersion/results/pilot_kurt.json`。

结论：在这批数据上，靠高阶统计量从频散定 Q 不可行，这条路不作为方法。

## 2. 提出的算法：Q 不确定度下的期望反 Q（UQ-IQ）

### 2.1 只需要相对衰减

锚定理论给出：子波从子波窗估出，字典（或反 Q 算子）在时刻 t 只依赖 Δa(t)·u，其中 Δa(t) = a(t) − a₀，a₀ 是子波窗处的模型 t*。所以补偿只需要相对衰减的比例 u。绝对水平定不了，但它不进入补偿结果，只影响输出子波的定义。Q 的误差在补偿里表现为一个随深度线性增大的谱倾斜误差，在子波窗处为零。

### 2.2 闭式算子

设 b(f) = −πf + iθ(f)，θ(f) = 2f ln(f/f_ref)（与正演一致），真实传播 G(t, f) = exp[b Δa(t) u]。

u 不确定时，取 u ~ N(û, σ_u²)，σ_u 由第 2.3 节的误差模型给出。对传播算子取期望（高斯矩母函数，闭式）：

- E[G] = exp[b Δa û + ½ b² Δa² σ_u²]
- E|G|² = exp[−2πf Δa û + 2π²f² Δa² σ_u²]

信号功率 S(f)、噪声功率 N(t, f)（由相干信噪比估计，与现有 `lib.coherence_snr` 相同）下的 Wiener 型补偿算子：

  H(t, f) = S·E[G]* / (S·E|G|² + N)

性质（都可以直接验证）：

1. **σ_u → 0 时退化为普通稳定化反 Q**：H = G*/(|G|² + N/S)。实现上要求与现有 70 dB 反 Q 在 σ_u = 0 时逐值一致，作为代码检查。
2. **Q 不确定度自动带出时变高切**：振幅上多出因子约 exp(−1.5 π²f²Δa²σ_u²)，相位不确定度另乘 exp(−½θ²Δa²σ_u²)。等效的“Q 不确定度频带”为 f_Q(t) ≈ 1/(√1.5·π Δa(t) σ_u)。按模型 Q，分析窗底部 Δa = a(3.0) − a(1.4) ≈ 0.0331 − 0.0178 = 0.0153 s：σ_u = 0.25 时 f_Q ≈ 68 Hz，σ_u = 0.5 时约 34 Hz（u ≈ 1）。它随深度变窄，随不确定度变窄，**没有额外的调节参数**。
3. **自动偏向弱补偿**：由 Jensen 不等式，期望算子对过补偿的惩罚大于对欠补偿的惩罚。这给“Q 偏大更安全”的经验结果一个理论解释，可以检验：同一个 σ_u 下，期望算子相当于把 û 往弱补偿方向移动多少，可以事先算出。
4. **两个已有方法是它的极限**：σ_u = 0 时是反 Q；σ_u 很大时，振幅补偿被压到低频，接近“只做相位、振幅保守”的做法（van der Baan 2012 的建议、实验 11 的保守振幅）。

### 2.3 σ_u 从哪里来（不调参）

| 情形 | û | σ_u（对数尺度） | 依据 |
|---|---|---|---|
| 有 SR | u_SR | 0.20–0.30 | SR 单个实现 ±20%；整条测线平均后的颜色影响按实验 9 约 ±30% |
| 只有 QScan | 两锚点反解 (v₁ − κ̂)/(1 − κ̂) | σ_β/(1 − κ̂)，σ_β 按 1/√T 律由子波窗长算出 | 锚定理论与窗长检验；实测系统偏差另计，见第 4 节风险 |
| 只有区域经验值 | 模型 Q | 0.5 或更大 | 声明的先验范围 |
| 有可识别的 VSP | VSP | 由 VSP 自助区间换算 | 实验 5、6 |

σ_u 是写出来的误差模型，不在数据上调。检验时会故意让声明的 σ_u 小于实际误差，看算子如何退化。

### 2.4 与已有工作的区别（公开渠道，WoS 与 CNKI 未查）

- **Wang 稳定化反 Q**：常数增益限或稳定因子，与 Q 的不确定度无关。
- **van der Baan 2012**：Q 已知时做相位反 Q 再接时变 Wiener；没有处理 Q 的不确定度。
- **Eldar & Merhav 2005**（IEEE TIT）：谱不确定下的鲁棒 Wiener / regret 滤波器，是一般理论，不针对 Q。
- **仓库里的 BAE-Q**（`bae_q_20261024`）：把模型误差并入反演的噪声协方差，Q 正确时误差翻倍。UQ-IQ 在 σ_u → 0 时严格退化为反 Q，所以不会有这个问题；但 σ_u 估大了时会不会也损失精度，需要检验。

能主张的新意有三点：(1) 对 1/Q 的不确定度取期望，得到含频散的闭式反 Q 算子；(2) 由此导出无调节参数的时变频带 f_Q(t)，其中的 σ_u 来自误差模型（锚定理论、1/√T 律、颜色统计）；(3) 把“误差不对称”和“保守补偿”统一成同一族算子的性质。先例风险在于：鲁棒 Wiener 和贝叶斯反褶积在其他领域很常见，投稿前要做正式查新。

## 3. 检验方案（分阶段，每阶段先提交判据再运行）

**阶段 0：有没有空间（决定是否继续）**
- 在已用过的半合成（第一、二批）上，测 70 dB 反 Q、SC-a（a = 2⁻¹³、mu 0.25）、相位反 Q＋时变 Wiener（VDB，不用 Q 振幅）在 Q 乘子 0.5、0.6、0.7、0.85、1、1.2、1.4、1.7、2.0 下的 S 指标。
- **门槛**：Q 乘子在 0.7 和 1.4 时，最好的调好方法平均损失 ≥ 0.03（与“SR 换真 Q 只多 0.015–0.031”同一量级以上），或者损失明显不对称。达不到，说明调好的方法对 Q 误差已经不敏感，本算法没有空间，停止并报告。

**阶段 1：实现与开发（用已用过的数据）**
- 实现 UQ-IQ：σ_u = 0 时与 70 dB 反 Q 逐值一致（≤ 1×10⁻¹⁰）。
- 情形：Q 正确、SR 给 Q、Q 乘子 0.5–2.0 并按第 2.3 节声明 σ_u。
- 对照：反 Q 直接代入 û、SC-a、VDB、QScan＋SC。
- 只看开发结果，确定 N(t, f) 的估法（沿用现有相干信噪比，不新增参数）。

**阶段 2：冻结确认（未用过的数据）**
- 用断层与复杂 Q 生成器新建第四批构造（未用过的构造线和噪声线），另加独立的 Kennett 或二维有限差分数据，检验是否依赖生成器。
- 预定判据（草案，阶段 1 后定稿）：
  - U1：Q 乘子 ≤ 0.7 或 ≥ 1.4 时，UQ-IQ 比反 Q 直接代入 û 的 S 平均高 ≥ 0.03，单元胜率 ≥ 75%；
  - U2：Q 正确时，UQ-IQ 不比 70 dB 反 Q 差 0.01 以上；
  - U3：在所有 Q 乘子上，UQ-IQ 的最坏情况优于 VDB（不用 Q 的基线）。
- 描述：故意声明过小的 σ_u（实际误差的一半）时的退化程度。

**阶段 3：实测（只描述）**
- 8 组井、104 条 inline（实验 13 的流程），SR 给 û，σ_u = 0.3。井上分辨力有限，只看方向，不作判定。

## 4. 风险与局限（事先写明）

- **回报上限可能很小**：Q 已知时补偿只剩 0.005–0.03 的空间。UQ-IQ 的价值只在 Q 误差大的时候体现，阶段 0 就是为了先确认这一点。
- **σ_u 的误差模型不完整**：实测 β 有约 0.21 的系统偏差（子波窗 1.2–1.4 s 的强反射），按 1/√T 律算出的 σ_β 不含这部分。QScan 路线的 σ_u 在实测上会偏小。
- **高斯假设**：u 的误差用高斯近似，大误差时可能是对数正态或偏态；必要时改用对数正态，闭式变为一维数值积分。
- **只针对反 Q 型算子**：稀疏反演（SC-a）不能直接套用闭式。若阶段 1 显示 SC-a 才是主力，可把 E[G] 用作字典，E|G|² 进入噪声项，但那更接近 BAE，新颖性要重新评估。
- **指标**：S 指标对振幅标定敏感；实测上的效果仍受井上分辨力限制。
