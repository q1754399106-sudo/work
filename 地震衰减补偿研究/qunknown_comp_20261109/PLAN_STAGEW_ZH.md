# 阶段 W：由数据估计噪声项的 UQ-IQ（UQ-W）的开发检验（2026-11-09，开跑前提交）

## 问题

阶段 2b（`RESULTS_STAGE2B_ZH.md`）表明，在深部噪声主导的有限差分数据上，UQ-IQ 不如 30 dB 反 Q 和 VDB。原因是它沿用了 70 dB 反 Q 的常数稳定项 s，只处理 Q 的不确定度，不处理噪声。

本阶段把 s 换回设计原式中由数据估计的噪声项，检验两件事：
1. 能否同时在半合成（信噪比合适）和有限差分（噪声主导）两类数据上，不输给 VDB 和 30 dB 反 Q；
2. 好处是否仍来自 Q 不确定度本身。

两类数据都已用过，所以这是开发判断；通过后要在新数据上确认。

## 算子（`scripts/uqw.py`）

设计原式是 H = S·E[G]* / (S·E|G|² + N)，其中 S 是补偿后（震源一级）的信号功率，N 是噪声功率。数据中测得的相干信噪比是 snr = S|G|²/N，所以 N/S = E|G|²/snr。记 ρ(t, f) = s + E|G|²/snr(t, f)：

  H = (E[G*] + γ·ρ·E[P]) / (E|G|² + ρ)

- **γ = 1**：沿用 UQ-IQ 的形式，噪声主导处只校正相位、不放大。
- **γ = 0**：标准 Wiener，噪声主导处直接压低。
- **snr(t, f)**：现有的相邻道相干信噪比（`lib.coherence_snr`），在输入数据上用 0.4 s 窗、每 0.1 s 估一次（与 VDB 的 `tvw` 窗相同），再插值到每个输出时刻和算子的频率网格。下限 10⁻³。
- **s**：70 dB 增益上限对应的值，作为 snr 很高时的保底。
- **没有新增的可调参数**：窗长、步长取 VDB 现有的值。
- **Q 不确定度部分**：与 UQ-IQ 相同，对数正态，σ = 0.447。半合成的锚点为 1.4 s，FD 为 0 s。

**冒烟（已运行，未看分数）：**
- 1/snr = 0、γ = 1 时，与 `uqiq.uqiq` 的相对差 ≤ 1.6×10⁻¹⁵（两种分布，σ 取 0 和 0.447），与 FD 版本 `uq_t` 的相对差为 2.6×10⁻¹⁷；
- γ 取 0 和 1 时输出都有限；
- 估出的相干信噪比（10–60 Hz 中位数）：半合成 ZA_c0.75_r0 在 1.2–1.6 s 为 23.2，在 2.3–2.8 s 为 20.5。FD 深部按阶段 2b 的诊断为负 dB。
- 在一个半合成和一个 FD 任务上跑通了全部代码：各 45 条记录，约 55 秒，没有看分数。

## 数据与对照

- **半合成开发集**：24 个，与阶段 0、1 相同，c = m × c_eff_cum。
- **FD**：H1–H6 × 14 dB、8 dB × 3 个实现，噪声种子与阶段 2b 相同，所以噪声逐位相同。
- **Q 乘子**：m ∈ {0.5、0.6、0.7、0.85、1、1.2、1.4、1.7、2.0}，等权（情景 B）。
- **新计算**：
  - W0：σ = 0、γ = 0，即只用信噪比的 Wiener 反 Q，作为“好处是否来自 Q 不确定度”的对照；
  - UQ-W 的 γ = 0 和 γ = 1，σ = 0.447；
  - UQ-W 的 γ = 0，σ 取 0.245 和 0.894，只描述。
- **沿用旧结果（同一数据、同一噪声）**：IQ70、VDB、UQ-IQ（σ 0.447 对数正态）、C1（30 dB）。半合成取自阶段 0、1，FD 取自阶段 2b。

## 判据（每个 γ 分别判定；先在每个单元上对 9 个 m 取平均）

半合成的单元是数据集（24 个），区间按数据集自助 2000 次（随机种子 20261114），取 90%。FD 用 14 dB，单元是模型（6 个），先对 3 个实现取平均。

- **S1（半合成上不丢 UQ-IQ 的好处）**：UQ-W − UQ-IQ ≥ −0.01。
- **S2（半合成上胜过 VDB）**：UQ-W − VDB 的区间下限 > 0。
- **F1（FD 上不输 VDB）**：UQ-W − VDB 的模型平均 ≥ −0.01。
- **F2（FD 上胜过 30 dB 反 Q）**：UQ-W − C1 的模型平均 > 0，且 ≥ 5/6 个模型为正。
- **N1（好处来自 Q 不确定度）**：UQ-W − W0 在半合成上区间下限 > 0；在 FD 上模型平均 > 0，且 ≥ 5/6 个模型为正。

**结论：**
- 五项全部成立的 γ 为“开发通过”。两种都通过时，取半合成均值加 FD 14 dB 均值较高的一种。
- 开发通过后，另写确认方案，在新数据上检验。注意可用的新构造线已经很少，见第四批的说明。
- 没有 γ 通过：报告哪几项不成立。若 N1 不成立而其余成立，说明好处主要来自“由数据估计噪声项”，而不是 Q 不确定度。

## 预计（运行前写下，不作判定）

- 半合成上，snr 在 20 左右，E|G|²/snr 与 s 相比不再可以忽略，所以 UQ-W 会比 UQ-IQ 更保守一些。S1 大概率成立，S2 没有把握。
- FD 上，γ = 0 会大幅好于 UQ-IQ，F2 大概率成立；F1（不输 VDB）没有把握，因为 VDB 的整形目标是已知的 Ricker 子波。
- N1 的 FD 部分最没把握：噪声主导时，W0 的信噪比项已经起主要作用，Q 不确定度的额外贡献可能很小。

## 描述（不判定）

- 各方法的 S–m 曲线；FD 8 dB 的同样比较；σ 0.245、0.894 的效果；FD 各模型对 VDB 的差。

## 运行

2 个进程，低于正常优先级，每个进程 1 个 BLAS 线程。共 60 个任务（24 个半合成 + 36 个 FD），每个约 55 秒，预计约 30 分钟。脚本：`scripts/stageW.py`、`scripts/analyze_stageW.py`，输出 `results/stageW/`、`analysis/stageW.json`。
