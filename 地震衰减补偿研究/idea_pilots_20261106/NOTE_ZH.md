# 新创新点的小试探记录

日期：2026-11-06。用户要新的创新点。为避免再出现“方向选好才发现回报有限”，提出思路前先用已用过的数据做了三个小试探。**全部是探索性的，没有预先提交判定规则，只用来决定思路值不值得写方案，不能当结论引用。** 脚本用实验 13 的代码（经 `mu_field_20261106/scripts/env18.py`）和半合成第一批数据（构造 A、B、C，都已用过）。

## 试探 1：不用真值选反 Q 增益（`cv_pilot.py`、`cv_diag.py`）

**思路：** 同一数据分成噪声独立的两半，判据 C(g) = ‖iq_g(半 1) − iq_120dB(半 2)‖²。半 2 几乎不加限制的反演是有噪、但接近无偏的目标（Noise2Noise 的逻辑）。比较放在补偿后的域，因为 EI 实验显示数据域的留出损失看不到噪声放大。

**结果（12 个数据集，用真 Q，只选增益）：失败。**

| | 平均 S |
|---|---|
| 判据选（模拟半叠加） | 0.680 |
| 判据选（相邻道） | 0.694 |
| 固定 30 dB | 0.703 |
| 固定 70 dB | 0.909 |
| 固定 60 dB | 0.914 |
| 每个数据集选最优 | 0.933 |

判据和真实 MSE 的相关中位数为 −0.93（半叠加）和 −0.28（相邻道）。诊断：两条噪声线基本独立（相干 0.06–0.08，独立时约 0.07），但把真实噪声换成相位随机的噪声后，选的增益从 100 跳到 30，说明判据被放大噪声的方差淹没。这只否定了这个形式。

**更重要的数字：** 每个数据集选最优增益，比最好的固定增益只高约 0.02。所以自动定增益的回报上限很小。

## 试探 2：同层比较能否测横向 t* 变化（`lateral_pilot.py`）

沿层平移后，每道用 ±8 个道对的互谱，相对同一地层窗的全剖面平均谱，在 10–60 Hz 拟合斜率，dt* = −斜率/π。不需要颜色、子波或井。18 个 Z 组数据集，每个 3 个窗。

| 窗 | 相关中位数（范围） | 真实横向标准差 | 误差 | 回归斜率 |
|---|---|---|---|---|
| 1.8–2.4 s | 0.68（−0.39 到 0.84） | 0.8 ms | 1.1 ms | 0.92 |
| 2.1–2.7 s | 0.83（−0.10 到 0.95） | 1.9 ms | 1.5 ms | 0.74 |
| 2.4–3.0 s | 0.85（−0.24 到 0.98） | 1.8 ms | 1.0 ms | 0.98 |

构造之间差别大：A 0.76，B 0.91，C 0.24。这个数据对方法有利：反射系数按设计跟着地层走（η = 0.3），实测的横向相变可能破坏假设。

## 试探 3：横向 t* 对补偿的回报上限（`lateral_ceiling.py`）

70 dB 反 Q，12 个 Z 组数据集。CONST 是全局系数（实验 15 的预言机），LAT 加上真实的横向变化，TRUE 是完整真 t*，EST 加上试探 2 的估计值。自编的逐道反 Q 在全局系数下和 `lib12.iq` 的相对差为 1×10⁻¹⁴。

| 方法 | 平均 S | 气藏下方相关 | 气藏旁相关 |
|---|---|---|---|
| CONST | 0.889 | 0.791 | 0.910 |
| LAT | 0.893 | 0.803 | 0.920 |
| TRUE | 0.894 | 0.802 | 0.920 |
| EST | 0.870 | 0.799 | 0.900 |

相对 CONST：TRUE 的 S +0.005（11/12 为正），气藏下方 +0.011（10/12）。EST 的 S −0.019（0/12），气藏下方 +0.008（6/12）。构造 B 气藏最强，气藏下方也只从 0.668 到 0.686。

**结论：** 补偿的回报上限很小，估计值还会损害全局。气藏下方相关低，主要不是因为不知道 Q。这里只测了反 Q 和 S 指标，气藏下方的原因是推断（信号可能已低于噪声），没有单独验证。

## 合起来的判断

叠后、已知或近似已知 Q 的情况下，增益选择、全局 Q、横向 Q 的回报都只有约 0.005–0.03。所以在这批半合成数据和这个指标下，继续改进补偿算法本身空间很小。

## 文献（公开渠道，没有查 WoS 和 CNKI）

- 分叠加或奇偶数据选反 Q 参数、频率相关的半数据相关用于地震：没找到。FSC 半图相关在冷冻电镜是标准做法（如 [arXiv 2003.13828](https://arxiv.org/pdf/2003.13828)）。
- 横向变化 Q：Q 层析加 Q-PSDM 处理气烟囱已是工业常规（如 [ASEG 2010](https://publish.csiro.au/EX/ASEG2010ab075)、[西北陆架案例](https://www.searchanddiscovery.com/abstracts/html/2015/90217ice/abstracts/2209086.html)）。叠后有 LCFS 估空变 Q（[Applied Sciences 2025](https://doi.org/10.3390/app152111504)）。
