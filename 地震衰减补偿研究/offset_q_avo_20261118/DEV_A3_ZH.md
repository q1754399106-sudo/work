# 第三关设计前的开发：同样用校准后的 Q，补偿算子之间差多少？（2026-11-19）

只用已用过的 M24–M27（第二关的数据和 ĉ，种子 0–2，24/30 dB，拉平的孤立事件与薄层，40 个单元/方法）。脚本 `scripts/dev_a3.py`，结果 `results/dev_a3_M*.json`。限频反 Q 用 `bandlim.py`（我按 Ratnett 等 2019 思路的实现，信噪比规则 k = 3，k 是 11-06 在 M1 上挑的）。没有冻结、没有判定。

## 单元中位数（全部 c）

| 方法（都用模型 Q × ĉ，λ 用残差原则） | 有噪逐事件 G/A | 波形 | E_G |
|---|---|---|---|
| 真值 Q 的频率饱和阻尼（参考） | 0.014 | 0.292 | 0.176 |
| **频率饱和阻尼（第二关 cal）** | 0.092 | 0.331 | 0.314 |
| 一步 Tikhonov | 0.134 | 0.299 | 0.389 |
| 分步法 | **0.088** | 0.436 | 0.312 |
| 限频反 Q | 0.094 | **0.238** | **0.290** |
| 只按垂向 t* 的 Tikhonov（忽略炮检距多出的路径） | 1.036 | 1.341 | 2.215 |
| 不校准的频率饱和阻尼 | 0.536 | 0.854 | 1.620 |

配对比较（40 个单元，频率饱和阻尼对其他方法）：G/A 好于一步 Tikhonov 84%（比值中位数 0.67），好于分步 56%（0.99），好于限频反 Q 62%（0.98）；波形只有 16% 好于限频反 Q（比值 1.34）、31% 好于一步 Tikhonov。

按 c 看，G/A 上频率饱和阻尼、分步、限频反 Q 在每个 c 都相差 ≤ 0.02；c = 0.5、0.7 时一步 Tikhonov 明显差（0.57、0.26）。

## 结论

1. **校准之后，按路径补偿的方法之间几乎没差别。** 频率饱和阻尼在 AVO 上与分步、限频反 Q 打平（0.092、0.088、0.094），波形和 E_G 还不如限频反 Q。它在第 2b 步对分步的那点优势（无噪 G/A 0.006 对 0.014）在 ĉ 的估计误差（约 0.07）面前看不出来。**所以第三关要检验的“频率饱和阻尼这一环的贡献”回报上限约为零，不再做冻结检验。**
2. **AVO 结果主要由两件事决定：Q 的绝对水平准不准（校准），以及补偿是否沿炮检距路径。** 只按垂向 t* 补偿（时间域处理的常规做法）在所有 c 下 G/A 误差约 1，比完全不校准还差；不校准则在 0.4–1.8。
3. 对论文主张的含义：方法上的新意不能落在“频率饱和阻尼”上。能站住的是**机制和流程**：AVO 梯度误差约为 1 × σ_lnQ（`uq_avo_20261118/DEV_GATE2_ZH.md`）；叠前稳健（UQ）补偿在 AVO 上有代价（第一关）；未拉平道集的炮检距谱比能把 σ 降到约 0.09（远道等长窗是必要修正），再接任何沿路径的补偿，AVO 误差可降 85–90%；忽略炮检距路径的常规补偿会毁掉 AVO。估计器本身（QVO、PSQI）和限频反 Q（Ratnett 2019）都有先例。
