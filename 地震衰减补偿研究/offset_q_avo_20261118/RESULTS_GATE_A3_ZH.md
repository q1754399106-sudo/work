## 看到的事（事后，不是判定）

1. **打平是整体的，强衰减端略有分化。** 差值最大的单元都在 c = 0.5，而且都偏向频率饱和阻尼。M29 60 Hz events c0.5 30 dB 处，频率饱和阻尼 0.278，分步 0.481。频率饱和阻尼在 48% 的单元好于分步、71% 好于限频反 Q，但差值很小（四分位在 ±0.008 内）。这与第 2b 步无噪下频率饱和阻尼的优势方向一致，只在 Q 很低时露出来；没有为此设判定，不能写成结论。
2. **一步 Tikhonov 的劣势集中在 c ≤ 0.7**（0.51、0.23），c ≥ 1.4 时与其他打平。这与开发时一样，F4 的中位数比值由强衰减单元撑起来。
3. **波形仍是限频反 Q 最好、分步最差**，与开发一致。
