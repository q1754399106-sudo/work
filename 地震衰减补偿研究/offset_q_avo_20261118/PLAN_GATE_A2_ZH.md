# 方向 2 第二关：炮检距谱比校准后，端到端 AVO 误差降多少？（看结果前提交）

日期：2026-11-18。第一关（重跑，`3648a30`）通过：24 dB、50 个 CMP、有 AVO 时 ln(ĉ/c) 均方根 0.091。用户同意第二关做真正的端到端检验。

## 1. 问题

真值 Q = c × 模型 Q，c 未知（0.5–2）。用同一工区 50 个 CMP 的超道集估出 ĉ，把模型 Q 乘 ĉ 后做频率饱和阻尼补偿，逐事件 G/A 误差能否：(a) 比不校准的补偿降一半以上；(b) 接近用真值 Q 的结果；(c) 在模型 Q 本来就对时代价很小？

## 2. 设置

- **新模型，从未用过：** M24 Q = [42, 70, 55, 95]，M25 [75, 45, 30, 65]，M26 [35, 40, 85, 50]，M27 [95, 60, 45, 35]。c ∈ {0.5, 0.7, 1.0, 1.4, 2.0}（第一关只测过 0.7–1.4，两端也在这里检验）。
- **估 ĉ：** `oqa.py` 的冻结估计器（远道等长窗、不平滑），每个（模型、子波、c、信噪比、种子）一个 50 个 CMP 的超道集，稠密 Shuey-AVO 反射系数，种子基数 51 000 000。估计失败（NaN 或 ≤ 0）时退回模型 Q（ĉ = 1），计入结果。
- **AVO 道集：** 第 2b 步的生成器原样（`scripts/legacy2b/`，精确 Zoeppritz、孤立事件 / 薄层、NMO 场景带拉伸切除），真值 Q = c × 模型 Q；种子按第 2b 步规则（模型编号 24–27，新），10 个种子；不同 c 共用同一反射系数与噪声实现（配对）。
- **场景：** events_aligned、thin_aligned（判定），events_nmo（保护）。子波 60、40 Hz；信噪比 24、30 dB（两者的道集噪声与 ĉ 的超道集噪声同档）。
- **方法**（λ 都用第 2b 步的残差原则，σ 已知）：
  - oracle：频率饱和阻尼，真值 Q（上限）
  - uncal：频率饱和阻尼，模型 Q
  - tik_uncal：一步 Tikhonov，模型 Q（开发上 Q 不确定时它最好）
  - **cal：频率饱和阻尼，模型 Q × ĉ**
- **指标：** `step2b.metrics` 的有噪逐事件 G/A 误差（ga，带通 10 Hz 到子波主频）、波形误差（wave）。单元 =（模型、子波、场景、c、信噪比），取 10 个种子平均。
- 8 个进程（模型 × 子波），估计约 3 小时。

## 4. 判定（aligned 两个场景，160 个单元）

| 判定 | 内容 | 门槛 | 开发值 |
|---|---|---|---|
| **E1 校准有用** | 每组（模型、子波、场景、信噪比，32 组）对 5 个 c 平均：cal ≤ 0.5 × min(uncal, tik_uncal) 的组比例 | ≥ 90% | 3 个 c 平均 0.117 对 0.907，比值 0.13 |
| **E2 接近真值** | 单元 cal − oracle 的中位数 | ≤ 0.10 | +0.04 到 +0.16 |
| **E3 Q 本来对时的代价** | c = 1 单元 cal − uncal 的中位数 | ≤ 0.05 | +0.041 |
| **E4 波形保护** | c = 1 单元 cal − uncal 波形的中位数 | ≤ 0.02 | +0.008 |
| **E5 NMO 保护** | events_nmo、c ≠ 1 单元 cal ≤ uncal 的比例 | ≥ 80% | 未测 |

全过：方法候选成立（炮检距谱比校准＋频率饱和阻尼），下一步是实测或与先例（QVO/PSQI 接反 Q）比较的方案，另定。任一不过：停下来汇报。门槛是我定的经验值，E2、E3 的 0.10、0.05 是看过开发值后定的。

## 5. 只作描述

按 c 的四种方法 ga 与波形；每个 c 的 ln(ĉ/c) 与失败数（尤其 0.5、2.0）；按子波、场景、信噪比、模型分组；NMO 场景的四种方法。

## 6. 预期（可能是错的）

- E1 几乎必过：c 偏离 1 时不校准的误差是 1 左右。
- **E2 是主要风险**：c = 0.5（强衰减）时开发上差 0.16；ĉ 的 +0.02 剩余偏差加上离散，在强衰减时被放大。40 Hz 子波上 ĉ 更差。
- E3 在门槛附近（开发 +0.041）。
- E5 不确定：NMO 拉伸本身的 G/A 误差约 0.4，校准只修 Q 那部分。

## 7. 局限

超道集与 AVO 道集共享同一 Q 模型（无横向变化）；各层同比例的 Q 误差；ĉ 估计与 AVO 道集的噪声档相同但独立；浅模型、双曲时差；σ 已知的残差原则。没有与 QVO/PSQI 接常规反 Q 比较（新意在于“校准＋保 AVO 的频率饱和阻尼”的组合和 σ–AVO 灵敏度的论证，不在估计器本身）。

## 8. 运行

`python scripts/e2e.py run <M> <fp>`（M24–M27 × 60/40，8 个进程），`python scripts/verdict_a2.py` → `results/a2_verdict.json`。
