# 实测检验 I：Volve 平台旁炮检距谱比 Q 与 F-15A VSP Q 对比（2026-11-22，看实测谱之前提交）

## 1. 问题

炮检距谱比校准在合成数据上三关都已通过（A1b、A2EB、A3），但从未在实测上和独立的 Q 比较过。这里用 Volve 平台旁的叠前炮集估计 TVD 约 1000–2600 m 层段的层 Q，与 F-15A 零偏 VSP 在同一层段得到的 Q（`field_vsp_f15a_20261113/NOTE_ZH.md`）比较。

这是**描述性的一次实测对照**，只有一条线、一口井，不是方法确认。

## 2. 数据

- **地震：**ST0202R08 PZ 叠前炮集，第 79 序列、电缆 5081（`uq_rtm_20261117/DATA_VOLVE_PRESTACK_ZH.md`，本地 683 MB，不上传）。没有动校、没有 Q 补偿；做过去签名、零相位化、82 Hz 高切、PZ 合并、τ-p 反褶积和顶部切除（切除线 t ≈ −0.13 s + |x|/1216 m/s，`direction_theory_20261121/RESULTS_FIELDNOISE_ZH.md`）。
- 只读过道头（核对可行性）：平台 ±1 km 内约 3 万道，|x| ≤ 350 m 的近道 2169 道，500–4000 m 每档约 6000 道；检波点间距 25 m，水深 83–98 m。**没有计算过任何谱或谱比。**
- **速度：**VTI-2008 模型的垂向 Vp（阶段 4 已沿测线抽取，`cache/fld/vp.bin`），取 CMP ±1 km 的平均列。没有 δ，动校速度用垂向 Vp 近似。
- **对照：**F-15A VSP，2600 m 以上（TVD 1005–2600 m，单程 0.51–1.20 s）。1000/Q 随频带为 11.4 [5.6, 17.4]（10–60 Hz）到 16.4（30–100 Hz），即 Q 约 60–90。地震有效频带约 8–40 Hz，所以**主对照取 10–60 Hz 频带：1000/Q = 11.4，90% 区间 [5.6, 17.4]**。处理方的仅相位反 Q 用 Q = 120（1000/Q = 8.3），也落在这个区间内，所以本检验分不出 VSP 与处理方的 Q。

## 3. 估计器（`scripts/field79.py`）

- CMP 在平台 ±1000 m 内，按 250 m 分 8 块。
- 一维射线（垂向 Vp，震源 6 m、检波点在海底，两支同一射线参数）给出走时和各层内的走时。层 A：海底到双程 1.02 s（深 980 m）；层 B：双程 1.02–2.40 s（980–2550 m）；水层不衰减。
- 时窗：零炮检距记录时间的中心 0.6–2.4 s（步长 0.2 s），长 0.4 s。远道窗等长、以窗中心的射线走时为中心（冻结的 A1b 规则 EQLEN，不平滑谱）。近道参考：|x| ≤ 350 m；炮检距档 500–3900 m（±100 m）。远道窗起点须晚于切除线 0.1 s 以上，拉伸比 ≤ 1.3。
- 频带 8–60 Hz 内，两边功率都高于各自带内峰值的 2%，从 8 Hz 起连续，宽度 ≥ 10 Hz（实测没有噪声估计，见第 6 条）。
- y = −d/df [½ ln(P_x/P_ref)] = π(Δτ_A/Q_A + Δτ_B/Q_B)，Δτ_L 为远道射线比近道多在 L 层走的时间；最小二乘、无截距。
- **主量：**8 块合并的 1000/Q_B；90% 区间来自对 8 块的自助（2000 次，种子 79）。

**合成自检（实测运行前）：**同一观测系统、同一切除，稀疏反射系数、25 Hz Ricker、Q_A = 60、Q_B = 90、其下 100、24 dB 白噪声（`field79.py synth`）。要求 1000/Q_B 落在 11.1 ± 25%（8.3–13.9），区间覆盖 11.1。不通过只能修程序错误（此时还没看实测），修完重跑自检；改动在结果文件中说明。

## 4. 判定（主量，事先写定）

1. **不可判：**有层 B 时窗数据行的块少于 6 个，或 1000/Q_B 的 90% 区间宽度大于 20。
2. **一致：**点估计在 VSP 10–60 Hz 的 90% 区间 [5.6, 17.4] 内（Q 57–179）。
3. **不一致：**点估计高于 17.4（衰减比 VSP 强）或低于 5.6（弱，含负值）。

只描述：区间是否排除 11.4 或 8.3；层 A 的值；逐时窗的有效 Q（一层整体拟合，与 ST10010 线 10199 初看的 16、12、8.4 对照）；逐块值；速度 ×0.95、×1.05 的结果（`field79.py run 0.95 / 1.05`）。

## 5. 预测（运行前写下）

- 按 ST10010 线 10199 的初看（双程 0.9–2.0 s 的有效 1000/Q 为 16、12、8.4），预计 1000/Q_B 在 8–16 之间，判为“一致”。
- 如果 τ-p 反褶积按射线参数把谱拉平，远近道的谱差会被抹掉，1000/Q_B 会接近 0 或为负，判为“不一致（偏弱）”。这种情况说明的是这份数据的处理，不是估计器本身。
- 层 A 只能用到约 1.2 km 以内的炮检距（切除限制），预计区间很宽。

## 6. 已知局限

- 没有噪声估计（切除后不存在初至前的纯噪声段），频带只按功率相对峰值截取。
- τ-p 反褶积、PZ 合并、震源虚反射、层间多次波对谱比的影响无法评估。
- VTI 的 δ 未知，动校速度用垂向 Vp，可能偏低几个百分点（速度 ±5% 只描述）。
- 只有一条线、一口井；F-15A 是斜井，VSP 层段与测线的横向距离未核实。

## 7. 运行

```
python scripts/field79.py synth      # 自检，4 进程
python scripts/field79.py run        # 主运行
python scripts/field79.py run 0.95 ; python scripts/field79.py run 1.05
```

结果 `results/field79*.json`、日志 `logs/field79*.log`，结论写 `RESULTS_FIELD_I_ZH.md`。
