# 方向 2 第一关：有 AVO 时，炮检距谱比能否把 Q 定到 σ ≤ 0.1？（看结果前提交）

日期：2026-11-18。用户选了方向 2。动机来自 `uq_avo_20261118/DEV_GATE2_ZH.md`：叠前补偿的逐事件 AVO 梯度误差约为 (0.6–1.5)·σ_lnQ，算子设计压不住，只有缩小 Q 的不确定度才有用；要让 G/A 误差到 0.1 左右，需要 ln Q 的误差 ≲ 0.1。叠前道集里关于 Q 绝对水平的信息就在炮检距方向的谱衰减里。

## 1. 问题

在**有 Shuey AVO**、24 dB 的未拉平道集上，沿时距曲线取窗的炮检距谱比（`offset_anchor_20261111` 的 c_off），合并 N = 50 个 CMP 时，估计 c = Q_true/Q_model 的对数误差（含偏差）能否 ≤ 0.1？

先导试验没有 AVO（各炮检距反射系数相同），并有一个原因未查的 +0.05 到 +0.07 系统偏差。AVO 与频率无关，但窗内各反射层的梯度不同，会让远道的反射系数序列和近道不同，相当于给谱比加了随机扰动。这一关就是看这一点和那个偏差能不能吃掉 0.1 的预算。

## 2. 设置

- 估计器：`scripts/oqa.py`，c_off 的公式、取窗（0.35–1.2 s，0.25 s 窗、步长 0.1 s）、拉伸比 1.3 切除、自适应频带（功率 > 3 倍噪声，从低端连续）原样沿用；频带改为 12–90 Hz（原来 15–70 Hz 是为 45 Hz 子波设的）。
- **新模型，从未用过：** M16 Q = [45, 60, 35, 80]，M17 [90, 35, 55, 45]，M18 [32, 50, 90, 60]，M19 [65, 85, 30, 40]。几何同 `core.py`（0–1500 m，11 道）。
- 真值 Q = c × 模型 Q，c ∈ {0.7, 1.0, 1.4}（各层同比例，对应 UQ 先验的全局乘子）。
- 反射系数：30% 稀疏，A ~ N(0, 1)，B = −0.8A + 0.6ε（同第 2b 步 dense 场景的比例），r(t₀, x) = A + B sin²θ。
- Ricker 40、60 Hz；每道噪声按该道 rms 定（与第 2b 步、λ 实测一致）；200 个 CMP，8 个种子（基数 31 000 000），分成 N = 10、50、200 的组分别估计。
- 4 个进程（每个模型一个），估计约 1 小时。

## 3. 判定（M16–M19，24 dB，有 AVO，速度准确，N = 50；每格 4 组 × 8 种子 = 32 个估计，共 24 格、768 个）

| 判定 | 内容 | 门槛 |
|---|---|---|
| **A1 精度** | 全部估计的 ln(ĉ/c) 均方根（含偏差） | ≤ 0.10 |
| **A2 无系统失败** | 最差一格（模型 × c × 子波）的 \|ln(ĉ/c) 均值\| | ≤ 0.10 |
| **A3 可用率** | ĉ 为 NaN 或 ≤ 0 的比例 | ≤ 2% |

- **全过**：进入第二关（把 ĉ 接到频率饱和阻尼，端到端看逐事件 G/A，对照 σ 0.447 先验下的 Tikhonov 和真值 Q）。**任一不过**：停下来汇报。
- 门槛 0.10 来自开发试算的灵敏度（σ 0.1 对应 G/A 均方根 0.09–0.13），是我定的。

## 4. 只作描述

N = 10、200；30、18 dB；无 AVO（同种子）；速度 ±2%（取窗位置和预测额外路径都用错的速度）；按模型、c、子波分组；每次估计用到的窗数。

## 5. 开发信息（只在 M1 上，c = 1，2 个种子，已看过）

`results/dev_M1.json`，ln(ĉ/c) 的均值 / 标准差 / 均方根（2 个种子；N = 50 每格只有 8 个估计、N = 200 只有 2 个，很粗）：

| 情形 | N = 10，40 / 60 Hz | N = 50，40 / 60 Hz | N = 200，40 / 60 Hz |
|---|---|---|---|
| 有 AVO，24 dB | RMS 0.205 / 0.146 | **+0.048 / 0.102 / 0.112；+0.042 / 0.033 / 0.053** | 0.059 / 0.051 |
| 无 AVO，24 dB | 0.191 / 0.097 | 0.084 / 0.057 | 0.060 / 0.057 |
| 有 AVO，30 dB | 0.216 / 0.116 | 0.117（均值 +0.098）/ 0.038 | 0.106 / 0.036 |
| 有 AVO，18 dB | 0.224 / 0.160 | 0.120 / 0.083 | 0.069 / 0.070 |
| 速度 +2% / −2%（24 dB） | | 0.156、0.065 / 0.131、0.079 | |

读法：+0.04 到 +0.06 的系统偏差仍在；AVO 只让 N = 50 的离散略增（40 Hz 0.084 → 0.112）；40 Hz 子波明显比 60 Hz 差；N = 10 不够（0.15–0.2）。N = 50、24 dB 两种子波合并约 0.09，**A1 预计在门槛附近**。30 dB 时 40 Hz 偏差反而变大（+0.10），原因未查。门槛是在看过这些开发值之后定的，这里写明。

## 6. 预期（可能是错的）

- AVO 会让 N 小时的离散明显变大；N = 50 时我估计 RMS 0.05–0.12，A1 是主要失败点。
- 先导里的 +0.05 偏差大概率还在。若偏差 0.06、离散 0.06，RMS 约 0.085，刚好过。
- c = 0.7（衰减强）时高频更早落到噪声下，频带变窄，离散最大。
- 速度 ±2% 预计移动 ∓0.03（先导值）。

## 7. 局限

模型浅（到 1.2 s），双曲时差、无多次波、无各向异性；各层同比例的 Q 误差（分层独立的形状误差没有测）；200 个 CMP 共享同一 Q，没有横向变化；没有子波随炮检距变化（震源方向性、接收组合）。这些都会在实测上加误差。
