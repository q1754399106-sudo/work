# 待查新的工作
**名称**：叠前 Q 补偿中的 AVO 误差预算，以及基于未动校道集炮检距谱比的 Q 自校准

**要解决的问题**：叠前 Q 补偿常常是为了保 AVO 而做的。已有工作分成两头：改进补偿算子（分步法、限频反 Q、稳健补偿），或者改进 Q 估计（QVO、PSQI），两头各自评价。本文要回答的是：对 AVO 来说，瓶颈到底是补偿算子，还是 Q 的绝对水平。

**技术方案**：
1. **闭式 AVO 增益**：在局部平稳假设下，写出 Tikhonov 型（以及其他正则型）叠前补偿对每个炮检距的振幅增益 Γ(x)，由此预测补偿造成的假 AVO 梯度，没有拟合参数（数值验证斜率 0.97–1.03，R² ≥ 0.977）。
2. **一阶灵敏度**：由 Γ 推出 G/A（梯度/截距）对 Q 绝对水平误差的灵敏度 ΔG/A ≈ −π·f_eff·κ·[1 + (B/A)β − (B/A)²α]·(u − 1)，含反射层自身 B/A 的因子；结论是逐事件 AVO 梯度误差约为 k·σ_lnQ（k 为 0.4–1.9），σ 超过约 0.2–0.45 时，最朴素的 Tikhonov 已经与最好的算子设计一样好。
3. **稳健补偿的代价**：对 Q 不确定度取期望的叠前补偿算子，因为远道 t* 的绝对不确定度与路径长度成正比，会自己造出负的假 AVO 梯度（24–30 dB 时 0.21–0.29）。
4. **炮检距谱比自校准**：在未做 NMO 的 CMP 道集上沿时距曲线取窗，用炮检距方向的谱比估计 Q 的绝对水平。**远道窗必须与近道等长**，否则远道窗受时差压缩、谱被抹平，产生随子波频带变窄而增大的偏差（40 Hz 子波 +0.08，30 Hz +0.35）。修正后在有 AVO、24 dB、50 个 CMP 时，ln Q 误差均方根 0.091。
5. **端到端**：校准后再做沿炮检距路径的补偿，AVO 误差从 0.4–1.8 降到 0.06–0.18（降 85–90%）；校准之后，频率饱和阻尼、分步法、限频反 Q 在 AVO 上基本打平；只按垂向 t* 补偿（常规时间域做法）的 G/A 误差约为 1，比不校准还差。
6. **频率饱和阻尼**（次要，可能不新）：正则算子 L 由炮检距路径的吸收构造，在噪声上界决定的频率 f_n 以下使各炮检距的响应相同；一步求解，不做高切。

**我认为的创新点**（请逐条判断）：
1. 叠前 Q 补偿后假 AVO 梯度的闭式预测公式（无拟合参数），以及 G/A 对 Q 绝对水平的一阶灵敏度。
2. "AVO 梯度误差 ≈ k·σ_lnQ，瓶颈在 Q 的绝对水平而不在补偿算子"这一定量结论。
3. 对 Q 不确定度取期望的稳健叠前补偿会自造负的假 AVO 梯度。
4. 未动校道集的炮检距谱比必须用等长窗，以及远道窗时差压缩造成偏差的机理。
5. "先用炮检距谱比校准 Q，再沿路径补偿"的流程，以及"只按垂向 t* 补偿会毁掉 AVO"的结论。
6. 频率饱和阻尼算子（我已判断很可能不新，请确认）。

# 重点要回答的问题
1. 有没有人**定量**给出 Q 误差（或 Q 补偿正则）造成的 AVO 梯度误差，特别是闭式公式或"梯度误差 ∝ σ_lnQ"这样的误差预算？还是只有定性展示？
2. 有没有人比较过"改进补偿算子"和"改进 Q 精度"对 AVO 的相对作用？
3. 有没有人指出稳健或保守的叠前补偿本身会引入假 AVO 梯度？
4. QVO、PSQI 和其他基于 CMP 道集的 Q 估计中，有没有讨论过分析窗长、远道窗的时差压缩、NMO 拉伸对谱比偏差的影响？等长窗是否已经是标准做法？
5. "只按垂向 t* 做叠前补偿会破坏 AVO、必须沿炮检距射线路径补偿"这一点是否已是共识？最早出处在哪？
6. 频率饱和阻尼与 Ratnett 2019、Li 2015、Du 2022、谱整形正则在数学上有什么区别？是否只是已有形式的改写？
7. 中文文献（"叠前 Q 补偿 AVO""保幅 Q 补偿""炮检距 吸收补偿""叠前 Q 估计 CMP 道集"）和中石油、中石化相关专利中有没有类似工作？
