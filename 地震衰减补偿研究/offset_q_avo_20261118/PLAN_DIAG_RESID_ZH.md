# 诊断方案：等长窗下剩余正偏差的来源（2026-11-21，运行前提交）

**性质：**开发诊断，只用已用过的 M1（无噪声、无 AVO、c = 1），不判定方法，不动冻结的估计器。

## 1. 问题

`DIAG_A1_ZH.md`：改成远道等长窗、不平滑后，无噪声 M1 上 ln(ĉ/c) 仍为 +0.052（30 Hz 子波）、+0.011（40 Hz）、0.000（60 Hz）；有噪声时剩约 +0.02，原因未查。外部文档（2026-11-20）把它归因于“窗内多个事件的相对时差被双曲时差压缩 t₀/t_x，改变了多事件干涉谱”，并提出短滞后自相关截断谱比。

本仓库的看法：反射系数在 200 个 CMP 上独立、零均值（`oqa.reflectivity`），事件间交叉项 2 r_j r_k cos(2πfΔt) 的期望为 0，压缩只改变窗内事件个数（常数因子），不改变谱斜率。所以预计压缩不是原因。

## 2. 变体（`scripts/diag_resid.py`）

全部用冻结的估计器设置（远道等长窗、不平滑；`oqa.c_off` 的同一套窗、炮检距、切除、频带 12–90 Hz、合并回归 ĉ = Σx²/Σxy），σ = 0（无噪声）。子波 30、40、60 Hz；M1；c = 1；种子 777–780（与 `diag_bias.py` 相同）；200 个 CMP。逐窗、逐炮检距单独合成道，每次只改一处：

| 变体 | 远道合成 | 衰减 | x |
|---|---|---|---|
| V0 | 原样（`oqa.gathers`） | 原样 | 原样（Hann² 加权 a_x） |
| V1 无压缩 | 窗内所有事件整体平移 Δ = t_x(t_c) − t_c，相对时差不变 | 每个事件的总衰减与 V0 相同 | 同 V0 |
| V3 无窗内衰减变化 | 同 V0（有压缩） | 近道 a₀(t_c)、远道 a₀(t_c) + a_x(t_c) 全窗为常数 | π a_x(t_c) |
| V2 单事件 | 每窗只有 t_c 附近一个采样点的事件（逐 CMP 标准正态幅值），按时差放到远道 | 常数，同 V3 | π a_x(t_c) |
| V2n 单事件无频散 | 同 V2 | 同 V2，但衰减只取振幅、去掉频散相位 | 同 V2 |
| V0b 频带截断（只描述） | 同 V0 | 同 V0 | 同 V0；拟合频带限在近、远两谱都高于各自峰值 −40 dB 的连续段 |

## 3. 事先写下的预测与判读

偏差 b = 4 个种子 ln ĉ 的平均（c = 1）。主判在 30 Hz（偏差最大）；40 Hz 只描述，60 Hz 作零点检查。

- “无影响”：|b_V − b_V0| ≤ 0.015；“解释了大部分”：|b_V| ≤ |b_V0|/3；其余写“部分”。
- **预测 1（压缩假说不成立）：**V1 对 V0 无影响。若 V1 解释了大部分，则外部文档的压缩假说成立，本仓库的看法错误，照实写。
- **预测 2：**V3 对 V0 无影响（窗内衰减变化不是原因；与 `DIAG_A1` 中 xw 无效一致）。
- **预测 3：**V2 对 V0 无影响，即偏差在单个事件上就存在，来自单事件的谱估计（窗函数对衰减后变长、变形的子波的截取），而不是事件之间的关系。
- **预测 4：**V2n 相对 V2 解释了大部分。即主要来自频散相位：衰减后的子波相对等长窗中心的延迟与变形，远道比近道多。
- **描述：**V0b 是否减小偏差（看高频端功率很低的频点是否主导斜率）。
- 若预测 3 成立而预测 4 不成立，原因只缩小到“单事件谱估计”，不再细分，照实写。

## 4. 对外部文档建议的含义（事先写下）

- 预测 1 成立：短滞后自相关截断谱比的动机不成立，不进入开发。另外，28 ms 滞后窗等于约 36 Hz 的频域平滑，超过 12–90 Hz 拟合段的一半宽度，本身会改变谱斜率。
- 预测 1 不成立：该方法可以进入开发，但须先在 M1 上量化 28 ms 滞后窗本身带来的斜率偏差。
