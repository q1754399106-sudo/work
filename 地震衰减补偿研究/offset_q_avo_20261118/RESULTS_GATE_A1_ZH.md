# 方向 2 第一关结果：炮检距谱比定 Q，有 AVO、24 dB、50 个 CMP

日期：2026-11-18。方案在运行前提交（`f8bb252`，`PLAN_GATE_A1_ZH.md`）。数字来自 `results/a1_verdict.json`。4 个进程，各约 20 分钟。

## 结论

**按预设规则不通过（A1、A2 不过，A3 过），停下来汇报。**

| 判定 | 内容 | 结果 | 门槛 | |
|---|---|---|---|---|
| A1 | ln(ĉ/c) 均方根，768 个估计 | 0.109（均值 +0.039，标准差 0.102） | ≤ 0.10 | **不过** |
| A2 | 最差格 \|均值\| | 0.161（M18，c 0.7，40 Hz） | ≤ 0.10 | **不过** |
| A3 | 失败比例 | 0 | ≤ 2% | 过 |

**失败几乎全来自 40 Hz 子波的系统偏差：**

| N = 50，24 dB | 均值 | 标准差 | 均方根 |
|---|---|---|---|
| 60 Hz | −0.002 | 0.082 | **0.082** |
| 40 Hz | +0.079 | 0.105 | 0.131 |

40 Hz 的 +0.08 偏差在所有情形下几乎不变：30 dB +0.081，18 dB +0.084，无 AVO +0.080，N = 200 +0.083。所以它是估计器本身的偏差，与噪声、AVO、样本数无关。60 Hz 基本无偏。先导试验（45 Hz）里原因未查的 +0.05 到 +0.07 很可能是同一个东西。M18（浅层 Q = 32）上最大（40 Hz：+0.12 到 +0.16）。

## 其他（只作描述）

- **AVO 几乎没有影响**：无 AVO 时 0.102，有 AVO 时 0.109。这一点比我预期的好。
- **样本数**：N = 10 时 0.21（不够）；N = 200 时 0.081（60 Hz 0.052，40 Hz 0.103）。
- **信噪比**：30 dB 0.100，18 dB 0.134。
- **速度 ±2%**：+2% 为 0.114，−2% 为 0.120，影响小。
- **分 c**：0.7 为 0.106，1.0 为 0.095，1.4 为 0.125。
- 每次估计用到的窗数中位数 36。

## 开跑前预期对照

- “A1 是主要失败点，N = 50 时 0.05–0.12”：对，0.109。
- “+0.05 偏差大概率还在”：对，但它只在 40 Hz 上，约 +0.08；60 Hz 上没有。
- “c = 0.7 离散最大”：错，c = 1.4 最大（0.125）。
- “AVO 会让离散明显变大”：错，几乎不变。

## 读法

- 去掉 40 Hz 的系统偏差后，标准差只有 0.08–0.10，**问题集中在一个有确定来源的偏差上，而不是噪声或 AVO**。偏差的原因没有查。候选：沿时距曲线取窗时远道窗被压缩（窗长不同、谱泄漏不同），子波频带越窄、低频端越受影响；自适应频带从 12 Hz 起，40 Hz 子波的低频端占比更大。
- 换算成 AVO：σ_eff 0.08–0.13 对应逐事件 G/A 误差约 0.07–0.2。σ 0.447 先验下是 0.5–0.7，所以即使不修正，也能把 AVO 误差压到三分之一到七分之一。但这是推算，不是本关的检验内容。
- 门槛 0.10 是看过开发值后定的；没过就是没过，不追加放宽。
