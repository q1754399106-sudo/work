# 实测检验 I 补充 1：合成自检未过，主量改为单一有效 Q（2026-11-22，仍未看任何实测谱）

## 1. 第一次自检（`PLAN_FIELD_I_ZH.md` 第 3 节，种子 500 000）：不通过

`results/field79_synth_s500000*.json`，`logs/field79_synth_s500000*.log`。

| | 1000/Q_A（真 16.7） | 1000/Q_B（真 11.1） | Q_B 的 90% 区间 |

| 24 dB | 9.7 | **18.0** | [12.0, 23.6] |

判据 8.3–13.9 不满足。诊断（同一批合成数据）：
1. **定义错误：**时窗中心是记录时间，比垂向双程时间约短 0.06 s，所以 2.4 s 时窗的反射点已经越过层 B 底界（2550 m），含层 C。即使用真值 y 回归，两层拆分也只给出 15.4 / 12.6。
2. **两层拆分定不住：**切除使层 A 只有 0.8、1.0 s 两个时窗（40 行，最大炮检距 0.7–0.9 km）。无噪声时各时窗的实测斜率相对真值也有 0.79–1.22 的波动（来自窗内多事件干涉，与 `DIAG_RESID_ZH.md` 同一机制），两层回归把它放大成 Q_B 的 +35–50% 偏差。
3. **单一有效 Q 是稳的：**对整段沉积层只拟合一个 1/Q（回归量为远道在沉积层中多走的时间），24 dB 时为真值加权结果的 0.95 倍，无噪声时 0.93 倍；逐块 ±30%。

这不是可以在两层框架内修掉的程序错误，所以按原方案两层主量作废，不在实测上作判定。

## 2. 改动（实测运行前）

- 时窗中心改为 0.6–2.2 s（去掉 2.4 s）。
- **主量改为单一有效 1000/Q_eff：**8 块合并，回归 y = π Δτ_sed / Q_eff，90% 区间来自同样的 8 块自助（2000 次，种子 79）。这也正是校准方法本身的形式：一个整体因子。两层值只描述。
- **第二次自检（新种子 600 000，其余不变）：**真值取同一批行用真值 y 做同样回归的结果（按路径加权的 1/Q）。通过条件：估计与真值之比在 [0.85, 1.15] 内，且 90% 区间覆盖真值。不通过就停下，不在实测上运行主量。

## 3. 对照与判定（替换原方案第 4 节）

- 实测的 Q_eff 是海底（89 m）到时窗深度的路径平均，包括 VSP 没有给出 Q 的 89–980 m 段；合成中这一段约占权重的一半。只有在浅层 Q 与 980–2550 m 段相近时，它才和 VSP 的层 Q 可比。这一点在结论中必须写明。
- 判定规则同原方案，只把 Q_B 换成 Q_eff：90% 区间宽于 20 → 不可判；点估计在 [5.6, 17.4] 内 → 一致；在区间外 → 不一致（偏强 / 偏弱）。
- 预测不变：预计 8–16；若 τ-p 反褶积抹平了远近道的谱差，会接近 0 或为负。
