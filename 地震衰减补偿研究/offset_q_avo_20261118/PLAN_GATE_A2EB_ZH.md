# 第二关重做：经验贝叶斯收缩校准 ĉ_EB（2026-11-21，看结果前提交）

## 1. 问题

第二关（`RESULTS_GATE_A2_ZH.md`）E3、E4 不过：模型 Q 本来就对（c = 1）时，硬代入 ĉ 使 G/A 误差 +0.062（门槛 0.05）、波形 +0.027（门槛 0.02）。原因是 ĉ 的离散（c = 1 时 ln 误差标准差 0.068），而 G/A 对 Q 误差很敏感。

改动：用超道集自身的刀切标准误把 û = 1/ĉ 向 1（模型 Q）收缩：

û_EB = 1 + max(0, 1 − γ ŝ²/(û − 1)²)(û − 1)，ĉ_EB = 1/û_EB，**γ = 1 事先固定，不调**。

ŝ：50 个 CMP 分 10 组（每组 5 个），逐组删除重算 û_k，ŝ² = (9/10) Σ(û_k − ū)²。估计器其余部分为冻结的 A1b 版本（远道等长窗、不平滑）。

注意：标量收缩没有 James–Stein 的占优性质，是一种预检验估计量；c 稍偏离 1（0.85、1.2）时可能比硬代入更差，所以本方案加这两档专门检查代价。

## 2. 第 0 步：标准误是否可信（只用用过的 M24–M27，只估 ĉ，不做补偿）

- c ∈ {0.85, 1.0, 1.2}，子波 60、40 Hz，24、30 dB，10 个种子，种子规则同 `e2e.c_hat`（种子基数 51 000 000，c 0.85、1.2 是新种子）。
- z = (û − 1/c)/ŝ。**通过：**z 的标准差在 [0.7, 1.5] 内，且 |z 的均值| ≤ 0.5。
- 不通过就停下报告，不改 γ、不改分组。

## 3. 第 1 步：新模型上的端到端确认

- **新模型（从未用过）：**M32 Q = [55, 38, 80, 45]，M33 [85, 50, 65, 32]，M34 [40, 90, 48, 70]，M35 [65, 35, 100, 55]。
- c ∈ {0.5, 0.7, 0.85, 1.0, 1.2, 1.4, 2.0}；子波 60、40 Hz；24、30 dB；6 个种子（与第三关相同）；场景 events_aligned、thin_aligned（判定）、events_nmo（保护）。ĉ 的种子基数 52 000 000；道集生成、λ 选择、指标与 `e2e.py` 完全相同。
- 方法：oracle、uncal、tik_uncal、cal（硬代入 ĉ）、**cal_eb（代入 ĉ_EB）**。估计失败时两者都退回 ĉ = 1。
- **判定（对 cal_eb；E1–E5 门槛与第二关相同，均只用原来的 5 个 c）：**
  - E1：每组对 5 个 c 平均，cal_eb ≤ 0.5 × min(uncal, tik_uncal) 的组比例 ≥ 90%
  - E2：单元 cal_eb − oracle 的中位数 ≤ 0.10
  - E3：c = 1 单元 cal_eb − uncal（G/A）的中位数 ≤ 0.05
  - E4：c = 1 单元 cal_eb − uncal（波形）的中位数 ≤ 0.02
  - E5：events_nmo、c ≠ 1 单元 cal_eb ≤ uncal 的比例 ≥ 80%
  - **E6（新，收缩代价）：**c ∈ {0.85, 1.2} 的单元，cal_eb − cal（G/A）的中位数 ≤ 0.03
- 全过：收缩校准替代硬代入，第二关判为通过（第二次尝试，在新模型上）。任一不过：照实报告，不改 γ。
- 只描述：各 c 的五种方法 G/A 与波形；收缩因子的分布；cal 在新模型上是否重现第二关的 E3/E4 失败。
