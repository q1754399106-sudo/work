# 方向 2 第二关结果：炮检距谱比校准后的端到端 AVO

日期：2026-11-19。方案在运行前提交（`d9561ac`，`PLAN_GATE_A2_ZH.md`）。数字来自 `results/a2_verdict.json`。8 个进程，约 4.4–4.9 小时（中途按用户要求挂起过一次，进度未丢）。

## 结论

**按预设规则不通过：E1、E2、E5 过，E3、E4 不过，停下来汇报。** 不过的两条都是“模型 Q 本来就对时，校准带来的代价”，超出门槛不多；方法的主要作用（Q 不准时把 AVO 误差压下来）三条都通过，而且幅度很大。

ĉ 没有一次失败；c = 0.5 和 2.0（第一关没测过）也估得住（均方根 0.096、0.125）。

- **Q 不准时：** 不校准的 AVO 误差 0.4–1.8，校准后 0.06–0.18，降 85–90%；波形也大幅改善（c = 2 时 2.91 → 0.24，不校准会过补偿放大噪声）。
- **Q 本来就对时：** 校准把 G/A 误差从 0.014 升到 0.080，波形从 0.300 升到 0.330。代价来自 ĉ 的估计噪声（c = 1 时均方根 0.069）。按灵敏度约 1 推算，这是估计精度决定的下限，不是实现错误。它正好等于用对了 Q 的一步 Tikhonov（0.080）。
- **分组：** 60 Hz 0.096、40 Hz 0.081；孤立事件 0.091、薄层 0.082；24 dB 0.089、30 dB 0.084；模型 0.074–0.113。
- **NMO（events_nmo）：** oracle 0.503、uncal 0.551、tik_uncal 0.600、cal 0.506。校准把 Q 那部分修到与真值 Q 相同，但拉伸带来的约 0.5 误差远大于 Q 的影响，**NMO 道集上做 AVO 的主要问题不是 Q**。

## 开跑前预期对照

- E1 几乎必过：对。
- E2 是主要风险：错，+0.070 过了；c = 0.5 时差 0.135，仍是最差的一档。
- E3 在门槛附近：不过（0.062 对 0.05）。开发上的 +0.041 只有 3 个种子。
- E5 不确定：过，但只是因为不校准的误差略大，拉伸主导了一切。

## 读法

- 作为方法：**Q 只知道在 2 倍以内时**，按 5 个 c 平均，校准后的 AVO 误差约 0.10，不校准约 0.67（频率饱和阻尼）或 0.69（Tikhonov），接近真值 Q（0.019）的程度在 +0.07 以内。
- 代价：模型 Q 已经准时会变差约 0.06。是否值得，取决于对模型 Q 的把握；ĉ 的离散随 CMP 数下降（第一关 N = 200 时 0.051），超道集更大时代价会按比例减小，这里没有检验。
- E3、E4 的门槛 0.05、0.02 是看过开发值（3 个种子）后定的，不过就是不过，不放宽。
- 局限同方案：Q 无横向变化、各层同比例误差、浅模型、σ 已知的残差原则、未与 QVO/PSQI 接常规反 Q 比较、没有实测。
