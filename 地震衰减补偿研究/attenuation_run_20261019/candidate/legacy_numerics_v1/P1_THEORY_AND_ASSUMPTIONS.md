# P1 fixed-pilot implementation

This is a candidate, not a validated replacement for Frozen. All settings are frozen before held-out execution. `p1_prepare_calibration` accepts only the original public whitelist and an independent observed calibration gather. It estimates the same effective Q and nominally constrained frequency as Frozen. It then fits six nuisance event coefficients per calibration trace and refits Q and frequency jointly on fitted calibration templates plus circular moving blocks from the actual prescribed noise window. The paired Q/frequency draws, boundaries and optimizer exits are retained. This conditional template bootstrap captures noise-induced calibration variability under that template model; it cannot establish coverage or represent arbitrary systematic source/geometry error. Its draw range is not a confidence interval.

The observation prior is the original observed-only conservative pilot and the AVO-protected H in the Offset domain; Section data receive no AVO projection. The pilot is fixed. For each paired calibration draw, the full nonstationary operator supplies `e_k=(G(Q_k)-Gref)*sp`. The mean is `b=mean(e_k)` and the centered sample covariance is shrunk as `(1-rho)*U*U' + rho*diag(diag(U*U'))`, where `U=(e-b)/sqrt(R-1)`. The low-rank term retains cross-trace dependence from a common Q draw. Source frequency affects joint calibration, hence marginal Q uncertainty; it is not inserted into an attenuation operator whose unknown is already the bandlimited waveform s. Template-shape and phase failures must be tested separately.

With `d=Gref*s+e+n`, the centered data are **d-b**, so the residual is `Gref*s-d+b`. Noise and model error are treated as independent conditional on the fixed observed pilot/calibration estimate. That independence and the conditional pilot approximation are assumptions; no claim of exact Bayesian marginalization is made. The covariance and H do not depend on the optimization variable, so the covariance log determinant is constant in this quadratic solve. No omitted variable-dependent determinant is hidden in an iteration.

The point noise estimate is the prescribed-window Gaussian MAD. Noise uncertainty uses a predeclared upper empirical quantile of the joint noise-window circular block-bootstrap MAD squared, clamped below by the point estimate. This is a conservative covariance plug-in, not a posterior or a confidence limit. Default temporal covariance is white. `NoiseCovarianceOnly` uses the point MAD and a clipped, window-estimated AR(1) Toeplitz covariance; it deliberately tests that separate covariance mechanism. A selected AR(1) model is a low-order approximation, and coherent interference is not reclassified as zero-mean Q error.

The objective is `(G*s-(d-b))' Ceff^{-1}(G*s-(d-b)) + scale*(sum_j lambda_j/sigma_ref_j^2*||s_j||^2 + gamma*median(lambda_j/sigma_ref_j^2)*||H*s||^2)`. Lambda, sigma_ref, pilot and H are fixed from the same observed gather. All candidates and both routes use the same ridge reference units and scalar grid. The Direct route selects the scalar with a discrepancy target `sqrt(tr(P*Cphysical))`. Direct has target `sqrt(N)` except any recorded numerical jitter. All normal-equation residuals are measured against the full actual operator, including its low-rank cross-trace term. PCG failures, endpoint choices, every searched scale and target mismatch remain visible.

The Split first-stage map M is the existing offset-only ridge map, with fixed lambda_x. Its **full** forward operator is `M*Gref`, its data are `M*(d-b)`, and its covariance is `M*Ceff*M' + floor`. The floor is `cov_floor*sigma_ref_j^2*I` per trace in physical variance units. The target removes the artificial floor contribution: `tr(Ps*M*Ceff*M') = N - tr(Ps*floor)`. Woodbury precision and this target are evaluated without a full gather-sized covariance. With an invertible M and zero floor, Direct and Split are the same quadratic problem, which is explicitly tested. This candidate route is an exact propagated-G control, and is different from the inherited approximate `K*(X*A)` Split. The reference Frozen comparison keeps the inherited route. Numerical near equivalence is not evidence that Split is superior.

Branches:

- `NoiseUncertaintyOnly`: upper-quantile noise variance; no model-error mean or covariance.
- `QModelErrorOnly`: point noise variance plus the model-error mean and shrunk covariance.
- `CombinedUncertainty`: upper-quantile noise variance plus model-error mean and covariance.
- `ScalarBudgetDamping`: ordinary stronger damping with no model-error mean correction; uses `alpha*Cn_reference`, where alpha matches the Combined covariance trace. This tests whether ordinary additional damping can explain the candidate gain. Because it also omits mean correction, it is not a pure covariance-shape ablation.
- `NoiseCovarianceOnly`: point MAD and window-estimated AR(1), no model-error term.
- `NoStructureCombined`: same Combined model/noise terms, same conservative pilot, H set to zero.

`out.calibration_cache` is reusable only for exactly the same public input, calibration data, bootstrap settings and an offset subset already present in that cache. It stores reference models and Q-draw operators so calibration refitting and operator construction need not repeat for scenes, observation noise or branches. The cache includes no geological truth. It is large and should normally be retained once per calibration realization rather than repeated in every saved result.

`p1_selftest` checks Woodbury precision against a dense covariance, the fixed-mean sign and quadratic solution against a dense normal solve, exact Direct/Split equivalence, the physical floor-adjusted discrepancy target, deterministic bootstrap, and global RNG preservation. It is a mathematical test, not new-geology evidence. The geological experiment must still preserve separate development/held-out families, independent calibration and observation seeds, all stress suites, failures, local scores, matched Direct controls, and source/config hashes.
