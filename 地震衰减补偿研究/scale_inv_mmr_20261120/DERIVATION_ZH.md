# 尺度不变（自由增益）反 Q 算子：良定性与推导（2026-11-20，开发运行前写）

## 0. 符号与前提核对

沿用 `qunknown_comp_20261109`（UQ-W、MMR、CBL）的记号。输出行 t（每个输出时刻一行滤波器）、频率 f、情景 j（衰减剖面 x_j(t) = x̂(t) + Δx̂(t)(u_j − 1)）：

- 传播 G_j(t, f) = exp[(−πf + ik) x_j(t)]，k = 2f ln(f/f_ref)；
- 噪声项 ρ_j = s + |G_j|²/snr(t, f)，s 为 70 dB 保底；
- 逐点损失 l_j(H) = |H G_j − 1|² + ρ_j |H|²（UQ-W、MMR、CBL 共用，γ = 0）。

**前提核对（第 0 步）：**

1. "UQ-W、MMR、CBL 都基于逐频可分的平方损失"——成立。`mmr.py` 的推导和 `PLAN_MMR_ZH.md` 的命题已证明：可分平方损失下，任何先验混合或极小极大设计都落在同一个贝叶斯形式 H = Σπ_j G_j* / Σπ_j(|G_j|² + ρ_j)，三者只差先验 π。
2. "评价指标 S、T2 只看归一化相关"——成立，但要说清楚范围：
   - S = ½(M1 + M1_lag)（`lib15.score`、`specslope_q_volve_20261028/scripts/run.py:m1`）：在 2.30–2.80 s 窗内逐道算零延迟相关（M1），以及全剖面共用一个 ±20 ms 平移后的相关（M1_lag），各取道中位数。
   - T2（`uqw_improve_20261113/scripts/probe.py:t2`）：输出道与"真反射系数 * Ricker(f_peak)"在 2.3–2.8 s、±20 ms 内的最大相关，每 5 道取一道平均。
   - 两者都对整个评分窗的整体缩放不变；对窗内缓变的增益近似不变。参考子波不同：S 用 ideal（与数据同一子波），T2 用 Ricker(f_peak)。
   - FD 数据的 S（`fdcheck.score_fd`）同样定义，窗 1.0–1.75 s。FD 没有反射系数道，**不算 T2**；FD 的 M1_lag 只作描述。
3. "目标失配"（`RESULTS_MMR_ZH.md` 第 111 行"平方损失与基于相关的 S 不一致"）——是原文记载的局限，属实。
4. "已有人做过"：仓库内没有尺度不变损失的反 Q 设计；`PLAN_MMR_ZH.md`"推论 2"把"每个时窗一个自由增益"列为下一步但未做。文献查新按用户 11-20 起的要求暂缓，本文件不作新颖性主张。

## 1. 原式不良定

用户原式（每个时窗 t）：

  min_H max_π Σ_j π_j min_{α_j>0} ∫ S0² ( |α_j H G_j − 1|² + ρ_j |H|² ) df。

记 w = S0²，E0 = ∫w，q_j(H) = Re∫w H G_j，D_j(H) = ∫w |H G_j|²，N_j(H) = ∫w ρ_j |H|²。对 α_j 求极小：

  min_α = E0 − q_j₊²/D_j + N_j(H)（q_j ≤ 0 时 α = 0，值为 E0 + N_j）。

前两项对 H 的缩放不变，N_j(εH) = ε² N_j(H)。所以沿 H → εH（α_j → α_j/ε），目标单调下降到 E0 − q_j₊²/D_j，**噪声项完全消失**：

- 下确界取不到（ε → 0 时 α → ∞；H = 0 本身给出 E0，反而最差）；
- 极限问题是"无噪声的相关最大化"，单情景时它的解是 H ∝ 1/G（不加稳定的纯反 Q），无界增益。

数值核对（`scripts/smoke.py` 第 4 项，ZA_c0.75_r0 的 64 行）：原式在 ε = 1、0.1、0.01、10⁻⁴ 处单调下降，见 `logs/smoke.log`。

## 2. 良定的候选形式

| 编号 | 形式 | 单情景最优 | 与指标的关系 | 结论 |
|---|---|---|---|---|
| **A** | ρ 项也乘 α_j²：∫w(\|α_j H G_j − 1\|² + ρ_j \|α_j H\|²)，即对等效算子 α_j H 计损失 | Wiener（差一个行增益） | min_α = E0·(1 − ρ̂_j²)，ρ̂_j 是输出与目标 R * W_out 的零延迟相关（期望之比近似、白反射系数、窗内平稳）——**正对 M1** | **采用** |
| B | 固定 ‖H‖_w = c（或某频点 H(f₀) = 1），ρ 项不缩放 | 依赖 c；c → 0 退化为无噪声纯反 Q | 数据项是相关，噪声项不是；c 是新的任意参数 | 不采用 |
| C | 直接最大化带惩罚的余弦：max_H Re∫wHG / √(∫w\|HG\|² + ∫wρ\|H\|²) | Wiener | 与 A **等价**（A 的内层极小值 = E0(1 − C²)）；若惩罚写成 −λ‖H‖² 加在余弦外面，则又引入任意 λ 且不缩放 | 并入 A |
| D | A 再加每情景一个时移：α_j e^{−i2πfτ_j}，对 τ_j 也取极小 | Wiener | 对应 M1_lag 与 T2 的 ±20 ms 平移 | 不采用：对 τ 的内层是非凹的一维搜索；而且情景间频散相位的线性部分会被 τ 吸收，算子将不再校正时移，这部分正是 M1（零延迟）要求的 |
| E | A 但 α_j 取复数 | Wiener | 允许整体常相位旋转（Hilbert 混合），实信号的相关不允许 | 不采用 |

**选 A。**理由：它是唯一既不引入新参数、又与 S 的零延迟部分（M1）一一对应的形式；单情景时退化为 Wiener，所以 Q 准确且无不确定度时与 W0 只差一个行增益（相关不变）。它只部分对应 M1_lag 和 T2（不含平移自由度；T2 的参考子波是 Ricker 而非 W_out）。

w 的取法：w = |W_out(f)|²，W_out 是数据估计的输出子波（半合成用 `sc11.prepare_sc(D)["wv"]["w_out"]`，即 VDB 的目标子波；FD 用已知震源 Ricker(f_peak)，与 VDB 相同）。反射系数取白谱。w 只依赖数据，不用真值。

## 3. 内层闭式与 Rayleigh 商形式

对 A，记 b_j = w ⊙ G_j*，A_j = diag(w(|G_j|² + ρ_j))（在频率上对角），q_j = Re(b_j^H h)，P_j = h^H A_j h：

  α_j* = q_j₊ / P_j，  min_α L_j = E0 − q_j₊² / P_j。

- 单情景：max_h (Re b^H h)²/(h^H A h) 是秩一分子的广义 Rayleigh 商，最大值 b^H A⁻¹ b，在 h ∝ A⁻¹b = G*/(|G|² + ρ) 处取得，正是 Wiener。
- 后悔：令 h_j^W = A_j⁻¹ b_j（情景 j 的 Wiener），L_j* = E0 − b_j^H A_j⁻¹ b_j（Wiener 的最小损失，与可分形式相同），则

  R_j(h) = [min_α L_j − L_j*]/E0 = κ_j [1 − cos²_{A_j}(h, h_j^W)]，κ_j = 1 − L_j*/E0，

  其中 cos_{A_j} 是 A_j 内积下的余弦（取实部）。即**后悔 = 可达相关² × (1 − 与该情景 Wiener 的加权余弦²)**，只看谱形，不看绝对增益。
- 多情景混合 Σπ_j R_j 是不同度量 A_j 下 Rayleigh 商之和，不是单个广义特征值问题，对 h 非凸。

**驻点结构（新算子的形式）。**对固定 π，Σπ_j L_j(h, α_j) 对 (h, α) 双凸。对 h 求驻点：

  h(f) = Σ_j π_j α_j G_j*(f) / Σ_j π_j α_j² (|G_j(f)|² + ρ_j(f))。

这是"推广的贝叶斯形式"：分子权 π_jα_j、分母权 π_jα_j²。α_j = 1 时退回 UQ-W/MMR/CBL 的贝叶斯形式。**跨频耦合只经由每行 J 个标量 α_j(t) 进入**（J = 17 或 41），而 α_j 又由整条频带上的 q_j、P_j 决定。所以每个时窗是一个 J 维的小规模非凸问题，而不是 nf = 513 维。

## 4. 求解

**固定 π（SIU，π 取 UQ-W 的对数正态 Gauss–Hermite 权）：**交替两个闭式——h 步（上式）、α 步（α_j = q_j₊/P_j）。这是双凸目标上的块坐标下降，目标单调不增；从 α = 1（即 UQ-W）出发。收敛到驻点（局部极小）。输出电平：每行把 h 乘以 Σπ_jα_j，使先验平均增益为 1（相关不受影响）。

**极小极大后悔（SIR，用户方向本体）：**整段共用一个 π（与 RGJ 一致；MMR 的机制归因 B 已表明整段共用优于逐点），17 点比例族 u ∈ [0.5, 2]：

  max_π φ(π)，φ(π) = mean_t min_{h_t, α_t} Σ_j π_j R_jt。

- φ 对 π 的梯度是各情景的平均后悔（Danskin，内层取到的局部极小处）；指数梯度上升加回溯，α 跨步热启动。
- 内层非凸，Sion 定理不再适用：max_π min_h ≤ min_h max_π 可能严格。报告 "对偶间隙" max_j R̄_j(h(π*)) − φ(π*)。它衡量的是 h(π*) 离"使所有情景后悔相等"有多远；即使为 0，也只说明 h(π*) 是局部意义下的鞍点。
- π 用每隔一行求，算子作用于全部行（与 RGJ 相同）。

## 5. 事先能说的性质与预期

- Q 准确、σ → 0：SIU 退化为 W0（差行增益），所以 Q 准附近的上限就是 W0/真 Q。
- 情景族之间的差别主要是谱倾斜 exp[−πfΔx(u − 1)]，标量 α 吸收不了倾斜，只能吸收带内的平均电平。w 把权重集中在 W_out 的通带（半合成约 10–60 Hz），带内的倾斜相对电平较小，所以 α 的作用有限。**预期增益不大**，可能与 CBL 一样在 +0.01 量级或更小。
- 可能的好处：UQ-W 的分母由衰减最小的情景主导（|G|² 大），对数正态左尾使算子偏保守；自由增益让"衰减大"的情景不必为电平失配付代价，h 会向更强补偿偏移——方向上与 CBL 的上限（权重落在 u = 2）一致。
- 可能的坏处：在噪声主导的 FD 上，ρ 项也随 α 缩放，弱信号情景的噪声惩罚不会被免除；但若 α 把 u = 2 的情景放大，低频噪声放大会像 RGJ 那样伤 FD。
