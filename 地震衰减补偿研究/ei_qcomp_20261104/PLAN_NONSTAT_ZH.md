# 非平稳反射系数检验：方案（开跑前提交）

日期：2026-11-05。到目前为止，所有 EI 结果用的反射系数都是平移不变的，这正是 EI 损失默认的前提。这一步打破这个前提，看 EI 的优势还在不在。

## 问题

1. 反射系数的统计特性随深度变化时，MC+EI 是否仍优于 MC？
2. 哪种变化最伤 EI：密度、强度，还是频谱？
3. 如果深层有浅层没有的高频，或者浅层有深层没有的高频，EI 会丢失细节，还是会造出假高频？

## 设置

数据仍由 Q = 50 生成，算子 Q 正确，30 dB，子波不变。`u` 从第一个样点的 0 变到最后一个样点的 1。除平稳组外，反射系数都整体缩放到平稳组的方差（0.08）。

| 场景 | `EI_SCEN` | 随深度的变化 |
|---|---|---|
| 平稳（基线） | `stationary` | 密度 0.08，高斯幅度。直接复用已有结果，不重跑 |
| 密度 | `density` | 脉冲密度 0.14 − 0.12u，浅层密、深层稀 |
| 强度 | `amp` | 幅度乘 1.6 − 1.2u，浅层强、深层弱 |
| 频谱：宽到窄 | `broad2narrow` | 浅层白、深层低通（块状），下面 a = 1 的部分 |
| 频谱：窄到宽 | `narrow2broad` | 浅层低通、深层白，a 反过来 |

频谱场景：r = √(1−a)·白序列 + √a·低通序列，两者独立；低通用 σ = 2 个样点（8 ms）的高斯核，40 Hz 处幅度约降到 0.13。`broad2narrow` 中 a = clip((u−0.2)/0.4, 0, 1)，`narrow2broad` 中用 1−a。这样深层窗（t > 0.6 s）基本是纯的一种统计，浅层窗（t < 0.3 s）大部分是另一种。

其余固定不变：种子 1、2、3，4000 步，余弦学习率，取最后一步，配置 MC 和 MC+EI。f_max 已两轮未见增益，这一步不再跑。网络输入含时间通道，这一点也不变。

同一场景同一种子内，MC 和 MC+EI 用相同数据，可以配对。不同场景的随机抽样不同，真值的频谱也不同，所以 SNR 绝对值不能跨场景比较。比较看场景内的差值。

平稳基线（全道 +2.66 dB，来自 `qerr_table.csv` 的 Qerr = 0 行）已经看过。四个非平稳场景的 4000 步结果都没有看过。冒烟运行（30 步、200 道）也打印了 SNR，但网络基本没训练（3 dB 左右），不反映结果。

## 开跑前的检查（冒烟运行，已删除产物）

- 平稳分支改动后，种子 1 的 Tikhonov 全道 SNR 为 19.24 dB，与基线 19.2357 dB 一致，所以数据路径没变，基线可以复用。
- 真值在 40–70 Hz 的能量占比（用 50 道的平均幅度谱估计）：

| 场景 | 深层窗 | 浅层窗 |
|---|---|---|
| `density` | 0.085 | 0.099 |
| `amp` | 0.086 | 0.096 |
| `broad2narrow` | 0.008 | 0.102 |
| `narrow2broad` | 0.082 | 0.010 |

频谱场景的深浅差异约 10 倍，密度和强度场景的频谱基本不变，和设计一致。

## 判定规则

差值都按同种子配对，每个场景分别判定。设 d 为 3 个种子的差值：

- 3 个都为正且平均 ≥ 1 dB：**优势保留**
- 3 个都为正但平均 < 1 dB：**优势存在但不足 1 dB**
- 3 个都为负且平均 ≤ −1 dB：**EI 有害**
- 其他：**无法判定**

判定项：

- **E1**：MC+EI − MC，全道 SNR（主判据）。
- **E2**：MC+EI − MC，深层 SNR。
- **E3**：MC+EI − Tikhonov（用真值挑 μ），全道 SNR。

总体结论按 E1：

- 四个场景都“优势保留”：**EI 前提对这几类统计变化稳健**。
- 两个频谱场景都不是“优势保留”：**EI 优势依赖频谱平稳**，无论密度和强度场景如何。
- 其他情况：**部分敏感**，逐场景列出。

## 只作描述

- MC+EI 和 MC 都取记录点中的最佳值（用真值选，是预言机停止）时的差值。这是为了防止优势只来自 MC 在最后一步退化。
- 相对平稳基线，差值缩小了多少。两者数据不同，只作参考。
- 浅层 SNR。
- 40–70 Hz 带内的能量比（估计 / 真值）和带内 SNR，分深层和浅层窗。能量比明显大于 1 且带内 SNR 低，提示造出了假高频；能量比明显小于 1，提示高频丢失。
- 留出的 MC、EI 损失是否能反映问题。

## 我开跑前的预期（可能是错的）

密度和强度变化对 EI 影响较小，因为 x 的局部频谱没变。`narrow2broad` 最可能失去优势，因为浅层没有高频可借，而 HANDOFF 把 EI 的作用解释为“借用浅层的高频去补深层”。`broad2narrow` 可能在深层造出假高频。

## 局限

- 只有 3 个种子和 4 种人为设定的变化，变化的强度是我选的，不代表实际地层。
- Q 仍然完全已知，反射系数也没有层间相关（低通部分除外）。Q 有误差时的结果要看 `RESULTS_QERR_ZH.md`，两者叠加的情况没有测。
- 全部是合成数据。
- 对手只有 MC 和 Tikhonov。
