# 多种子与稳定训练：方案（开跑前提交）

日期：2026-11-04。起因：首轮（种子 0，恒定学习率，4000 步）MC+EI 比只用 MC 高 2.14 dB，但 MC+EI 在 3000 步掉到 17.14 dB，单次波动约 5.8 dB，大于差距本身；MC 组也可能没有收敛。

## 问题

1. 学习率衰减后，训练末段的尖峰是否消失？
2. MC+EI 优于只用 MC，在换种子、训练更久之后是否还成立？
3. f_max(t) 掩码在 MC+EI 之上有没有增益？

## 设置

数据和网络结构不变：Q=50，Q 无误差，30 dB，dt=4 ms，N=256，25 Hz Ricker，训练 4000 道，测试 500 道。

| 项目 | 取值 |
|---|---|
| 种子 | 1、2、3（种子 0 已看过，不计入判定）。种子同时改变数据和网络初始化 |
| 学习率 | 余弦衰减，1e-3 → 1e-5 |
| 步数 | 4000：MC、MC+EI、MC+EI+fmax；12000：MC、MC+EI |
| 停止准则 | 固定步数，取最后一步，不用真值挑选 |
| 评价 | 测试集全道 SNR 和深层（t > 0.6 s）SNR；主指标是全道 SNR |

每组配置单独设随机数（`rng(1000*seed + 配置编号)`），所以不受运行顺序影响。同一种子内，各配置的训练集和测试集相同。

## 判定规则

差值都按“同一种子内配对”计算。

- **C1 稳定性（问题 1）**：4000 步和 12000 步的所有运行，最后 3 个记录点（每 500 步一个）的全道 SNR 极差都 ≤ 1 dB，则成立。
- **C2 EI 优势（问题 2）**：分别看 4000 步和 12000 步的 MC+EI − MC。
  - 3 个种子都为正且平均 ≥ 1 dB：优势成立。
  - 3 个种子都为正但平均 < 1 dB：优势存在但不足 1 dB。
  - 符号不一致：无法判定，再加种子 4、5。
  - 4000 步成立而 12000 步不成立：记为“优势主要来自收敛速度”。
- **C3 fmax（问题 3）**：4000 步的 MC+EI+fmax − MC+EI。平均 ≥ 0.5 dB 且 3 个种子都为正，判为有增益；平均 ≤ −0.5 dB 且 3 个种子都为负，判为有害；其余判为未见增益。

## 只作描述，不参与判定

- 深层 SNR 的同样差值。
- Tikhonov（用真值挑 μ）作参照。它用了真值，所以不是公平的自监督对手。
- 留出 500 道、不用真值的验证损失（MC 项和固定平移 ±20、±60 的 EI 项），看它能否指示停止时机：对比“验证损失最低的记录点”和最后一步的测试 SNR。

## 局限

- 3 个种子很少，3/3 同号只是初步证据。
- 反射系数仍然平移不变，这正是 EI 假设成立的理想情形，非平稳的情形留到后面。
- Q 完全已知，Q 误差留到下一步。
- 恒定学习率只有种子 0 的一次运行，所以“衰减消除尖峰”只能和那次运行作描述性比较。
