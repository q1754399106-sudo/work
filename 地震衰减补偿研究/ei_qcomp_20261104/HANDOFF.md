# 接手说明：基于等变成像（EI）的自监督 Q 补偿

> 给 Claude Code 的上下文。打开项目后请先读这份文件。来源：2026-11-04 的一次 Claude 对话（检索文献、讨论选题、做了一个最小验证实验）。

## 1. 研究目标

为地震吸收（Q）补偿找一个有创新点的方向，并且能接到已有的 **Fourier-feature PINN 逐步补偿 + 误差传播约束** 工作上。

## 2. 选定的方向

主线 = **Fourier 特征网络 + 物理推导的时变带宽 f_max(t) + 等变成像（EI）损失**

- **f_max(t)**：每个时刻允许恢复的最高频率，由衰减量和信噪比决定：
  f_max(t) = Q·ln(1/ε)/(π t)，ε 为噪声与信号的振幅比。作用是稳定补偿、不放大噪声。
- **EI 损失**（Chen, Tachella & Davies, ICCV 2021）：
  L = ‖A_Q f(y) − y‖² + λ‖f(A_Q T_g x̂) − T_g x̂‖²，其中 x̂ = f(y)，T_g 为时间平移。
  作用是突破衰减算子的零空间，让网络借用浅层的高频去补深层。
- **为什么成立**：Tachella 等的感知定理要求 ∩_g N(A T_g) = {0}。时变衰减与平移不可交换，所以条件可以满足；平稳褶积与平移可交换，所以 EI 对平稳褶积无效。

## 4. 已完成的实验

**秩检验**：N=256，dt=2 ms，Q=40，阈值取最大奇异值的 1%。
- A_Q 单独的有效秩：209
- 循环平移叠加后：256（满秩）
- 非循环平移 ±80 点：238
- 平稳褶积：110 → 110（无变化）

**线性最小实验**（`ei_qcomp_linear.py`，重建器为线性矩阵 W，numpy 手写梯度）
设置：Q=50，dt=4 ms，N=256，25 Hz Ricker 子波，训练 4000 道，测试 500 道。

| 方法 | 30 dB（8000 步）全道 / 深层 | 20 dB（3000 步）全道 / 深层 |
|---|---|---|
| Tikhonov（用真值挑 μ） | 19.3 / 16.9 | 13.3 / 11.3 |
| 只用 MC | 18.7 / 15.4 | 13.3 / 10.4 |
| **MC + EI** | **21.7 / 18.7** | **15.7 / 12.9** |
| 有监督线性（上限） | 24.0 / 20.9 | 16.9 / 14.0 |

- EI 的主要作用：压住 55 Hz 以上的噪声放大，同时把主频带（到约 45 Hz）贴合真值。
- 45～55 Hz 段 EI 和有监督结果都偏低，这是线性模型的上限。
- **局限**：只是线性模型；Q 完全已知；反射系数按构造平移不变；只跑了一个随机种子；只用 MC 时对训练步数敏感（3000 步和 8000 步差 3 dB）。

## 5. 文件

- `ei_qcomp_linear.py`：线性原型，可直接运行（`python3 ei_qcomp_linear.py <SNR_dB> <iters>`），只依赖 numpy。
- `ei_qcomp_net.m`：MATLAB 网络版（R2021b+，Deep Learning Toolbox）。**还没实际运行过。**
  - 四组对比：Tikhonov / MC / MC+EI / MC+EI+fmax。
  - 参数在结构体 `P` 里：`Qerr`、`snrdB`、`lamEI`、`gmax`、`iters`。
  - 可能需要修的地方：`toCBT` 中对未加格式的 dlarray 重新贴 'CBT' 标签（个别版本会报错）；训练步数和收敛判据。

## 6. 下一步（按顺序）

1. 让 `ei_qcomp_net.m` 跑通，复现"MC+EI 优于只用 MC"。
2. Q 误差测试：`P.Qerr = ±0.2`。
3. 反射系数统计随深度变化（打破平移不变性），检验 EI 是否还有优势。
4. 统一停止准则，跑多个随机种子。
5. 接入用户现有的 Fourier-PINN。注意：EI 需要一个"把 y 映射成 x"的摊销式网络，单道坐标网络不能直接用。可选做法：条件 INR（编码器把 y 压成隐变量，再输入 Fourier 特征网络），或在同一工区多道上自监督训练。

7. 实际数据验证。目标期刊：IEEE TGRS 或 Geophysics（理论和实际数据都扎实时）；否则先投 GRSL 或会议。
