# Q 误差检验：方案（开跑前提交）

日期：2026-11-05。上一步（`RESULTS_MULTISEED_ZH.md`）在 Q 完全已知时，MC+EI 比 MC 的最佳停止点高约 1.7 dB。这一步问：训练算子用错 Q 时，这个优势还在不在？

## 问题

1. Q 有 ±20% 误差时，MC+EI 是否仍优于 MC？
2. MC+EI 是否仍优于用真值挑 μ、但同样用错 Q 的 Tikhonov？
3. f_max(t) 依赖 Q，在 Q 有误差时有没有增益或害处？

## 设置

- `Qerr` = +0.2（算子 Q = 60，补偿偏弱）和 −0.2（算子 Q = 40，补偿偏强）。数据仍由 Q = 50 生成。
- 种子 1、2、3，每组 4000 步，余弦学习率，取最后一步，配置 MC、MC+EI、MC+EI+fmax。
- Qerr = 0 直接复用上一步的 4000 步结果。同种子的数据、初始化和抽样序列相同，所以可以配对。
- 选 4000 步是看过上一步曲线后定的：此时 MC 接近峰值，对 MC 有利，比较偏保守。这些种子的 Qerr = 0 结果已看过，但 Qerr ≠ 0 的结果没有看过。

## 判定规则

差值都按同种子配对，主指标是全道 SNR，±0.2 分别判定。

- **D1 EI 对 MC**：MC+EI − MC。3 个种子都为正且平均 ≥ 1 dB：优势保留；都为正但平均 < 1 dB：优势存在但不足 1 dB；符号不一致：无法判定。如果平均 ≤ −1 dB 且都为负：判为 EI 在 Q 有误时有害。
- **D2 EI 对 Tikhonov**：MC+EI − Tikhonov（用真值挑 μ）。判法同 D1。
- **D3 fmax**：MC+EI+fmax − MC+EI。平均 ≥ 0.5 dB 且都为正：有增益；平均 ≤ −0.5 dB 且都为负：有害；其余：未见增益。

## 只作描述

- 各方法相对 Qerr = 0 的 SNR 损失，以及 EI 是否比 MC 或 Tikhonov 更敏感。
- 深层 SNR。
- SNR 对全道整体时移敏感，Q 错误带来的频散误差会计入，所以这里不允许时移；如有需要再单独看。

## 局限

- 只有 ±20%，并且只有 3 个种子。仓库已有实测 Q 不确定度可能更大。
- Q 误差是全道一个常数，不是随深度变化。
- 反射系数仍然平移不变。
