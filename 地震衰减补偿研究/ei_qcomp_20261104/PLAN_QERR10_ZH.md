# Q 误差 ±10% 检验：方案（开跑前提交）

日期：2026-11-05。Q 误差 ±20% 时（`RESULTS_QERR_ZH.md`），MC+EI 损失 10–15 dB，比 MC 的优势只剩 +0.30 / +1.14 dB。±20% 可能偏悲观，这一步问：Q 准到 ±10% 时，EI 还有没有实用价值？

## 问题

1. Q 有 ±10% 误差时，MC+EI 是否仍优于 MC？
2. MC+EI 是否仍优于用真值挑 μ、但同样用错 Q 的 Tikhonov？
3. 从 Q 正确到 ±20%，SNR 损失随 Q 误差怎样变化？

## 设置

- `Qerr` = +0.1（算子 Q = 55，补偿偏弱）和 −0.1（算子 Q = 45，补偿偏强）。数据仍由 Q = 50 生成。
- 种子 1、2、3，4000 步，余弦学习率，取最后一步，配置 MC 和 MC+EI。f_max 已多轮未见增益，不再跑。
- 反射系数平稳（`EI_SCEN=stationary`）。
- Qerr = 0 和 ±0.2 复用已有结果。同种子的数据、初始化和抽样序列相同，所以可以配对。

Qerr = 0 和 ±0.2 的结果已看过，±0.1 的 4000 步结果没有看过。冒烟运行（30 步、200 道训练、50 道测试）打印出 ±0.1 的 Tikhonov 全道 SNR：Q = 45 为 15.95 dB，Q = 55 为 15.26 dB。这些数字是在下面的判定规则和预期写好之后才看到的，规则和预期没有因此改动；网络的冒烟结果基本没训练，不反映结果。

## 判定规则

差值按同种子配对，主指标是全道 SNR，±0.1 分别判定。设 d 为 3 个种子的差值：

- 3 个都为正且平均 ≥ 1 dB：**优势保留**
- 3 个都为正但平均 < 1 dB：**优势存在但不足 1 dB**
- 3 个都为负且平均 ≤ −1 dB：**EI 有害**
- 其他：**无法判定**

判定项：

- **F1**：MC+EI − MC。
- **F2**：MC+EI − Tikhonov（用真值挑 μ）。

总体结论：

- 两个方向的 F1、F2 都是“优势保留”：**Q 准到 ±10% 时 EI 仍有优势**。
- 否则：**EI 对 Q 的要求比 ±10% 更严**，并列出未保留的方向和判定项。

这个结论只针对 MC 和 Tikhonov 这两个对手，以及 3 个种子上的合成数据，不说明优于其他方法。

## 只作描述

- 五档 Q（40、45、50、55、60）下各方法的全道和深层 SNR，以及相对 Q 正确的损失。
- EI 比 MC、Tikhonov 更敏感还是更不敏感。
- MC+EI 的损失是否大于它在 Q 正确时的收益（约 1.7 dB，对 MC 最佳停止点）。
- 留出的 MC、EI 损失随 Q 的变化，看能否选 Q。上一步只有 3 档，且 EI 损失随 Q 单调下降。
- SNR 随训练步数的曲线，看 Q 偏低时提前停止是否更好。

## 我开跑前的预期（可能是错的）

- 损失大致在 4–7 dB，仍明显大于 EI 约 1.7 dB 的收益。
- F1：Q = 45 可能优势保留，Q = 55 可能不足 1 dB，因为 ±0.2 时是 Q 偏低一侧优势更大。
- F2：Q = 55 可能优势保留，Q = 45 不确定，因为 ±0.2 时 Q 偏低一侧输给了 Tikhonov。

## 局限

- 3 个种子；Q 误差是全道一个常数，不随深度变化；反射系数平稳；全部是合成数据。
- Tikhonov 的 μ 用真值挑选，比较对 EI 偏严。
- 对手只有 MC 和 Tikhonov。
- 真 Q 只有 50 一档，结论不能外推到其他 Q 值。

`run_qerr10.ps1` 依次运行，同一时间只开一个 MATLAB。共 6 个，每个约 5.6 分钟，约 35 分钟。结果由 `aggregate_qerr10.m` 按上面的规则判定，写入 `outputs/qerr10_table.csv` 和 `outputs/qerr10_verdicts.txt`。
