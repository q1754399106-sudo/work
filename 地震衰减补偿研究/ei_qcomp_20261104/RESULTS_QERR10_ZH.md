# Q 误差 ±10% 检验：结果

日期：2026-11-05。方案在开跑前提交（`840ec67`，`PLAN_QERR10_ZH.md`）。判定来自 `outputs/qerr10_verdicts.txt`，逐种子数据见 `outputs/qerr10_table.csv`。

## 结论

按预设规则，总体结论是 **EI 对 Q 的要求比 ±10% 更严**。Q 误差 ±10% 时，MC+EI 损失 6.0–8.6 dB，比 MC 的优势只剩 +0.36 和 +0.82 dB。Q 偏低一侧（Q = 45）还比用真值挑 μ 的 Tikhonov 低 1.34 dB。

这些损失部分可能和频散参考频率设在 Nyquist 有关（见局限），这一点没有测。

## 判定

差值单位 dB，按种子 1、2、3 配对，取 4000 步的最后一步。

| 判定项 | Q = 45（Qerr −0.1） | Q = 55（Qerr +0.1） |
|---|---|---|
| F1 MC+EI − MC | +0.28, +0.35, +0.45；均值 +0.36，**优势存在但不足 1 dB** | +0.72, +0.68, +1.05；均值 +0.82，**优势存在但不足 1 dB** |
| F2 MC+EI − Tikhonov | −1.37, −1.32, −1.31；均值 −1.34，**EI 有害** | +2.02, +1.96, +2.07；均值 +2.02，**优势保留** |

F2 的“有害”是预设规则的用语，这里的含义是 MC+EI 低于 Tikhonov。Tikhonov 的 μ 用真值挑选，实际中做不到，所以这个比较对 EI 偏严。

## 开跑前的预期对不对

- **损失 4–7 dB，仍大于 EI 约 1.7 dB 的收益：** 大于收益这一点成立；Q = 55 的 5.99 dB 在范围内，Q = 45 的 8.62 dB 超出。
- **F1：Q = 45 优势保留，Q = 55 不足 1 dB：** 前者错了（+0.36），后者对了（+0.82）。
- **F2：Q = 55 优势保留，Q = 45 不确定：** Q = 55 对了，Q = 45 实际低于 Tikhonov。

## 事后观察（只作描述）

- **MC+EI 在这四档都比另两种方法更怕 Q 错。** 它在 Q 正确时领先最多，失去得也最多。
- **偏离 ±10% 就失去大半优势。** 对 MC 的优势从 +2.66 dB 降到 +0.36 和 +0.82 dB。
- **优势随 Q 误差不单调。** Q = 40 的 +1.14 dB 大于 Q = 45 的 +0.36 dB。Q = 40 时 MC 自身从约 8.7 dB 退化到 7.58 dB，这可以解释一部分：两者都取记录点中的最佳值时，差值为 +0.82（Q = 40）、+0.53（Q = 45）、+0.81（Q = 55）、+0.28（Q = 60）。这时 Q = 50 仍是 +2.66，但 4000 步内 MC 还没到它的峰值。
- **两种方法偏向相反。** 网络方法在 Q 偏高时更好（MC+EI 在 Q = 55 比 Q = 45 高 2.63 dB），Tikhonov 则在 Q 偏低时略好（高 0.72 dB）。如果 Q 拿不准，这组结果倾向于让网络方法取偏大的 Q，但真 Q 只有一档，不能外推。
- **留出损失仍不能选 Q。** MC+EI 的留出 EI 损失随 Q 单调下降（0.125、0.113、0.076、0.059、0.049），MC 损失也一样（0.063、0.026、0.021、0.019、0.018），最小值不在真 Q 处。
- **留出 MC 损失比值这个假设，在 Q 有误差时站不住。** 比值（MC+EI / MC）在 Q = 40、45、55、60 约为 2.1、0.97、0.75、0.72，和 SNR 差值 +1.14、+0.36、+0.82、+0.30 对不上。这只对比了 4 档平均值，见 `RESULTS_NONSTAT_ZH.md`。
- **提前停止的作用不大。** 只有 Q = 40 明显（最佳值比最后一步高约 0.8 dB）；Q = 45 约 0.3 dB；Q ≥ 50 基本没有。

## 局限

- **频散参考频率设在 Nyquist（125 Hz），可能放大了损失。** 粗算：25 Hz 处，Q 从 50 错成 55 或 45，在 1 s 处带来约 0.9–1.1 ms 的整体时移，相当于约 0.15–0.18 rad 的相位误差。仅这一项就把最深处的 SNR 限制在约 15–17 dB，和深层实测（12–15 dB）同一量级。实际处理常用主频附近的参考频率，时移也可能被速度或层位对齐吸收。这是估算，没有实验验证；此前只有 Tikhonov 的拆解显示振幅、频散损失量级相当（`RESULTS_QERR_ZH.md`）。
- 这里对比的是 4000 步最后一步，Q 正确时 MC 还没到峰值，所以 Q = 50 的 +2.66 dB 偏高。对 MC 最佳停止点约 +1.7 dB。
- 3 个种子，真 Q 只有 50 一档；Q 误差是全道一个常数；反射系数平稳；全部是合成数据。
- 对手只有 MC 和 Tikhonov，没有和仓库里调好的反 Q、小 a 的 SC-a 比较。
