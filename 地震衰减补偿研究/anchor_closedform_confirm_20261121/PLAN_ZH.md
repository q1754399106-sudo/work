# 方案：单次求解＋固定活跃集闭式 κ 的预登记确认（运行前提交）

2026-11-21。用户要求“预登记检验单次求解闭式 κ”。来源：`anchor_active_hessian_20261120/RESULTS_ZH.md` 第 6 节。程序在 `scripts/`。

## 0. 要确认的主张

**主张**：在锚点 c_a = 1 的 QScan 选择点 v₀ 上只解一次 lasso，取活跃集和符号，用闭式目标
J_A = Σ_j[½‖d‖² − ½cᵀ(B̃_AᵀB̃_A)⁻¹c]/σ_j² 求 α_F = −J_{v v_a}/J_vv（L1 权重 μ 随字典重算，与扫描相同）。
它应等于两锚点完整扫描测得的 κ̂ = [v_sel(0.7) − v_sel(1.4)]/(1/0.7 − 1/1.4)。

**已知证据（全部来自用过的数据）**
- Volve 半合成 12 个剖面：α_F 与 K_ref 的差不超过 0.025。
- 按数据集对比 90 个（不含基准；本方案写作时补算，算法见下）：|α_F − κ̂| 中位数 0.014，第 90 百分位 0.050，98% 的数据集 ≤ 0.10，最大 0.114（D 剖面）。
- U1320A 4 个组合：差不超过 0.023（事后补充）。

**本次确认不包括的内容**
- U1320A 已用过，这次不进确认。
- 事后公式 a₀/a(t_med) 只作次要检验（第 3 节 S2），因为它已在 U1320A 深窗上失败。

## 3. 计算与判读（运行前写死）

### 计算（`scripts/run.py`）

每个数据集按以下步骤计算：

1. **三次锚点扫描**：c_a = 1.0、0.7、1.4，调用 `qprofile.scan`，带提前停止，取抛物线顶点。
2. **真值**：κ̂ = [v_sel(0.7) − v_sel(1.4)]/(1/0.7 − 1/1.4)。
3. **α_F**：取 v₀ = v_sel(1.0)。用未归一化子波，热启动之外的设置都与上次相同（KKT 容差 1e-3）。解一次 lasso，再按闭式有限差分算 α_F，步长 3×10⁻³。
4. **描述量**：记录 θθ/θμ/μμ 三块的份额和各块的 α、均匀公式 U、a₀/a(t_med)。

**有效数据集**的条件：三次扫描的 v_sel 都不在网格端点，顶点邻域收敛，v₀ 处的求解也收敛。无效的数据集不进统计，数量单独报告。

### 判据（κ̂、α_F 都只取有效数据集）

- **C1（逐数据集）**：全部有效数据集中，|α_F − κ̂| 的中位数 ≤ 0.03，且 ≥ 90% 的数据集 ≤ 0.10。
- **C2（逐剖面）**：每个剖面先对各数据集取中位数，|med α_F − med κ̂| ≤ 0.05 的剖面 ≥ 15/17。
- **C3（新剖面）**：只看 B 族的 36 个数据集，C1 的两条门槛也要成立。
- **通过**：C1、C2、C3 都成立，结论写作“单次求解闭式 κ 在新种子、新剖面上复现两锚点扫描”。任一条不成立，就写不通过，并报告失败的位置：哪个剖面、哪个 c、偏差符号。
- **无法判定**：有效数据集 < 80%（< 82 个），或 B 族有效数据集 < 80%。

**门槛的来历**：旧数据逐数据集的中位数是 0.014，第 90 百分位 0.050。门槛按约 2 倍余量设定，因为 B 族剖面更极端。门槛是在看过旧数据、没看新数据的时候定的。

### 次要（预登记，不影响主结论）

- **S1**：逐剖面列出 α_F、均匀 U、a₀/a(t_med) 对 med κ̂ 的误差，并统计 α_F 误差最小的剖面数。
- **S2（事后公式第一次在新数据上检验）**：a₀/a(t_med) 逐剖面 |误差| ≤ 0.05 的剖面 ≥ 15/17，记作“成立”，否则记作“不成立”。这条不改变上次“不建议作为公式推广”的判断，只记录结果。
- **S3**：描述 θθ 与 θμ 两块在 B 族上是否仍大部分抵消，即 μμ 块份额与 α_μμ 是否接近 a₀/a(t_med)。
