# SID-UQ（本征吸收与薄互层散射解耦的贝叶斯期望算子）：第 0 步核对方案

日期 2026-11-20。本文件在运行任何第 0 步诊断前提交。性质：**机制诊断 / 立项核对**，不是方法检验。

## 0. 背景与重开说明

用户提出“创新方向 1”：正演写成
G(t,f;u,η) = exp[(−πf + i·2f·ln(f/f_ref))·Δa(t)·u − η·φ_scat(f,Δt)]，
u ~ LogNormal(0, σ_u²)（本征 1/Q 不确定度），η ~ N(η̂, σ_η²)（O'Doherty–Anstey / Shapiro–Kneib 薄互层散射：低频约 f²、高频饱和，使对数谱比高频走平），η̂、σ_η 由浅/深时窗跨道平均对数谱比的二次项无监督估计；相位只受 u 支配，振幅对 u、η 同时求期望；算子 E_{u,η}[G*]/(E|G|²+ρ)。目标是解释并修正“UQ-W 合成通过、实测相反”。

叠后 UQ-W / CBL 线已于 2026-11-19 封盘（`qunknown_comp_20261109`、`uqw_improve_20261113`、`uqw_shaping_confirm_20261119`），UQW-S 11-20 并入封盘。本次是**用户要求重开**。相对封盘时已做过的内容，SID-UQ 声称的新增点只有两条：
1. 把实测谱比的非常 Q 弯曲归因于薄互层散射，用参数化的 η·φ_scat 表示，而不是用经验谱整形；
2. η 不用井、由数据无监督估计，并对 η 的不确定度求期望。

因此第 0 步只回答两个问题：(Z1) η 项在算子上是否就是已测过的“UQ-W + 时变零相位整形”；(Z2) 实测弯曲能否用薄互层散射解释（物理前提是否成立）。

## 2. Z1：算子等价性（解析，写进 RESULTS）

u 与 η 独立、φ_scat 为实数时，
E[G*] = E_u[G_u*]·M1，E|G|² = E_u|G_u|²·M2，M1 = exp(−η̂φ + σ_η²φ²/2)，M2 = exp(−2η̂φ + 2σ_η²φ²)，
所以 K_SID = g(t,f) · E_u[G_u*] / (E_u|G_u|² + ρ/M2)，g = M1/M2 = exp(η̂φ − 1.5σ_η²φ²) > 0。

判据 Z1 成立 ⇔ 推导表明 K_SID 的相位与 UQ-W 完全相同，差别只是一个实、正、随时间变化的零相位增益，加上噪声项按 1/M2 放大。成立时，SID-UQ 属于“UQ-W 后接时变零相位整形（带信噪比收缩）”这一族，HAW 与 UQW_TV 是同族已测成员。

## 3. Z2：物理前提诊断（数据，运行前定门槛）

数据：Volve 105 条分析 inline（已见数据；只算谱，不补偿、不看井震相关）；测井只作物理参照，不用于打分：覆盖 1.4–2.55 s 整段路径的 F-12（1.358–2.624 s）和 F-14（1.081–2.680 s），以及 11 口井在 2.3–2.8 s 的反射系数。代码 `scripts/step0.py`，日志 `logs/step0.log`，结果 `results/step0.json`。谱的算法与 `uqw_improve_20261113/scripts/specform.py` 相同（汉宁窗、512 点、5 点平滑；深窗 2.3–2.8 s，浅窗 1.2–1.6 s）。

- **Z2a（二次项估计的符号）。**用户设想的 η̂ 来自二次项：在 φ_scat 的 f² 区，对数谱比 ≈ a − bf − (η/f_c²)f²，η ≥ 0 要求二次系数 c2 ≤ 0。逐线在 10–55 Hz 拟合二次式。**若 ≥ 80% 的线 c2 > 0，判 Z2a 否定**：按设想的估计器，实测 η̂ < 0，截到 0 后 SID-UQ 在实测上退化为 UQ-W。
- **Z2b（带约束全模型拟合）。**对 105 条线平均对数谱比在 10–72 Hz 拟合 a − πfD − η·f²/(f²+f_c²)，D ≥ 0、η ≥ 0、f_c ∈ [2, 200] Hz（f_c 网格，D、η 非负最小二乘）。记 û = D / Δa_curtain（Δa_curtain = 0.0119 s，帘幕模型 1.4→2.55 s）。**若 û < 0.5，判 Z2b 否定**：散射解释要求把一半以上的衰减从本征 Q 移给散射，与 u 先验以基线 Q 为中心（LogNormal(0, σ_u²)）不相容。同时报告残差均方根与仅直线拟合的比较。
- **Z2c（测井预测的散射量）。**F-12、F-14 在 1.4–2.55 s 内用 1 ms 层的精确一维垂直入射递推（含全部层间多次波）求透射 |T(f)|，取双程 ln|T|。实测超额下降 E_field = [lnr(10) − lnr(35)] − π·25·D_HF，D_HF 为 36–72 Hz 直线斜率给出的 Δt*（下限取 0）。测井预测 E_well = 2·[ln|T(10)| − ln|T(35)|]（单程透射平方，即双程）。**若两口井都有 E_well < 0.25·E_field，判 Z2c 否定**。另报 2·[ln|T(35)| − ln|T(72)|]。

只描述、不判定：
- D3：11 口井 2.3–2.8 s 反射系数振幅谱（汉宁窗）对直线的残差，与实测谱比残差的相关（深窗反射系数颜色 / 调谐能否造成弯曲）。
- D4：深窗、浅窗的相邻道相干信噪比 snr = C/(1 − C)（C 为相邻道幅度平方相干，按线平均）随频率的分布：35–72 Hz 走平是否接近噪声底。
