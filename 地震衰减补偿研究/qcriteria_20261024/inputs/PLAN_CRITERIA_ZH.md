# 登记：不依赖稀疏先验的 Q 选择准则（无噪声 M1 / M5 检验）

登记时间：2026-10-24，运行任何准则之前。

## 数据

F1–F4 的 M1（完整细层、密集反射系数）与 M5（块状、稀疏反射系数）无噪声观测，与 `run_variants.m` 完全相同（33 道、归档 σ、偏移距 0、名义上采样 Q）。误差最优因子 c_opt 直接取自已归档的 `analysis/variants_*.json`。附加检查：F1–F4 归档的含噪 Moderate 观测（M1 物理），同 33 道。

## 准则（均只用数据与字典，不用真值；因子网格 0.6–2.2 对数 25 点，A = G·W 为未归一化正演）

- C0 QScan：原 lasso 目标（参照）。
- C1 高斯证据：反射系数先验 r ~ N(0, s²I)，噪声 N(0, σ²I)；每道用 ML 估计 s²，选使负对数边缘似然之和最小的因子。
- C2 岭回归 GCV：每道在 μ 网格上取 GCV 最小值，对各道求和后选因子。
- C3 留出预测：时间轴连续 5 折；每折用其余样本做岭回归（μ = σ²/s²，s² 取自 C1），预测留出样本，选总预测误差最小的因子。
- C4 频谱斜率：四个时窗（0.30–0.60、0.60–0.90、0.90–1.20、1.20–1.60 s）的道平均功率谱，在 8–50 Hz 拟合 ln 谱比斜率得 Δt*；字典给出名义 Q 下的 Δt*(1)，因子 c = Σ Δt*(1)² / Σ Δt*(1) Δt*_obs 的最小二乘解（Δt*(c) = Δt*(1)/c），取最近网格点。

## 成功标准

对每个准则计算 b = ln(c_sel / c_opt)：

- 主标准：M1 与 M5 的 |b| 平均都 ≤ 0.054（一个网格步长）；
- 附加：含噪 M1 的 |b| 平均 ≤ 0.108。

满足主标准的准则进入下一轮（含噪开发、与相干标准版组合、新数据确认）；都不满足则记录失败，不再在本轮调整准则参数。
