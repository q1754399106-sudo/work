# 已有局限汇总与突破点

日期：2026-11-09。依据：本目录 README（10-19 至 11-06 全部登记）、`qscan_anchor_theory_20261030/PAPER_DRAFT_ZH.md` 第 6.3 节，以及 `idea_pilots_20261106`、`ei_qcomp_20261104`、`sr_horizon_20261106`、`avo_bias_theory_20261106` 的总结。本文只做整理和提方向，没有新的计算；下文的“预测”都还没有检验。

## 一、局限按根源归类

### 1. 根本限制：叠后反射资料定不了衰减的绝对水平

| 现象 | 出处 |
|---|---|
| QScan 选择被子波窗锚定，κ ≈ 0.68，真 Q 的信息只剩约 1/3 | 锚定理论、实验 14 |
| 截距 β 由反射系数实现决定（换种子标准差 0.09–0.14），反解时放大约 3 倍，**无法事先计算** | 论文 5.7、6.3 节 |
| SR 受反射系数颜色趋势影响：趋势每 0.0033 /Hz/s 使 log c 移动 0.08–0.11；单井颜色可使 SR 偏 ±25–50% | sr_horizon 阶段 0、实验 9 |
| 留出损失、频带交叉验证、EI 留出损失都选不出 Q，Q 的信息被反射系数吸收 | qscan_bandcv、ei_qcomp |
| 换准则、常数去偏、预测偏移、分深度校正、“有把握才修正”全部失败 | 第六部分各实验 |
| 4 口井的 VSP Q 中只有 F-15A 有判别力 | 实测 4、5、6，论文 5.7 节 |

这些不是互不相关的失败，而是同一个限制：单道谱上，**衰减的绝对量与子波谱、反射系数颜色混在一起，只有深浅之差可辨识。** 论文引言已经引用了地震学的源谱–t* 权衡，但仓库里的结果还没有被统一到这一条下面。

### 2. Q 已知时，补偿本身的上限很小

- 选增益、全局 Q、横向 Q 的回报只有 0.005–0.03（idea_pilots）；用真 Q 代替 SR，M1 只高 0.015–0.031（实验 15）。
- 调好参数的 70 dB 反 Q 与小 a 的 SC-a 打平；正则和增益参数比 Q 的准确度更重要（实验 12、16、17）。
- 但 Q 错时损失很大：半合成数据上 Q 误差是最大的误差来源（实验 8）；EI 在 Q 误差 10% 时损失 4.4–8.6 dB，是其收益的几倍。

所以**价值集中在 Q 的不确定性上**：Q 对的时候各种方法差不多，Q 错的时候都失败。

### 3. 方法新颖性

- 所有组成部分在文献里都有先例；本研究自己的方法在中立数据上都不如文献方法 SC（H1–H6 上 12/12）。
- 站得住的贡献只有机制发现：锚定选择方程、QScan 与收缩互相替代、偏移因模型而异。
- 新试探（EI、沿层 SR、地层吸收解耦/AVO 闭式）都没能成为方法：EI 怕 Q 误差，沿层 SR 几何不够，AVO 方法在带内指标上不如限频反 Q。

### 4. 验证与证据

- 实测始终“无法判定”：井上指标的分辨力与阈值相当；Volve 全工区 κ̂ 近似常数，诊断的分辨能力没有检验过。
- 半合成数据全部来自 Volve 一个工区；合成实验多数只有 3 个种子、一档真 Q。
- 没有在已发表扫描 Q 方法的原实现上检验（没有公开代码）。
- 只做了叠后；Volve 的 Databricks 登录已过期，无法确认有没有叠前资料。
- 理论是一阶线性化；r > 1 时 φ₂ 没有建模；主频 Ricker 下 κ 的数值不成立；效应依赖判据。

## 二、突破点

思路：既然绝对水平在叠后资料里辨识不了，再改补偿算法或换选 Q 准则都会撞到同一个限制。突破只能来自三类做法：(a) 把限制本身定量化，变成结论；(b) 引入能定绝对水平的新信息；(c) 承认 Q 不准，按不确定性做决策。

### 更正（2026-11-09，同日）：突破点 1 的核心已在 11-01 至 11-02 检验过

写这份笔记时漏读了 `qscan_anchor_theory_20261030/BETA_ZH.md` 第六、七步和 `RESULTS_BETASR_ZH.md`。已有结果：

- 谱色公式 β_color = Σa(τ₀ − τ)/Σa² 在新种子上 r = 0.64 [0.38, 0.86]、斜率 0.46，只解释 β 约 40% 的变化；
- SR 偏差与 β 的相关只有 0.24，**“β 与 SR 颜色偏差是同一个量”不成立**；
- 白稀疏反射系数让 β 升到 0.16（C2 不满足），β 还取决于稀疏程度与结构；
- 实测多出的 β（约 0.23）来自子波窗 1.2–1.4 s 内的实测结构，子波窗移到 1.4–1.8 s 后与半合成中位数相同（`RESULTS_WSHIFT_ZH.md`）。

所以下面的原突破点 1 不再作为新方向。仍未检验、成本相近的是：**子波窗加长（中心不变）能否按 1/√T 缩小 β 的种子间离散**。β 的随机部分来自子波窗内有限长度反射系数的谱估计，窗越长，τ₀ 的方差越小；这一步只降低误差下限，不消除 β 的系统部分。按仓库检索（“窗长”“window length”），这一点没有做过。

### 原突破点 1（已被上面的更正取代）：β 的来源就是颜色，事先给出 Q 的误差下限

**要解决的局限：** 论文 6.3 节写明“β 无法事先计算”；SR 的颜色偏差也没有理论。

**假设：** QScan 的 β 与 SR 的颜色偏差是同一个量：分析窗与子波窗之间反射系数谱斜率的差。若成立：

1. 用每个种子已知的反射系数，按预先写好的公式算出谱斜率差，可以预测该种子的 β；
2. 用测井统计反射系数颜色的分布，就能**在没有真值的情况下给出 β 的分布**，从而给出任何扫描法或 SR 的 Q 误差区间；
3. QScan 压缩（κ）、β、SR 颜色偏差和留出损失选不出 Q 就能用一条可辨识性结论统一起来：叠后只能辨识 Δt*，绝对水平的误差下限由颜色斜率的离散决定。

**已有迹象（只看方向，没有定量）：** SR 对颜色的响应斜率 25–26 接近衰减斜率的倒数（约 30），说明颜色和衰减在谱上等价；Volve 测井颜色越深越“红”，与衰减方向相同，这与实测 β̂ 全部为正（中位数 0.28）方向一致。

**检验（便宜，全用已有数据）：** 实验 14 和锚定理论的半合成种子已经有逐种子的 β。先提交公式和判定规则，例如逐种子预测 β 与实测 β 的相关 ≥ 0.7，回归斜率在 0.7–1.3 内；再用 Volve 10 口井的颜色分布预测 β 的区间，和实测 β̂ = 0.28 [0.26, 0.30] 比较。

**回报：** 论文最大的一条局限被去掉，题目可以从“一种偏差”升级为“叠后 Q 的可辨识性与误差下限”。失败也有价值：说明 β 另有来源，要写进局限。

### 突破点 2：在不确定的 Q 下按非对称损失选补偿强度

**要解决的局限：** Q 定不准（突破点 1 给出区间），而补偿的误差主要来自 Q。

**依据：** 损失是非对称的：EI 实验中 Q 偏大（补偿偏弱）比偏小好约 2.5 dB；实验 11 的保守振幅（c_SR × 1.3）有效；SC-a 调小 a 能抵消过强补偿。

**做法：** 不再取 Q 的点估计，而是在 Q 的区间上取使期望损失最小的值，在非对称损失下这是一个分位数，或者取最坏情况最小。用实验 8、12、15 已有的“误差—Q 误差”曲线定损失形状。

**检验：** 需要第四批未用过的半合成数据（第一批生成器可直接调用），与 SR 点估计、真 Q 预言机比较。

**提醒：** 新颖性一般，主要是实用规则；回报上限受第一部分第 2 条约束，要先估计“SR 点估计到真 Q”的差距有多大，不值得就停。

### 突破点 3：用炮检距补上绝对水平

**要解决的局限：** 理论说绝对水平要靠外加约束；炮检距差分估 Q 不受颜色影响（decouple 试探）。

**做法：** 只用炮检距差分来定锚点 c_a，叠后扫描负责其余部分。NMO 拉伸是之前失败的原因，可以改在未做 NMO 的道集上沿时距曲线取窗，避开拉伸。

**前提和风险：** 需要叠前资料（Volve 要用户本人重新运行 `databricks auth login --profile DEFAULT`）；Q 随炮检距变化（QVO，Dasgupta & Clark 1998）已有先例，新意只在“把它作为锚点”；速度误差 ±2% 的影响已知比正则差异大。

### 突破点 4：补论文的两处实测缺口

- **诊断的分辨能力：** κ 取决于子波窗相对吸收的位置。在海底时间横向变化大的工区，固定时窗的 κ̂ 会横向变化，正好检验诊断。要先核实 U1320A 或其他候选工区的水深变化。
- **原实现：** 向程亮等 2025、Yan 等 2023 的作者索取代码。这一步要你本人联系。

## 三、不建议再投入

已有证据足够说明回报很小或不可行：调补偿增益、横向 Q 用于补偿、换选 Q 准则、常数或预测型去偏、分深度 QScan、EI 作为主线、沿层 SR（Volve）、在带内指标上与限频反 Q 竞争的 AVO 正则。

## 建议顺序

原突破点 1 已做过，见上面的更正。可选的替代是“子波窗加长缩小 β 离散”（用 `betasr.py`、`wshift.py` 的配方即可）。突破点 2 不必等它，可以直接用 β 已知的离散（1/c 上约 ±0.1，乘以 1/(1 − κ)）作 Q 区间。突破点 3 要先恢复数据访问。
