## 6. 诚实论文主张定盘（面向顶刊审稿人的稳固叙事）

1. **核心科学主张（每一条均经代码接线与原始 JSON 硬验证）**：
   - **主张 1（定理 3 在 `DSA` 域全场景成立）**：在 `U6–U9`（`+4.0~+4.8 dB` 成像 SNR、`l30` 相关噪声）与 Volve 4–25/45 Hz 上，全频无混叠 `B=300` 整炮极性翻转将 `B=1` 的 `-2.5 ~ -3.3` 档低估修正至 `±0.57` 档内；在 Volve 4–45 Hz 上揭示全频 `df=0.25 Hz`（$T_{\max}=4.0\text{ s}$）对避免 `df=0.50 Hz` 隔频混叠的必要性（`30/35/40 Hz` 真实 SNR 为 `+8.7 / +5.8 / +4.1 dB`）。
   - **主张 2（贝叶斯 `UQW1b` 相对确定性补偿的真实稳健收益）**：在合成 `U6–U9`（含非标量错位气烟囱与深浅反向 Q 误差）及真正开机（`G_HF = 1.493x`）的 Volve 4–45 Hz 过补偿端 $m=0.6$ 上，`DSA_UQW1b` 均稳定优于同域确定性 `DSA_W1b`（Volve 4–45 Hz `m=0.6`: `0.5333` vs `0.5221`, `+0.0112`；`U6–U7` `m=0.5`: `+0.1867 / +0.0381`）与 `DSA_IQ70`（`+0.0209`），同时相对纯相位 `DSA_PH` 将振幅误差 `E_amp` 降低 `35%–53%`。
   - **主张 3（`DSA` 倾角权衡与 `PSAE` 物理归因）**：明确区分缓倾（用平层 `SA` 避免结构张量扰动）与中陡倾 $>15^\circ$（用 `DSA` 防 `-0.11` 截断损失并在 Volve 上压降 `89%–95%` 上覆假频画弧）；明确证明 `PSAE` 并非简单抵消 `(2πf)^2`，在 4–25 Hz 实测中约 `61%` 来自去除 `(2πf)^2`、`39%` 来自扣除未知实测子波与浅层衰减。
2. **明确写进论文的适用边界与局限**：
   - Volve 4–45 Hz 储层 `29–40 Hz` 频段 1D 测井相关固有偏低（`r ≈ 0.15`），故真开机宽频补偿（`G_HF = 1.493x`，谱斜率压平至 `-0.0032 /Hz`）虽较 `RAW_R0` 提升 `+0.0677`、较 Stage 4H 提升 `+0.0196`，但略低于零振幅补偿的 `DSA_R0_Eq`（`-0.0118`），反映**宽频分辨率恢复与单井未加权相关指标的客观权衡**。
   - 盲井 `F-14` 在 2D 偏移速度场下存在 `-55 ~ -60 m` 深标滞后，常规 `±30 m` 窗口无法覆盖其真实主峰。
   - 当原始成像 SNR 低于 `-10 dB` 时盲结构张量倾角不可靠，应回退平层 `SA`。
