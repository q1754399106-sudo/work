# 方案：由锚点处 lasso 解的能量包络给 φ₂（机制诊断，运行前提交）

2026-11-19。对应论文初稿 `qscan_anchor_theory_20261030/PAPER_DRAFT_ZH.md` 第 5.6 节“机制尚未建模”：均匀权重 α_{a,U} = a₀⟨a⟩/⟨a²⟩ 在深层强吸收剖面 D 上给 0.294，实测 0.598。

## 0. 上次试了什么、怎么做的、差在哪（先核实，再判断是否重复）

外部审核（`README.md` 外部审核记录）把 N1“lasso 活跃集权重”评为“已试过，差 0.05–0.10，段间耦合强”。核实结果如下，涉及三件不同的事：

1. **非零系数比例权重（N1 本身）**：`qscan_anchor_theory_20261030/scripts/probe_active.py`，`logs/probe_active.log`，`THEORY_ZH.md` 第 5h 节末尾。事后探索，没有预先方案。
   - 做法：只用开发种子 9940，三个剖面（基准、S、D），真 c = 0.7/1.0/1.4。**子波和字典都取在真值处**（锚点 = 扫描 = 真 Q，读了真 Q），λ = 1/2，求一次 lasso 解 X。权重 φ₂(t) = 该时刻非零系数（|X| > 10⁻⁸）占有效道的比例，逐采样点，不平滑。代入 κ = a₀Σφ₂a/Σφ₂a²。
   - 结果：基准 0.73–0.76（实测 0.66–0.71），S 0.90–0.91（0.86），D 0.46–0.55（0.60）。方向对：D 剖面 2.7–3.0 s 只有 1–3% 的系数非零（基准 8–14%）。但基准偏高约 0.06–0.10，D 偏低 0.05–0.14。
   - 脚本里还算了系数绝对值的平均 `en`，但没有代入公式，**按系数能量加权的版本没有算过**。
2. **分段扰动**（`PLAN_SEGPHI_ZH.md`、`RESULTS_SEGPHI_ZH.md`，预先登记，三项判据都没过）：这不是活跃集权重，而是直接测各时间段的目标曲率。D 给 0.619（两锚点 0.592），说明“深层敏感度低”可以解释 D；但各段曲率之和是均匀扰动曲率的 1.2–9 倍，二次型有很强的段间耦合，D2 差 0.21、U1320A 4508-32 深窗差 0.63。“段间耦合强”指的是这一条。
3. **其他对角权重**（`THEORY_ZH.md` 5h、`PLAN_BOUND_ZH.md` 第 1 节、`scripts/dev_phi2_model.py`）：f² 信号功率、饱和 Fisher 信息两种、有效带宽、10–60 Hz 信噪比、逐时刻目标曲率（`RESULTS_PHI2_ZH.md`），都是按数据或线性最小二乘的量算的，与 lasso 解无关；最好的最大误差 0.26。

**判断：部分重复。**
- “按非零系数比例（活跃集指示）加权”与上次**实质相同**。本次在锚点处求解、加平滑窗，只改变求解点和一个对缓变 a(t) 几乎不起作用的平滑；在真 c = 1 的数据集上，锚点解与上次的真值解是同一个解。所以这一版**不作为判定对象**，只在同一批解上顺带算出，作为上次结果的复现与扩展（标为“复现”）。
- “按 lasso 解的能量包络加权”**没有试过**。理论上它比指示函数更贴近曲率：活跃集固定时，原子 k 对 J 关于 v 的二阶导的贡献为 x_k²‖∂b̂_k/∂v‖²（字典列已归一化，x_k² 就是该原子拟合进数据的能量），零系数贡献 0，小系数贡献也小，而指示函数把它们与大系数等权。上次的 f² 信号功率是数据域的量，不经过 lasso 的收缩。此外上次读了真 Q，本次只用锚点处的解。
- 本次**只检验能量包络版本**。它仍是对角权重，第 2 条的段间耦合是已知的反对理由；本次结果只能说明对角能量权重在这些剖面上够不够用，不能推翻耦合的结论。

## 1. 权重与公式（写死）

- **锚点解 r⁽⁰⁾**：现流程锚点 c_a = 1（v_a = 1）。子波 `lib.wavelets(D, TW, cm[Q·1])`，字典取在 v = v_a = 1（模型 Q），λ = 1/2，`bm.solve` 冷启动，迭代上限 20000，`sc11.prepare_sc` 给 σ、K、有效道。与各剖面原扫描在 c = 1 网格点上的求解设置相同。得到 X（原子 × 道，字典列已归一化）。
- **能量包络（判定用）**：e(t) = 有效道上 X(t)² 的平均；φ₂ᴱ(t) = e(t) 的居中滑动平均，**窗长 25 个采样点（4 ms 采样，0.1 s）**，窗口越出分析窗时只对窗内样点求平均。
- **非零密度（复现，不判定）**：n(t) = 有效道上 |X(t)| > 10⁻⁸ 的比例，同一 0.1 s 平滑，得 φ₂ᴺ。
- **公式**（符号沿用 `PAPER_DRAFT_ZH.md` 的 α_a）：
  α_a = a₀ Σ_t φ₂(t) a(t) / Σ_t φ₂(t) a(t)²，
  t 取分析窗 1.2–3.0 s 的采样点，a(t) = `lib.absorption(cm, t)`（模型 Q，c = 1），a₀ = a(1.4 s)。
- **只用锚点处已有的量**：X、模型 Q、锚点子波。不读真 c、真 Q、真子波、真反射系数。合成数据要按原配方重新生成（生成函数内部用真 c），但权重计算只接触合成后的记录 D。
- 每个数据集算一个 α，剖面取中位数，同时列出最小–最大。
- 误差 e = α（中位数）− K_ref；均匀公式误差 e_U = α_{a,U} − K_ref。

## 3. 判读规则（开跑前写死）

- **a（不损害已成立的范围）**：r ≤ 1 的 7 个剖面（基准、S、M、R1–R4）每一个都要满足 |e| ≤ |e_U| + 0.02。
- **b（D 上有改进）**：|e(D)| ≤ 0.5 × 0.304 = 0.152，即 α(D) ∈ [0.446, 0.750]。
- **c**：逐剖面列出 α、e、e_U（含 r > 1 的 D2、X1–X3），不只报平均；同时列出复现用的非零密度版本。

解读：
- a、b 都成立：能量包络权重在已有剖面上修好了 D 的大部分偏差，且不损害 r ≤ 1 的剖面。只写“机制诊断支持‘深层被 lasso 收缩后不再提供 Q 信息’的解释”；不称确认，要进论文主张须在新剖面、新种子上另写方案检验。
- b 成立、a 不成立（D 改进但 r ≤ 1 某些剖面变差）：写“适用范围缩小”——能量包络权重只作为 r > 1 时的参考，r ≤ 1 仍用均匀公式；门槛不改，不事后挑窗长或换权重。
- b 不成立：能量包络也修不好 D，记为第七种失败的对角 φ₂ 模型；与分段扰动的段间耦合结论一致。
- r > 1 的 D2、X1–X3：只描述，不判定。特别注意 X3（均匀公式已对）是否被新公式弄坏。
- 某个数据集的锚点解未收敛：如实报告，仍按结果判定；某剖面超过 1/4 未收敛，该剖面标“无效”，不参与判定。
