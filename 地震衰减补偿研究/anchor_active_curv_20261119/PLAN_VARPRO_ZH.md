# 方案二：含活跃集投影的曲率与频率归一化非零密度（机制诊断，运行前提交）

2026-11-21。接 `RESULTS_ZH.md`：能量包络 φ₂ᴱ 修好了 D，但 r ≤ 1 的 7 个剖面全部高估；非零密度 φ₂ᴺ（复现）对所需修正的相关为 0.96，但 r ≤ 1 上系统偏高 +0.04~+0.07。外部文档（2026-11-20）给出两个候选，本方案检验它们。数据与上次完全相同（12 个剖面、100 个数据集，全部用过多次），所以本结果仍是**事后机制诊断**，即使过关也只能作为新剖面预登记的依据。

## 1. 两个候选（写死）

记锚点（c_a = 1）字典 B（列归一化，`lib.dictionary`）、lasso 解 X（λ = 1/2，与上次同一求解）。原子 k 的总衰减 A_k = a(t_k)·u，b_k 为归一化列。

**VP（变量投影曲率）：**目标函数对各原子衰减失配 δ 的高斯–牛顿曲率在活跃集重拟合后为 Φ = (P⊥Q)ᵀ(P⊥Q)，其中
- 每道 j 的活跃集 𝒜 = {k : X_kj ≠ 0}，Q 的列 q_k = X_kj · ∂b_k/∂A_k（k ∈ 𝒜）；
- ∂b_k/∂A_k 用中心差分：字典按 a ± h 重建（h = 10⁻⁴ s，含列归一化）；
- P⊥ = I − B_𝒜(B_𝒜ᵀB_𝒜)⁻¹B_𝒜ᵀ，用最小二乘实现。

失配 δ_k = a_k s − a₀ s_a（s 为扫描误差、s_a 为锚点误差），对 s 求极小得
α_VP = a₀ Σ_j (P⊥Q a_𝒜)ᵀ(P⊥Q 1) / Σ_j ‖P⊥Q a_𝒜‖²，对有效道 j 求和。Φ 为对角时退化为原公式 α = a₀Σφa/Σφa²。

**NF（频率归一化非零密度，外部文档路线图 4B）：**φ₂(t) = n̄(t) / f_c(t)。n̄ 为非零密度的 0.1 s 滑动平均（与上次相同）；f_c(t) 为该时刻字典原子 b_k 的功率谱质心（nfft 1024）。代入 α = a₀Σφa/Σφa²。

**描述项（不判定）：**
- G（对角、无投影）：φ_k = Σ_j X_kj² ‖∂b_k/∂A_k‖²。用来把 VP 与能量包络的差别拆成“导数范数”和“投影”两部分。
- E、N 复算：与 `results/` 存档的 α_E、α_N 逐数据集比较，差 ≤ 0.002 才算复现成功；不成功则先报告原因，不判定。

## 3. 判读规则（开跑前写死，与上次相同的门槛）

对 VP 和 NF 分别判：
- **a：**r ≤ 1 的 7 个剖面每个都有 |e| ≤ |e_U| + 0.02；
- **b：**|e(D)| ≤ 0.152；
- **c：**逐剖面列出 α、e，包括 r > 1 的 D2、X1–X3（只描述）。

解读：
- a、b 都成立：该权重在这批用过的剖面上同时覆盖 r ≤ 1 和 D。下一步只能是另写方案、在新剖面和新种子上预登记检验；不进论文主张。
- b 成立、a 不成立：与能量包络同样的“适用范围缩小”，记为第八种不够用的 φ₂ 模型（VP 为非对角，单独注明）。
- b 不成立：照实记录。
- 外部文档的两个具体预测一并核对：NF 在 r ≤ 1 上“退化为 α_U”（|α_NF − α_U| ≤ 0.02）；VP 的非对角元为负、对角元之和大于总二次型（逐数据集统计 1ᵀΦ1 与 tr Φ 之比的中位数）。
