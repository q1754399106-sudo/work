# 噪声底能否解释实测谱比弯曲（方向 B）——方案

日期：2026-11-21。本文件在计算任何新数之前提交；脚本 `scripts/run.py` 与方案同一次提交，哈希写入 `PRE_RUN_HASHES.txt`。运行后若需改脚本，只能修 bug，并在 RESULTS 里逐条记录；判据不改。

## 1. 要检验的说法

实测（`sid_uq_20261120` 第 0 步 Z2a）：Volve 105 条 inline，2.3–2.8 s 对 1.2–1.6 s 的对数振幅谱比，10–55 Hz 二次拟合系数 c₂ 中位数 +1.32e-3 /Hz²，105/105 条 c₂ > 0（先降后平），符号与散射相反。

假说 H_N：弯曲来自加性噪声底。P_w = S_w + N_w，q_w = N_w/S_w，则

L(f) = ½ ln(P₂/P₁) = L_s(f) + ½ ln(1+q₂) − ½ ln(1+q₁)。

深窗 q₂ 随 f 增大 → L'' > 0。注意 q₁ 随 f 增大则贡献 L'' < 0；所以 H_N 要求 q₂ 的增长强于 q₁（`sid_uq` D4 未经倾角校正的信噪比反而是浅窗更低，这是事先已知的反面线索）。

## 2. 数据与原统计复现

- 数据：`field_vsp_volve_f11_20261026/cache/seismic/MIG_RAW.segy`（只读，主检出），经 `field_baselines_volve_20261029/scripts/lib13.py` 的 `cube()`；道选择与 `read_inline` 相同（xline 2100–2500 每 2 道，201 道，死道剔除）。
- 线：`field_baselines_volve_20261029/analysis/lines.json`（HEAD 版本）的 105 条。
- 谱：与 `sid_uq_20261120/scripts/step0.py` 完全相同——窗 1.2–1.6 s、2.3–2.8 s，汉宁窗，NF = 512，dt = 4 ms，逐道 |X|² 沿线平均后 `lib.smooth(·,5)`，L = ½ ln(P₂/P₁)，10–55 Hz `np.polyfit(·,2)` 取 c₂。
- 第一步先复现原统计（中位数 +1.32e-3、105/105），不一致则停下查原因，不进入判定。

## 3. 噪声谱估计（每条线、每个窗分别估）

**主方法 M1：倾角对齐的相邻道相干。**相邻两道 a、b（均为活道）在该窗内（汉宁窗后）做互相关，取 ±3 样点（±12 ms）内峰值，抛物线插值到亚样点，得时移 τ；b 的谱乘 exp(+i2πfτ) 对齐。沿线累加互谱 X_ab = Σ a·b̃*，对实部、虚部分别 `smooth(·,5)`，

Ŝ(f) = |X_ab| / n_pair，N̂_M1(f) = P(f) − Ŝ(f)，

其中 P 是同一批道对的 (|a|²+|b|²)/2 平均后 `smooth(·,5)`（与原 P 只差首尾道，原 P 仍用于原 c₂）。假设：噪声横向不相关、信号在相邻道（25 m）间只差时移。横向相关噪声（`direction_theory_20261121` 定理 3）会使 N̂ 偏低，因此 M1 对 H_N 是偏保守的。

**副方法 M2：横向二阶差分残差。**对每道 i（i−1、i、i+1 都是活道），把 i−1、i+1 按与 M1 相同的方法对齐到 i，残差 r = x_i − (x̃_{i−1}+x̃_{i+1})/2；白噪声下 E|r|² = 1.5N，故 N̂_M2 = mean|r|² / 1.5，再 `smooth(·,5)`。信号的横向曲率漏进残差，N̂_M2 偏高（对 H_N 偏宽松）。

**描述项 M3（不进判据）：**记录尾部 4.0–4.4 s 的平均功率谱，作为平稳噪声底的上界（含残余信号、可能含处理增益），只画图、报与 N̂_M1 的比值。

## 4. 去偏与重算

P̂_s,w = max(P_w − N̂_w, ε·N̂_w)，ε = 0.1；频带 10–55 Hz、平滑长度 5、NF 与原统计相同，全部固定。

L̂ = ½ ln(P̂_s,2 / P̂_s,1)，逐线二次拟合得 c₂_deb。另报：被 ε 截断的频点比例（每窗），若某窗 10–55 Hz 内截断比例 > 20%，该线标为“噪声主导”，仍计入判据。

## 5. 判据（写死）

令 m₀ = 原 c₂ 逐线中位数（第 2 节复现值），m₁ = M1 去偏后 c₂ 逐线中位数，下降比例 R = (m₀ − m₁)/m₀。

- **R ≥ 0.50 → 噪声底解释成立；R < 0.50 → 不成立，停止，不再追这条线。**
- 判据只用主方法 M1。c₂ > 0 的比例（原 105/105）与 M2 的同样量一并报告，不改变判定；若 M1、M2 结论不一致，照写，结论仍按 M1。
- 过度去偏（m₁ < −m₀）也算 R ≥ 0.5，但要在结果里指出 N̂ 可能偏大。

## 6. 闭式预测

由 M1 的 q̂_w = N̂_w / P̂_s,w，逐线计算 Δc₂_pred = 二次拟合系数{½ ln(1+q̂₂) − ½ ln(1+q̂₁)}（10–55 Hz），并分成深窗项 Δc₂⁽²⁾ = coef{½ ln(1+q̂₂)} 与浅窗项 Δc₂⁽¹⁾ = −coef{½ ln(1+q̂₁)}。

- 无截断时 c₂ − c₂_deb ≡ Δc₂_pred（代数恒等），所以逐线“预测 / 观测”的比值中位数 median(Δc₂_pred)/m₀ 与 R 同义，不是独立证据；独立信息是：
  1. 跨线 R²：c₂_obs 对 Δc₂_pred 的线性回归决定系数（弯曲的线间差异是否随噪声变）；
  2. 深窗项与浅窗项的符号与大小：H_N 的机制要求 Δc₂⁽²⁾ > 0 且占主导。
- 这些只描述，不改判定。

## 8. 局限（事先写明）

- 叠后偏移数据没有初至前纯噪声窗；M1/M2 都依赖“噪声横向不相关”，M3 依赖平稳性。
- 偏移把噪声横向涂抹，产生横向相关噪声，M1 会低估 N。因此“成立”不受此影响；“不成立”则可能部分来自 N̂ 不足，M2（偏高）用来看这个方向的敏感性，但不改判定。
- 105 条线是已见数据（原统计的同一批）。
