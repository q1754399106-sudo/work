# 追加诊断：第二关 NMO 道集上 Q 灵敏度被抵消约 80% 的来源（方案，算数之前）

日期：2026-11-21。接 `RESULTS_STEP0_ZH.md` 的 S2 一节：缓存中 Q 灵敏度 d(G/A)/d ln(1/c) 的中位数在拉平道集上为 −1.40，在 NMO 道集上为 −0.34（φ = 0.79）；无噪的拉伸运动学模型 `s2_ideal.py` 却给出 φ < 0。本步要找出差在哪里。属描述性诊断，不立项、不改第二关结论。

## 数据与复现

- 只用第二关已用的 M24–M27、40/60 Hz、c ∈ {0.5, 0.7, 1.4, 2.0}，生成器、算子、指标全部调用 `offset_q_avo_20261118/scripts/e2e.py` 和 `legacy2b/` 中的原函数，不改。不用新模型（M32 起仍不动），不加噪声。
- 观察：`events_*` 场景的反射体不用随机数，所以无噪数据 Cl 与种子无关；缓存的 gac0–2 是对 Cl 求解的结果，只通过 λ（残差原则在有噪数据上选出）依赖于种子和 SNR。因此对每个 (模型, fp, c, 场景, 算子 Q) 只需在 λ 网格（13 个值）上各解一次，再按缓存的逐列 λ 查表。
- **复现门槛 R0：** 按缓存 λ 查表得到的 gac0–2 与缓存值的中位绝对差 ≤ 1e-3，且 φ 中位数与 0.79 相差 ≤ 0.02。不过就先查实现，不解读后面的数。

## 因素与变体（每个只改一处）

φ 的计算口径与 `s2_stretch.py` 相同：逐单元 (模型, fp, 事件) 以主 c ∈ {0.7, 1.4} 拟合 d_j = gac_j(uncal) − gac_j(oracle) 对 ln(1/c) 的斜率，φ = 1 − S_nmo/S_aligned，报 24 个单元的中位数。每个变体同时报 S_aligned、S_nmo 的中位数。

| 编号 | 改动 | 检验的假说 |
|---|---|---|
| V0 | 无（缓存 λ 查表） | 复现 |
| V1 | uncal 也用 oracle 的逐列 λ | H1：抵消来自 uncal 与 oracle 选到不同的 λ（反演对拉伸失配数据的响应经 λ 体现） |
| V2 | 两者都用固定 λ（网格中每个值各算一次，报 φ(λ) 曲线；主口径取 1e-3） | 同 H1，并看 φ 是否随 λ 系统变化 |
| V3 | 饱和阻尼换成同 λ 的普通 Tikhonov（`direct`），λ 同 V2 | H2：抵消来自频率饱和阻尼（fb 截止与噪声下界 w_n） |
| V4 | 正演与算子都去掉频散相位（只留振幅衰减），其余同 V2 | H3：抵消来自频散相位——NMO 后残余时延 τ(1/m − 1) 使相关读出对 ε 一阶敏感 |
| V5 | 拉平场景的 AVO 拟合与读出也用 NMO 场景的切除掩码 keep | H4：两个场景用的炮检距不同（拉平场景不切除），拉平场景的 S 因含远道而偏大 |

V2–V4 在拉平与 NMO 两个场景上都算（V5 只改拉平场景）。

## 判定（写在算数之前）

- 某个变体单独把 φ 中位数降到 ≤ 0.30，就认定该因素是主要来源；降到 0.30–0.60 记为部分来源；仍 > 0.60 记为不是。
- 若没有单个因素达到 ≤ 0.30，报告组合（V3+V4 等）并写明"未分离"。
- H4 另看 S_aligned：若 V5 使 S_aligned 从约 −1.40 变到 −0.8 附近（`s2_ideal.py` 拉平场景用了切除，得 −0.80），记为"拉平场景基准差异"，并单独报它对 φ 的贡献。

## 开算前的预期

- H1 不太可能（两个场景 λ 中位数都是 10⁻³），预计 V1 的 φ 仍 > 0.6。
- 我先验倾向 H3（频散相位）或 H4（切除掩码），H2 次之；把握都不大。上一步已经在符号上猜错一次，这里只作记录。
