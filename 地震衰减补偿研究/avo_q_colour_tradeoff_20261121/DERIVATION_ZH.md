# 推导：AVO 中 Q 误差与反射系数颜色的最优折中

2026-11-21。本文逐式核对方向分析中给出的推导，并写全。第 5 节讨论 NMO 拉伸，其中 5.3–5.4 是看过 S2 数字后写的，属于事后内容，已标明。

## 1. 读出模型

道 x（s = sin²θ）上一个事件经补偿后，按相关方式读出振幅（`step2b.metrics` 的逐事件 G/A：输出 O 与真值 A 道在窗内相关）。在频率域里，读出权重是

  W_r,x(f) = S(f)² · bp(f)² · |R(f)|² · T_x(f) · exp[−π(u−1) a(x) f]

- S：子波振幅谱（真值 A 道和输出各贡献一个 S）；
- bp：指标带通（两边各一个）；
- R(f)：该事件局部反射系数（窗内）的谱，|R|² 是因为真值道与输出道各带一个 R；
- T_x：模型 Q 下的净传递；
- 最后一项是 Q 水平误差的残差。u = Q_模型/Q_真，即真实 t* 为 u·a(x)，a(x) 为模型下道 x 的总路径 t*。

只看振幅时，频散相位误差在相关读出中是二阶小量（与 `mm_uqavo_20261120/THEORY_ZH.md` 第 4 节相同）。记

  p_x(f) = S²bp²T_x / ∫S²bp²T_x（不含颜色、已归一化的读出权重），ρ(f) = |R(f)|²

则（略去与 x 无关的常数）

  ln Γ(x) = ln ∫ p_x(f) ρ(f) e^{−π(u−1)a(x) f} df − ln ∫ p₀^true(f) ρ(f) df    (1)

第二项是真值读出（未衰减的 S²bp²），与 x 无关，所以不进入梯度。前提是 ρ 不随角度变化（见第 6 节）。

## 2. 一阶展开

令 ρ(f) = ρ₀ e^{β(f − f_c)}（对数线性颜色）。则 (1) 的第一项为

  ln ∫ p_x e^{(β − πε̃a)f} df + 常数 = K_x(β − πε̃ a(x)) + 常数

其中 ε̃ = u − 1，K_x(t) = ln ∫ p_x e^{tf} df 是 p_x 的累积量生成函数。K_x(t) = t f̄ₓ + ½ t² σ²_x + …，因此

  ln Γ(x) = β f̄ₓ − π ε̃ a(x) f̄ₓ + ½(β − πε̃a)² σ²_x + …    (2)

前两项就是方向分析里的式子，**核对无误**。ε̃ = u − 1 与 ε = ln u 只差 O(ε²)；蒙特卡罗用精确的 u = e^ε。

对非对数线性的 ρ（薄层陷波、测井窗的随机起伏），把 β 定义为"读出质心平移 δ 时 ln∫pρ 的导数"：

  β_d = Cov_{p₀}(f, ρ_d) / [Var_{p₀}(f) · E_{p₀}(ρ_d)]    (3)

ρ 平滑时它等于 ln ρ 的斜率。但设计族改变的不只是质心（第 3 节的 fs 族是按比例缩放），所以 (3) 只是近似。S1 检验的就是这个近似够不够用。

## 3. 设计族与梯度误差

**设计族（sat → fs）。** 令 r(x) = a(x)/a(0)，

  p_x^γ(f) = r^γ p₀(r^γ f)    (4)

γ = 0 时各道读出权重相同（炮检距一致，sat）。γ = 1 时远道读出谱按 1/r 压缩，于是 a(x)·f̄ₓ 与 x 无关（f·t* 不变，fs）。在这个族里质心精确等于 f̄ₓ = f̄₀ r^{−γ}，所以

  a(x) f̄ₓ = â₀ f̄₀ r^{1−γ}，β f̄ₓ = β f̄₀ r^{−γ}

**梯度。** dGA 定义为 ln Γ 对 s 的最小二乘斜率 sl_s(·)。Shuey 拟合得到的 G/A 误差还要乘反射层因子 F = 1 + (B/A)β_s − (B/A)²α_s（`uq_avo_20261118/THEORY_K_ZH.md`），F 对式 (2) 的每一项都相同，所以不改变最优点和误差比，只改变 RMSE 的绝对量级。由 (2)：

  dGA(γ) ≈ β f̄₀ sl(r^{−γ}) − π ε â₀ f̄₀ sl(r^{1−γ})    (5)

**线性化。** 令 a(x) = â₀(1 + h s)，f̄ₓ = f̄₀ + g s，代入 (2) 并对 s 求导（在 s = 0 处）：

  dGA = β g − π ε â₀ (h f̄₀ + g)

这就是方向分析的式子，其中 **k = 1**。k ≠ 1 有两个来源：

1. **有限炮检距范围上的非线性。** 最小二乘斜率是对整个 s 范围取的，r(x) 在远道可达 1.3–2，sl(r^{1−γ}) 与 sl(r) − γ·sl(r)·… 的线性关系不再成立。按 (5)，"真"的 sat 灵敏度是 H ≡ f̄₀·sl(r)，而不是 h f̄₀ = f̄₀·sl(ln r)。r 是凸的，所以 H > h f̄₀。按方案冻结的口径，k 由 γ = 0.5 处的有限差分得到（只用设计与几何）：

     k = −[S_Q(0.5) − S_Q(0)] / [π â₀ g(0.5)]，S_Q(γ) = ∂dGA/∂ε |_{β=0}

   这一定义下，k 是 Q 项对 g 的平均斜率；它在实际几何下明显大于 1（见结果）。
2. **设计族不只是平移质心。** 这部分进入的是 β 的定义 (3)，而不是 k。

**一般形式。** 把 H 记作 sat 时的 Q 灵敏度系数（H = −S_Q(0)/(π â₀)），写成 dGA = β g − π ε â₀ (H + k g)。方向分析的版本对应 H = h f̄₀。下面的最优化对任何 H 都成立，只是 g* 按 H 缩放。

## 4. 最优 g、误差比与端点

β 与 ε 独立、零均值，E β² = σ_β²，E ε² = σ_ε²：

  E[dGA²] = σ_β² g² + π² â₀² σ_ε² (H + k g)²

对 g 求导并令其为零：

  σ_β² g + π² â₀² σ_ε² k (H + k g) = 0  ⇒  g* = −H · kλ/(1 + k²λ)，λ = π² â₀² σ_ε² / σ_β²    (6)

代回，H + k g* = H/(1 + k²λ)：

  MSE* = σ_β² H² [k²λ² + λ]/(1 + k²λ)² = σ_β² H² λ/(1 + k²λ)，MSE_sat = σ_β² H² λ

  **MSE*/MSE_sat = 1/(1 + k²λ)**，MSE_fs/MSE_sat = 1/(k²λ)    (7)

（fs：g = −H/k，Q 项为 0，只剩颜色项 σ_β² H²/k²。）**核对无误**；方向分析里的 h f̄₀ 应读作 H，k = 1 是线性极限。

**离 fs 的比例。** γ̃ = −k g/H ∈ [0, 1]，于是 γ̃* = k²λ/(1 + k²λ)。方案冻结的口径用 γ̃ = −k g/(h f̄₀)，相当于取 H = h f̄₀；两者相差 H/(h f̄₀) 倍（结果中报告这个比值，并给出用 H 的事后口径）。

**读法。**

- λ 是"Q 误差在梯度中的标准差"与"颜色误差在梯度中的标准差"之比的平方，两者都按单位 g 计。
- λ ≫ 1（Q 很不准、反射系数接近白）时接近 fs；λ ≪ 1（Q 已校准、颜色起伏大）时停在 sat。
- 增益只取决于 k²λ。σ_ε 从 0.447 降到 0.09，λ 就降为原来的 1/25。所以炮检距谱比校准一旦做了，这个折中几乎没有剩余价值，这是 (7) 的直接推论。

**均值颜色。** 若 E β = β̄ ≠ 0，(6)、(7) 中的 σ_β² 应换成 E β² = β̄² + Var β（主口径），而且 fs 端带有确定性偏差 β̄ g。若 β̄ 已知可以扣掉，那就要用 Var β，但这是另一个需要验证的方法组件。

**噪声。** 未计入。fs 端是对远道做低通，有噪时会少放大噪声，但会改变残差原则选出的 λ，留给第 1 关。

## 5. NMO 拉伸

### 5.1 运动学（看数之前）

NMO 后 y(t₀) = d(t_x(t₀))。在事件附近，y(t₀e + δ) ≈ d(t_xe + mδ)，m = dt_x/dt₀ < 1，所以 Y(f′) = D(f′/m)/m：谱向低频压缩。数据上已有的 Q 损失 e^{−πf a_true} 在 f′ 域变成 e^{−π f′ a_true/m}，即等效 t* 为 a/m。如果读出权重和参照子波也一起拉伸，Q 项 (a/m)·f̄′ = (a/m)·m f̄ = a f̄ 不变。**纯拉伸不改变 Q 灵敏度**。拉伸只有通过"不随拉伸变化"的部分才起作用：固定的指标带通、未拉伸的参照子波 A 道、按 a 而不是 a/m 补偿的算子。

### 5.2 方案里的预期

我在 PLAN 第 1 节写过：按上式粗算，第二关的这些"不随拉伸变化"的成分会**放大** t* 随角度的增长（φ < 0），不会抵消。

### 5.5 更正：Q 误差应放在算子一侧（事后，`scripts/s2_ideal_operr.py`）

第二关比较的是同一数据（真值 Q 固定）用两种算子 Q 的结果，所以 Q 误差的因子是 exp(−π f′ ε a)：算子在 t₀ 域按 a 补偿，不经过 1/m。数据一侧的 a/m 只进入 oracle 的基线（残余损失 exp[−π f′ a(1/m − 1)] 与拉伸谱）。于是 NMO 场景的 Q 灵敏度约为 −π a(x) f̄′_x（再经 G/A 拟合），f̄′_x 是拉伸后、经固定带通与未拉伸参照加权的读出质心，随炮检距下降。这就是抵消的方向。数值见 `RESULTS_S2SRC_ZH.md`。

### 5.3 S2 的观测（事后补写）

缓存第二关数据测得 φ 的中位数为 0.79（见 RESULTS）。也就是说，在第二关的处理链里，Q 灵敏度在 NMO 道集上确实小了约 4/5。我开算前的预期方向是错的。

### 5.4 理想化闭式核对（事后，描述；`scripts/s2_ideal.py`）

> **2026-11-21 追加更正（`RESULTS_S2SRC_ZH.md`）：** 本节“理想模型给出 φ < 0、拉伸放大”是错的——`s2_ideal.py` 把 Q 误差放在了数据一侧（ε·a/m），而 uncal 与 oracle 的差别在 t₀ 域的算子里（ε·a）。改正后理想模型 φ = 0.77、S_NMO = −0.33，复现缓存。抵消来自：拉平场景不切除、多用远道（浅层为主），以及 t₀ 域算子作用于拉伸数据（深层为主，读出质心远道只降约 10%）。λ、饱和阻尼、频散都不是来源。“拉伸 ≈ fs 端”仍不成立（幅度不够），同炮检距下 φ 为 0.48–0.57。

用 5.1 的式子构造无噪、理想补偿的读出：K1 = 第二关的做法（t₀ 域按 a 补偿，参照未拉伸）；K2 = 按 a/m 补偿；K3 = 再把参照也拉伸。三者都经过 bp。另有 SH：把 K1 送进与第二关相同的振幅域 Shuey 拟合，含精确 Zoeppritz 系数和 1.3 拉伸切除。

- SH 复现缓存中的拉伸偏差（oracle、NMO、逐事件 G/A）：R² 0.985，斜率 1.02，中位绝对差 0.03。说明理想模型抓住了拉伸本身。
- 但理想模型的 φ 都为负：K1 −1.06，K2 −1.26，K3 −0.97，SH −0.67。K3 不为 0，是因为指标带通 10–fp 固定在 f′ 域：拉伸把更多谱能量挪进带内，物理有效频率反而升高。
- 理想模型的 Q 灵敏度（中位数）：拉平场景 −0.80，NMO 场景 −1.27。缓存中对应为 −1.40 和 −0.34。

**结论：** "NMO 拉伸本身靠近 fs 端"这一推论**不成立**。拉伸运动学加上第二关的读出方式，预测的是放大。第二关观测到的约 79% 抵消来自处理链中理想模型没有包含的部分：频率饱和阻尼的噪声界、残差原则下的反演对拉伸失配数据的响应、窗内 G/A 比值的非线性。两种场景下 λ 的中位数都是 10⁻³，所以不是"拉伸失配迫使 λ 变大"。具体是哪一部分，本步没有分离出来。因此本步给不出"最优去拉伸比例"，原推论里的这一项撤回。

## 6. 未检验的假设

- 反射系数谱不随角度变化（薄层调谐实际随角度变化）。
- 事件之间相互独立；ε 是整体 Q 水平误差，所有道相同。
- 只算振幅，不计频散相位；无噪声。
- 设计族只取 (4) 这一种按比例缩放的族。其他族（例如只平移质心）的 k 不同，但 (6)、(7) 的形式不变。
