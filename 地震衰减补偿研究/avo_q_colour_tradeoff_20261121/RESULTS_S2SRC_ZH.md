# 追加诊断结果：第二关 NMO 道集上 Q 灵敏度抵消约 80% 的来源

日期：2026-11-21。方案在算数之前提交（`a83165c`，`PLAN_S2SRC_ZH.md`）。数字来自 `results/s2_source.json`（V0–V5），事后部分来自 `results/s2_ideal_operr.json`。只用第二关已用的 M24–M27、无噪数据，调用第二关原函数，没有新模型。8 进程，约 2.1 小时。

## 一句话

**抵消有两个来源，都不是 λ、频率饱和阻尼或频散：**

1. **比较基准不同（约占 1/3）：** 第二关的拉平场景不做切除，用全部 11 道；NMO 场景在拉伸切除 1.3 之后浅层只剩约 5 道。拉平场景的 Q 灵敏度因为含远道而偏大。
2. **算子在 t₀ 域作用于已拉伸的数据（其余部分）：** uncal 与 oracle 的差别在算子里，算子在 t₀ 域按 a 补偿，Q 误差项的指数是 ε·a，不是 ε·a/m。远道拉伸后读出谱向低频挪动，再加上拉伸使远道振幅偏低、G/A 比值随之非线性，Q 项随炮检距的增长就变慢了。

上一步 `s2_ideal.py` 把 Q 误差放在数据一侧（ε·a/m），这是我的错误，所以得出“拉伸放大”（φ < 0）。改到算子一侧后，理想无噪模型复现了缓存。

## 按方案判定

φ 口径同 `s2_stretch.py`（24 个单元的中位数）。

| 变体 | 改动 | φ | S_拉平 | S_NMO | 判定 |
|---|---|---|---|---|---|
| R0 / V0 | 缓存 λ 查表复现 | 0.79 | −1.40 | −0.34 | 复现：与缓存 gac 的中位绝对差 9e-16（门槛 1e-3） |
| V1 | uncal 也用 oracle 的 λ | 0.76 | −1.40 | −0.36 | H1（λ 差异）**不是** |
| V2 | 固定 λ（饱和阻尼） | λ ≤ 3e-4 时 0.79–0.81；1e-3 时 0.70；1 时 0.03 | | | λ 不是来源；正则越强，抵消反而越少 |
| V3 | 普通 Tikhonov 代替饱和阻尼 | λ ≤ 3e-5 时 0.81（与 V2 相同） | | | H2（饱和阻尼）**不是** |

按预设规则，没有单个因素把 φ 降到 0.30 以下，所以四个候选假说下的结论是“只分离出部分来源（切除基准）”。在 λ → 0、无噪、不正则的极限下 φ 仍有 0.81，说明剩余部分出在数据和读出本身，不在反演。

我的开算前预期：H1 不是，对；H3 是，错；H4 是，部分对。

## 事后：改正理想模型后复现（`scripts/s2_ideal_operr.py`，描述）

做法同 `s2_ideal.py`（拉伸运动学、未拉伸参照、固定带通 10–fp、精确 Zoeppritz、振幅域 Shuey 拟合），只改一处：Q 误差乘在算子上，因子为 exp(−π f′ ε a)，不再是 exp(−π f′ ε a/m)。

| | 理想（改正后） | 管线（缓存或 λ → 0） |
|---|---|---|
| S_拉平，全部炮检距 | −1.25 | −1.40 / −1.43 |
| S_拉平，NMO 切除 | −0.80 | −0.90 |
| S_NMO | **−0.33** | **−0.34 / −0.33** |
| φ（拉平用全部炮检距，即第二关口径） | **0.77** | **0.79** |
| φ（拉平同样切除） | 0.48 | 0.54–0.57 |

按事件（理想模型）：

| 事件 | 保留道数 | φ 全部 | φ 同切除 | 只看读出质心的 φ（K1op） | 远道读出质心 / 拉平 | 远道 m |
|---|---|---|---|---|---|---|
| 0.38 s | 5 | 0.84 | **0.24** | 0.27 | 0.94 | 0.78 |
| 0.65 s | 8 | 0.65 | 0.48 | 0.38 | 0.92 | 0.76 |
| 0.90 s | 11 | 0.73 | **0.73** | 0.57 | 0.88 | 0.72 |

读法：

- **浅层基本是比较基准的问题。** 0.38 s 处切除去掉 6 道远道，拉平场景的斜率从 −0.43 变成 −2.04（远道 a(x) 凸）。
- **深层基本是拉伸机制。** 0.90 s 处不切除，两种口径一样，φ 为 0.73。
- **拉伸机制分两部分：**
  - 远道读出谱的质心下降。拉伸把谱压低，但固定带通和未拉伸的参照把它托住了，远道只低 6–12%，远小于 1 − m（22–28%）。这部分单独给出 φ 0.27–0.57。
  - 其余来自振幅域 G/A 拟合的非线性：拉伸让远道振幅本身偏低（oracle 的 G/A 偏差约 −0.5），同样的 Q 误差在 B/A 上的影响就变小。
- **离 fs 端还远。** fs 要求读出频率按 1/r 随炮检距下降，这里只下降约 10%。

## 对上一步结论的修正

- `RESULTS_STEP0_ZH.md` S2 一节与 `DERIVATION_ZH.md` 5.4 节说“拉伸运动学预测放大（φ < 0）”，**这个说法错了**：原因是误差放错了位置。改正后：
  - 拉伸运动学本身就预测抵消。
  - 第二关的 φ = 0.79 由“切除基准不同”和“t₀ 域算子作用于拉伸数据”两项完全解释，不需要噪声、λ 或反演响应。
- “拉伸 ≈ fs 端”仍不成立，但原因改了：方向对（远道有效频率下降），幅度远不够（读出质心只降约 10%）。“最优去拉伸比例”仍不给。
- 第二关“NMO 道集上 Q 不是主要问题”的读法要收窄：
  - 浅层主要因为 NMO 场景切掉了远道，这是比较口径的问题，不是物理抵消。
  - 同样炮检距下，NMO 道集的 Q 灵敏度约为拉平道集的 0.4–0.5（φ 0.48–0.57）。
- S2 原判定（按冻结规则过）不变；方向 A 不立项不变。

## 局限

- 只有 4 个浅模型、3 个孤立事件、拉伸切除 1.3；没有薄层与密集反射。
- 理想模型与管线在拉平全部炮检距时仍差约 0.15（−1.25 对 −1.40），没有追。
- “G/A 非线性”那部分是按 SH 与 K1op 的差推出的，没有单独做变体。
