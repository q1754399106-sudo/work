# 方向 A 第 0 步：AVO 中 Q 误差与反射系数颜色的最优折中（方案，算任何数之前提交）

日期：2026-11-21。本步只用闭式计算、蒙特卡罗（闭式 Γ，无正演、无噪声）和已用过的数据：开发模型 M1、M12，第二关模型 M24–M27 的缓存分数（`offset_q_avo_20261118/results/a2_*.json`），Volve 10 口井的 AC/DEN 测井（实验 9 起已多次使用）。**不建新模型，M32 起仍不用。** 蒙特卡罗的随机反射系数（薄层、稀疏随机）用种子基数 62 000 000，它们只是谱的样本，不是检验模型。

## 1. 要检验的推导（摘要；完整推导在 `DERIVATION_ZH.md`）

一个事件在道 x（s = sin²θ）上的读出振幅，经补偿后按权重 W_r = S²·bp²·|R(f)|²·T_x(f) 读出（S 子波谱，bp 指标带通，R 该事件的反射系数谱，T_x 模型 Q 下的净传递）。记 p_x(f) = S²bp²T_x / ∫(…)（不含颜色的归一化读出权重），ρ(f) = |R(f)|²，u = Q_模型/Q_真，ε = ln u，a(x) 为道 x 的总路径 t*。只保留振幅：

  ln Γ(x) = ln ∫ p_x(f) ρ(f) exp[−π(u−1)a(x) f] df − 常数

一阶累积量展开（ρ 在带内取对数线性斜率 β）：ln Γ(x) ≈ 常数 + β f̄ₓ − π ε a(x) f̄ₓ。令 a(x) = â₀(1 + h s)，f̄ₓ = f̄₀ + g s，对 s 求导得对数梯度误差

  dGA = β g − π ε â₀ (h f̄₀ + k g)

（Shuey 拟合的 G/A 误差 = dGA × 反射层因子 F，F 对两项相同，不影响最优点和误差比，见 `uq_avo_20261118/THEORY_K_ZH.md`。）一阶展开下 k = 1；k ≠ 1 来自设计族改变的不只是谱的质心。β、ε 独立、零均值时对 g 求 E[dGA²] 极小：

  g* = −h f̄₀ · kλ/(1 + k²λ)，λ = π² â₀² σ_ε² / σ_β²，MSE*/MSE_sat = 1/(1 + k²λ)

端点：g = 0 为炮检距一致（sat）；g = −h f̄₀/k 为 f·t* 不变（fs）。以下用"离 fs 的比例" γ̃ = −k g/(h f̄₀)，闭式最优点 γ̃*_CF = k²λ/(1 + k²λ)。

**开算前我对"NMO 拉伸靠近 fs 端"这条推论的看法（可能错）：** 拉伸在时间上同时作用于子波和已经印在数据上的 Q 损失。拉伸后频率 f′ = m f（m = dt_x/dt₀ < 1），Q 残差在 f′ 域的等效 t* 是 a(x)/m，而读出质心也按 m 降低，两者相乘不变；所以只有当读出权重不跟随拉伸（参照子波未拉伸）、或补偿算子在 t₀ 域用 a(x) 而不是 a(x)/m 时，才出现净效应。第二关的实现正是这两种情况，按我的粗算，净效应的方向是**放大** t* 随角度的增长（φ < 0），而不是抵消 60–75%。另外，第二关 NMO 上"Q 误差只贡献约 0.05"用的是逐事件 |G/A 误差| 的平均：当拉伸带来约 0.5 的同号偏差时，|S + q| − |S| ≈ ±q，c < 1 与 c > 1 两侧会相互抵消，0.05 小未必说明 Q 灵敏度变小。S2 就是用缓存数据把这两种解释分开。

## 2. 量的取法（写死）

- **几何与 Q：** `offset_q_avo_20261118/scripts/legacy2b/gate1.py` 的层状模型（4 层、炮检距 0–1500 m 每 150 m、3 个事件 0.38/0.65/0.90 s）。模型 Q 取 M1、M12、M24、M25、M26、M27（6 个，全部已用）。a(x) = a0 + ax(x)（`a0_ax`）在事件样点上取值；s 用 `SIN2`。
- **â₀** = a(0)；**h** = ln a(x) 对 s 的最小二乘斜率（11 道全用；拉平场景无切除）。
- **读出权重 p₀(f)** = RIC_fp(f)²·bp(f)²，bp 与 `step2b.bp` 相同（10 Hz 到 fp，两侧余弦斜坡 5 Hz、8 Hz）；T = 1（理想补偿，模型 Q 下各道一致）。子波 fp = 40、60 Hz。频率网格 0–150 Hz，Δf = 0.25 Hz。
- **设计族（sat→fs）：** p_x^γ(f) = r^γ p₀(r^γ f)，r = a(x)/a(0)，γ ∈ [0, 1.5]，步长 0.025。γ = 0 为 sat，γ = 1 为精确的 f·t* 不变。f̄ₓ(γ) = ∫ f p_x^γ df，g(γ) = f̄ₓ 对 s 的最小二乘斜率；f̄₀ = f̄ 在 x = 0 处。
- **k**（只用设计和几何，不看颜色）：β = 0 时用 ε = ±0.01 的有限差分得 Q 灵敏度 S_Q(γ) = ∂dGA/∂ε；k = −[S_Q(0.5) − S_Q(0)] / (π â₀ g(0.5))。并报告 h f̄₀ 与 −S_Q(0)/(π â₀) 的一致程度（检查一阶模型本身）。
- **dGA**：ln Γ(x) 对 s 的最小二乘斜率（11 道）。
- **σ_ε：** 不校准 0.447（全研究沿用的先验 σ_lnQ）；校准后 0.09（第二、三关 ln(ĉ/c) 均方根 0.069–0.125 的代表值）。ε ~ N(0, σ_ε²)，u = e^ε，同一 u 用于所有道（整体 Q 水平误差）。
- **β 与 σ_β（只用反射系数谱本身和 p₀，不看设计族）：** 对每个反射系数样本 d，β_d = Cov_{p₀}(f, ρ_d) / [Var_{p₀}(f)·E_{p₀}(ρ_d)]（读出质心平移一个 δ 时 ln∫pρ 的导数，ρ 平滑时等于 ln ρ 的斜率）。σ_β² = E[β_d²]（**对零取二阶矩，主口径**：算子不知道颜色均值）；对均值取方差的口径与 ln ρ 对数线性拟合斜率只作描述。λ 用这个 σ_β。
- **反射系数谱来源（三类，每类单独判定）：**
  - **A. Volve 测井**：TIE_WELLS 中 11 口井，按 `multiwell_tie_volve_20261028/scripts/tie.py` 的 `tie_log`（AC/DEN、5 点滑动中值、按井分层点拉伸到双程时、1 ms）重算 rc，保留锚定段 ≥ 0.15 s 的井。窗：Hann，长 6/fp（即读出窗 ±3/fp），步长为半窗长，每窗一个样本。蒙特卡罗按窗等概率重抽。
  - **B. 薄层**：两个反射系数 (1, q)，q ~ U(−1, 1)，时差 τ ~ U(2, 40) ms，放在同样的 Hann 窗中心。
  - **C. 稀疏随机**：2 ms 网格上 30% 的点取 N(0, 1)（与第二关 dense 场景和 `oqa.reflectivity` 同族），同样的 Hann 窗。
- **蒙特卡罗：** 每个单元（来源 × 模型 × fp × 事件 × σ_ε = 3 × 6 × 2 × 3 × 2 = 216）抽 N = 20 000 个 (ρ_d, ε_d)，各 γ 用公共随机数。精确计算 Γ(x; γ)（不做累积量展开），MSE(γ) = E[dGA²]。γ*_MC 为 MSE 网格最小点附近 ±5 个点的二次拟合顶点，换成 γ̃*_MC = −k g(γ*_MC)/(h f̄₀)。比值 ratio_MC = MSE_MC(γ*_MC)/MSE_MC(0)；闭式 ratio_CF = 1/(1 + k²λ)。自助（200 次重抽 draws）给出 γ̃*_MC 的标准误，只作描述。
- **代数自检（不参与判定）：** 把 ρ_d 换成严格对数线性 exp(β_d f)、β_d ~ N(0, σ_β²)，重复同一流程；预计与闭式相差远小于门槛。

## 3. 检验项与写死的停止规则

**S1（闭式与真实谱的蒙特卡罗一致）：** 对 A、B、C 每一类分别取 72 个单元：
- median |γ̃*_MC − γ̃*_CF| ≤ 0.01，且
- median |ratio_MC − ratio_CF| ≤ 0.05。

三类都满足才算 S1 通过。另报告各类的 90% 分位数（描述）。

**S2（拉伸对 t* 增长的抵消，第二关缓存，M24–M27）：** 用 `a2_M2{4..7}_f{40,60}.json` 中 method = uncal、oracle，scene = events_aligned、events_nmo，c ∈ {0.5, 0.7, 1.4, 2.0} 的行；gac_j 是干净数据上逐事件带符号的 G/A 误差。
- d_j = gac_j(uncal) − gac_j(oracle)（同模型、fp、c、snr、种子配对），先对 (snr, 种子) 取中位数。
- 灵敏度 S_scene(模型, fp, j) = d_j 对 ln(1/c) 的最小二乘斜率，主口径用 c ∈ {0.7, 1.4}（近线性区），四个 c 的斜率只作描述。
- φ = 1 − S_nmo / S_aligned，24 个单元（4 模型 × 2 fp × 3 事件）。
- **S2a：** median φ ∈ [0.50, 0.85]。
- **S2b：** 观测 Δ_obs = 逐行 [mean_j |gac_j(uncal, nmo)| − mean_j |gac_j(oracle, nmo)|] 在 c ≠ 1 行上的中位数；预测 Δ_pred = 逐行 [mean_j |gac_j(oracle, nmo) + (1 − φ_单元) d_j(拉平同键行)| − mean_j |gac_j(oracle, nmo)|] 的中位数。要求 Δ_pred 与 Δ_obs 同号且 Δ_pred/Δ_obs ∈ [0.5, 2]。另算 φ = 0（不抵消）时的 Δ_pred⁰：若它也落在 [0.5, 2]，就说明 0.05 本身分不出两种解释（记录，不改判定）。有噪指标 ga 的 uncal − oracle（第二关报告约 0.048）只作描述。
- S2 = S2a 且 S2b。

**S3（不校准时值不值得）：** 来源 A（Volve 测井）、σ_ε = 0.447 的 36 个单元，用**闭式选出的** γ*_CF（可实现的选择）在蒙特卡罗中算 RMSE 降幅 1 − √[MSE_MC(γ*_CF)/MSE_MC(0)]，中位数 ≥ 30% 通过。B、C 与 σ_ε = 0.09 的降幅照实报告（预计校准后只有 2–17%）。

**判定：**
- S1 或 S2 任一不过 → 方法不立项，只保留推论（反面定理的定量形式、拉伸与 Q 灵敏度的关系）作为机制结论。
- S1、S2 都过但 S3 不过 → 不立项（收益太小），同样只保留机制结论。
- 三项都过 → 立项，只写第 1 关方案草稿，不跑新模型。

门槛写死，不过就是不过，不放宽。

## 4. 这一步没有算进去的东西（预先说明）

- **噪声代价：** fs 端要求远道有效谱压低（低通），本模型无噪，不计噪声放大或压制。远道低通在有噪时反而少放大噪声，但 λ 选择也受影响；第 1 关才处理。
- **频散相位：** 只算振幅；u ≠ 1 时的相位误差在相关读出里是二阶效应。
- **颜色随炮检距不变：** 假设反射系数谱不随角度变（薄层调谐实际随角度变，属于另一项误差）。
- **事件间独立、零均值：** σ_β 用对零的二阶矩，等于假定算子不使用颜色先验。
