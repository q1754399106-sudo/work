# 研究任务书：未知Q条件下兼顾稳定性与保幅的吸收补偿

版本：2026-10-19；执行对象：能够访问文件与官方 MATLAB Engine 的 AI。

## 1. 目标与交付边界

在已验证的 Frozen 主版上，优先研究噪声/Q不确定性如何改变补偿强度；之后才研究结构可靠性。必须让用户知道：改善发生在哪里、幅度多大、代价是什么、有没有最差失败、是否优于相同先验的一步法。
本包提供精简主版、历史证据、可执行入口和未来验收器；不把尚未实现的误差协方差新方法写成已验证成果。

## 2. 保留、降级与停用决策

| 内容 / Component | 决策 / Decision | 理由 / Reason |
|---|---|---|
| 精确分层射线、完整非稳态算子、强一步基线 | 保留基础能力 | 分离近似误差，公平检验分步流程 |
| 噪声窗MAD与残差选参 | 保留 | 比预知合成噪声更实际；中炮检距有收益，仍需处理估计方差 |
| 步间协方差白化 | 保留 | 第一阶段将噪声变色；不代表所有误差都得到解决 |
| 保守先导+AVO子空间保护 Frozen | 默认研究主版 | 三模型等权整体误差较常规分步降低约6.48%，有局部保幅代价 |
| 有效Q/近似主频估计 | 保留为有前提的输入模块 | 不读取真Q；不是逐层Q恢复，也不是任意实测资料全盲估计 |
| 时频惩罚、经验谱稳健项、RawH、EdgeAware、Combined | 不进入默认主链 | 未显示稳定净收益或有明显偏差；历史报告仍保留 |

Frozen仅为内部版本代号。保守先导倍数4、gamma=10、噪声目标倍数1及第一步lambda_x=0.001均为自选设置。只有炮检距域使用AVO投影；横向剖面不投影。新版入口不加载已停用候选搜索。

## 3. 原理及当前问题

观测 d=G*s+n。正则化抑制弱信息方向的噪声增益，但增加恢复偏差。
固定第一步逆M时，噪声协方差变为 C1=M*Cn*M'；只白化原白噪声不够。
非稳态矩阵一般不满足 Gtotal=X*A；必须保留复合误差。
多道约束 ||H*s||^2利用邻道可预测性，但相干噪声也可预测，断层/尖灭/弱反射可能被惩罚。
Frozen从保守补偿先导学习H，并使用 Hprotected=Hp*(I-P)，避免结构项直接惩罚指定二项AVO子空间。其他正则化、错Q和角度误差仍能改变振幅。
未知Q时 d=Ghat*s+e_model+n，当前选参主要按n确定残差目标，可能把模型失配也当成必须恢复的信号。

## 4. 现有起点与适用范围

历史18dB整体相对误差，按模型等权：普通一步0.734007、常规分步0.733775、Frozen分步0.686253、Target08分步0.733758。该平均不是地质概率加权。
强吸收Frozen0.763758、Target08 1.004657；薄层弱反射误差Frozen1.178977、Target08 1.355316。不能只看整体均值。
相同结构先验下，主试验一步/分步的模型平均差异最大约0.000618，不能宣称分步本身优越。
历史真值：零相位Ricker，三个模型真实主频45/70/80Hz，名义参考52/60/92Hz；dt=2ms，601样点，11道，炮检距0:150:1500m。合成随机噪声18/12dB；相干干扰另加，不包括在名义白噪声SNR中。
Shuey二项、理想拉平、已知速度/几何、列时变吸收矩阵、独立校准道集，单个有效Q。尚非真实NMO、Zoeppritz、波动方程实测验证。

## 5. 分阶段工作

### P0：恢复与检查，不改算法

1. 校验SHA256，阅读当前效果报告及不利结果。
2. 连接ResearchMATLAB，记录名称、版本、sqrt(144)=12；不得启动新实例。
3. 执行validate与regression，保存实际日志、求解器误差、会话状态保留结果。
4. regression只检查历史一个固定案例，不算新独立实验。replay以原估计Q/种子复跑126个观测、四方法504行，亦不算新地质泛化。
5. 所有原文件保持不变，候选开发在新的副本中进行。

### P1：噪声与Q误差共同选参，优先完成

假设：允许合理模型失配进入误差预算，可减少强吸收下过拟合与失败尾部，同时保留可恢复频带。
分别做 NoiseUncertaintyOnly、QModelErrorOnly、CombinedUncertainty，不能先堆叠全部改进。

建议原型：
- 重新生成多个独立校准观测；按噪声相关性选择重采样，不把历史局部profile范围直接当置信区间。
- 联合估计Q和受限子波，保留相关性；增加显式模板失配情景。
- 固定保守先导sp，计算 ek=(Gk-Gref)*sp，估计均值be与收缩协方差Ce。
- 在明确简化条件下使用 Ceff=Cn+Ce，最小化 ||Ceff^(-1/2)*(Gref*s-d+be)||^2+lambda*R(s)+mu*||H*s||^2。
- 分步路线传播Ceff并重新推导白化目标；完整一步使用相同误差信息。
- 先固定先导与协方差。若Ce依赖优化变量，不能遗漏logdet或相关误差项。相干噪声单独处理，不能随意归入零均值Q误差。
- 当前未知量是带限波形s，G不直接含主频；主频通过Q校准和信号先验传递。改成G(Q)*W(f)*r时才显式放进正演。

必须对照：同等更强普通阻尼、仅噪声协方差、同先验一步、无结构版本。防止把单纯欠补偿误称为新机制。

### P2：补偿可靠性与结构可靠性（P1之后）

选参增加局部噪声增益和Q扰动敏感性诊断；不能只用观测预测误差。
结构方面分别测试倾角/时移对齐、Huber预测残差、独立留道可靠性；不把相关性等同于真反射概率。
优先检查尖灭尾部、弱反射、断层邻域、残余NMO与AVO截距/梯度。
一次只改变一个机制，确认净收益再组合。低维时变Q是后续任务，不立即逐样点估Q。

## 6. 实验约定和“有效”的定义

NEXT_EXPERIMENT.json中的阈值是本次自选的工程目标，不是统计显著性界限。可以在开发阶段调整，但必须在独立测试前冻结并保存哈希。
至少2个开发模型和4个此前未用于选参的新测试地质模型；每测试模型至少3份独立校准噪声、每校准6份观测噪声。独立校准种子与观测种子写入CSV，不能仅换观测噪声却宣称验证Q估计方差。
白噪声主试验与有色/相干/脉冲压力分开报告。近似主频、非Ricker形状/相位、速度及NMO误差应独立变化。
真Q、真子波、干净答案只能生成与事后评分，不用于候选选择。所有方法使用同一观测、估计Q、信息量和调参预算。

候选相对Frozen的目标：主试验等模型平均波形误差降低至少5%；每模型每SNR均值退化不超过2%；事件、弱反射及AVO误差退化不超过5%（近零时绝对容限0.001）；尖灭泄漏允许max(原值10%,0.001)；误差>1失败比例不增加；求解器相对正规方程残差<=2e-7。
这些是全部同时检查的门槛，而不是挑选通过项。参数触边/残差目标未满足必须报告。算法不通过仍须交付失败结论。
同时报告均值、中位数、90/95分位、最差值、失败率及配对差。统计区间按地质/校准分层重采样；同模型道数和噪声次数不等于独立地质样本。小样本区间仅作描述。
配对验收器会检查指标、缺失配对和数值有效性；它不能单凭CSV证明盲测、独立性、无真值泄漏或统计显著性。通过输出仍是 PROVISIONAL_PASS，不自动批准替换主版。
