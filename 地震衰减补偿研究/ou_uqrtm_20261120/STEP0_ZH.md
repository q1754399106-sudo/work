# 第 0 步核对：OU 随机场先验的路径积分 UQ-RTM（2026-11-20）

被检验的设想（用户“创新方向 2”）：

- 把 δu(x) = Q_true⁻¹/Q_model⁻¹ − 1 建成随机场，协方差 σ_loc²·exp(−|Δz|/L_z − |Δx|/L_x)；
- 沿源、检双程路径积分，得到逐点 σ_eff²(x) = Var(t*)/t̂*² ≈ (2L_z/z)·σ_loc²；
- σ_loc 可以随空间变化：背景 0.15，气烟囱、断层、低速薄层 0.6。

预期是改善三种情形：Q 准确时深部过度保守、E4 深浅反向、E2 局部低 Q 体。

本文件只用已有结果（`../uq_rtm_20261117/analysis/stage2_*.json`）和新写的方差计算，没有跑任何偏移。

## 2. 公式核对

单程路径上，若 L ≪ 路径长，则

  Var(∫a(1+δu)ds) ≈ ∫ σ_loc² a² ℓ_c ds，其中 ℓ_c = 2/(|cosθ|/L_z + |sinθ|/L_x)。

这里 a = 1/(Qv)，θ 为路径与竖直方向的夹角。

- **零炮检距：** 下行、上行两支路径重合，相关系数为 1，方差是单程的 4 倍，t̂* 是单程的 2 倍。若 a、σ 都均匀，得 σ_eff² = 2L_zσ²/z。**用户公式在零炮检距、a 均匀时成立。**
- **大炮检距：** 两支路径在浅部分开，相关性衰减，σ_eff² 趋于 L_zσ²/z。
- **a 不均匀**（低 Q 体）：σ_eff² = 2L_zσ²·∫a²dz/(∫a dz)²，低 Q 段的权重更大。

实现见 `scripts/ou_sigma.m`：
- 直射线，检波点一支取镜像检波点（同 `two_way.m`）；
- 两支路径之间的协方差按同一深度分数处的水平间距 d 乘 exp(−d/L_x)，两支重合时精确。

**蒙特卡罗核对**（`scripts/ou_mc_check.m`，D2，400 个实现，AR(1) 可分离指数协方差，L_z = 50 m，L_x = 250 m，背景 0.15，标记区 0.6）：

| z、x（m） | 炮点 x（m） | 公式 σ_eff | 模拟 σ_eff | 简式 (2L_z/z)^½·0.15 |
|---|---|---|---|---|
| 1000、1200（烟囱下） | 1200 | 0.199 | 0.186 | 0.047 |
| 1000、1200 | 400 | 0.033 | 0.033 | 0.047 |
| 1000、600 | 600 | 0.048 | 0.051 | 0.047 |
| 500、1200（烟囱内） | 1200 | 0.275 | 0.242 | 0.067 |
| 1400、1800 | 1000 | 0.094 | 0.088 | 0.040 |
| 800、1600 | 1600 | 0.054 | 0.051 | 0.053 |

- 方差上公式比模拟高 0~30%，在路径穿过有限尺寸的标记体时偏差最大。
- 结果见 `analysis/mc_check_D2.json`。
- **结论：公式可用，量级可靠。**

## 4. 推论：可达上界

### 纯局部场（σ_g = 0）

深部 σ_eff 只有 0.03–0.1，算子近似等于 W1（σ = 0）。已缓存的 W1 分数可以直接给出它的表现（m30 W_deep，W1 − UQW1）：

| 情形 | 范围（8 个模型） |
|---|---|
| m = 1 | 0.000 到 +0.021 |
| E4（m = 0.7 / 1.4） | 0.000 到 +0.030 |
| E2，m = 1 / 1.4 | −0.002 到 +0.029 |
| E2，m = 0.7 | −0.060 到 +0.009 |
| **E1，m = 0.5** | **−0.20 到 −0.40** |

- W1 的 M1（m < 1 平均）全为负，低于阶段 3 门槛 C1（≥ +0.05）。
- 所以纯局部场在标量误差场景上必然大输，正是任务里担心的风险。

### 全局 + 局部（σ_g = 0.447 不变）

- 深部总方差为 σ_tot² = 0.2 + 局部项（背景约 0.002，标记体下最多约 0.05），算子近似等于 UQW1。
- 因此 Q 准确、E4 的保守代价不会减小；在标记体下方，算子只会更保守。

### 唯一的杠杆是降低 σ_g

- 这等于重新调标量 σ，与随机场结构无关。
- 收益上界约为 W1 − UQW1，即 ≤ +0.03；代价是 m < 1 时的大幅优势（阶段 3 M1 +0.099）。

### E4 不是“方差结构”问题

`scripts/e4_ratio.m` 的结果（`analysis/step0_tstar_ratio.json`）：深部窗内 E4 补偿模型的双程 t* 与正确 t* 之比，中位数为：
- m = 0.7：0.84–0.94；
- m = 1.4：1.08–1.20。

所以在深部，浅层误差和深层误差大部分相互抵消，E4 相当于 m ≈ 0.85–1.2 的标量误差。它的损失就是 Q 近似准确时的保守代价，E1 在 m = 0.85–1.2 时也正是 −0.003 到 −0.036。

### E2 方向相反

- E2 的平均 Q 抹掉了低 Q 体，体下方欠补偿：E2（m = 1）t* 比为 0.81–0.95，相当于 m ≈ 1.1。
- 在标记区加大 σ_loc 只会让算子更保守，预计在欠补偿一侧更差。
- 要帮到 E2，先验得带均值偏移（“标记体内 Q 更低”）。那是偏差校正，不是随机场方差。

## 5. 计算资源

- 新算子的 H 依赖每一炮的 t*（`migrate2.m` 在炮循环内施加），所以要精确评估，每个模型都得重做一遍逐频 LU 偏移。
- 已缓存的单频成像只存了实部（`est_noise2.m`），没法事后施加复数算子。
- 每遍 105 个频率：12 线程约 66 s/频率，峰值内存约 7.5 GB。
- 本会话限 3–4 线程，估计每个模型 4–6 小时。
- 当前空闲内存约 1.6 GB：另一会话的两个 `est_block` MATLAB 进程各占约 4.2 GB 提交内存。
- 按完整计划（4 个开发模型 + 2–4 个新确认模型的正演、噪声估计和偏移），合计约 30–50 小时。

## 6. 小结

- 公式本身没错，但设想的三个前提里有两个与仓库结果不符：
  - Q 准确时的损失只有 0.006–0.032；
  - E4 并不是深浅结构问题。
- 纯局部场必然在标量误差场景上大输。
- 全局 + 局部在 σ_g 不变时与标量 UQ 几乎相同。
- 在 E4、E2、Q 准确三种情形上，能拿到的改进上界约 +0.03，而且都来自降低 σ_g，也就是重调标量 σ，不是随机场结构带来的。
