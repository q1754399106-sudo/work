# OU 随机场先验的路径积分 UQ-RTM（2026-11-20）

**状态：在第 0 步停止（用户 2026-11-20 决定）。标签：已淘汰（机制研究）。没有跑任何偏移，也没有预注册门槛。**

## 设想

现有 UQ-RTM（`../uq_rtm_20261117/`）用一个标量乘子描述 Q 模型误差，全模型共用。用户提出改成随机场：

- 设 δu(x) = Q_true⁻¹/Q_model⁻¹ − 1，协方差为 σ_loc²·exp(−|Δz|/L_z − |Δx|/L_x)；
- 沿双程路径积分，得到逐点的 σ_eff(x)；
- σ_loc 可以随空间变化：背景 0.15，气烟囱、断层、薄层 0.6。

目的是改善三种情形：Q 准确时过于保守、E4 深浅反向、E2 局部低 Q 体。

## 第 0 步的结论

详见 [STEP0_ZH.md](STEP0_ZH.md)。

- **公式成立。** 零炮检距、a 均匀时 σ_eff² = (2L_z/z)σ_loc²。蒙特卡罗核对的方差差 0–30%。
- **局部场在深部几乎不起作用。** 深部窗 σ_eff 中位数 0.045（D2）、0.079（D4），气烟囱正下方最大 0.22；标量 UQ 用的是 0.447。
- **两种实现都落回已有方法：**
  - 纯局部场约等于 W1：m=0.5 时比 UQW1 低 0.20–0.40，过不了 C1；
  - 全局 0.447 加局部场约等于 UQW1。
- **改进上界约 +0.03。** 在 Q 准确、E4、E2（m≥1）上，相对 UQW1 最多 +0.021、+0.030、+0.029，而且只能靠降低全局 σ 拿到，也就是重调标量 σ，不是随机场的作用。
- **前提与仓库不符：**
  - Q 准确时的实际损失是 −0.006 到 −0.032，不是 0.04–0.07；
  - E4 在深部的积分 t* 只偏 6–16%，等效 m≈0.85–1.2，不是深浅结构问题；
  - E2 体下方补偿不足，加大局部 σ 只会更保守。
- **成本太高。** 精确评估每个模型要重做一遍 LU 偏移（3 线程 4–6 小时，峰值约 7.5 GB），完整计划需 30–50 小时。
