# 主智能体验收与方向更新

日期：2026-10-25。用户请求为结合最近工作与 GitHub 制定创新方向、交由 `gpt-6.1-sol/high` 子智能体执行、最终由主智能体审阅。上述委托和第一阶段实际实验均已完成。

## 验收结论

**接受代码与实验作为有效的机制试验；不接受联合事件收缩作为优于现有方法的新候选，不晋级独立确认。**

创新主线宜收敛为：**物理 Q 校正与统计降噪的解耦，以及二者对最终补偿波形偏差—方差的共同影响。** 其中已较有证据的资产是现有相干构造与析因机制实验；本轮检验的“加入事件交叉项”不是足够有效的算法突破。

这不是对整个方向的否定。它排除了一个具体、低成本且可归因的改进假设；不应用更多模型容量或事后调参掩盖这个结果。

## 冻结结果

所有数值均来自保存的波形重新评分，越低越好。开发为 F1/F2 × 两种噪声；诊断为历史已见的 F3/F4/V4/V5 × 两种噪声，不能当作未见地质确认。

| 方法 | 4 个开发场景均值 | 8 个诊断场景均值 |
|---|---:|---:|
| FullCalRefit | 0.497243427 | 0.486374015 |
| Standard | 0.389528005 | 0.415961869 |
| 本轮 Joint，冻结 eta=0.25 | 0.389512656 | 0.415822934 |
| 仅波形 Gram 交叉项 | 0.389573386 | 0.415853376 |
| 仅噪声交叉项 | 0.389465288 | 0.415928581 |
| SC 文献目标的既有独立实现 | 0.298350898 | **0.394409417** |

SC 沿用此前全部收敛的归档输出，逐例与固定 Git 提交对账，本轮未重跑 SC 求解。它不是作者原版，也不代表全部文献方法。

- 开发集改善 **0.003940%**，低于预先固定的 2% 门槛。
- 诊断集改善 **0.033401%**，低于 3% 门槛。
- 最坏逐场景退化 **0.012571%**，满足不超过 5% 的限制。
- V4 两种噪声的弱投影误差分别改善约 **0.08884% / 0.04607%**，满足不恶化的限制，但收益很小。
- Joint 平均误差仍比 SC 高 **5.4293%**，仅在 **4/8** 个场景胜出。

两个收益门槛失败，按原计划停止晋级。未更换主候选、改门槛或用诊断集重新选择 eta。

## 主智能体独立复核

1. **源码与隔离**：检查真实 SVD ridge 重拟合、物理振幅尺度、事件分组、fallback、G/N 构造和盒约束；开发选参仅用规定四场景。确认诊断开始后源码、方案和开发输入哈希未变。
2. **优化解**：独立穷举小问题的全部 lower/free/upper 约束状态，核验 54 个问题，最大目标相对差 `6.45e-16`、增益最大差 `4.81e-10`。
3. **交叉协方差**：对 F1 三条代表道，用直接 ridge 线性方程与逐组显式输出噪声映射重算完整 N；最大相对差 `5.78e-15`。该检查与子智能体的 Schur 乘积实现不同。
4. **原始波形评分**：从 8 份保存波形独立复算各方法的整体误差及 V4 弱投影比值，与报告最大差 `4.45e-16`；四条门槛判定一致。
5. **查新**：独立打开并核对冗余表示联合去噪与 SURE 反卷积原文。一般的合成域联合收缩、Gram 内积和相关噪声处理已有先例；本候选只能讨论具体地震构造的增量，不能称新统计原理。

复核程序和机器可读证据：`review_solver.py` / `solver_review.json`、`review_covariance.py` / `covariance_review.json`、`review_results.py` / `results_review.json`。三个复核结果均绑定本次冻结的 `joint.py` 哈希 `d980b4ca56190d8b98cf4785c1d665cb2b01a0d6e66d2ce34d816e6df378e133`。

## 创新主张的取舍

适合保留的科学问题是：为什么 QScan 的隐式正则化收益会在相干收缩后减少，而偏差代价仍保留；独立标定能在什么条件下把物理 Q 校正与最终输出风险控制分开？已有析因结果为前半句提供模型内证据，后半句仍需新实验。

不建议把本次 Joint 当作论文主算法；不以微小均值变化主张有效突破；不把历史已见的八场景当作独立确认；不将尚未完成的二维或实测结果写成已支持。

后续投入顺序建议：

1. 等已有冻结二维复验形成结果，检验现有偏差—方差机制能否跨正演成立，保持其原设计。
2. 若机制成立，优先研究独立标定下震源与 Q 的可辨识性，再设计对应最终输出的风险控制。SharedGhost 已有剖面收益，但其失败的参数门槛不能事后豁免。
3. 只有新机制产生实质收益，再与 SC 及其他最近邻文献方法做对等预算比较和全新地质确认。

以上是更新后的后续路线，**未在本轮启动新的校准算法或更改已有二维任务**。本轮完成范围是方向决策、定向查新、一个可复现候选的开发/诊断，以及最终主审。
