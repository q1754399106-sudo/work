# 定向文獻與數學質疑（2026-10-25）

結論：值得做一次有界 pilot，但尚不足以立為新理論。固定 ff95a69 的 Standard 均值誤差 0.415962，高於 SC 的 0.394409；本輪應檢驗「組間干涉是否是可修復的誤差來源」。

**已有先例。** Blu–Luisier（2007）已把冗餘變換的收縮寫成基本估計器的線性組合，在合成域聯合選權；Raphan–Simoncelli（2008）§III–V 明確處理相關噪聲、重建交互項與二次參數優化。Pesquet 等（2009）§VI-B 式43更直接出現重建分量內積矩陣。因此 Gram 聯合收縮、相關噪聲、凸二次優化均有一般原型，不能作為首創點。[1–3]

**可辨識增量。** 馬雄等（2023）式17在反演中懲罰空間預測殘差；本候選則固定校準 Q、支撐與本道重擬合波形，讓未收縮事件組的鄰道相干控制傳播噪聲懲罰，再聯合選擇本道組增益。差異是具體的事件組、條件協方差與相干調制構造；不是首次利用空間結構，也不是首次在合成域選權。相對 SURE-LET，候選缺少 Stein 導數修正，應稱可觀測代理。[1–4]

**可證與不可證。** 若 N 由一致的聯合協方差構成，令 e_k=W_kε_k，則 N_kl=E〈e_k,e_l〉，故 N 半正定；G 與 DND 亦然，盒約束保證最優解存在，未必唯一。對角/全矩陣凸插值保持凸性。只有 G_kk=E_k、N_kk=V_k 且度量完全一致時，對角退化才精確還原 Standard。聯合最優只保證降低所定義代理，不保證真誤差、峰值或波形能量降低。

即使外生支撐、固定 g、D=I，觀測 G 的期望也是真信號 Gram 加 N；代理相對真風險多出 (g−1)'N(g−1)。資料依賴的 g、相干及支撐選擇再增加偏差；DND 亦不是一般情況下的原始輸出噪聲能量。不能宣稱無偏 MSE、統一風險改善、無跨道影響或非擴張。

**第一步的否證條件。** 固定資料與選參預算，先分開測「只開 G 交叉項」「只開 N 交叉項」「兩者皆開」，再測相干 λ。若收益不集中於高重疊／相消組，或僅代理下降、真誤差與弱反射變差，則干涉修正敘事失敗。正交／遠距事件應接近對角結果。η 只用開發集選，保留原 SC 對照與失敗場景；勿由測試集選最優 η。盒約束排除放大，也不保證包含最佳合成域估計器。[2]

**檢索範圍。** 已查 SURE-LET、冗餘 frame 相關噪聲與地震吸收補償的定向關鍵詞；未找到上述完整事件組構造的直接同式方法。這是有界檢索結果，不能推論全球不存在。
