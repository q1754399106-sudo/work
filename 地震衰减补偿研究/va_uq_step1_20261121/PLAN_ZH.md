# VA-UQ 第 1 步：合成数据、实测速度约定下检验诊断（2026-11-21，出数前提交）

**来源：** Claude 文档《Q 补偿：最近失败的原因与新方法（2026-11-21）》（https://claude.ai/artifact/1L2wvkePtvwsvLK7mNZ5Hs），第 0 步脚本在 `地震衰减补偿研究/va_uq_step0_20261121/`。本目录做文档“事先预言与检验步骤”的第 1 步。

**要检验的诊断：** UQ-RTM 合成验证的收益中位 96% 来自频散相位校正，因为合成偏移速度是 100 Hz 相速度（GSLS 参照 f_r = 100 Hz）；实测速度在频带内（约 25 Hz）标定，同一校正会把同相轴挪走，这能解释阶段 4 的“补偿不如不补偿”。本步把合成的偏移速度换成频带内相速度，看能不能复现这个对调。

**开发数据：** 只用开发模型 D2、D4，不碰 C1–C4 确认数据。

## 1. 事先预言与停止规则（文档原文，不改）

- P1：R0 的 E1 比原约定高 ≥ 0.2（原 D2、D4 为 0.37、0.56）。
- P2：PH(100) 和 UQW1(100) 在 m ≤ 1 时低于 R0，复现阶段 4 的形状。
- P3：UQW1(25) 与 VA-UQ 在所有 m 上 ≥ R0 − 0.02，且 m 平均比 UQW1(100) 高 ≥ 0.10。
- 停止：P1 或 P2 不成立，说明相位约定解释不了实测，这条诊断作废，不调参再试。

### 判定口径（运行前写定）

“E1”在这里指阶段 2 的指标 S（`score_stage2.m`：去低波数，z < 140 m 置零；S = ½[零延迟相关 + ±2 样点内最大相关]），主窗 W_deep（x 300–2100 m，z 820–1550 m），Q 误差形式 E1（Q_c = m·Q_m）。

| 预言 | 判定（每个模型分别判，D2、D4 都成立才算成立） |
|---|---|
| P1 | S(R0, v_band) − S(R0, v100) ≥ 0.20。S(R0, v100) 用同一评分代码由阶段 2 的像重算，应为 0.374、0.564 |
| P2 | m ∈ {0.5, 0.7, 1} 时，S(PH100) < S(R0) 且 S(UQW1_100) < S(R0)，每模型 6 个比较全部成立 |
| P3 | 对 UQW1_25 和 VA 各自：5 个 m 上 S ≥ S(R0) − 0.02 全部成立，且 5 个 m 的平均 S − UQW1_100 的平均 S ≥ 0.10 |
| 停止 | P1 或 P2 不成立 → 诊断作废，不调参、不重跑。P3 无论如何都报告 |

只描述、不判定：W_body 窗；PH25、VAfix 两个附加变体。

## 2. 数据、速度与参照

- **数据：** m30（黏声 + −30 dB 随机噪声），`uq_rtm_20261117/cache/data_<模型>.mat`，不重新正演。
- **Q 误差：** E1，m ∈ {0.5, 0.7, 1, 1.4, 2}。
- **偏移速度：** v_band = v₁₀₀·[1 + ln(25/100)/(πQ)]，在真模型上逐点计算（真 v、真 Q），再做与 M.vmig 相同的高斯平滑（σ = 30 m）。平滑代码从 `make_model.m` 复制，冒烟中 gsmooth(v) 与 M.vmig 逐点相同（差 0）。内部区域 v_band/v₁₀₀：D2 0.980–0.995（中位 0.9937），D4 0.978–0.996（中位 0.9960）。
  - 冒烟另算了 GSLS 本身 25 Hz 与 100 Hz 的相速度比：比文档公式多慢约 10%（Q = 60 时 0.99183 对公式 0.99265，即速度差 0.08%）。按文档用公式，不改；这在 1.5 km 深处约合 1 m 量级的残余深度误差，小于一个样点（4 m）。
- **t\* 场：** 程函方程在 v_band 中算（`tstar_fields.m`，补偿 Q = 真 Q_m），镜像检波点双程 t\*（`two_way.m`），E1 按 1/m 缩放。
- **参照：** 弹性数据用 v₁₀₀ 偏移的像。直接取阶段 2 已有的 `cache/images2_<模型>.mat` 中 `ref.R0`（同一数据、同一速度、同一频率、同一代码），不重算。
- **噪声估计（1/snr）：** 复用阶段 2 的 `inv_<模型>.mat` 中 m30（est_noise2，逐道随机极性 B = 1，v₁₀₀ 偏移）。理由：
  1. 1/snr 是同一速度下翻转像与未翻转像功率之比，再经 ±5 Hz 频带求和与 400 m 方框平滑；速度变 0.4%–2%（中位约 0.5%），分子分母一起移动，比值几乎不变。
  2. 重估每个模型要多做约 105 个频率 × 2 次回传，约 1.5 小时。
  3. 1/snr 只进入 UQW1、VA 两类方法；R0、PH 不用它，所以 P1、P2 中的 R0、PH100 不受这个选择影响。

## 3. 方法

所有带噪声项的方法都用 UQW1 的形式（γ = 1，s = gain_s(70)）：

H = (A + s·P·C + P/snr) / (1 + s·C + 1/snr)，即 K = (E[G\*] + P·ρ) / (E|G|² + ρ)，ρ = s + E|G|²/snr，

其中 A = E[G\*]/E|G|²，C = 1/E|G|²，P = E[exp(−ikx)]，G = exp[(−πf + ik)x]，k = 2f·ln(f/f_ref)。

| 名称 | 作用量 x | 相位参照 | 不确定度 | 用途 |
|---|---|---|---|---|
| R0 | — | — | — | 不补偿 |
| PH100 | 绝对 t\*/m | 100 Hz | 无 | P2 |
| UQW1_100 | 绝对 t\*/m | 100 Hz | u 对数正态 σ = 0.447（在 t\* 上） | 现行方法，P2、P3 |
| UQW1_25 | 绝对 t\*/m | 25 Hz | 同上 | P3 |
| **VA** | 锚定 Δt\*/m | ln f_v 在 [15, 35] Hz 内均匀 | u 对数正态 σ = 0.447（只在 Δt\* 上） | P3 |
| PH25 | 绝对 t\*/m | 25 Hz | 无 | 只描述 |
| VAfix | 锚定 Δt\*/m | 25 Hz（已知） | u 只在 Δt\* 上 | 只描述：拆开“锚定”和“f_v 不确定” |

**VA-UQ 的实现（`scripts/va_tab.m`）：**
- 对 f_v 的期望用闭式：E_fv[exp(−i2fx·ln(f/f_v))] = exp(−i k̄ x)·sinc(f x Λ)，k̄ = 2f·ln(f/f̄_v)，f̄_v = √(15·35) = 22.9 Hz，Λ = ln(35/15) = 0.847，sinc(y) = sin y / y。|G| 与 f_v 无关。
- sinc 因子含 u，所以放在对 u 的 41 点 Gauss–Hermite 求积里面，而不是在 u = 1 处乘在外面。这对所述模型是精确的；Δt\* 只有百分之几秒，两种做法差别很小。
- A、C 不变；P 与 A 都带 sinc。
- f_v 频带取 [15, 35] Hz：覆盖 25 Hz 主频子波的主能量带，也是实测层析速度所用的频带；几何中点 22.9 Hz 故意不等于真值 25 Hz，检验“只知道 f_v 在带内”是否够用。
- **锚定：** Δt\* = 同一条射线在锚点以下累积的 t\*，即 t\* 减去这条射线在锚点以上的部分。实现：把补偿 Q 模型在锚点以上设为 1/Q_c = 0，再用同一程函方程求 t\*（`tstar_fields.m` 的 dT/dε 在驻定射线上取值，所以只有锚点以下的路径有贡献），镜像检波点双程。锚点以上的节点 Δt\* ≈ 0（不补偿）；W_deep 与 W_body 都在锚点以下。
  - 第一版写的是“减去同一 x、同一炮检对在锚点深度节点的 t\*”。冒烟发现这不是同一条射线：大偏移距时到锚点节点的射线更斜地穿过浅层低 Q 层，它的 t\* 可以接近甚至超过深部点的 t\*（D4 的 W_deep 中 Δt\*/t\* 中位数只有 0.05，按垂直路径估算应约 0.4；锚点以上还出现 0.016 s 的正值）。所以改成同射线的定义。日志：`logs/smoke_tstar_v1_samex.log`（旧）、`logs/smoke_tstar.log`（新）。这是出数前的修正，不涉及任何评分。
- 冒烟已查：Δt\* = 0 时 H = 1（1/snr = 0、0.1、10，f = 10–55 Hz）；闭式与对 ln f_v 的 20001 点直接平均一致到 1e−5；f_v 固定时 va_tab 与 uq_tab 逐位相同。sinc 的第一个零点在 Δt\* = 0.01 s 时为 371 Hz。
- 不估子波。

## 4. 锚点（运行前写定）

**规则：** 取离 500 m 最近、横向连续的宏观层界面（构造界面，跨整条测线），条件是在 x 300–2100 m 内整条都比 W_deep 顶（820 m）浅至少 100 m（即 ≤ 720 m）。锚点随界面起伏（逐列取界面深度）。细层没有单独可辨认的界面，不作锚点。

| 模型 | 锚点 | 深度（x 300–2100 m） | 依据 |
|---|---|---|---|
| D2 | 第 1 号界面（第 1、2 宏观层之间，背斜顶面）z_a(x) = 450 − 120·exp(−((x − 1200)/500)²) | 330 m（x = 1200）到 445 m（两端），平均 392 m | 速度 2150 → 2550 m/s（+19%），Q 70 → 50，连续强反射。更深的第 2 号界面 670–810 m，两端距 W_deep 顶只有约 10 m，不满足条件 |
| D4 | 第 2 号界面，水平 z_a = 330 m | 330 m | 速度 2250 → 2700 m/s（+20%），Q 60 → 80，位于 Q = 20 浅层薄层（120–260 m）和 Q = 60 薄层（260–330 m）之下。更深的第 3 号界面 375–825 m（倾角 14°），在 x > 2080 m 处进入 W_deep，不满足条件 |

- 两个锚点都比文档说的“≈ 500 m”浅（D2 浅约 55–170 m，D4 浅 170 m）。原因是 500 m 附近再无满足条件的宏观界面。锚点越浅，VA 补的 Δt\* 越多，越接近未锚定的 UQW1_25。
- D2 的气烟囱（x 1080–1320 m，z 300–800 m）穿过锚点：烟囱顶部约 30 m 在锚点以上，其余在 Δt\* 里。

## 6. 运行

- **代码：** `scripts/`（va_cfg、va_vband、va_tstar、va_tab、va_mig、va_score、va_judge、va_smoke、va_run）。`uq_rtm_20261117/scripts` 用 addpath 复用，不改那里的文件；所有新产物（t\* 场、断点、像）写本目录 `cache/`（被 `.gitignore` 的 `cache/` 规则忽略，不上传）。
- **每频率：** 一次 v_band 的 LU、一次震源正传、一次 m30 回传（参照不重算），约 40–80 s（12 线程）。共 105 个频率（3–55 Hz，步长 0.5 Hz）。
- **进程：** 计划 D2、D4 各一个 MATLAB 进程并行、后台分离、高优先级。单个进程的内存峰值在阶段 2 约 7.5 GB，本机 13.8 GB，另有其他任务；若冒烟实测的峰值使两个进程放不下（空闲内存 < 2 × 峰值 + 1 GB），改为一个进程依次跑 D2、D4，在结果里写明。
- **续跑：** 每 5 个频率存断点（`cache/vamig_<模型>/state.mat`），重启即接着跑；t\* 场缓存在 `cache/fields_<模型>_vb.mat`。
- **冒烟：** `va_smoke('tab')`（表、sinc、GSLS 频散、v_band，已过，`logs/smoke_tab.log`）；`va_smoke('tstar')`（`logs/smoke_tstar.log`，已过）；`va_smoke('mig')`（D2 单个频率 25 Hz 跑通，记录耗时与内存，产物带 `_smoke` 标签，不评分）。
  - t\* 冒烟（同射线定义）：W_deep 中 Δt\*/t\* 中位数 D2 0.690（5%–95%：0.59–0.76），D4 0.394（0.30–0.46），与按垂直路径的估算（D4 约 0.4）一致。t\* 中位数 D2 0.0186 s、D4 0.0170 s；Δt\* 中位数 0.0128 s、0.0067 s。
  - 锚点下第一行节点 Δt\* 中位数 D2 0.28 ms、D4 1.2 ms，不是严格 0：程函方程取初至，大偏移距时初至是沿锚点下高速层的首波，有一段路径在锚点以下。在 25 Hz，1.2 ms 对应的相位只有约 0.005 rad。锚点以上的节点同理有少量正值（D2 7%、D4 27% 的节点 > 0.1 ms，最大 13 ms、7 ms），都不在评价窗内。算子表本身在 Δt\* = 0 时 H = 1。
