## 结论

**G1 不通过，所以按方案，下面的比较只作描述，不作判定。描述上，这口井不支持“独立 Q＋标准版优于 QScan＋标准版”：用本实验的 VSP Q 跑标准版，在两个井上指标都比 QScan＋标准版差，而且没有超过不补偿的输入。不过，这个独立 Q 本身不可靠，井上指标的分辨力也只和 0.02 的阈值相当。因此这次实测仍然不能回答“独立 Q 能好多少”。**

1. **VSP 的 Q 只识别出一个整体趋势，没有通过 G1。**
   - Δt\* 对 Δτ 的斜率很稳定：Q_int = 128，90% 区间 110–155；CFS 给出 88，比值 0.68，在 [0.5, 2] 之内；频带 10.7–119 Hz。
   - 但单级谱比拟合的 R² 中位数只有 0.13（门槛 0.5），因此 G1 不通过。
   - 一个可能的原因：离参照级越近的级，Δt\* 越接近 0，R² 天然很低。所以“单级 R² 中位数”这一条对长排列 VSP 偏严。这只是观察，不改变判定。
   - 顶层（以震源子波为参照）：t\*_top = 0.00541 s，区间很窄，但拟合 R² = 0.489，差一点没到 0.5，所以 G1b 不通过。按规则 Q_top 取 Q_int = 128；若采用估计值则是 101。承包商给出的对应值是 46.2。
   - 因此本实验的 Q_VSP 四层都是 128。在顶层，它很可能比实际 Q 偏高。

2. **主比较（G2，只作描述）：QScan＋标准版更好。**

| 指标 | Input | 标准版（Q_VSP） | QScan＋标准版（起点 Q_VSP） | Δ（标准版 − QScan＋标准版） |
|---|---:|---:|---:|---:|
| T1 走廊叠加相关 | 0.181 | 0.157 | **0.211** | −0.054（QScan 更好） |
| T2 测井合成相关 | 0.199 | 0.197 | **0.233** | −0.036（QScan 更好） |

   - **G3**：标准版（Q_VSP）的 T1 比 Input 还低 0.023，不通过；QScan＋标准版高出 0.030，通过。
   - 标准版的最佳时移落在 −20 ms 边界上，说明它和走廊叠加的匹配本来就弱。

3. **QScan 一致地朝更强补偿方向移动，没有找回 Q_VSP（G4：1/5，不通过）。**

| 起点（×Q_VSP） | 0.5 | 0.7 | 1.0 | 1.3 | 1.5 |
|---|---:|---:|---:|---:|---:|
| 选中因子 | 1.031 | 0.745 | 0.600（网格下限） | 0.600（下限） | 0.600（下限） |
| 隐含 Q | 66 | 67 | 77 | 100 | 115 |
| 是否在 [0.86, 1.21]×Q_int 内 | 否 | 否 | 否 | 否 | 是 |

   - 起点为 0.5 和 0.7 时，QScan 都收敛到 Q≈66–67；起点更高时，停在网格下限。这说明 QScan 的选择区间偏向比 128 低得多的 Q。
   - 方向与合成数据上的发现相反：合成数据上 QScan 选的 Q 偏高（少补偿），这里选的 Q 偏低（多补偿）。

4. **井上指标的分辨力有限，与 0.02 的阈值相当。**
   - 所有方法和运行的 T1 都在 0.13–0.23，T2 在 0.18–0.34。36 个方法输出中，有 11 个 T1 的最佳时移落在 ±20 ms 的搜索边界上。
   - 起点 0.5 时，QScan 只把因子从 1 改成 1.031（Q 从 64 变到 66），T1 就从 0.215 降到 0.190。这么小的 Q 变化引起 0.025 的变化，说明 T1 对细节很敏感，0.02–0.05 量级的差别不宜解读成方法优劣。
   - 对 Input 做常相位扫描，T1 最大的相位落在扫描边界 −90°（T1 = 0.280，0° 时为 0.181）。说明这一时窗里，地震道与走廊叠加之间还有接近 90° 的相位差，没有被零相位假设解释。这也限制了 T1 的意义。

## 描述性结果

- **Q 有误时 QScan 能挽回多少**：每个错误起点下，QScan＋标准版的 T1 减去同一起点标准版的 T1，分别为 −0.025（×0.5）、−0.005（×0.7）、−0.004（×1.3）、−0.052（×1.5），全部为负。
- **没有独立 Q 的代价**：T1（标准版，Q_VSP）减去 4 个错误起点中 QScan＋标准版的最低 T1，为 +0.020。但由于标准版（Q_VSP）本身就不如 QScan＋标准版，这个数不能理解为“独立 Q 的价值”。
- **补偿越强，测井合成相关越高**：T2 最高的是起点 ×0.5 的标准版（Q = 64，T2 = 0.343）和 FullCalRefit（0.338）。这与 QScan 选择 Q≈66–77 的方向一致，也与承包商的顶层 Q（46）远低于 128 一致。这是一个事后观察，没有预登记为检验。
- **承包商的 Q（R0）**：标准版 T1 = 0.211、T2 = 0.213；QScan＋标准版 T1 = 0.225、T2 = 0.251，QScan 只把因子调到 0.925。两者 T1 差 −0.014，在“无可辨差别”范围内；T2 差 −0.038。
- **VSP 自带的 R4 幕帘剖面**（最终处理，做过反 Q 补偿和叠后反褶积）：T1 = 0.249。数据不同，只作参照。
- **频谱**：Input 在 2–3 s 内 95% 的能量低于 29 Hz（5%–95% 频带为 7–29 Hz）。各补偿输出的频带移到约 10–65 Hz，60–100 Hz 能量是输入的 665 到约 10,700 倍。输出是用主频 32.25 Hz 的 Ricker 字典重建的，所以这个比值主要反映字典子波和噪声放大，不能说明恢复了真实的高频信号。

## 对研究方向的含义

- 合成数据上的推论是：独立 Q 准确时，标准版应优于 QScan＋标准版。这次实测**没能检验这一推论**。原因有两个：一是独立 Q 没通过 G1/G1b，顶层 Q 很可能偏高；二是井上指标的分辨力只有约 0.02–0.05。
- 能确定的只有一点：在这口井上，QScan 的选择方向和合成数据上相反（朝更强补偿）。所以“QScan 系统性少补偿”不能推广为实测上的一般规律，这与 `qscan_offset_20261025` 中“偏移方向因模型而异”的结论相符。
- 如果还要继续做实测，需要能分辨方法差别的参照，例如：
  - 全频带、可信相位的 VSP 上行波成像（不是 6–70 Hz 的走廊叠加）；
  - 多口井；
  - 或者用 VSP 直接标定、并通过可识别性门槛的分层 Q。

  否则建议把实测部分写成“无法判定”，这条研究线以合成数据结论收尾。

## 边界

- 一口斜井，单个实测个例，不报告显著性检验。PSDM 成像位置与井的对应只是近似；评价道按时间跟随井轨迹取最近的幕帘道。
- 走廊叠加只有 6–70 Hz，并且经过承包商处理；测井合成只覆盖 2.29–2.68 s。
- 子波按零相位 Ricker 处理，不旋转相位；数据做过 82 Hz 高切。
- Q_VSP 用一个值代表全部 4 层；Q_READ 中有两段是承包商设的上限值 300。
