## 唯一主候选

每道独立、固定原支持、原事件分组与未收缩波形相干。Y_k=W[:,S_k] r_k，G=Y'Y。以原 SVD ridge 算子的 K=(C'C+ρI)^(-1)C' 和 P=W[:,S]/scale[S] 构造 N_kl=σ² tr(P_k (KK')_kl P_l')。λ=.5+15.5(1-c)^2，fallback 组 λ=1。求解盒约束凸二次代理 (g-1)'G_eta(g-1)+g'D_sqrtλ N_eta D_sqrtλ g，其中 M_eta=(1-eta)diag(M)+eta M。

主候选唯一网格 eta=[0,0.25,0.5,1]。完整 G+N 候选仅按 F1/F2×Moderate/Strong 四个开发场景全波形相对误差的算术均值选 eta，平局选择更小 eta。不得按诊断数据改参数。若 N 对角无法准确复现原 V，先停止完整候选并解释；不能将 OLS 协方差冒充 ridge。eta=0 须严格复现 Python Standard（包括 fallback 和空支持）。

## 验证与冻结顺序

1. 在 F1_Moderate 做代数和实现检查：G/N PSD、E/V 对角复现、真实 ridge 正规方程、目标梯度有限差分、盒 KKT、eta=0 全输出复现。数值失败仅修实现，不换候选。
2. 完整候选只跑四个开发场景与四个 eta，写 selection.json，含 PLAN/源码/输入 SHA256，随后锁定。
3. 固定 eta 后一次性评分 F3/F4/V4/V5×两噪声，完整保留 8 场景。它们是历史已见诊断，绝不称未见确认。
4. 同一选定 eta 的仅 G 耦合（保留原 V 对角）、仅 N 耦合消融不再选参。诊断数据不能拯救或替换主候选。开发集也只在主候选选定后报告这两个消融，不新增网格。

## 解释边界

该目标是可观测波形变化和条件传播噪声的联合代理，不是真实无偏 MSE、不称 SURE 新理论。条件噪声模型固定已经选出的支持且假定白噪声；不涵盖支持选择、Q 偏差或跨道噪声。g 不跨道混合波形，但原相干由邻道决定。此次只提供可证伪机制 pilot，不证明全球首创或实测优越性。
