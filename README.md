## 获取完整资料

较大的文件和交付压缩包使用 Git LFS 保存。完整下载请安装 Git LFS 后执行：

```bash
git lfs install
git clone https://github.com/q1754399106-sudo/work.git
cd work
git lfs pull
```

GitHub 的网页源码压缩包可能只包含 LFS 指针；需要实际数据时使用上面的命令。
