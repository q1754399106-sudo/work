# 诊断计划：QScan 在独立正演上偏 1.28 倍的物理来源

登记时间：2026-10-24，运行任何变体之前。

## 问题

QScan 在 Kennett 细层正演（F1–F4）上，即使无噪声，Q 正确时也选约 1.28 倍（少补偿）；同源卷积正演上则选约 1.0。偏差来自正演与字典的哪部分失配？

## 设计

F1–F4 的细层模型（真值文件中的 base）不变，只切换正演中的物理项，生成无噪声观测 D0，用各自归档的 σ 计算 λ（与偏差—方差研究一致）。每 3 道取 1 道（33 道），因子网格 0.6–2.2 对数等分 25 点。

| 变体 | 内部多次波 | 透射损失 | 细层 Q 起伏 |
|---|---|---|---|
| M1 full | 有 | 有 | 有（复现归档数据） |
| M2 primaries | 无 | 有 | 有 |
| M3 noloss | 无 | 无 | 有 |
| M4 noloss + 宏观 Q | 无 | 无 | 无（每个细层取其宏观层 Q） |

每个变体、每个模型在名义 Q（上采样 Q，误差 0%）下记录：

- QScan 选出的因子 c_sel（同一 lasso 目标）；
- 误差最优因子 c_opt：使 FullCalRefit 输出与该变体自身弹性目标（Q=∞、同一物理项）误差最小的网格因子；
- 两者的 log 差 b = ln(c_sel / c_opt)，即选择偏差。

## 归因规则

按模型平均 b：多次波贡献 = b(M1) − b(M2)；透射损失贡献 = b(M2) − b(M3)；Q 起伏贡献 = b(M3) − b(M4)；剩余 b(M4) 归为频散、子波与上采样等其余失配。同时报告 c_opt 本身的移动（理想因子是否也偏离 1），区分“选择偏差”与“名义 Q 本身不是最优 Q”。

## 判断

- 若某一项贡献超过 M1 总偏差的一半，下一步针对该项改进字典（例如透射损失的有效 Q 校正或多次波项）。
- 若各项都小、剩余项为主，则字典物理改进不是优先方向，改为寻求独立 Q 信息。

## 自检

M1 必须逐道复现归档的无噪声数据 clean（相对差 < 1e-10），否则停止。
