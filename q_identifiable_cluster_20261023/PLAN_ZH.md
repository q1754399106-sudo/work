## 要检验的机制

相邻反射的系数可能无法逐个分辨，但组合波形仍然有信息。将整簇删除改为簇内组合模式的自由度选择；独立校准得到的 Q 局部误差尺度决定哪些观测方向可信。

基线的独立校准、L1 支持发现、反射字典和振幅拟合代码冻结。候选首先使用相同 FullCalRefit 支持，首轮只检验支持发现之后的簇内表示和重估机制，不宣称解决 L1 已经遗漏的事件。

在固定先导反射系数 r0 下计算 Jq=[∂(B r0)/∂logQ_i]，用独立校准的线性化敏感性估计 Sigma_q。定义 Ceff=I+Jq Sigma_q Jq'/sigma²，F=Ceff^(-1/2)。每个反射簇对 F B_g 做 SVD，得到局部组合模式；在所有簇之间联合重估，并依次降低使下列固定复杂度目标下降最多的簇秩：

    ||F (B T_k a-d)||² + sigma² log(nt) * sum_g k_g

T_k 是各簇保留模式的组合矩阵，允许簇秩降至0。微小岭项采用原 FullCalRefit 相同条件数保护规则。该准则是工程模式选择，不是具有已验证覆盖率的 BIC 检验；F、支持和方向依赖先导和观测，不能套用固定设计自由度的显著性解释。

校准同时剖除未知各事件的相位/振幅自由度，并把子波主频作为 nuisance 参数；从五参数局部 Hessian 的逆中取四层 logQ 块。使用 log 参数标准差0.5的弱高斯尺度保护奇异方向，协方差特征尺度限于0.03—0.5；这些是预先固定的数值/模型误差尺度，未验证为后验或置信区间。固定先导模型误差协方差不是精确贝叶斯边缘化。

## 配对方法与归因

1. FullCalRefit：原支持及振幅重估。
2. PrunedFullCalRefit：原整组删除。
3. GlobalTSVD：在相同支持上普通全局截断，奇异值比阈值1e-2，对应原条件数上限1e4。
4. ClusterModesNoQ：相同簇内模式与复杂度选择，F=I。
5. QAwareRidge：相同 F 与原支持，不做簇秩选择。
6. QAwareCluster：本次候选，同时使用 F 和簇秩选择。

所有方法共用相同观测和校准，不读取模型名、真 Q、反射位置或评分真值。所有方法输出同一 nt×nx 波形。F 的效应由 QAwareRidge 与 FullCalRefit、QAwareCluster 与 ClusterModesNoQ 配对比较；簇秩效应由 QAwareCluster 与 QAwareRidge 比较。

## 开发与冻结验证

- 开发：已有 complex_fieldlike_20261023 地质模型，在原99道中预先均匀取22道，Moderate/Strong 两种观测；两者属于同一模型。可查看开发结果和修复实现错误；如变更机制或参数，必须保留首轮结果并重新冻结。
- 验证：三个新地质实现，每个99道生成、预先均匀取22道反演，两种观测，每模型单独生成独立校准。变更地层密度、Q剖面、主频、源相位和偏移距。共132道验证波形；同模型的道和噪声条件不当作独立地质模型。
- 生成器继承已有准1D属性驱动正演；这些是同族新地质配置，不是独立正演或实测验证。
- 验证结果在冻结 SHA256 清单之后才计算评分；不据验证结果修改参数。
- 额外数值控制：Q误差尺度为0时 F=I；重复/高度相关字典下的有限输出、方向数守恒及目标不升；合成无噪声数据的有限误差与零道输出。
- 追加预登记的 Q 点估计敏感性：第一新模型的 Moderate 观测，对全部22条既定道分别把名义校准 Q 乘0.8、1.25，保持名义校准协方差来源不变，重新执行全部方法；与名义 Q 比较相对误差及输出变化。这两组是同观测控制扰动，不计入三个模型的主验证门槛，也不使用真 Q。

## 评分与晋级规则

分模型、分条件报告全道与正常道相对波形误差、深部误差、真值定义低能量区误差、相关系数、投影增益、拟合残差、簇秩及先导依赖。低能量区指标不能称为单反射系数误差。评分程序与求解入口分开。

首轮晋级必须同时满足：

- 三个新模型等权平均正常道误差比 FullCalRefit 至少低2%；每个新模型均值不退化超过2%。
- 相比 ClusterModesNoQ 和 QAwareRidge 都有至少1%的同口径整体收益，证明两个机制都有贡献。
- 新模型等权低能量区误差不高于 FullCalRefit 的1.02倍。
- 所有输出有限；无未收敛标志；模式拟合正规方程残差<1e-8；每步记录的工程目标不升。

上述是工程筛选，不是统计显著性检验。未通过则完整报告失败，不改门槛。即便通过也仅为同族合成首轮证据，不能宣称首次提出、实测成功或已解决全部 Q 误差。
