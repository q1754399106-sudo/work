# 方法定义与归因边界

## 1. 从反射系数到观测

令 r 为反射系数，W 为校准主频下的零相位 Ricker 卷积字典，G(q) 为四层射线积分 Q 衰减矩阵。观测模型为 d=G(q)Wr+n。沿用 FullCalRefit 的列归一化，B=G(q)W diag(1/scale)，x=diag(scale)r。

独立校准只使用公开几何和校准观测，不接收目标模型的真 Q、反射位置或真值振幅。校准主频与四层Q点估计沿用原算法；本次新增的是局部误差尺度和后续簇内模式表示。

## 2. 独立校准的局部 Q 误差尺度

参数 theta=[logQ_1,...,logQ_4,logf]。每道校准以三个事件的同相/正交相位模板拟合六个振幅系数。对 theta 作步长0.02的中心差分，用模板列空间的正交补剖除振幅/相位自由度，再累加加权敏感性 H=Σ J_j'J_j。

校准噪声由原噪声窗 MAD 估计，局部残差使用 Huber 权重并由残差尺度膨胀。加入 logQ 标准差0.5和 logf 标准差约0.223的固定尺度保护，求五参数局部逆矩阵，取四层 logQ 对应的块。最后将特征方差限制在0.03²至0.5²。

这是一个带先验保护的局部敏感性尺度；特征截断和有色噪声等因素意味着它没有已验证的置信覆盖率。第四层若没有校准反射敏感性，会保留接近先验的不确定方向，而不是凭空成为可靠的Q估计。

## 3. 固定先导模型误差

先用原 FullCalRefit 得到 r0 和候选支持。计算 Jq 的四列：

    Jq_i = ∂[G(q)W r0]/∂logQ_i

局部误差模型为 d≈G(qhat)Wr + Jq δlogQ + n。以 Sigma_q 表示上述校准误差尺度，采用

    Ceff = I + Jq Sigma_q Jq' / sigma²,
    F = Ceff^(-1/2).

只需对851×4的误差因子作薄SVD，避免形成完整851×851协方差的逆。固定 r0 后，F 在所有秩候选之间保持不变；本轮没有迭代更新误差协方差。若把协方差随 r 一起更新，不能照搬本轮目标而忽略 logdet 和先导依赖。

sigma²I只是本轮工作噪声模型。正演含有色、空间相关噪声和额外相干干扰，F没有覆盖这些全部误差。

## 4. 簇内组合与秩选择

原支持上相邻位置间隔不超过0.5/f的系数连为反射簇。对每簇的 F B_g 分解为 U_g S_g V_g'，在每簇依奇异值次序保留前 k_g 个组合方向。把各簇方向嵌入整体支持形成 T_k，联合拟合全部簇：

    a_k = argmin_a ||F(B T_k a-d)||² + ridge*||a||².

微小岭项与原振幅重估使用相同条件数上限1e4和最小相对尺度1e-8。以数据拟合项加 sigma² log(nt)Σk_g 作为工程复杂度目标。每步比较每簇删除末位模式后重新联合拟合的目标，执行下降最多的一次；直到没有下降。记录全部目标路径、保留秩和正规方程残差。

最终 x=T_k a、r=diag(1/scale)x，输出 s=W r。整个过程中不使用真实事件位置、地质名称或评分真值。

该方法允许保留混合了多条相邻反射的组合模式，但不保证单条反射可辨识，也不保证组合波形已经保幅。支持、模式和误差权重都从数据先导得到，因此复杂度准则不能自动解释为经校准的统计检验。

## 5. 六方法配对

| 方法 | Q模型误差白化 | 簇内模式降秩 | 支持 |
|---|---|---|---|
| FullCalRefit | 无 | 无 | 原L1及残差补入 |
| PrunedFullCalRefit | 无 | 整组删除 | 相同初始支持 |
| GlobalTSVD | 无 | 全局普通截断，阈值1e-2 | 相同初始支持 |
| ClusterModesNoQ | 无 | 有 | 相同初始支持 |
| QAwareRidge | 有 | 无 | 相同初始支持 |
| QAwareCluster | 有 | 有 | 相同初始支持 |

每种模式选择都在同一观测上重新拟合。QAwareCluster 对 ClusterModesNoQ 衡量在该模式机制中加入Q权重的组合效应；对 QAwareRidge 衡量加入秩选择及相应联合重估的效应。不能仅用对整组剪枝的优势就证明Q模块有贡献。

## 6. 如何评价创新假设

单独使用稀疏反演、SVD、自适应参数化、去偏振幅重估或固定先导误差协方差均不能直接称为首创。本次拟研究的区别是将校准Q误差下的局部观测可信度用于反射簇的组合自由度选择。

实验完成与方法晋级是不同结论。只有冻结后的新模型整体、弱区和配对消融同时支持该机制，才有理由继续扩展验证；本轮全部数值与失败门槛见 RESULTS_ZH.md。是否具有发表所需的原创性，还需要对最接近的完整论文和实现作进一步比对。
