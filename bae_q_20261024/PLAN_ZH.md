# 实验 1：BAE-Q（Q 模型误差边缘化）预登记计划

登记时间：2026-10-24，开发运行前。来源：`literature_review_20261024` 建议 1（Kaipio & Somersalo 2006；Nissinen et al. 2008）。

## 问题

在应用 Q 存在误差（−50% 至 +50%）时，把 Q 模型误差的均值和协方差并入数据项，能否降低 FullCalRefit 的**最坏情况误差**，同时不损害 Q 正确时的结果和弱反射？

## 方法（全部共享观测、σ、子波和所施加的 Q；真值不进入求解）

- **FullCalRefit**：现有主版本，对照基线。PrunedFullCalRefit 和 SoftGroupRefit 用同一冻结代码重算，作为参考。
- **BAE**（`core/bae_q_refit.m`）：
  - 抽样：Q_s = Q̂·exp(s(ρξ0 + √(1−ρ²)ξk))，M=32 个对偶样本，ρ=0.7，种子 20261024；
  - 误差样本：ε_s = (G(Q_s) − G(Q̂))·ŝ，其中 ŝ 是 FullCalRefit 的输出（插值式条件 BAE，只迭代一次）；
  - 噪声模型改为 σ²I + Cov(ε)，数据先减去 mean(ε)；
  - 在白化并重新归一化列的空间里，执行与 FullCalRefit 相同的 lasso、阈值、残差峰补入和岭重拟合规则。
- **BAECovOnly**（消融）：不减均值，只用协方差。
- **QEnsembleMean**（稳健基线）：在 Q̂·exp(s·z) 上取 7 个等概率分位节点，各做一次 FullCalRefit，再取平均。
- s 网格：{0.10, 0.20, 0.35}。数学检查：零模型误差时 BAE 必须精确复现 FullCalRefit；白化恒等式。

## 资料

- **开发**：`soft_refit_20261023` 的 primary（四层，真 Q 已知）和 complex（复杂模型，Q 为既有标定值）。Moderate/Strong 两档噪声；Q 误差 {−50, −30, −10, 0, +10, +30, +50}%。这些都是已看过的开发资料。
- **验证**：`coherence_soft_20261023` 的 V1/V2/V3（新噪声种子、FaultPinch、新复杂地质及独立标定），Q 误差同上。BAE 的开发阶段不读取这些资料。V1–V3 的真值在 coherence_soft 自身的验证中已经被评分过，但它与本方法的选择无关。

## 指标

- 波形相对误差：‖S − target‖/‖target‖，只算活道；
- **WC**：同一模型和噪声下，7 个 Q 误差中的最大波形误差；
- **Q0**：Q 误差为 0% 时的波形误差；
- 弱反射振幅误差：Ricker 模板投影，用于 primary、V1、V2。

## 开发选择规则（每个方法族独立）

在可行候选中，选使 4 个开发组合（模型 × 噪声）的 **WC 比值（候选 / FullCalRefit）均值最小**的 s。可行条件：Q0 比值均值 ≤ 1.02，且 primary 的 Q0 弱反射误差比值均值 ≤ 1.10。没有可行候选则判定失败，不进入验证。

## 验证验收门槛（BAE 选定版本，全部满足才算通过）

- G1：6 个验证组合的 WC 比值均值 ≤ 0.95；
- G2：WC 改善的组合 ≥ 4/6；
- G3：Q0 比值均值 ≤ 1.02；
- G4：V1、V2 在 Q0 下的弱反射误差比值均值 ≤ 1.10；
- G5：数值检查——优化标志为 0，正规方程残差 < 1e-8。

此外，描述性报告 BAE 与 QEnsembleMean、BAECovOnly 的对比，不作晋级门槛。

## 补充登记 1b：Q 扫描自检（QScanRefit）——在看过 primary 开发结果之后、运行之前登记

**登记原因**：primary 开发集上，BAE 三个 s 值都违反 Q0 可行条件（Q0 比值 1.79–4.81）。按规则，BAE 判定失败，不进入验证。机制诊断：Q 模型误差与信号高度相关，增强误差模型把信号方向当作噪声，导致整体缩小振幅。另做的小 s 探索（0.02、0.05）属于**事后探索**，只用于描绘取舍曲线，不作晋级依据。

**方法（文献路线 A：Chai 2019；Cheng 2019/2020；Yan 2023）**：
- 对整个道集取共同的校正因子 c ∈ exp(linspace(log 0.6, log 2.2, 13))，用 Q̂·c 构造字典；
- 对每道用与 FullCalRefit 相同的 lasso（同一 λ 规则）求解，计算目标值 J = (½‖D − Bx‖² + λ‖x‖₁)/σ²，并对全部活道求和；
- 选 J 最小的 c，再用 Q̂·c 运行完整的 FullCalRefit。
- 不调参，没有开发选择项；真值不进入求解。

**验收（验证 V1–V3 和独立确认 F1–F2 分别报告）**：
- H1：WC 比值均值 ≤ 0.95；
- H2：Q0 比值均值 ≤ 1.02；
- H3：WC 改善的组合超过一半；
- H4：V1、V2 在 Q0 下的弱反射误差比值均值 ≤ 1.10；
- 并描述性报告所选 c 与"应有校正" 1/(1+e) 的对应关系。

## 边界

插值式 BAE 使用高斯近似和当前估计，不是经过校准的后验。全部资料仍是同族准 1D 正演，不能当作独立物理验证（实验 3 处理这一点）。不报告显著性检验。
