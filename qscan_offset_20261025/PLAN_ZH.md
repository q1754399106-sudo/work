# QScan 选择偏移的模型间稳定性（冻结方案）

登记：2026-10-25 02:00（本地时间）。时间点：开发模型 G1–G8 已生成之后（只看过生成日志中的层数、上尺度 Q 与能量比），任何扫描运行之前。冻结哈希见 `logs/PRE_RUN_HASHES.json`。

## 背景与问题

`combo_bias_variance_20261024` 阶段 2 在 F1/F2 上发现：在 QScan＋相干标准版中，最终误差最小的有效 Q 就是真 Q0（14 dB 下有效 Q 比 1.00–1.03），而 QScan 稳定地选在 1.24–1.28×Q0，即高出约 2 个网格步长（步长比 1.1145）。最优固定因子比 QScan 好 24–33%。

一个直接的改进是“常数去偏”：把 QScan 的选择向下平移固定的 k 个网格步长。这只有在偏移跨模型稳定时才可行。F1/F2 只是两个模型，而 `qcriteria_20261024` 中 F3/F4 的偏移看起来更小，不过那里的最优因子是按 FullCalRefit 的误差定的，不是按组合的误差。

本轮只回答一个开发层面的问题：**在同一正演生成的新模型上，QScan 选择相对组合最优 Q 的偏移有多稳定，平移 1 步或 2 步是否安全？** 本轮不选定 κ，不设计确认，不使用 U1–U4。

## 数据

- **模型**：8 个新开发模型 G1–G8（`scripts/make_dev.m`）。生成器与 `bae_q_20261024/make_independent.m`、`b0_world_truth_20261024/scripts/make_unseen.m` 逐字相同（Kennett 一维细层黏声正演，偏移距 0），只换种子与宏观模型。种子、宏观参数都与 F1、F2、U1–U4 不同，见 `scripts/os_setup.m`。
  - 有碳酸盐层：G2、G4、G6、G8。
  - 宏观 Q 的形态：随深度递增（G1、G8）、递减（G2、G6）、反转（G3、G7）、中等（G4）、整体低（G5）。
- **场景**：每个模型 3 个场景。
  - Q0、14 dB；Q0、8 dB；
  - Q0×0.7、14 dB，与 Q0/14 dB 用同一噪声。
- **噪声**：生成器与阶段 1、2 相同（AR(1) 0.45、10% 道间共模、按 Frobenius SNR 定标）。种子为 1.3e9 + 1e7·模型号 + 1e5·档位 + r，档位 14 dB 为 1，8 dB 为 2。每个实现重新估计 σ。
- **实现**：r=1–6（R=6）；另加无噪声实现 r=0，其 σ 取同场景 r=1 的估计。

## 计算

与 `combo_bias_variance_20261024/scripts/run_sweep.m` 逐句相同（只去掉阶段 1 核对）：对因子 f ∈ {1} ∪ QScan 的 13 个网格值，在 Q = 所用 Q × f 下跑完整流程 refit_state → coherence_scores → apply_gain（Standard，λ 0.5–16）。同时保存同一 Q 下的 FullCalRefit，以及 QScan 在同一道集上的目标函数和选择。4 线程，2 个 worker。

## 指标（标准版，MSE 除以 ‖x⋆‖²，99 道全时段）

- **D**：QScan＋标准版，每个实现取其所选因子。
- **S1、S2**：把每个实现的 QScan 选择向下平移 1、2 个网格步长（到网格下端为止），再取该处的标准版输出。
- **B**：名义 Q（f=1）的标准版。
- **最优**：R 个实现平均 MSE 最小的因子（含 f=1），以及只在 13 个网格值中取的最优网格点。
- **偏移 k**：QScan 众数选择的网格序号 − 最优网格点的序号（单位为网格步长，正值表示 QScan 选的 Q 偏高）。
- **无噪声最优**：r=0 的误差曲线最小点。
- **描述**：强反射区振幅增益 g（定义同阶段 1），以及 FullCalRefit 的误差曲线。

## 预先判定

- **O1 偏移稳定性**（Q0/14 dB，8 个模型）：若 max k − min k ≤ 1，且同一个 k 值出现 ≥6 次，判为“偏移跨模型稳定”；否则判为“偏移不稳定”。
- **O2 平移是否安全**（24 个模型×场景）：对 S1、S2 分别计算 rel = MSE_S/MSE_D − 1。若 rel < 0 的数目 ≥20，且最大 rel ≤ +0.05，判为该平移“安全”；否则“不安全”。
- **O3 最优是否就在上尺度 Q0**（Q0/14 dB，8 个模型）：无噪声最优有效 Q 比 q 满足 |ln q| ≤ 一个网格步长（ln 1.1145）的模型 ≥6 个，判为“无噪声最优就在上尺度 Q0”。这检验阶段 2 的结论能否推广到其他模型。
- **只描述**：Q0×0.7 下 D、S1、S2 与 B 的比较；偏移与模型特征（Q 形态、碳酸盐层、信噪比）的关系；最优点与 QScan 处的振幅增益；F1/F2 阶段 2 结果作为参照。

## 结论规则

- O1 稳定，且 S1 或 S2 安全：常数去偏值得作为候选方法另行登记确认。κ 取安全平移中较小的一个，在确认方案中预先写明，确认数据由用户决定。
- O1 不稳定：常数去偏不可行。描述偏移与模型或信噪比的关系，供后续设计参考。
- 无论哪种结论，本轮都不选定最终方法，也不在本轮数据上调整任何算法参数。

## 不做

- 不使用 U1–U4，不读取它们的输入或真值。
- 不改 QScan、相干标准版或噪声模型。
- 看到结果后不改 R、场景、判定阈值或平移定义。若运行失败需要重跑，记录原因，不改设计。
