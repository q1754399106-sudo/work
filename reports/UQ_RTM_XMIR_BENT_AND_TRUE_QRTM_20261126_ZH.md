1. **Test 1A（解析线性梯度 $v(z) = 1500 + 0.8z$ 精确圆弧 Snell 射线真解对比）**：
   - 在深度 `z ∈ [500, 1800] m`、偏移距 `200–1400 m` 区间内，直射线弦角 $\theta_s^{\text{chord}}$ 存在 **`5.25°–9.27°`** 系统低估，而程函梯度 $\theta_s^{\text{eik}} = \operatorname{atan2}(\partial_x T, \partial_z T)$ 将入射角中位误差压降至 **`0.86°–1.21°`**；
   - 在四个非零倾角（`-20° / -10° / +10° / +20°`）上，直射线 `xmir_str` 中位出射点误差高达 **`189.1 / 118.3 / 262.8 / 783.8 m`**（`+20°` 时 `p90 = 1,528.9 m`），升级的二维同步 RK2 上行追踪 `xmir_bent` 将中位误差压降至 **`15.2 / 16.5 / 29.5 / 43.2 m`**（误差分别削减 **`92.0% / 86.0% / 88.8% / 94.5%`**）。
   - **客观限制**：当倾角严格为 `0°` 且速度为纯一维 $v(z)$ 时，对称性使直射线 $2x - x_s$ 恰为精确解（`0.0 m`），而一阶 Godunov 程函 `eikonal_fs` 数值扩散使 `xmir_bent` 留有约 `20.6 m`（约 2 网格步）残余误差。
2. **Test 1B（无噪真 $Q$ 黏声波方程 Q-RTM 非稻草人物理核验）**：

## 6. 实事求是总结：优势、适用边界与当前局限

### 6.1 已证实的优势
1. **升级弯曲射线 `xmir_bent` 的几何与连续地层成像收益**：在解析强梯度斜层中将出射点误差削减 `86.0%–94.5%`；在全排列合成模型 `S1 / S3 / S4` 与独立时间域 8 阶 GSLS 有限差分 `S5` 上，`DSA_Bent_UQW1b_25` 较直射线 `DSA_Str_UQW1b_25` 带来 **`+0.0035` 至 `+0.0280`** 的稳定 `E1` 提升（`S5` 达 `+0.0280`，`SNR_img +0.79 dB`），并在 Volve 盲井 `F-14` 上提升 `+0.0543`（`+0.2481 → +0.3024`）。
2. **硬刚真黏声波方程 Q-RTM 的核心实证结论**：在有噪（`l30` 相关噪）且 $Q$ 模型存在 `0.5×–2×` 标量或非标量空间错位误差的现实条件下，声波 `DSA-UQW1b` 以 **`1/3–1/5` 的 LU 算力开销**：
   - 在全部 5 个合成模型（`S1–S5`，含独立 GSLS FD）的过补偿端 $m=0.5/0.6$ 上，均高于全部 3 种标准真 Q-RTM（`WE_QRTM_Unreg / ZhuLP / Reg`）与最强同域噪声自适应真 Q-RTM（`DSA_WE_QRTM_W1b`，领先 `+0.051` 至 `+0.154`）；
   - 在 Volve 4–25 Hz 实测全 85 频数据上，原版 `DSA_Str_UQW1b_PAnc_25`（`F-5 = 0.6306`，`Sm = 4.3%`，`sl = -0.0005`）高于全部 7 种真黏声 Q-RTM（原始 `WE_QRTM_Unreg_Raw` 崩至 `0.4209 / Sm=91.3%`；公平 `PSAE` 版 `WE_QRTM_Unreg_PAnc = 0.5950 / Sm=68.3%`；同域 `DSA_WE_QRTM_W1b_PAnc` 在 `m=0.5` 跌至 `0.494` vs `DSA_Bent_UQW1b_PAnc_25 = 0.572`、`DSA_Str_UQW1b_PAnc_25 = 0.625`）。

### 6.2 明确暴露的限制、短板与不可外推边界
1. **无噪已知精确 $Q$ 与强多路径场景中，真黏声波方程 Q-RTM 物理精度更高**：在 `S1 / S2 / S3 / S5` 的无噪 `m=1` 基准上，`WE_QRTM_Unreg` / `DSA_WE_QRTM_Reg` 在波形 `E1`（高 `+0.009` 至 `+0.073`）与振幅恢复 `E_amp`（低 `2×–3×`）上均优于射线 `DSA_Bent_UQW1b_25`；在 Volve 同域 `m=1.0` 上 `DSA_WE_QRTM_W1b_PAnc` 的 `F-5 (0.576 vs 0.565)`、`L0 (+0.223 vs +0.105)` 与 `F-14 (+0.425 vs +0.302)` 也高于 `DSA_Bent_UQW1b_PAnc_25`（但代价比高 `3×` LU 且在 `m=0.5` 崩至 `0.494`）。
2. **`xmir_bent` 在 Volve 实测中的待修复参数缺陷（Gate `X7` 失败原因）**：当前冻结版将 `cfg.inc_max_deg = 55°` 施加于强折射后的局部程函角并结合白垩系反转全内反射切除，在 `F-5` 误杀 `17.6` 炮有效反射导致 `F-5` 掉分 `-0.0653`（低于直射线 `DSA_Str_UQW1b_PAnc_25`）；因此**在完成“角限迁至地表出射角 `th_surf` + 放宽局部 `inc_max_deg`”的新一轮独立预登记复验前，Volve 实测仍应沿用 `DSA_Str_UQW1b_PAnc_25`（或仅用 `t_arr(xmir_bent) * t_surf`）**，不可贸然宣称 `xmir_bent` 在实测全面优于 `xmir_str`。
3. **交叉多倾角 + 窄单边拖缆下的 `DSA` 共同失效边界（Gate `X3` 失败原因）**：当相反陡倾层在单倾角结构张量平滑窗内交叉且拖缆偏窄（如 `S2`）时，单倾角假设本身失效，应回退无倾角硬切或采用多倾角/纯频散波方程（`WE_Q_DispOnly`）。
4. **合成定标失误留存记录**：`S2 (+1.06 dB)` 与 `S5 (+1.08 dB)` 未达预登记 `[+2, +6] dB` 信噪比窗口，致使 `X4 / X6` 预登记判负；后续独立轮次须对含非对称缆与时间域 GSLS FD 模型单独执行全频冒烟定标后再冻结。
