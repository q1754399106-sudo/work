# QScan 偏差—方差来源分解（冻结方案）

登记：2026-10-24，阶段 0 复现检查之后、无噪声对照和重复噪声运行之前。来源：`theory_predict_diagnostic_20261024` 之后提出的“偏差来源分解实验”。

## 问题

F1/Moderate 与 F2/Moderate 的 QScan 都选 c=1.2803，前者全道误差 +16.91%，后者 −4.18%。这两个数各来自**单个噪声实现**。本轮只回答：

1. 两者差别是系统性的，还是噪声运气；
2. 误差变化来自系统偏差还是输出方差；
3. 局部敏感性指标为什么把 F1/Moderate 评为风险下降。

不研究无真值诊断，不改算法，不据本轮结果调补偿强度。

## 固定项

- 地质模型、纯净观测 D0、目标、公开配置（含 Q0）、σ 估计方法、FullCalRefit、QScan 全部沿用 `bae_q_20261024`，上游哈希见 `UPSTREAM_HASHES.json`。
- 噪声：原生成器（时间 AR(1) 系数 0.45，10% 道间共模，按 Frobenius SNR 14/8 dB 定标），新种子 `seed_base + r`，r=1…100，与原种子不重叠。每个实现按原窗口 MAD 重新估计 σ。同一实现上运行全部估计量（配对设计）。
- 主分析：F1/Moderate、F2/Moderate。F1/Strong、F2/Strong 用同法复核，仅作描述。
- 阶段 0 已通过：原种子噪声与 σ 逐位复现；FullCalRefit/QScan 与归档相对差 ≤2.7e-8（归档为 single）；“选择＋重拟合”与原 `qscan_refit` 逐位一致；旧评分复现差 ≤2.4e-10。见 `analysis/reproduction_check.csv`。

## 估计量

- **FullCalRefit**：c=1，即公开 Q0。
- **QScan**：原选择规则，再用所选 c 运行 FullCalRefit。
- **固定因子扫描**：在 QScan 网格的 13 个 c 上各运行 FullCalRefit，不做选择。用于把 QScan 的误差拆成“所选因子的固定效应”和“选择随机性”。
- **无噪声对照**：D0 加归档 σ（λ 相同），运行全部因子和 QScan 选择。它给出不含噪声的确定性偏差。

## 指标

全部 99 道、全时段，与旧评分同口径，R=100：

- MSE = Bias² + Var。Var_u 为逐样本无偏方差之和，Bias²_u = ‖x̄−x⋆‖² − Var_u/R，因此两者之和严格等于经验 MSE。三项均除以 ‖x⋆‖²。
- 每个实现的相对误差分布；配对比值 rel_QScan / rel_FullCalRefit。
- 窗口级：35 道 × 26 个 50 ms 窗，与诊断相同；逐窗 Bias²、Var、期望 ΔMSE、退化概率。

## 预先判定

- **D1 系统性**：配对差同号的实现 ≥90%，判为系统性影响；否则判为噪声主导。
- **D2 F1/Moderate 机制**：ΔVar<0 且 ΔBias²>|ΔVar|，判定“方差下降、偏差增加更多”成立；ΔVar≥0 则判定不成立，下一步转查局部线性化与支持选择。
- **D3 F2/Moderate 机制**：报告 ΔBias² 与 ΔVar 的符号和大小；ΔBias²<0 判为改善来自偏差减小。
- **D4 偏差最优因子**：在 c=1 与 13 个网格因子中取 Bias² 最小者。若 F1 的最优值 ≤1.149，F2 的最优值 ≥1.2803，判定相反效果来自两个模型需要的补偿强度不同。
- **D5 指标性质**：窗口级比较 Spearman(U, 经验标准差) 与 Spearman(U, |偏差|)；FullCalRefit 用 U_r，QScan 用 U_scan。前者更高，且场景级 log(U_scan/U_base) 与 log(Var_scan/Var_base) 同号，判定该指标主要反映方差。

以下只作描述，不设门槛：QScan 所选因子分布及无噪声选择；时间剖面；目标到平均输出的频谱传递 |H(f)|，以 10–60 Hz 对数斜率换算残余吸收 Δa；单实现窗口退化标签与期望退化方向的一致率；目标函数中拟合项与 ℓ1 项随 c 的变化。

## 不做

不改 FullCalRefit、QScan 和评分；不调因子网格；不用真值选择任何算法参数；不生成新地质模型。F1/F2 的历史结果已知，本轮属于已见模型上的机制诊断，不是盲测。

## 补充登记 A：高信噪比探针

登记：2026-10-24，阶段 1 无噪声结果已看过，阶段 2 正在运行、尚未汇总。

**依据**：无噪声对照中，c=1.2803 在 F1 和 F2 上都比 c=1 差（F1/Moderate 0.337→0.437，F2/Moderate 0.227→0.309）。若 F2/Moderate 的改善只来自方差下降，那么提高信噪比、缩小方差后，QScan 在 F2 上也应变差。

**设计**：F1、F2 地质模型和噪声生成器不变，只把 Frobenius SNR 改为 20 dB 和 26 dB；新种子 `1e9 + 1e6·模型号 + 1e5·(3 或 4) + r`，r=1…40；每个实现重新估计 σ。估计量：FullCalRefit（c=1）、固定 c=1.2803 的 FullCalRefit、QScan。指标同主分析。

**预先判定 P-A**：20 dB 下 F2 的 ΔMSE(QScan − FullCalRefit) > 0，且 26 dB 下仍 > 0，则判定 F2 的改善依赖噪声水平、来自方差下降；若 20 dB 下 F2 仍改善，则判定方差解释不充分。F1 只作对照描述。
